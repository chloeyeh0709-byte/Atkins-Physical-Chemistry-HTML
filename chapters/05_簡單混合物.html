第五章　簡單混合物

Simple Mixtures

本章從純物質延伸到混合物（mixtures）的熱力學描述。以偏莫耳量（partial molar quantities）概念為出發點，建立混合物中化學勢的表達式，並導出兩個基本的溶液定律：描述溶劑行為的Raoult定律和描述稀溶液溶質行為的Henry定律。

進一步引入活度（activity）以處理非理想溶液，並分析混合溶液的四類束一性質（colligative properties）——蒸氣壓下降、沸點升高、凝固點下降、滲透壓。章節末討論電解質溶液及Debye-Hückel理論。

5.1　偏莫耳量

(a) 偏莫耳體積

混合物中，組分 JJJ 的偏莫耳體積（partial molar volume） VJV_JVJ​ 定義為：

VJ=(∂V∂nJ)T,p,nJ′V_J = \left(\frac{\partial V}{\partial n_J}\right)_{T,p,n_{J'}}VJ​=(∂nJ​∂V​)T,p,nJ′​​ (5.1)

VJV_JVJ​ 代表在恆溫恆壓下，向無限大量混合物中加入1莫耳 JJJ 時體積的增量。注意：VJV_JVJ​ 不等於純組分的摩爾體積 Vm(J)∗V_{\rm m}(J)^*Vm​(J)∗，因為加入後分子間的相互作用改變了體積貢獻。

混合物的總體積：

V=nAVA+nBVBV = n_A V_A + n_B V_BV=nA​VA​+nB​VB​ (5.2)

在25 °C，將少量乙醇（nEtOH=1 moln_{\rm EtOH} = 1\,\rm molnEtOH​=1mol）加入大量純水中，體積增加約 14.0 cm314.0\,\rm cm^314.0cm3（= 偏莫耳體積 VEtOHV_{\rm EtOH}VEtOH​）。但純乙醇的摩爾體積為 Vm∗(EtOH)=58.4 cm3 mol−1V^*_{\rm m}(\rm EtOH) = 58.4\,\rm cm^3\,mol^{-1}Vm∗​(EtOH)=58.4cm3mol−1。

差異的原因：乙醇加入水中後，乙醇分子嵌入水的氫鍵網絡，占據的空間比純態時更小，故 $V_{\rm EtOH} < V^*_{\rm m}(\rm EtOH)$。

(b) 混合物的化學勢

偏莫耳Gibbs自由能即為化學勢：

μJ=(∂G∂nJ)T,p,nJ′\mu_J = \left(\frac{\partial G}{\partial n_J}\right)_{T,p,n_{J'}}μJ​=(∂nJ​∂G​)T,p,nJ′​​ (5.3)

混合物的Gibbs自由能：

G=∑JnJμJG = \sum_J n_J \mu_JG=J∑​nJ​μJ​ (5.4)

(c) Gibbs-Duhem 方程式

對式(5.4)進行全微分，並利用 dG=−SdT+Vdp+∑JμJdnJdG = -SdT + Vdp + \sum_J \mu_J dn_JdG=−SdT+Vdp+∑J​μJ​dnJ​，在恆溫恆壓下得到重要的Gibbs-Duhem方程式：

∑JnJ dμJ=0（恆溫恆壓）\sum_J n_J\,d\mu_J = 0 \qquad \text{（恆溫恆壓）}J∑​nJ​dμJ​=0（恆溫恆壓） (5.5)

對二元混合物（A + B）：

nA dμA+nB dμB=0  ⟹  dμA=−nBnA dμBn_A\,d\mu_A + n_B\,d\mu_B = 0 \implies d\mu_A = -\frac{n_B}{n_A}\,d\mu_BnA​dμA​+nB​dμB​=0⟹dμA​=−nA​nB​​dμB​

Gibbs-Duhem方程式說明：混合物中各組分的化學勢不能獨立改變；若溶質化學勢增大，溶劑化學勢必然相應減小（通過組成比例關聯）。

5.2　理想混合物的熱力學

(a) 理想溶液的化學勢

在理想溶液（ideal solution）中，各組分的化學勢為：

μJ=μJ∗+RTln⁡xJ\mu_J = \mu_J^* + RT\ln x_JμJ​=μJ∗​+RTlnxJ​ (5.6)

其中 μJ∗\mu_J^*μJ∗​ 是純液體 JJJ 在同溫同壓下的化學勢，xJx_JxJ​ 是 JJJ 的摩爾分率。由於 xJ≤1x_J \leq 1xJ​≤1，ln⁡xJ≤0\ln x_J \leq 0lnxJ​≤0，因此混合物中每種組分的化學勢都低於純液態的化學勢——這正是混合（溶解）的驅動力。

(b) 混合的Gibbs能、焓、熵

設有 nAn_AnA​ mol A 和 nBn_BnB​ mol B 混合（均為液體），混合前後的Gibbs能差：

其中 n=nA+nBn = n_A + n_Bn=nA​+nB​。由於 $x_J < 1，，，\ln x_J < 0，故，故 ，故\Delta_{\rm mix}G < 0$——理想混合是自發過程。

混合的熵（由 ΔmixS=−(∂ΔmixG/∂T)p\Delta_{\rm mix}S = -(\partial\Delta_{\rm mix}G/\partial T)_pΔmix​S=−(∂Δmix​G/∂T)p​ 計算）：

ΔmixS=−nR(xAln⁡xA+xBln⁡xB)>0\Delta_{\rm mix}S = -nR(x_A\ln x_A + x_B\ln x_B) > 0Δmix​S=−nR(xA​lnxA​+xB​lnxB​)>0 (5.8)

理想混合由熵增（$\Delta_{\rm mix}S > 0）驅動，而非焓（）驅動，而非焓（）驅動，而非焓（\Delta_{\rm mix}H = 0$）。在分子層次上，A-B相互作用與A-A、B-B相互作用完全相同（這是「理想」的定義），所以混合不釋放或吸收熱量；但混合後分子的排列方式大幅增加，構型熵增加，使Gibbs能下降。

5.3　氣液平衡

(a) Raoult 定律

對理想溶液，溶劑的蒸氣壓滿足Raoult定律（Raoult's law）：

pA=xApA∗p_A = x_A p_A^*pA​=xA​pA∗​ (5.10)

pA∗p_A^*pA∗​ 為純溶劑A在同溫下的蒸氣壓。溶劑的蒸氣壓因溶質的加入而降低，降低量與溶質的摩爾分率成正比：

pA∗−pA=xBpA∗即ΔppA∗=xBp_A^* - p_A = x_B p_A^* \quad \text{即} \quad \frac{\Delta p}{p_A^*} = x_BpA∗​−pA​=xB​pA∗​即pA∗​Δp​=xB​
🔬 分子詮釋：Raoult 定律

蒸氣壓反映溶劑分子從液面逸出的傾向。溶質分子佔據液面的部分位置（比例 xBx_BxB​），使得單位面積上的溶劑分子數目減少（比例 xA=1−xBx_A = 1-x_BxA​=1−xB​），逸出速率因此降低，平衡蒸氣壓亦隨之降低。

(b) Henry 定律

在稀溶液中，溶質（B）的蒸氣壓服從Henry定律（Henry's law）：

pB=xBKBp_B = x_B K_BpB​=xB​KB​ (5.11)

KBK_BKB​ 稱為 Henry定律常數，單位為壓力，與溫度有關，但不等於純溶質的蒸氣壓 pB∗p_B^*pB∗​（除非溶液是理想的）。Henry定律適用於稀溶液中溶質，Raoult定律適用於稀溶液中的溶劑（以及理想溶液中任意組分）。

5.4　溶液的活度

(a) 溶劑的活度

真實溶液中，溶劑 A 的化學勢用活度（activity） aAa_AaA​ 表示：

μA=μA∗+RTln⁡aA\mu_A = \mu_A^* + RT\ln a_AμA​=μA∗​+RTlnaA​ (5.12)

Raoult定律表述為：aA=pA/pA∗a_A = p_A / p_A^*aA​=pA​/pA∗​。理想溶液中 γA=1\gamma_A = 1γA​=1，故 aA=xAa_A = x_AaA​=xA​。

(b) 溶質的活度

溶質 B 以純溶質或假想標準態（1 mol kg⁻¹）為參考，活度 aB=γB(bB/b∘)a_B = \gamma_B (b_B / b^\circ)aB​=γB​(bB​/b∘)，其中 bBb_BbB​ 為質量莫耳濃度，b∘=1 mol kg−1b^\circ = 1\,\rm mol\,kg^{-1}b∘=1molkg−1。稀溶液中 γB→1\gamma_B \to 1γB​→1。

5.5　束一性質

束一性質（colligative properties）只依賴溶質的粒子數目而與其化學本質無關（前提：溶質不揮發、非電解質）。共四種：

(a) 蒸氣壓下降

Δp=xBpA∗\Delta p = x_B p_A^*Δp=xB​pA∗​ (5.13)

(b) 沸點升高

溶液沸點 TbT_bTb​ 高於純溶劑沸點 Tb∗T_b^*Tb∗​，升高量：

ΔTb=Kb bB\Delta T_b = K_b\,b_BΔTb​=Kb​bB​ (5.14)

其中 Kb=RTb∗2MA/(1000 ΔvapH)K_b = RT_b^{*2}M_A / (1000\,\Delta_{\rm vap}H)Kb​=RTb∗2​MA​/(1000Δvap​H) 為沸點升高常數（ebullioscopic constant），單位 K kg mol⁻¹。常用溶劑的 KbK_bKb​：水 0.512，苯 2.53，環己烷 2.79 K kg mol⁻¹。

(c) 凝固點下降

ΔTf=Kf bB\Delta T_f = K_f\,b_BΔTf​=Kf​bB​ (5.15)

其中 Kf=RTf∗2MA/(1000 ΔfusH)K_f = RT_f^{*2}M_A / (1000\,\Delta_{\rm fus}H)Kf​=RTf∗2​MA​/(1000Δfus​H) 為凝固點下降常數（cryoscopic constant）。常用溶劑的 KfK_fKf​：水 1.86，苯 5.12，環己烷 20.2 K kg mol⁻¹。

(d) 滲透壓

半透膜（只允許溶劑通過）兩側存在濃度差時，溶劑自發從低濃度（高化學勢）滲入高濃度（低化學勢）側，產生滲透壓（osmotic pressure） Π\PiΠ：
