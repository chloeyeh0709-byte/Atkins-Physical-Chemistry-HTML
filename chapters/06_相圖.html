第六章　相圖

Phase Diagrams

本章將第四章的純物質相圖延伸至二元混合物（binary mixtures）。二元系統的相行為比純物質豐富得多，透過蒸氣壓圖（vapour pressure diagrams）和溫度-組成圖（temperature-composition diagrams），可直觀理解分餾原理、共沸現象及固液相平衡。

相律（F=C−P+2F = C - P + 2F=C−P+2）在此扮演核心角色：二元系統（C=2C=2C=2）中，F=4−PF = 4 - PF=4−P，單相時 F=3F=3F=3（溫度、壓力、組成均可變），兩相共存時 F=2F=2F=2，三相共存時 F=1F=1F=1（溫度固定、壓力固定）。

6.1　相律的應用

對二元系統（C = 2），相律為：

F=C−P+2=4−PF = C - P + 2 = 4 - PF=C−P+2=4−P (6.1)

6.2　揮發性液體的蒸氣壓圖

(a) 組成-壓力圖

對理想二元液體混合物（A + B，均遵守Raoult定律），恆溫下總蒸氣壓：

p=pA+pB=xApA∗+xBpB∗=pB∗+(pA∗−pB∗)xAp = p_A + p_B = x_A p_A^* + x_B p_B^* = p_B^* + (p_A^* - p_B^*)x_Ap=pA​+pB​=xA​pA∗​+xB​pB∗​=pB∗​+(pA∗​−pB∗​)xA​ (6.2)

ppp 對 xAx_AxA​（液相組成）是直線（液相線 liquidus）。氣相組成 yAy_AyA​：

yA=pAp=xApA∗pB∗+(pA∗−pB∗)xAy_A = \frac{p_A}{p} = \frac{x_A p_A^*}{p_B^* + (p_A^* - p_B^*)x_A}yA​=ppA​​=pB∗​+(pA∗​−pB∗​)xA​xA​pA∗​​ (6.3)

由此得到 ppp 對 yAy_AyA​（氣相組成）的關係（氣相線 vaporus），為曲線（雙曲線形）。兩線之間為兩相共存區，上方為液相，下方為氣相。

(b) 溫度-組成圖

恆壓（通常1 atm）下，TTT-xxx 圖更為實用。易揮發組分（較低沸點）濃縮於氣相：

6.3　槓桿規則

在兩相共存區，液相量 nln_lnl​ 和氣相量 ngn_gng​ 可由槓桿規則（lever rule）確定。對於TTT-xxx圖中整體組成 zAz_AzA​、液相組成 xAx_AxA​、氣相組成 yAy_AyA​（均為A的摩爾分率）：

nl(zA−xA)=ng(yA−zA)n_l (z_A - x_A) = n_g (y_A - z_A)nl​(zA​−xA​)=ng​(yA​−zA​) (6.4)

即：nlng=yA−zAzA−xA\dfrac{n_l}{n_g} = \dfrac{y_A - z_A}{z_A - x_A}ng​nl​​=zA​−xA​yA​−zA​​

視覺上，如以 xAx_AxA​、zAz_AzA​、yAy_AyA​ 為槓桿的兩端和支點，各相的量與對應「臂長」成反比——這就是「槓桿規則」名稱的由來。

6.4　蒸餾

(a) 簡單蒸餾

加熱液態混合物使其沸騰，氣相富含易揮發組分（低沸點者）。收集冷凝的蒸氣即可部分分離混合物。每次簡單蒸餾只能實現有限的分離效果（氣相組成 $y_A > z_A$，但不是純A）。

(b) 分餾與理論板數

在分餾塔（fractionating column）中，蒸氣在多個理論板（theoretical plates）上反覆蒸發-冷凝，逐步富集易揮發組分。每個理論板對應 TTT-xxx 圖上的一步「階梯」。達到接近純組分分離所需的理論板數越多，分離越難。

圖6.3　TTT-xxx 圖中的分餾「階梯」示意：每個階梯代表一個理論板，蒸氣從液相組成 xxx 富集至氣相組成 yyy，再冷凝為新的液相，如此反覆。
圖6.3　分餾過程在 TTT-xxx 圖上的階梯圖示。理論板數越多，可達到的分離程度越高。

(c) 共沸物

真實溶液可能出現共沸物（azeotrope）：液相線與氣相線在某組成點相切，液氣組成相同，蒸餾無法進一步分離。

  • 最低共沸物（minimum boiling azeotrope）：正偏差（A-B作用弱於A-A和B-B）時出現，沸點低於兩純組分。例：乙醇-水（95.6% 乙醇，78.1 °C）、鹽酸-水（20.2% HCl，108.6 °C）。
  • 最高共沸物（maximum boiling azeotrope）：負偏差（A-B作用強於A-A和B-B）時出現，沸點高於兩純組分。例：硝酸-水（68% HNO₃，121.8 °C）、丙酮-氯仿。
圖6.4　最低共沸物（左，TTT-xxx 圖有極小值）與最高共沸物（右，有極大值）示意。
圖6.4　共沸物相圖。共沸組成點液相線與氣相線相切，無法用蒸餾跨越該點。

6.5　液液相圖

(a) 上臨界溶液溫度（UCST）

部分互溶的液體（如苯胺-環己烷）在較低溫度分成兩個液相，高於上臨界溶液溫度（upper critical solution temperature，UCST）後完全互溶。UCST即液液相圖中的最高點。

圖6.5　具有UCST的液液相圖（如苯胺-環己烷）：低溫分兩相，高溫合一相，最高點為UCST。
圖6.5　具有上臨界溶液溫度的相圖。在UCST以下，混合物在兩液相共存區內分層。

(b) 下臨界溶液溫度（LCST）

某些系統（如三乙胺-水）在低溫互溶，但超過下臨界溶液溫度（LCST）後分層。原因常與氫鍵在低溫的形成有關（低溫有序結構穩定混合態）。某些系統同時具有UCST和LCST（如尼古丁-水）。

6.6　固液相圖

(a) 共熔混合物

不互溶的固體形成共熔系統（eutectic system）。降溫時：

  1. 先析出純固體（A或B），液相組成沿液相線向共熔組成移動
  2. 到達共熔點（eutectic point）（F=1F=1F=1：壓力固定後，共熔溫度和組成均固定）時，A、B固體同時析出
  3. 液相在共熔溫度完全凝固
圖6.6　典型二元共熔相圖（如鉛-錫或金-矽）：兩條液相線匯聚於共熔點E，共熔點以下為固態混合物。
圖6.6　二元共熔相圖。E = 共熔點（固液三相共存），液相線以下（E點以上）為兩相共存區（固體+液體）。
📝 共熔焊料（solder）

鉛-錫合金的共熔組成為63% Sn、37% Pb（重量比），共熔點 183 °C。在電子焊接中，共熔焊料在精確溫度瞬間固化（不像其他組成在「糊狀」區間冷凝），焊點清晰。無鉛焊料（Sn-Ag-Cu）也利用相似的共熔設計。

(b) 化合物形成

若A、B在固相能形成化合物（AmBn\rm A_m B_nAm​Bn​），相圖中出現居於中間的峰（化合物熔點），相圖被分成兩個共熔系統。例如：KCl-FeCl₂形成 KFeCl3\rm KFeCl_3KFeCl3​ 和 K2FeCl4\rm K_2FeCl_4K2​FeCl4​；水-硫酸形成 H2SO4⋅H2O\rm H_2SO_4 \cdot H_2OH2​SO4​⋅H2​O（水合物）。

也可能出現包晶反應（peritectic reaction）：固體化合物在某溫度分解為另一固相和液相（不穩定化合物）。

6.7　液晶

液晶（liquid crystals）是介於液體（流動性）和晶體（長程有序）之間的狀態。構成液晶的分子通常為長棒形，具有取向有序但位置無序的特點：

  • 向列型（nematic）：分子方向有序（沿「指向矢 director」排列），位置無序。最常見，LCD顯示器即利用此相。
  • 層列型（smectic）：除取向有序外，分子還排成層狀，位置有一維有序性。
  • 膽固醇型（cholesteric/chiral nematic）：向列型的手性版本，方向在空間螺旋扭轉，對光有選擇性反射（結構色）。
🔬 分子詮釋：液晶的有序-無序

棒形分子（如4'-戊基-4-氰基聯苯 5CB）在高溫為等向液體（所有取向等機率），降溫後分子傾向平行排列（取向有序）但不規則堆疊，形成向列型液晶；再降溫才形成層列型或晶體。液晶的折射率各向異性（雙折射）使外加電場可改變光的偏振方向，這是液晶顯示器（LCD）的基礎。

重點概念整理

  • 二元系統相律：F=4−PF = 4 - PF=4−P；恆壓下（固定 ppp）：F=3−PF = 3 - PF=3−P。
  • 理想溶液蒸氣壓：p=pB∗+(pA∗−pB∗)xAp = p_B^* + (p_A^* - p_B^*)x_Ap=pB∗​+(pA∗​−pB∗​)xA​（液相線，直線）；氣相組成 yA=xApA∗/py_A = x_A p_A^* / pyA​=xA​pA∗​/p（氣相線，曲線）。
  • 槓桿規則：nl(zA−xA)=ng(yA−zA)n_l(z_A - x_A) = n_g(y_A - z_A)nl​(zA​−xA​)=ng​(yA​−zA​)，兩相量與「臂長」成反比。
  • 共沸物：液氣組成相同（xA=yAx_A = y_AxA​=yA​），不能用蒸餾進一步分離。最低（正偏差）和最高（負偏差）兩種。
  • 液液相圖：UCST（上臨界溶液溫度）—高溫互溶；LCST（下臨界溶液溫度）—低溫互溶。
  • 共熔點：三相共存（F=0F=0F=0，恆壓），液相完全凝固的最低溫度，具有固定組成。
  • 液晶：介於液體和晶體之間，具取向有序；向列型（LCD基礎）、層列型、膽固醇型。

討論問題

  1. 在二元液體的 TTT-xxx 圖中，液相線（bubble-point curve）和氣相線（dew-point curve）的形狀如何反映溶液的理想性或非理想性？正偏差和負偏差各有何特徵？
  2. 共沸物無法用普通蒸餾跨越，工業上如何突破此限制以獲得純組分？（提示：改變壓力、加入第三組分萃取蒸餾、滲透蒸發）
  3. 槓桿規則不僅適用於氣液系統，也適用於任何兩相共存的情形。試將其應用於固液相圖（共熔系統），說明如何從整體組成計算固液量之比。
  4. 為何具有LCST的系統（如三乙胺-水）在升溫後反而相分離？用分子間作用力與熵的競爭解釋。
  5. 比較共熔型和形成化合物型固液相圖在結構和冷卻曲線上的差異。在後者中，化合物是穩定還是不穩定的如何從相圖判斷？
