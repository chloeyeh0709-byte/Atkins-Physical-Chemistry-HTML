第八章　量子理論：導論與原理

Quantum Theory: Introduction and Principles

本章是量子力學的入門，也是物理化學中最具革命性的章節。在1900年前後，一系列實驗現象（黑體輻射、光電效應、原子光譜、低溫熱容）顯示古典力學（Newtonian mechanics）和電動力學（Maxwell's electrodynamics）的深刻失效。

Planck、Einstein、de Broglie、Schrödinger、Heisenberg等人的工作催生了量子力學。其核心思想是：能量是量子化的、微觀粒子具有波粒二象性、觀測量有固有的不確定性。掌握量子力學的基本語言（波函數、算符、本徵值、不確定性原理），是理解後續章節（原子和分子結構、光譜學、化學鍵）的必要前提。

8.1　古典物理的失效

(a) 黑體輻射

黑體（blackbody）是完全吸收並輻射電磁波的理想物體。實驗測得黑體輻射的能量密度隨頻率的分布（在固定溫度下）有一個峰值，隨溫度升高峰值向高頻移動（Wien位移定律 λmaxT=2.898×10−3 m K\lambda_{\rm max} T = 2.898\times10^{-3}\,\rm m\,Kλmax​T=2.898×10−3mK）。

古典物理（Rayleigh-Jeans定律）預測能量密度在高頻端無限增加（「紫外災難 ultraviolet catastrophe」）：

ρ(ν,T)=8πν2c3kT（Rayleigh-Jeans，古典）\rho(\nu, T) = \frac{8\pi\nu^2}{c^3}kT \quad \text{（Rayleigh-Jeans，古典）}ρ(ν,T)=c38πν2​kT（Rayleigh-Jeans，古典）

Planck（1900）假設振子能量是量子化的（ε=hν\varepsilon = h\nuε=hν 的整數倍），得到完全符合實驗的 Planck分布：

ρ(ν,T)=8πhν3c3⋅1ehν/kT−1\rho(\nu, T) = \frac{8\pi h\nu^3}{c^3} \cdot \frac{1}{e^{h\nu/kT} - 1}ρ(ν,T)=c38πhν3​⋅ehν/kT−11​ (8.1)

其中 h=6.626×10−34 J sh = 6.626\times10^{-34}\,\rm J\,sh=6.626×10−34Js 為Planck常數（Planck constant），k=1.381×10−23 J K−1k = 1.381\times10^{-23}\,\rm J\,K^{-1}k=1.381×10−23JK−1 為Boltzmann常數。

(b) 熱容的量子效應

古典均分定理預測固體的摩爾熱容為 CV,m=3R=24.9 J mol−1 K−1C_{V,m} = 3R = 24.9\,\rm J\,mol^{-1}\,K^{-1}CV,m​=3R=24.9Jmol−1K−1（Dulong-Petit定律），在高溫時正確。但低溫下 CV,m→0C_{V,m}\to 0CV,m​→0，與古典預測不符。

Einstein（1907）用量子化振子模型解釋：每個振子能量量子 ε=hνE\varepsilon = h\nu_Eε=hνE​（Einstein頻率），低溫下 kT≪hνEkT \ll h\nu_EkT≪hνE​，大多數振子無法獲得足夠能量被激發，故熱容趨向零。Debye（1912）進一步改進，得到更精確的低溫描述（CV,m∝T3C_{V,m} \propto T^3CV,m​∝T3）。

(c) 原子光譜

氫原子光譜由一系列離散（量子化）的譜線組成，Rydberg公式：

ν~=RH(1n12−1n22),n2>n1\tilde{\nu} = R_H\left(\frac{1}{n_1^2} - \frac{1}{n_2^2}\right), \quad n_2 > n_1ν~=RH​(n12​1​−n22​1​),n2​>n1​ (8.2)

RH=1.097×107 m−1R_H = 1.097\times10^7\,\rm m^{-1}RH​=1.097×107m−1 為Rydberg常數，n1=1n_1 = 1n1​=1（Lyman系列，紫外），n1=2n_1 = 2n1​=2（Balmer系列，可見），n1=3n_1 = 3n1​=3（Paschen系列，近紅外）。古典物理完全無法解釋離散光譜的存在。

8.2　波粒二象性

(a) 光的量子性：光電效應

將光照射在金屬表面，若頻率 ν\nuν 超過截止頻率（threshold frequency） ν0\nu_0ν0​，則電子立即逸出（光電效應 photoelectric effect）。古典理論預測電子動能與光強有關，但實驗發現電子最大動能 EkE_kEk​ 只與頻率有關：

Ek=hν−ΦE_k = h\nu - \PhiEk​=hν−Φ (8.3)

Φ=hν0\Phi = h\nu_0Φ=hν0​ 為功函數（work function）（逸出電子所需的最小能量），依賴於金屬材料。Einstein（1905）解釋：光由光子（photons）組成，每個光子能量為 hνh\nuhν，電子吸收一個光子後，若能量超過功函數則逸出。

(b) 物質的波動性：de Broglie 關係

de Broglie（1924）提出：若光（波）具有粒子性（光子動量 p=hν/c=h/λp = h\nu/c = h/\lambdap=hν/c=h/λ），則粒子（如電子）也應具有波動性，其de Broglie波長為：

λ=hp=hmv\lambda = \frac{h}{p} = \frac{h}{mv}λ=ph​=mvh​ (8.4)

此關係聯繫了粒子的力學量（動量 p=mvp = mvp=mv）和波的特徵（波長 λ\lambdaλ）。

(c) 電子繞射

Davisson和Germer（1927）的電子束照射晶體實驗，觀察到繞射圖案，直接証實了電子的波動性。繞射條件（Bragg定律）：2dsin⁡θ=nλ2d\sin\theta = n\lambda2dsinθ=nλ，與X射線繞射完全類似。今日的電子顯微鏡（SEM/TEM）和電子繞射即利用電子波的短波長（可達皮米量級）實現納米解析度成像。

8.3　Schrödinger 方程式

(a) 方程式的形式

Schrödinger（1926）建立了描述量子系統的波動方程式。對於一維空間中質量 mmm 的粒子，含時 Schrödinger 方程式為：

iℏ∂Ψ∂t=H^Ψ=(−ℏ22m∂2∂x2+V(x,t))Ψi\hbar\frac{\partial\Psi}{\partial t} = \hat{H}\Psi = \left(-\frac{\hbar^2}{2m}\frac{\partial^2}{\partial x^2} + V(x,t)\right)\Psiiℏ∂t∂Ψ​=H^Ψ=(−2mℏ2​∂x2∂2​+V(x,t))Ψ (8.5)

其中 ℏ=h/(2π)=1.055×10−34 J s\hbar = h/(2\pi) = 1.055\times10^{-34}\,\rm J\,sℏ=h/(2π)=1.055×10−34Js（約化Planck常數），H^\hat{H}H^ 為Hamiltonian算符（Hamilton operator），Ψ(x,t)\Psi(x,t)Ψ(x,t) 為波函數（wavefunction）。

對於穩態（VVV 不依賴 ttt），可分離時間部分，得到不含時 Schrödinger 方程式（定態方程式）：

H^ψ=Eψ即−ℏ22md2ψdx2+V(x)ψ=Eψ\hat{H}\psi = E\psi \quad \text{即} \quad -\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2} + V(x)\psi = E\psiH^ψ=Eψ即−2mℏ2​dx2d2ψ​+V(x)ψ=Eψ (8.6)

其中 ψ(x)\psi(x)ψ(x) 為定態波函數，EEE 為能量本徵值（eigenvalue）。解方程式 (8.6) 得到允許的能量值（能量量子化的數學根源）及對應的波函數。

(b) Born 詮釋

Born（1926）提出波函數的機率詮釋：∣ψ(x)∣2 dx|\psi(x)|^2\,dx∣ψ(x)∣2dx 是粒子在位置 xxx 到 x+dxx+dxx+dx 之間被發現的機率（probability），∣ψ∣2|\psi|^2∣ψ∣2 稱為機率密度（probability density）。

📝 波函數本身沒有直接物理意義

波函數 ψ\psiψ 可以是複數，沒有直接的物理意義。有意義的是 ∣ψ∣2=ψ∗ψ|\psi|^2 = \psi^*\psi∣ψ∣2=ψ∗ψ（若 ψ\psiψ 為複數，取複共軛 ψ∗\psi^*ψ∗），其積分（機率）為實數且必須為正。Born詮釋是量子力學哥本哈根詮釋的核心，至今仍是最廣泛接受的詮釋。

(c) 歸一化條件

由於「粒子必定在某處」，全空間找到粒子的總機率為1：

∫−∞+∞∣ψ(x)∣2 dx=1（歸一化條件）\int_{-\infty}^{+\infty} |\psi(x)|^2\,dx = 1 \qquad \text{（歸一化條件）}∫−∞+∞​∣ψ(x)∣2dx=1（歸一化條件） (8.7)

滿足此條件的波函數稱為歸一化波函數（normalized wavefunction）。若 ψ\psiψ 是 Schrödinger 方程式的解但未歸一化，可乘以歸一化因子 NNN：ψnorm=Nψ\psi_{\rm norm} = N\psiψnorm​=Nψ，N=1/∫∣ψ∣2dxN = 1/\sqrt{\int|\psi|^2 dx}N=1/∫∣ψ∣2dx​。

物理上可接受的波函數必須滿足：

  • 連續、可微
  • 在邊界處有正確行為（如在無限深勢阱壁為零）
  • 可歸一化（∫∣ψ∣2dx=1\int|\psi|^2 dx = 1∫∣ψ∣2dx=1 有限）

8.5　Heisenberg 測不準原理

Heisenberg（1927）提出：某些對應算符不對易（non-commuting operators）的物理量不能同時精確測定。最重要的是位置-動量測不準關係：

Δx⋅Δpx≥ℏ2\Delta x \cdot \Delta p_x \geq \frac{\hbar}{2}Δx⋅Δpx​≥2ℏ​ (8.10)

其中 Δx=⟨x2⟩−⟨x⟩2\Delta x = \sqrt{\langle x^2\rangle - \langle x\rangle^2}Δx=⟨x2⟩−⟨x⟩2​ 和 Δpx=⟨px2⟩−⟨px⟩2\Delta p_x = \sqrt{\langle p_x^2\rangle - \langle p_x\rangle^2}Δpx​=⟨px2​⟩−⟨px​⟩2​ 分別是位置和動量的標準差（不確定度）。

📝 測不準原理的本質

測不準原理不是實驗技術的限制，而是量子力學的根本特性。對位置的精確限制（Δx\Delta xΔx 小）必然導致動量不確定（Δpx\Delta p_xΔpx​ 大），反之亦然。這是因為 x^\hat{x}x^ 和 p^x\hat{p}_xp^​x​ 不對易：[x^,p^x]=x^p^x−p^xx^=iℏ[\hat{x},\hat{p}_x] = \hat{x}\hat{p}_x - \hat{p}_x\hat{x} = i\hbar[x^,p^​x​]=x^p^​x​−p^​x​x^=iℏ。

類似地，能量和時間的測不準關係：ΔE⋅Δt≥ℏ/2\Delta E \cdot \Delta t \geq \hbar/2ΔE⋅Δt≥ℏ/2。

8.6　量子力學的基本假設

量子力學建立在以下幾條基本假設（公設）上：

  1. 狀態公設：量子系統的完整資訊由波函數 Ψ(r,t)\Psi(r,t)Ψ(r,t) 描述。
  2. 算符公設：每個可觀測量對應一個線性Hermitian算符；位置 x^=x\hat{x} = xx^=x，動量 p^x=−iℏ∂/∂x\hat{p}_x = -i\hbar\partial/\partial xp^​x​=−iℏ∂/∂x。
  3. 本徵值公設：測量結果只能是對應算符的本徵值；若系統處於本徵態，測量給出確定本徵值。
  4. Born規則：若系統處於歸一化態 Ψ\PsiΨ，測量算符 Ω^\hat{\Omega}Ω^ 得到本徵值 ωn\omega_nωn​ 的機率為 ∣⟨ψn∣Ψ⟩∣2|\langle\psi_n|\Psi\rangle|^2∣⟨ψn​∣Ψ⟩∣2（ψn\psi_nψn​ 為對應本徵函數）。
  5. 時間演化公設：波函數隨時間按Schrödinger方程式 iℏ∂Ψ/∂t=H^Ψi\hbar\partial\Psi/\partial t = \hat{H}\Psiiℏ∂Ψ/∂t=H^Ψ 演化。
📝 量子力學的哲學意涵

量子力學從根本上改變了物理實在的概念。粒子在未被測量前沒有確定的位置和動量（玻爾的哥本哈根詮釋）；測量行為本身「坍縮」波函數。愛因斯坦（「上帝不擲骰子」）等人難以接受這種機率性描述，但所有精確實驗（包括Bell不等式測試）均支持量子力學的非局域性和內稟隨機性。

重點概念整理

  • Planck量子假設：振子能量 ε=nhν\varepsilon = nh\nuε=nhν（n=0,1,2,...n=0,1,2,...n=0,1,2,...）；Planck分布解決了紫外災難。
  • 光電效應：Ek=hν−ΦE_k = h\nu - \PhiEk​=hν−Φ；光子能量 E=hν=ℏωE = h\nu = \hbar\omegaE=hν=ℏω；光的粒子性。
  • de Broglie關係：λ=h/p\lambda = h/pλ=h/p；物質的波動性（波長與動量成反比）。
  • Schrödinger方程式：H^ψ=Eψ\hat{H}\psi = E\psiH^ψ=Eψ；H^=−ℏ2∇2/(2m)+V\hat{H} = -\hbar^2\nabla^2/(2m) + VH^=−ℏ2∇2/(2m)+V；解出允許的能量值和波函數。
  • Born詮釋：∣ψ∣2|\psi|^2∣ψ∣2 為機率密度；歸一化 ∫∣ψ∣2dx=1\int|\psi|^2 dx = 1∫∣ψ∣2dx=1。
  • 算符與本徵值：Ω^ψ=ωψ\hat{\Omega}\psi = \omega\psiΩ^ψ=ωψ；觀測量的測量結果為本徵值。
  • Heisenberg測不準原理：Δx Δpx≥ℏ/2\Delta x\,\Delta p_x \geq \hbar/2ΔxΔpx​≥ℏ/2；ΔE Δt≥ℏ/2\Delta E\,\Delta t \geq \hbar/2ΔEΔt≥ℏ/2。
  • 常數：h=6.626×10−34 J sh = 6.626\times10^{-34}\,\rm J\,sh=6.626×10−34Js；ℏ=h/2π=1.055×10−34 J s\hbar = h/2\pi = 1.055\times10^{-34}\,\rm J\,sℏ=h/2π=1.055×10−34Js；F=96485 C mol−1F = 96485\,\rm C\,mol^{-1}F=96485Cmol−1。

討論問題

  1. Planck在1900年引入量子化假設時，僅將其視為數學技巧而非物理實在。為何後來（尤其在Einstein解釋光電效應後）量子化被認為是物理實在？請描述這個概念轉變的關鍵步驟。
  2. 波粒二象性是否真的「矛盾」？電子在雙縫實驗中同時表現波動性（干涉條紋）和粒子性（逐個落點）——解釋量子力學如何統一這兩個看似矛盾的現象。
  3. 測不準原理常被誤解為「測量儀器干擾了粒子」。請解釋其更深層的含義：位置和動量的不確定性是波函數的固有性質，與測量手段無關。
  4. 「物理可接受的波函數必須歸一化且連續可微」——解釋為什麼這些條件對於量子力學的機率詮釋是必要的。如果波函數在某點不連續，物理上意味著什麼？
  5. 比較量子力學描述（波函數、算符、本徵值）與古典力學描述（位置、動量、Hamilton方程式）的對應關係，討論在何種極限下量子力學退化為古典力學（對應原理）。
