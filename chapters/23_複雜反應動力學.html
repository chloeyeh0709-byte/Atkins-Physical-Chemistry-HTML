第23章　複雜反應動力學

本章探討三類重要的複雜反應：（1）鏈式反應（chain reactions）——涉及自由基的連鎖過程，包括爆炸和聚合；（2）酶催化反應——Michaelis-Menten 機構及其各種抑制模式；（3）光化學反應——光吸收後的各種光物理和光化學過程，包括螢光、FRET 和光敏化。

23.1 鏈式反應

鏈式反應（chain reaction）的特徵步驟：

  • 鏈引發（initiation）：產生自由基
  • 鏈傳播（propagation）：自由基消耗反應物並再生成另一個自由基
  • 鏈終止（termination）：自由基被消滅

H₂ + Br₂ 反應

實驗速率定律：

v=k[H2][Br2]1/21+k′[HBr]/[Br2]v = \frac{k[\text{H}_2][\text{Br}_2]^{1/2}}{1 + k'[\text{HBr}]/[\text{Br}_2]}v=1+k′[HBr]/[Br2​]k[H2​][Br2​]1/2​

這複雜的形式由以下機構解釋（Rice-Herzfeld 型）：

  1. Br2→ki2Br\text{Br}_2 \xrightarrow{k_i} 2\text{Br}Br2​ki​​2Br（引發）
  2. Br+H2→k2HBr+H\text{Br} + \text{H}_2 \xrightarrow{k_2} \text{HBr} + \text{H}Br+H2​k2​​HBr+H（傳播）
  3. H+Br2→k3HBr+Br\text{H} + \text{Br}_2 \xrightarrow{k_3} \text{HBr} + \text{Br}H+Br2​k3​​HBr+Br（傳播）
  4. H+HBr→k4H2+Br\text{H} + \text{HBr} \xrightarrow{k_4} \text{H}_2 + \text{Br}H+HBrk4​​H2​+Br（抑制）
  5. 2Br→ktBr22\text{Br} \xrightarrow{k_t} \text{Br}_22Brkt​​Br2​（終止）

對 H 和 Br 套用 SSA，得到上述實驗速率定律，其中 k=2k2(ki/kt)1/2k = 2k_2(k_i/k_t)^{1/2}k=2k2​(ki​/kt​)1/2，k′=k4/k3k' = k_4/k_3k′=k4​/k3​。

Rice-Herzfeld 機構

有機物熱分解的通用鏈式反應機構（如乙醛分解）：引發→傳播→終止。自由基 SSA 給出一階或半階的速率定律，取決於終止步驟類型。

23.2 爆炸

爆炸（explosion）發生在鏈式反應不能以穩態方式進行時。

熱爆炸（thermal explosion）：反應放熱使溫度急升，速率指數增加，無法與散熱速率平衡。

支鏈爆炸（branching chain explosion）：某些傳播步驟產生多於一個自由基（鏈支化），如 H₂/O₂ 反應：

  • H+O2→OH+O\text{H} + \text{O}_2 \to \text{OH} + \text{O}H+O2​→OH+O（支化，一個自由基 → 兩個）
  • O+H2→OH+H\text{O} + \text{H}_2 \to \text{OH} + \text{H}O+H2​→OH+H（支化）

當支化速率超過終止速率，自由基濃度指數增長，發生爆炸。H₂/O₂ 混合物有兩個爆炸界限（pressure limits），在中間壓力範圍內穩定燃燒。

23.3 聚合動力學

(a) 逐步聚合

（step-growth polymerization）：單體間官能團逐步縮合，如聚酯、聚醯胺。

轉化率 ppp（官能團已反應分率），平均聚合度：⟨N⟩=1/(1−p)\langle N \rangle = 1/(1-p)⟨N⟩=1/(1−p)（Carothers 方程式）。

(b) 鏈式聚合

（chain-growth polymerization）：自由基引發，鏈傳播非常快，終止步驟決定鏈長。平均聚合度與引發速率、傳播速率相關：

⟨N⟩=kp[M](ktki[I])1/2\langle N \rangle = \frac{k_p[\text{M}]}{(k_t k_i[\text{I}])^{1/2}}⟨N⟩=(kt​ki​[I])1/2kp​[M]​

其中 [M] 為單體濃度，[I] 為引發劑濃度，kpk_pkp​、ktk_tkt​、kik_iki​ 分別為傳播、終止、引發速率常數。

23.6 光化學基本概念

(a) 光化學基本定律

  • Grotthuss-Draper 定律：只有被分子吸收的光才能引起光化學反應
  • Stark-Einstein 定律：每個吸收的光子引起一個初級光化學過程

(b) 量子產率

量子產率（quantum yield）ϕ\phiϕ：發生特定事件的速率與光子吸收速率之比：

ϕ=事件發生速率光子吸收速率\phi = \frac{\text{事件發生速率}}{\text{光子吸收速率}}ϕ=光子吸收速率事件發生速率​

例如：螢光量子產率 ϕf\phi_fϕf​（螢光發射光子數/吸收光子數）；光化反應量子產率 ϕ\phiϕ（分子反應數/光子吸收數）。初級過程的量子產率之和等於 1：ϕf+ϕic+ϕisc+ϕrxn+⋯=1\phi_f + \phi_\text{ic} + \phi_\text{isc} + \phi_\text{rxn} + \cdots = 1ϕf​+ϕic​+ϕisc​+ϕrxn​+⋯=1。

(c) FRET（Förster 共振能量轉移）

供體（D）的激發能量非輻射轉移給受體（A）：

FRET 的生物應用
FRET 廣泛用於蛋白質構型變化、核酸雜交、受體-配體結合距離的測量，以及活細胞中分子相互作用的實時監測。

23.8 複雜光化學反應

(a) 整體量子產率

光化學反應的整體量子產率 Φ\PhiΦ（包含後續熱反應的放大效應）可遠大於 1：

Φ=產物分子數吸收光子數\Phi = \frac{\text{產物分子數}}{\text{吸收光子數}}Φ=吸收光子數產物分子數​

例如 HCl 的光化合成（Φ≈106\Phi \approx 10^6Φ≈106）：一個光子引發一個鏈式反應，可形成大量 HCl 分子。

(b) 光敏化

光敏劑（sensitizer, S）吸收光，透過系間穿越到三重態 T₁，再將激發能量轉移給受體（acceptor, A）：

S+hν→S∗→ISC3S→ET3A∗+S\text{S} + h\nu \to \text{S}^* \xrightarrow{\text{ISC}} {}^3\text{S} \xrightarrow{\text{ET}} {}^3\text{A}^* + \text{S}S+hν→S∗ISC​3SET​3A∗+S

光敏化可使不吸收特定波長光的受體分子被活化（如染料光敏化太陽能電池）。

I23.1 技術應用：平流層臭氧的化學

Chapman 模型（未考慮催化）：

  • O2+hν→2O\text{O}_2 + h\nu \to 2\text{O}O2​+hν→2O（$\lambda < 240$ nm）
  • O+O2+M→O3+M\text{O} + \text{O}_2 + \text{M} \to \text{O}_3 + \text{M}O+O2​+M→O3​+M（三體碰撞）
  • O3+hν→O2+O\text{O}_3 + h\nu \to \text{O}_2 + \text{O}O3​+hν→O2​+O（$\lambda < 310$ nm）
  • O+O3→2O2\text{O} + \text{O}_3 \to 2\text{O}_2O+O3​→2O2​

Chapman 模型預測的臭氧濃度比觀測值高，說明存在額外的催化消耗機制。

CFC（氟氯碳化物）的催化破壞：CFC 在平流層光解產生 Cl 自由基：

  • Cl+O3→ClO+O2\text{Cl} + \text{O}_3 \to \text{ClO} + \text{O}_2Cl+O3​→ClO+O2​
  • ClO+O→Cl+O2\text{ClO} + \text{O} \to \text{Cl} + \text{O}_2ClO+O→Cl+O2​
  • 淨反應：O3+O→2O2\text{O}_3 + \text{O} \to 2\text{O}_2O3​+O→2O2​（Cl 為催化劑）

一個 Cl 原子可破壞 10510^5105–10610^6106 個臭氧分子。NOx_xx​（xxx = 1, 2）和 OH 自由基也催化臭氧分解。

I23.2 生化應用：光合作用中的集光

光合作用利用多種色素分子將光能傳遞到反應中心：

  • 天線色素（antenna pigments）：吸收不同波長光子，透過 FRET 逐步將能量導向反應中心
  • P680（光系統 II 反應中心）：激發態（P680*）氧化水釋放 O₂，電子沿電子傳遞鏈傳遞
  • P700（光系統 I 反應中心）：最終將電子傳給 NADP⁺，生成 NADPH
  • 電子傳遞鏈：H2O→P680→PQ→P700→Fd→NADPH\text{H}_2\text{O} \to \text{P680} \to \text{PQ} \to \text{P700} \to \text{Fd} \to \text{NADPH}H2​O→P680→PQ→P700→Fd→NADPH
  • 量子效率：光合作用的整體量子效率約為 3.5%（考慮從光到糖的所有步驟後）
  • FRET 效率：天線色素系統到反應中心的能量傳遞效率 $> 95\%$
I23.3 技術應用：光動力療法

光動力療法（photodynamic therapy, PDT）利用光敏劑和光選擇性破壞癌細胞：

  • 光敏劑（通常為卟啉類）注射後在腫瘤組織中累積
  • 以特定波長（如 630 nm）光照射腫瘤
  • 光敏劑到達三重態（3sensitizer∗{}^3\text{sensitizer}^*3sensitizer∗），與 3O2{}^3\text{O}_23O2​ 能量轉移產生單態氧 1O2∗{}^1\text{O}_2^*1O2∗​
  • 1O2∗{}^1\text{O}_2^*1O2∗​ 氧化腫瘤細胞中的有機分子（脂質、蛋白質、核酸），引起細胞死亡
  • 優點：選擇性高（只破壞照光區域），副作用小
