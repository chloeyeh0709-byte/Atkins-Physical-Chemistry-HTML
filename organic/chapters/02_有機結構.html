第二章：有機結構

Clayden's Organic Chemistry, 2nd Edition  ·  Chapter 2: Organic Structures

烴類骨架

有機分子的核心是烴類骨架（hydrocarbon framework）——由碳與氫原子構成的骨架。所有其他官能基都連接在這個骨架上。

烴類可分為：

  • 烷烴（alkanes）：只有 C–C 單鍵和 C–H 鍵，如甲烷 (CH₄)、乙烷 (C₂H₆)
  • 烯烴（alkenes）：含 C=C 雙鍵，如乙烯 (C₂H₄)、丙烯 (C₃H₆)
  • 炔烴（alkynes）：含 C≡C 三鍵，如乙炔 (C₂H₂)
  • 芳香烴（arenes）：含苯環，如苯 (C₆H₆)、甲苯
烴類骨架的重要性

烴類骨架本身的化學活性很低（C–C 和 C–H 鍵不易斷裂），它的主要作用是提供分子的三維架構，並決定官能基之間的相對位置。官能基才是反應發生的地方。

結構式的畫法

有機化學家使用骨架結構式（skeletal structure / line-bond structure）來快速表示分子。畫法遵循三條規則：

骨架結構式的三條規則
  1. 折線表示碳鏈：每個折點代表一個碳原子，線段代表 C–C 鍵（呈鋸齒狀）
  2. 省略碳上的氫：每個碳上的氫原子不明確畫出（默認補滿四個鍵）
  3. 省略碳的符號：折點和線段端點的 C 符號不寫，只有非碳原子（N、O、S 等）要標出

範例對照

丁烷（正丁烷，n-butane）的不同表示方式
分子式： C₄H₁₀ 展開式： CH₃–CH₂–CH₂–CH₃ 縮合式： CH₃CH₂CH₂CH₃ 骨架式： ∧∨ （四個碳的折線，端點為 CH₃，中間節點為 CH₂）

雙鍵與三鍵的畫法

雙鍵用雙線 (=) 表示，三鍵用三線 (≡) 表示：

乙烯（ethene/ethylene）： H₂C=CH₂ 乙炔（ethyne/acetylene）： HC≡CH 丙烯（propene/propylene）：CH₂=CH–CH₃（骨架式：折點在中間碳，左端雙鍵）

環狀結構

環狀化合物畫成多邊形：

  • 環丙烷：正三角形
  • 環己烷：正六邊形（椅式構型在骨架式中常省略）
  • 苯：正六邊形內含圓圈（或交替雙鍵）

練習：辨認官能基

阿斯匹靈（acetylsalicylic acid）的結構包含哪些官能基？答：苯環 (arene)、酯基 (ester)、羧酸 (carboxylic acid)。

有機分子的氧化態

在有機化學中，碳的氧化態（oxidation level）由其與電負性原子（O、N、鹵素）相連的鍵數決定。連結到更多電負性原子的碳，氧化態更高。

化合物類型碳的鍵結氧化態（相對）
烷烴 –CH₃全部與 C、H 相連最低（最還原）
醇 –CH₂OH一個 O↑
醛 –CHO一個雙鍵 O↑↑
羧酸 –COOH兩個 O↑↑↑
CO₂兩個雙鍵 O最高（最氧化）
氧化還原在有機化學中的意義

有機氧化反應通常是在碳上增加 O（或去除 H），還原則相反。例如：乙醇 → 乙醛 → 乙酸（連續氧化）；乙酸 → 乙醛 → 乙醇（連續還原）。

有機化合物命名

有機化合物的命名有三個層次：

1. IUPAC 系統命名法

國際純化學與應用化學聯合會（IUPAC）制定的系統命名規則：

  1. 找出最長的碳鏈（主鏈），確定其英文詞幹（meth-/eth-/prop-/but-/pent-/hex-...）
  2. 加上後綴表示官能基（-ane=烷, -ene=烯, -yne=炔, -ol=醇, -al=醛, -one=酮, -oic acid=羧酸）
  3. 取代基以數字標明位置，從靠近官能基的端點開始編號
IUPAC 命名範例
  • CH₃CH₂OH → 乙醇 (ethanol)
  • CH₃COCH₃ → 丙酮 (propan-2-one)
  • CH₃CH(OH)CH₃ → 丙-2-醇 (propan-2-ol)
  • (CH₃)₃CCl → 2-氯-2-甲基丙烷 (2-chloro-2-methylpropane)

2. 俗名（Trivial Names）

歷史沿用的慣用名，在工業和日常中廣泛使用：

俗名IUPAC 名
丙酮 (acetone)丙-2-酮 (propan-2-one)
甲醛 (formaldehyde)甲醛 (methanal)
乙酸 (acetic acid)乙酸 (ethanoic acid)
氯仿 (chloroform)三氯甲烷 (trichloromethane)
苯酚 (phenol)苯-1-醇 (benzene-1-ol)

3. 縮寫與首字母縮略詞

大型生物分子常用縮寫：ATP (adenosine triphosphate)、DNA、NAD⁺ 等。有機反應中的試劑也常有縮寫，如 LDA (lithium diisopropylamide)、DIBAL (diisobutylaluminium hydride)。

本章總結

核心概念回顧
  • 骨架結構式以折線簡潔表示有機分子：折點=碳、省略 C 和其上的 H、標出雜原子
  • 烴骨架（烷/烯/炔/芳）提供分子架構；官能基決定反應性
  • 碳的氧化態越高，與電負性原子的連結越多（烷 < 醇 < 醛 < 酸）
  • IUPAC 命名：主鏈 → 取代基位置 → 官能基後綴
  • 熟記常用縮寫（Me、Et、Ph、Bu、Ac 等）是閱讀有機文獻的基本技能
