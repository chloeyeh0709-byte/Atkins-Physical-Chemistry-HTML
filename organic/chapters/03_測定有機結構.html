第三章：測定有機結構

Clayden's Organic Chemistry, 2nd Edition  ·  Chapter 3: Determining Organic Structures

現代有機化學家合成一個新化合物後，必須證明其結構。本章介紹四種主要分析技術，它們互補使用，可以確定有機分子的完整結構。

X 射線晶體學

X 射線晶體學是直接觀測分子三維結構的黃金標準。當 X 射線穿過結晶固體，被規律排列的原子衍射，從衍射圖案可以重建電子密度，進而確定所有原子的位置。

X 射線晶體學的特點
  • 可以直接確定所有原子位置（包括相對立體化學）
  • 需要長出適合衍射的單晶——這有時很難做到
  • 給出的是固態結構，溶液中的構型可能不同
  • 適合確定複雜天然產物的完整三維結構

實際上，大多數有機結構鑑定不使用 X 射線（因需結晶），而靠譜學方法（MS + NMR + IR）在溶液中完成。

質譜法 (Mass Spectrometry, MS)

質譜法測量分子的質量與電荷比 (m/z)，提供分子量和分子式資訊，以及片段化模式（碎片峰）幫助推斷結構。

游離方法

方法英文縮寫特點適用對象

分子離子峰與同位素峰

質譜中最重要的峰是分子離子峰 (M⁺)，給出分子量。由於天然同位素的存在，M⁺ 旁邊會出現 (M+1)⁺、(M+2)⁺ 等同位素峰：

溴的同位素特徵

⁷⁹Br（50.7%）和 ⁸¹Br（49.3%）幾乎等比例存在。含一個 Br 的化合物，M⁺ 和 (M+2)⁺ 峰強度比約為 1:1；含兩個 Br 則比為 1:2:1。這是判斷分子含 Br 的特征指紋。

氯：³⁵Cl（75.5%）/ ³⁷Cl（24.5%）→ M⁺:(M+2)⁺ ≈ 3:1

高分辨率質譜（High-Resolution MS）

精確測量 m/z（精度至 0.001 Da 以上）可以區分相同標稱質量但不同分子式的化合物，直接給出精確分子式：

精確質量範例

CO、C₂H₄、N₂ 標稱質量都是 28，但精確質量不同：

  • CO：27.9949
  • C₂H₄：28.0313
  • N₂：28.0061

高分辨 MS 可以明確區分，直接確定分子式。

¹³C 核磁共振（¹³C NMR）

¹³C NMR 利用 ¹³C 原子核的磁共振信號，提供分子中不同碳原子的化學環境資訊。

化學位移 δ

化學位移（chemical shift，δ）以 ppm 為單位，以四甲基矽烷（TMS，δ = 0 ppm）為參考標準。δ 越大（向低場偏移），代表該碳受到更強的去屏蔽效應（周圍電子密度低）。

碳的類型δ 範圍 (ppm)
烷基碳 (sp³, C–C, C–H)0–50
連氧烷基碳 (C–O, C–N)50–90
炔碳 (C≡C)70–100
烯碳 / 芳碳 (C=C, Ar)100–160
羰基碳–酮、醛 (C=O)190–220
羰基碳–酸、酯、醯胺160–180
TMS 與 δ 刻度

¹³C NMR 的化學位移：δ = 0 ppm 定義為 TMS（四甲基矽烷）的碳信號。信號出現在 0 ppm 右側（高場）表示屏蔽效應強；出現在左側（低場）表示去屏蔽效應強，電子密度低。

¹³C NMR 的特點

  • 每種化學環境不同的碳給出一個峰
  • 峰的數目 = 分子中化學不等價碳的種類數（對稱性影響）
  • DEPT 實驗可區分 CH₃、CH₂、CH、C（四季碳）
  • ¹³C 天然豐度僅 1.1%，靈敏度低，但可提供所有碳的資訊
¹³C NMR 練習

乙酸乙酯（CH₃COOCH₂CH₃）有幾種不等價碳？答：4 種（CH₃CO 的 CH₃、羰基 C=O、O–CH₂、末端 CH₃），應出現 4 個 ¹³C 峰。

¹H 核磁共振（¹H NMR）

¹H NMR 是有機結構鑑定最常用的技術。¹H 原子核（質子）的天然豐度接近 100%，靈敏度高。

¹H NMR 的三個關鍵資訊

  1. 化學位移：判斷質子所處的化學環境（官能基類型）
  2. 積分面積：峰面積正比於該類質子的數目
  3. 偶合裂分（coupling）：鄰近的非等價質子使信號裂分（n+1 規則：n 個鄰位 H 使信號裂分為 n+1 條線）；偶合常數 J 反映距離和幾何關係
乙醇的 ¹H NMR 分析

CH₃–CH₂–OH

  • CH₃（3H，δ ≈ 1.2 ppm）：與相鄰 CH₂ 的 2H 偶合 → 裂分為三重峰 (triplet)
  • CH₂（2H，δ ≈ 3.7 ppm）：與相鄰 CH₃ 的 3H 偶合 → 裂分為四重峰 (quartet)
  • OH（1H，δ ≈ 2.6 ppm）：寬峰（氫鍵交換快，偶合消失）

紅外光譜 (IR)

紅外光譜偵測分子的振動（伸縮振動、彎曲振動）。不同的化學鍵在特定波數（wavenumber，cm⁻¹）吸收紅外光，形成特徵吸收峰。

IR 最重要的原則

羰基 C=O 的伸縮振動（~1700 cm⁻¹附近的強吸收）是 IR 中最容易辨認、也最有診斷價值的峰。具體波數受取代基影響：連接到更多電負性基團（酯 > 酮 > 醯胺）使 C=O 伸縮頻率升高。

不飽和度（DBE）計算

不飽和度（degrees of unsaturation，DBE），又稱雙鍵等效數（double bond equivalents），計算分子中環和 π 鍵的總數。

DBE 計算公式

對分子式 CnHmNpOqXr（X = 鹵素）：

DBE=2n+2+p−m−r2\text{DBE} = \frac{2n + 2 + p - m - r}{2}DBE=22n+2+p−m−r​

氧和硫不影響 DBE（O、S 不計入）。每個環或 π 鍵貢獻 1 個 DBE；苯環貢獻 4（3個雙鍵 + 1個環）。

DBE 計算範例
  • 苯（C₆H₆）：DBE = (2×6 + 2 − 6)/2 = 8/2 = 4（3 個雙鍵 + 1 個環）✓
  • 乙醇（C₂H₆O）：DBE = (2×2 + 2 − 6)/2 = 0（無不飽和度）✓
  • 萘（C₁₀H₈）：DBE = (2×10 + 2 − 8)/2 = 14/2 = 7（5個雙鍵 + 2個環）✓
  • C₅H₉N：DBE = (2×5 + 2 + 1 − 9)/2 = 5/2 = 2.5 → 不是整數，說明分子式有誤；N 計入應為 +p 而非 −p

綜合結構解析

實際工作中，結構鑑定是將四種技術的資訊整合起來的過程：

綜合解析流程
  1. 先看 MS：確定分子量和分子式（高分辨 MS 直接給分子式）→ 計算 DBE
  2. 看 IR：確認或排除主要官能基（有無 C=O？有無 O–H？有無 N–H？）
  3. 看 ¹³C NMR：確定碳的種類和數目（烷/烯/芳/羰基碳）
  4. 看 ¹H NMR：確定質子環境、數目和相互連結（偶合常數）
  5. 拼圖：綜合所有資訊提出可能結構，驗證是否自洽
自我測驗：結構解析

分子式 C₃H₆O，DBE = 1。IR 顯示 ~1715 cm⁻¹ 強吸收（C=O，無 O–H）。¹H NMR 顯示僅有一個信號（6H 單峰）。

分析：DBE = 1 → 一個 C=O 或一個環；IR 確認 C=O 為酮或醛（無 O–H 排除醇）；¹H NMR 一個 6H 單峰 → 分子高度對稱，兩個相同的 CH₃ 無鄰位 H 可偶合。

答案：丙酮（acetone，CH₃COCH₃）✓

本章總結

核心概念回顧
  • MS：確定分子量和分子式；同位素峰識別 Cl/Br；高分辨 MS 直接確定精確分子式
  • ¹³C NMR：每種不等價碳給一個峰；δ 範圍識別碳的類型（sp³/sp²/C=O）
  • ¹H NMR：化學位移、積分（質子數比）、偶合裂分（n+1 規則）三要素
  • IR：四區域；C=O 伸縮（1600–1750 cm⁻¹）是最重要特征峰；O–H / N–H 在 3000–3600 cm⁻¹
  • DBE = (2C + 2 + N − H − X) / 2；每個環或 π 鍵 +1
  • 實際結構解析需要 MS + IR + NMR 互相印證，缺一不可
