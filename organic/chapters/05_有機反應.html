第五章：有機反應

Clayden's Organic Chemistry, 2nd Edition  ·  Chapter 5: Organic Reactions

大多數分子在靜置時相當穩定。硫酸、氫氧化鈉、水、丙酮在實驗室儲存多年也不會改變。但當這些物質混合，化學反應就可能發生。本章是有機分子反應行為的入門：為何有些分子會反應而有些不會？如何用電荷、軌域和電子流動來理解並預測反應性？

化學反應

要理解有機化學，需要熟悉兩種語言：

  1. 結構語言：原子、鍵、軌域（Ch2–Ch4 的內容）
  2. 反應性語言：反應機制、親核劑、親電劑

化學是關於動態的學問——如何從舊分子創造新分子。分子因電子的移動而發生反應。

Berthelot（1827–1907）的洞察

化學的創造能力——能合成自然界從未存在的全新分子——使其與自然科學和歷史科學截然不同。有機化學家每年合成數百萬種全新化合物。

為什麼分子會反應？

並非所有碰撞都導致化學變化

分子表面覆蓋著佔據成鍵和非成鍵軌域的電子——表面帶負電。因此大多數分子在碰撞時會互相排斥，像撞球一樣彈開。只有具備足夠能量克服這個靜電排斥的分子對才能反應。這個最低能量需求稱為活化能（activation energy）。

電荷吸引使分子靠近

離子之間的靜電吸引可以幫助分子克服電子排斥。但純粹的有機陰離子很少見，更常見的是偶極-偶極吸引——帶偶極的試劑（陽離子或陰離子）與有機化合物的偶極相互吸引。

氰化物攻擊甲醛

氰化鈉（NaCN）中的氰化物陰離子（⁻CN）被甲醛（HCHO）的正端吸引：

⁻C≡N + H₂C=O → HO–CH₂–CN （氰化物 甲醛 氰醇） ← 電荷吸引 → ← C=O 偶極，C 端δ+ →

氰化物陰離子（帶負電）被甲醛羰基的 δ+ 碳端吸引，完成反應。

靜電摘要

分子反應的三種驅動力：
  • 大多數有機反應涉及填充軌域與空軌域之間的相互作用
  • 許多（但非全部）同時涉及電荷相互作用，幫助克服電子排斥
  • 少數離子反應完全依靠電荷吸引

軌域重疊帶動反應

即使兩個分子完全不帶電、沒有偶極，只要它們的分子軌域能相互作用，反應就可能發生。

乙烯與溴的反應

乙烯（H₂C=CH₂）和溴（Br–Br）都不帶電、無偶極，但它們仍然反應！

原因：溴分子有一個低能量的空軌域（Br–Br 的 σ* 反鍵軌域），可以接受乙烯 π 鍵中的電子。軌域相互作用克服了靜電排斥，使反應得以進行。

這說明電荷和偶極不是反應的必要條件——軌域重疊本身就可以驅動反應。

反應機制：電子流動

當一對分子因靜電吸引或軌域重疊而靠近時，電子可以從一個分子移動到另一個分子，形成或斷裂化學鍵。這個過程的詳細描述就是反應機制（mechanism）。

在大多數有機反應中，電子從一個分子流向另一個分子：

  • 接受電子的分子：親電劑（electrophile，E）——電子的「愛好者」，用希臘文 philos（愛）+ 電子 = 愛電子者
  • 提供電子的分子：親核劑（nucleophile，Nu）——原子核的「愛好者」，傾向靠近正電荷（原子核）
有機反應的核心原則

當電子從親核劑流向親電劑時，就形成新鍵：

親核劑 (Nu) ──電子流動──→ 親電劑 (E 或 E⁺) 親核劑提供電子；親電劑接受電子。

HOMO 與 LUMO：軌域能量決定反應性

填充軌域傾向於能量低；空軌域傾向於能量高。最重要的相互作用發生在：

  • 親核劑的最高佔據分子軌域（HOMO，Highest Occupied MO）
  • 親電劑的最低未佔據分子軌域（LUMO，Lowest Unoccupied MO）
為什麼是 HOMO–LUMO 相互作用？

當 HOMO 與 LUMO 能量接近時，相互作用最強，能量增益最大（形成新鍵獲得的穩定化能最多）。當兩者能量差距很大時，相互作用弱，反應不易發生。

因此：最好的反應是 HOMO 和 LUMO 能量接近的反應。

HOMO–LUMO 原則：
  • 最好的親核劑具有高能量的 HOMO（電子容易給出）
  • 最好的親電劑具有低能量的 LUMO（電子容易接受）

反應發生的三個必要條件：

  1. 克服電子排斥（靠電荷吸引或軌域重疊）
  2. 有適當能量的軌域相互作用（HOMO 在親核劑，LUMO 在親電劑）
  3. 分子以正確方向碰撞（軌域需要有效重疊）

親核劑的辨認

親核劑是帶有電子對（高能量 HOMO）的分子或離子，能夠提供電子給親電劑。

類型一：帶孤對電子的中性分子

最常見的親核劑帶有非成鍵孤對電子：

親核劑HOMO親核位點
氨（NH₃）N 上的非成鍵 sp³ 軌域N
胺類（R–NH₂、R₂NH）N 上的孤對電子N
水（H₂O）O 上的孤對電子（sp³）O
醇（R–OH）O 上的孤對電子O
三甲基磷（Me₃P）P 上的孤對電子（3p，能量較高）P
硫醇（PhSH）S 上的孤對電子（3p，能量高）S
第三週期親核劑更強

磷和硫的孤對電子使用 3s/3p 軌域，能量比 N、O 的 2s/2p 高（因屏蔽效應），因此 P 和 S 通常是比 N 和 O 更好的親核劑。

類型二：帶負電荷的陰離子

帶負電的物種通常是很好的親核劑（兼有靜電吸引和高能 HOMO）：

陰離子親核劑說明
OH⁻（氫氧根）O 上有孤對電子；三個等價孤對對
Br⁻（溴離子）Br 上有孤對電子
⁻CN（氰化物）最重要的碳親核劑；親核位點在碳（C 端 sp 軌域能量高）
注意：氰化物攻擊位點

氰化物（⁻C≡N）雖然線形，N 和 C 都帶孤對電子，但親核攻擊通常發生在碳端——因為碳的 sp 軌域能量（HOMO）高於更電負的氮。

類型三：π 鍵（C=C 雙鍵）

π 鍵的電子能量高於 σ 鍵（因側向重疊效率低），因此 C=C π 鍵可以作為親核劑的 HOMO。簡單烯烴是弱親核劑，但含有電子推給基團的烯烴親核性更強。

類型四：σ 鍵（連接電正性原子）

當 σ 鍵連接電正性原子（B、Si、Li 等），該 σ 鍵的能量較高，可作為親核劑：

  • 氫化硼（BH₄⁻）：B–H σ 鍵能量高（B 電正性），是強親核劑；HOMO 是 B–H σ 軌域
  • 甲基鋰（LiCH₃）：C–Li σ 鍵能量高（Li 極電正性）；碳作為親核劑
親核劑提供電子的四種方式（彎箭頭從這裡出發）
  1. 孤對電子（NH₃、OH⁻ 等）
  2. 負電荷（代表孤對電子）
  3. C=C π 鍵（π 軌域電子）
  4. 連接電正性原子的 σ 鍵（B–H、Li–C）

親電劑的辨認

親電劑是帶有空軌域（低能量 LUMO）的分子或離子，能夠接受親核劑提供的電子。

類型一：帶空原子軌域的物種

親電劑LUMO說明
H⁺（質子）空 1s 軌域最簡單的親電劑；幾乎所有親核劑都能與 H⁺ 反應
BH₃（硼烷）空 2p 軌域在 B 上sp² 雜化，p 軌域完全空
BF₃（三氟化硼）空 p 軌域強 Lewis 酸；LUMO 是 B 的 p 軌域
AlCl₃（三氯化鋁）空 p 軌域強 Lewis 酸，Friedel-Crafts 反應常用

類型二：低能量反鍵軌域（π* 或 σ*）

大多數有機親電劑的 LUMO 是與電負性原子相連的反鍵軌域——電負性原子使反鍵軌域能量降低，更易接受電子：

親電劑LUMO例子
雙鍵接電負性原子（C=O、C=N）π* 軌域（能量低）酮、醛、酯、醯胺
單鍵接電負性原子（H–Cl、C–Br）σ* 軌域（能量低）HCl、CH₃Br
Br–Br（溴分子）σ* 軌域（大原子，能量低）烯烴的親溴反應
羰基：最重要的有機親電劑

羰基化合物（酮、醛、酯、醯胺）的 C=O π* 軌域能量低（因 O 電負），且 C=O 偶極使碳帶部分正電（δ+），雙重增強親電性。幾乎有機化學的每一章都涉及羰基的親核加成或類似反應。

Br₂ 的特殊性

溴雖然略帶電負性，但 4s/4p 軌域大而擴散，重疊效率低 → Br–Br σ 鍵弱，σ* 軌域能量也低 → 容易接受電子 → 溴是強親電劑。相比之下，C–C 鍵的 σ* 能量很高 → C–C 鍵幾乎不是親電劑。

親電劑接受電子的四種方式（彎箭頭指向這裡）
  1. 正電荷（代表空軌域，如 H⁺）
  2. 中性分子帶空原子軌域（BH₃、BF₃）
  3. 雙鍵到電負性原子（C=O 的 π* 軌域）
  4. 單鍵到電負性原子（H–Cl 的 σ* 軌域，Br–Br 的 σ*）

彎箭頭表示反應機制

彎箭頭（curly arrow）是有機化學最強大的符號工具——一支彎曲的箭頭代表一對電子的移動。它簡潔地表達了反應的本質：電子從哪裡來（HOMO），到哪裡去（LUMO）。

彎箭頭 vs 直箭頭
  • 彎箭頭：表示電子對的移動（機制箭頭）
  • 直箭頭（→）：表示反應方向（方程式箭頭）

最簡單的例子：Cl⁻ + H⁺

Cl⁻ + H⁺ → H–Cl ↑ 彎箭頭從 Cl 的負電荷出發（代表孤對），指向 H（空 1s 軌域） 彎箭頭的尾部 = 電子的來源（HOMO） 彎箭頭的頭部 = 電子的目的地（LUMO / 新鍵形成處）

氨攻擊硼烷（NH₃ + BH₃）

H H H H | | | | H-N: + B-H → H-N⊕-B⊖-H | | | | H H H H (孤對 sp³) (空 p 軌域) 彎箭頭：N 的孤對 → B 的空 p 軌域（形成 N–B σ 鍵）
配位共價鍵（dative bond）

氨與硼烷形成的 N–B 鍵，兩個電子都來自 N（氮「贈送」）。這類鍵稱為配位共價鍵，但本質上與普通 σ 鍵無異。氮帶正電，硼帶負電（各少/多一個電子）。

彎箭頭的規則

彎箭頭必須從代表電子對的符號出發：

✓ 負電荷（代表孤對電子）

✓ 孤對電子（用點或弧線表示）

✓ π 鍵（從鍵中間出發）

✓ σ 鍵（從鍵中間出發）

✗ 正電荷（不代表電子，不能作為箭頭起點）

電荷在每個步驟中必須守恆：

起始物的總電荷 = 產物的總電荷

例：NH₃（0）+ BH₃（0）→ H₃N⁺–BH₃⁻（整體仍為 0）✓

斷鍵的規則

當電子流入反鍵軌域（σ* 或 π*）時，相應的鍵會斷裂。需要用第二條彎箭頭表示斷裂鍵的電子去向：

NH₃ 攻擊 HCl（酸鹼反應）
H H H H | | | | H-N: H-Cl → H-N⊕-H + Cl⁻ | | H H 箭頭1：N 孤對 → H（新 N–H σ 鍵形成） 箭頭2：H–Cl σ 鍵中心 → Cl（H–Cl 鍵斷裂，Cl 獲得電子對）

注意：第一條箭頭將電子打入 H–Cl 的 σ*，導致 H–Cl 斷裂，所以必須同時畫第二條箭頭。

π 鍵斷裂的規則

當親電劑攻擊 π 鍵時（如羰基被親核劑攻擊），π 鍵斷裂，電子移到較電負的原子（O）：

OH⁻ 攻擊羰基
O⊖ O⊖ ‖ | HO⁻ + C → HO–C– 碳負離子中間體 箭頭1：OH⁻ 的負電荷（孤對）→ C 端（LUMO = π* 軌域，C 端） 箭頭2：C=O π 鍵中心 → O（π 鍵斷裂，O 獲得負電荷） 結果：C 上形成新 C–O 鍵，原 C=O π 鍵斷裂，O 帶負電
彎箭頭健康檢查清單
  • ✓ 每條彎箭頭從代表電子對的地方出發
  • ✓ 箭尾 = 填充軌域（HOMO）：孤對、負電荷、π 鍵、σ 鍵
  • ✓ 箭頭 = 空軌域（LUMO）或新鍵形成位置
  • ✓ 每步驟電荷守恆
  • ✓ C、N、O 不能超過 4 個鍵（八隅律）——若形成新鍵必須同時斷一個鍵

π 鍵作為親核劑

烯烴的 π 鍵可以作為親核劑的 HOMO，攻擊親電劑。

烯烴 + HBr（親電加成）

步驟 1：乙烯的 π 鍵攻擊 HBr 的 H（H 是親電劑，LUMO = H–Br σ*）

第一步：π 鍵攻擊 H H₂C=CH₂ + H–Br → H₃C–CH₂⊕ + Br⁻ ↑ 碳正離子 π 鍵出發 (空 p 軌域) 彎箭頭1：π 鍵中心 → H（穿過 H 原子）[新 C–H 鍵形成] 彎箭頭2：H–Br σ 鍵 → Br [H–Br 鍵斷裂，Br⁻ 離去]

步驟 2：Br⁻（親核劑）攻擊碳正離子（親電劑，空 p 軌域）

第二步：Br⁻ 攻擊碳正離子 Br⁻ + CH₃–CH₂⊕ → CH₃–CH₂–Br 彎箭頭：Br⁻ 的負電荷 → 碳正離子的空 p 軌域
碳正離子（carbocation）

碳正離子是 sp² 雜化的碳帶正電（6 個電子，空 p 軌域）。它是強親電劑，幾乎所有含孤對電子的分子都能攻擊它。

σ 鍵作為親核劑

連接電正性原子的 σ 鍵（如 B–H）可以作為親核劑，提供 σ 鍵電子給親電劑。

NaBH₄ 還原醛酮（σ 鍵親核反應）
第一步：B–H σ 鍵攻擊 C=O 的碳（LUMO = π*） H H O⊖ | | | H₂B-H + R₂C=O → H₂B⊕ + R₂C–H ↑ B–H σ 鍵出發（箭頭從 B–H 中心指向 C） 同時 C=O π 鍵電子 → O（π 鍵斷裂，O 帶負電） 第二步：烷氧化物中間體在水中接受質子 R₂C–O⁻ + H₂O → R₂CHOH + OH⁻

自己畫反應機制

遇到一個新反應，按以下兩步走：

  1. 確定哪些鍵形成、哪些鍵斷裂
  2. 確定哪個分子是親核劑，哪個是親電劑
範例：Ph₃P + MeI（三苯基磷 + 碘甲烷）
Ph₃P + CH₃–I → Ph₃P⊕–CH₃ + I⁻ 分析： • 形成 P–C 新鍵（P 是親核劑，C 是親電中心） • 斷裂 C–I 鍵（I 是離去基） • P 有孤對電子（高能 HOMO）→ P 是親核劑 • CH₃–I 的 C–I σ* 能量低（I 電負）→ CH₃I 是親電劑 彎箭頭1：P 孤對 → C（新 P–C 鍵形成） 彎箭頭2：C–I 鍵中心 → I（C–I 鍵斷裂，I⁻ 離去）

重要警告：碳不能有五個鍵！

B、C、N、O 最多四個鍵

如果你在不帶電的 C（或 H、N、O）上形成新鍵，必須同時斷裂一個既有的鍵——否則碳就有五個鍵（10 個電子），這在 2s/2p 軌域中是不可能的。

錯誤：Ph₃P 直接加到 CH₃I，如果不斷 C–I 鍵，得到五鍵碳 ✗

正確：P 攻擊 C 的同時，C–I 鍵斷裂 ✓

多步驟機制

許多有機反應需要多個步驟才能完成。每一步都是獨立的親核劑–親電劑反應，必須逐步畫出。

氰化物加成到乙醛（多步驟）
反應：CH₃CHO + NaCN → CH₃CH(OH)CN 步驟1：⁻CN 攻擊 C=O 的碳（親核加成） O⊖ CN ⁻CN + CH₃-CHO → CH₃-CH⟨ （烷氧陰離子中間體） | 彎箭頭1：CN⁻ 負電荷 → C（新 C–C 鍵形成） 彎箭頭2：C=O π 鍵 → O（π 鍵斷裂，O 帶負電） 步驟2：O⁻ 從水中摘取質子 ⁻O–CH(CH₃)CN + H₂O → HO–CH(CH₃)CN + OH⁻ 彎箭頭1：O⁻ → H（新 O–H 鍵） 彎箭頭2：O–H 鍵（水）→ O（O–H 斷裂，OH⁻ 離去）
乙醇在酸性條件下形成二乙醚（更複雜的多步驟）

自己畫機制的八步指南

  1. 按 Ch2 的規則畫出清晰的試劑結構（確認溶劑條件：鹼性？酸性？）
  2. 比較起始物與產物：哪些鍵形成了？哪些鍵斷裂了？有無原子加入/離去？
  3. 辨識所有親核中心（孤對、負電荷、π 鍵、電正性 σ 鍵）
  4. 辨識所有親電中心（空軌域、正電荷、C=O π*、C–X σ*）
  5. 組合兩個最可能的中心，畫出彎箭頭（從親核到親電）
  6. 檢查：有無原子超過 4 個鍵？若有，同步斷一個鍵
  7. 寫出步驟產物；驗證電荷守恆；若非最終產物，繼續重複步驟 3–6
  8. 重複直至得到穩定的最終產物

本章總結

核心概念回顧
  • 分子反應需要克服活化能；驅動力包括靜電吸引和軌域重疊
  • 有機反應 = 電子從親核劑（HOMO，高能填充軌域）流向親電劑（LUMO，低能空軌域）
  • 最好的反應：HOMO（親核劑）與 LUMO（親電劑）能量接近
  • 親核劑 HOMO 可以是：孤對電子、負電荷、C=C π 鍵、連電正性原子的 σ 鍵
  • 親電劑 LUMO 可以是：空原子軌域（H⁺、BH₃）、C=O π* 軌域、C–X σ* 軌域
  • 彎箭頭：尾部 = HOMO（電子來源），頭部 = LUMO（電子目的地）；每步電荷守恆
  • C、N、O 最多 4 個鍵——形成新鍵必須同步斷舊鍵
  • 彎箭頭是有機化學最重要的符號工具，貫穿全書所有章節
