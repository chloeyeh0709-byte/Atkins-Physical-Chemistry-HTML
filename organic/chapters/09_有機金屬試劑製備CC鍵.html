第九章：有機金屬試劑製備 C–C 鍵

Clayden's Organic Chemistry, 2nd Edition  ·  Chapter 9: Using Organometallic Reagents to Make C–C Bonds

形成 C–C 鍵是有機合成中最重要的任務之一。有機金屬試劑（organometallic reagents）利用金屬-碳鍵的極性，使碳原子成為親核劑，攻擊羰基碳，實現碳鏈的延長。本章介紹格氏試劑（Grignard reagents）和有機鋰試劑的製備、性質及其在 C–C 鍵形成中的應用。

有機金屬鍵的本質

在有機金屬化合物（R–M）中，碳的電負度（2.5）通常大於金屬（例如 Li 為 1.0，Mg 為 1.2），因此 C–M 鍵中電子雲偏向碳：

δ⁻ δ⁺ R — C — M C 帶部分負電荷，表現為親核劑

有機金屬試劑（RMgX、RLi 等）的 HOMO 本質上是 C 的 sp³ 軌域，指向外側。這使得碳原子具有「類碳負離子」的性質——強親核劑，也是強鹼。

注意：有機金屬試劑對水的敏感性

有機金屬試劑與水（pKa 15.7）或質子性溶劑劇烈反應，因為其共軛鹼（通常是 R–H，pKa ≫ 15.7）比水更弱，反應不可逆。操作必須在無水無氧條件下進行（乾燥 Et₂O 或 THF，氮氣/氬氣保護）。

格氏試劑（Grignard Reagents）

格氏試劑由法國化學家 Victor Grignard 發現（1900年，諾貝爾化學獎 1912年），是鹵代烴與金屬鎂在乾燥乙醚中反應的產物：

R–X + Mg → R–MgX (在 Et₂O 或 THF 中) X = Cl, Br, I R = 烷基、芳基、乙烯基等

反應機制

Mg 插入 R–X 鍵（氧化插入，oxidative insertion）：Mg 將兩個電子給予 R–X，Mg 被氧化（0 → +2），鹵素帶走一個電子，碳帶走另一個：

Mg(0) + R–X → [R• + MgX•] → R–MgX (自由基機制，但整體看是 Mg 嵌入 C–X 鍵)

格氏試劑的性質

  • 溶於醚（Et₂O 的 O 用孤對電子與 Mg 配位）
  • 反應活性：R–I > R–Br > R–Cl > R–F
  • 芳基格氏（ArMgBr）可從芳基溴/碘製備
  • 乙烯基格氏（vinylMgBr）可從乙烯基鹵製備，立體構型保留

有機鋰試劑（Organolithium Reagents）

有機鋰試劑比格氏試劑反應性更強（Li 比 Mg 更電正性，C–Li 鍵更富電子）：

R–X + 2 Li → R–Li + LiX 或：R–MgBr + n-BuLi → R–Li + n-BuMgBr （鹵素-金屬交換，較溫和）

有機鋰作為超強鹼

甲烷的 pKa ≈ 50；苯的 pKa ≈ 43。有機鋰（R–Li 的共軛酸 R–H）是超強鹼，可去質子化幾乎所有含 C–H 的分子：

試劑共軛酸 pKa常用用途
n-BuLi（正丁基鋰）~50鹵素-金屬交換；去質子化末端炔
sec-BuLi（仲丁基鋰）~51位阻較大，選擇性去質子化
t-BuLi（叔丁基鋰）~53最強；不帶 β-H，不與底物進行 E2
LDA（二異丙基醯胺基鋰）~36強位阻鹼，常用於酮的去質子化生成烯醇化物

炔的去質子化

末端炔（R–C≡C–H，pKa 25）可被格氏試劑或有機鋰去質子化，生成炔化物：

CH₃C≡CH + EtMgBr → CH₃C≡CMgBr + EtH 丙炔 丙炔格氏試劑 HC≡CH + NaNH₂ → HC≡C⁻ Na⁺ + NH₃ 乙炔 氨基化鈉 乙炔鈉（炔化鈉）

反應能進行的原因：EtH 的 pKa (~50) > 末端炔 pKa (25)，平衡強烈偏向產物。炔化物 R–C≡C⁻ 是良好的碳親核劑，可攻擊烷基鹵或羰基，實現碳鏈延長。

鹵素-金屬交換反應

芳基鋰試劑（ArLi）可通過格氏試劑與有機鋰的反應（鹵素-金屬交換，halogen-metal exchange）製備：

Ph–Br + n-BuLi → Ph–Li + n-BuBr 驅動力：苯基陰離子（Ph⁻，pKa ~43）比 正丁基陰離子（n-Bu⁻，pKa ~50）更穩定 → 平衡偏向更穩定的碳負離子
交換方向的熱力學規律

鹵素-金屬交換從穩定性較低的碳負離子轉移到穩定性較高的碳負離子。sp² 或 sp 碳的 pKa 比 sp³ 碳低，因此 n-BuLi 可以將 Li 轉移到 Ph–Br 上（Ph–Li 更穩定），而不是反過來。

轉金屬化（Transmetallation）

有機鋰試劑的反應性有時過強，可能與底物中的其他官能基反應。轉金屬化將鋰換成反應性較低的金屬，提高選擇性：

R–MgBr + ZnBr₂ → R–ZnBr + MgBr₂ 格氏試劑 有機鋅試劑（較溫和） 有機鋅可用於鈀催化偶聯反應（Negishi coupling）

有機銅試劑（Gilman 試劑，R₂CuLi）也是轉金屬化的產物：銅試劑對 1,4-共軛加成有選擇性（而非 1,2-加成），在合成中有重要應用。

有機金屬試劑與羰基的反應

有機金屬試劑（RMgX 或 RLi）作為碳親核劑攻擊羰基碳，是形成 C–C 鍵最重要的方法之一：

與醛/酮的反應（親核加成）

格氏試劑 + 醛/酮 → 醇（加 H₂O 後處理） R–MgBr + RCHO → R–CH(OH)–R （二級醇） R–MgBr + R₂CO → R₂C(OH)–R （三級醇） R–MgBr + CH₂O → R–CH₂OH （一級醇，延長一個 C）
醛/酮格氏試劑加成產物醇級數
甲醛（CH₂O）R–CH₂OH一級醇（延長 1C）
醛（RCHO）R'–CH(OH)–R二級醇
酮（R₂CO）R'–C(OH)–R₂三級醇

與 CO₂ 的反應

R–MgBr + CO₂ → R–COO⁻MgBr⁺ ↓ H₂O R–COOH （羧酸，延長一個 C）

格氏試劑與乾冰（CO₂）反應是合成羧酸的便捷方法，碳鏈延長一個碳。

合成醇：逆合成思路（Retrosynthetic Analysis）

在設計合成路線時，逆合成（retrosynthesis）從目標分子出發，逐步分析前體。對於一個醇，可以反向切斷 C–OH 附近的 C–C 鍵，確定需要哪個格氏試劑和哪個羰基：

合成二級醇 Ph–CH(OH)–CH₃

逆合成：切斷 Ph–C 鍵 → 需要 PhMgBr + 乙醛（CH₃CHO）
或：切斷 C–CH₃ → 需要 MeMgBr + 苯甲醛（PhCHO）
兩條路線均可行，選擇取決於原料可得性。

炔雌醇（Ethynyloestradiol）的合成

炔雌醇是口服避孕藥的活性成分。其合成中，乙炔化鋰（HC≡C–Li）加成至雌酮（oestrone，天然雌激素）的 C17 酮基，引入炔基，得到炔雌醇。這是工業上大規模使用有機金屬反應合成藥物的典型例子。

逆合成的核心邏輯

（1）認識目標分子中的「斷裂點」：通常在含氧官能基附近；（2）從較易得的出發物選擇路線；（3）考慮立體選擇性（如果目標分子有手性中心）。

醇的氧化：醛和酮的製備

格氏加成通常給出醇，若需要醛或酮，需要氧化。常用氧化劑：

氧化劑應用說明
PCC（吡啶氯鉻酸，pyridinium chlorochromate）一級醇 → 醛（停在醛）溫和，不再氧化醛為羧酸
PDC（吡啶二鉻酸，pyridinium dichromate）一級醇 → 羧酸（完全氧化）在濕 DMF 中可直接得羧酸
次氯酸（NaOCl/水）一級醇 → 羧酸工業規模，廉價
任何 Cr(VI) 試劑二級醇 → 酮酮不被進一步氧化
Swern 氧化（(COCl)₂, DMSO, Et₃N）一級或二級醇 → 醛/酮室溫以下，不影響敏感官能基
一級醇氧化的選擇性

一級醇（RCH₂OH）被 PCC 氧化停在醛（RCHO）是因為 PCC 在無水條件下操作——醛與 PCC 反應很慢；若有水，醛會水合成偕二醇，再被氧化成羧酸。用 PCC 製醛必須嚴格無水。

本章總結

核心概念回顧
  • C–M 鍵的極性：金屬電正性 → C 帶部分負電荷 → 碳親核劑；對水和質子性溶劑高度敏感
  • 格氏試劑：R–X + Mg(Et₂O) → R–MgX；氧化插入機制；是有機合成最通用的試劑之一
  • 有機鋰：R–X + 2Li → R–Li；或鹵素-金屬交換（需 pKa 熱力學驅動）；比格氏更活潑
  • 炔去質子化：末端炔 pKa 25，可被 EtMgBr 或 n-BuLi 去質子化 → 炔化物（碳親核劑）
  • 轉金屬化：R–MgBr + ZnBr₂ → R–ZnBr（有機鋅，反應性較低，選擇性好）
  • 與羰基的反應：甲醛 → 一級醇；醛 → 二級醇；酮 → 三級醇；CO₂ → 羧酸
  • 逆合成：切斷 C–OH 附近的 C–C 鍵，確定格氏試劑 + 羰基的組合
  • 醇的氧化：PCC → 一級醇停在醛；Cr(VI) → 二級醇得酮；PDC → 羧酸
