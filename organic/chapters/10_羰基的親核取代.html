第十章：羰基的親核取代

Clayden's Organic Chemistry, 2nd Edition  ·  Chapter 10: Nucleophilic Substitution at the Carbonyl Group

第六章學了羰基的親核加成（親核劑加成後留在分子內，無離去基）。本章的羰基親核取代則不同：親核劑加成後，四面體中間體的一個基團作為離去基脫離，最終親核劑「取代」了原來的基團。這是羧酸衍生物（醯氯、酸酐、酯、醯胺等）化學反應的核心機制。

加成 vs 取代：中間體的命運

親核劑攻擊羰基碳後，形成四面體中間體（sp² → sp³）：

O O⁻ O ‖ Nu⁻ | –LG⁻ ‖ R—C—LG → R—C—LG → R—C—Nu | Nu 加成：若 LG 不離去 → 加成產物（Ch6） 取代：若 LG 作為陰離子離去 → 取代產物（本章）

區別的關鍵是離去基（LG）的性質——LG 必須是能以穩定陰離子形式離去的基團。

離去基：pKa 決定離去能力

離去基 LG⁻ 的穩定性由其共軛酸 HLG 的 pKa 決定：pKa 越低，LG⁻ 越穩定，越容易離去。

離去基（LG⁻）共軛酸（HLG）HLG pKa離去能力
Cl⁻HCl−7極佳（excellent）
RCO₂⁻（羧酸根）RCOOH~5好（good）
RO⁻（烷氧化物）ROH~15差（poor）→ 需要酸催化
NH₂⁻（醯胺基）NH₃~35極差，難以離去
pKa 規則

若產物的共軛酸 pKa > 起始物，則反應在熱力學上有利（離去基穩定，親核劑不穩定）；反之亦然。酯（LG = OR⁻）水解的熱力學利於羧酸（生成 OH⁻ + RCOOH → RCOO⁻ + H₂O），但動力學上需要催化。

羧酸衍生物的反應性順序

四種主要羧酸衍生物的反應活性由高到低：

醯氯 > 酸酐 > 酯 > 醯胺 (acyl (anhydride) (ester) (amide) chloride) 最活潑 最不活潑

反應性降低的原因：

  • 醯氯：Cl⁻ 是最好的離去基（HCl pKa −7），且 Cl 的 p 軌域與 C=O π* 共軛較弱（原子大小不匹配）
  • 酸酐：RCO₂⁻ 是好的離去基（RCOOH pKa ~5）
  • 酯：RO⁻ 是差的離去基（ROH pKa ~15）；需要催化才能反應
  • 醯胺：NH₂⁻ 是極差的離去基（NH₃ pKa ~35）；N 的孤對電子與 C=O 共軛大大穩定了醯胺，使 C 的親電性降低
離域化與反應性的關係

醯胺中，N 的孤對電子與 C=O π* 共軛（N sp² 雜化），這使得羰基碳的正電性降低（部分電子由 N 流入），親電性下降，同時 NH₂⁻ 是很差的離去基。兩個因素合起來使醯胺是羧酸衍生物中最不活潑的。

四面體中間體的機制

以醯氯與醇的反應為例，詳細機制：

步驟 1（親核加成）： ROH + R'COCl → R'C(OH)(OR)(Cl) ← 四面體中間體（帶 OH, OR, Cl 三個取代基） 步驟 2（鹼去質子）： 四面體中間體 → 去掉 H⁺ 形成 R'C(O⁻)(OR)(Cl) 步驟 3（離去基離去）： R'C(O⁻)(OR)(Cl) → R'CO(OR) + Cl⁻ （C=O 重新形成，Cl⁻ 離去） 整體：R'COCl + ROH → R'COOR + HCl

反應是加成-消除（addition-elimination）機制，不是同時進行的協同反應。四面體中間體是真實的中間體（可通過 NMR 在低溫下檢測到）。

醯氯的反應

醯氯（R–COCl）是最活潑的羧酸衍生物，幾乎能與所有親核劑反應：

親核劑產物說明
H₂O（水）R–COOH（羧酸）醯氯遇水激烈水解
ROH（醇）R–COOR'（酯）需要鹼（Et₃N）中和 HCl
R'NH₂（伯胺）R–CONHR'（醯胺）需 2 equiv 胺（一個反應，一個中和 HCl）
R'₂NH（仲胺）R–CONR'₂（N,N-二取代醯胺）同上
NH₃（氨）R–CONH₂（伯醯胺）需 2 equiv NH₃
Schotten-Baumann 合成

醯氯與胺的反應常用 Schotten-Baumann 條件：兩相體系（CH₂Cl₂/NaOH 水溶液）。醯氯在有機相，胺在水相界面反應；NaOH 中和生成的 HCl，防止胺被質子化（質子化胺不具親核性）。這是工業和實驗室製備醯胺和酯的常用方法。

酯的反應——轉酯化與氨解

酯的氨解（aminolysis）

酯與氨（或胺）反應，NH₃（NH₂⁻，pKa ~35）作為親核劑攻擊酯，RO⁻（pKa ~15）比 NH₂⁻ 更穩定，因此 RO⁻ 作為離去基：

R–COOR' + NH₃ → R–CONH₂ + R'OH 酯 醯胺（伯） 此反應單向：RO⁻ (pKa 15) < NH₂⁻ (pKa 35) → 酯可以被胺所取代，但醯胺不能被醇取代（逆反應不利）

轉酯化（transesterification）

酯在酸催化或鹼催化下可以交換醇基：

R–COOR¹ + R²OH ⇌ R–COOR² + R¹OH （可逆！需要使用過量的一種醇，或蒸去另一種醇以驅動平衡）
生物柴油的製備

生物柴油是植物油（甘油三酯）在甲醇和 NaOH 催化下的轉酯化產物。甘油（glycerol）作為離去基，三個脂肪酸甲酯（FAME）即為生物柴油。這是工業規模最大的轉酯化應用。

酸催化酯化

羧酸和醇在無催化劑時反應非常慢（RO⁻ 是差的離去基）。酸催化將羰基質子化，大大增強親電性：

H⁺ R–COOH → R–C(⁺OH)–OH （質子化羰基，強親電劑） ↓ + R'OH（親核劑） 四面體中間體（R–C(OH)₂–OR'） ↓ –H⁺（質子移動） ↓ –H₂O（水離去） R–COOR'
費歇爾酯化（Fischer Esterification）

羧酸 + 醇 + 酸催化劑（H₂SO₄ 或 p-TsOH）→ 酯 + 水。平衡常數 K ≈ 1，需要：（1）過量一種反應物（通常過量醇），或（2）除去水（加 CaCl₂ 或分子篩，或迪安-斯塔克裝置蒸去水）來驅動反應完全。

皂化反應——酯的鹼催化水解

酯在 NaOH 水溶液中水解（皂化，saponification）是不可逆的：

R–COOR' + NaOH → R–COO⁻ Na⁺ + R'OH 酯 羧酸鈉（鹽） HO⁻ 攻擊酯羰基 → 四面體中間體 → R'O⁻ 離去 羧酸鈉（共軛鹼）是穩定的，不被再度酯化 → 反應不可逆（不同於酸催化，後者可逆）

肥皂的製造即是植物油脂（長鏈脂肪酸甘油酯）與 NaOH 的皂化反應，生成長鏈脂肪酸鈉（肥皂）和甘油。

酸催化（可逆）vs 鹼催化（不可逆）

酸催化水解：H⁺ 催化，產物是羧酸 + 醇，平衡可逆（K ~1）；用水過量或除去醇可以推動。
鹼催化水解（皂化）：HO⁻ 作為親核劑，產物是羧酸根（鹽），不能再被醇取代；不可逆，收率通常高。

醯胺的水解——需要強烈條件

醯胺是最不活潑的羧酸衍生物，水解需要非常強烈的條件：

R–CONH₂ + H₂O → R–COOH + NH₃ （酸/鹼催化，需回流數小時） 典型條件： （1）70% H₂SO₄，100°C，數小時 （2）濃 NaOH，回流 （3）酶（amidase，生物學條件）

醯胺難以水解的原因：

  • N 的孤對電子與 C=O 共軛（delocalization）→ 羰基碳親電性降低
  • NH₂⁻ 是極差的離去基（NH₃ pKa ~35）→ 中間體崩潰困難
蛋白質水解的重要性

蛋白質是由肽鍵（–CO–NH–，即醯胺鍵）連接的氨基酸鏈。醯胺鍵的穩定性使蛋白質在水溶液中可以長期穩定存在（生物降解需要蛋白酶）。若醯胺鍵容易水解，生命將無法存在。

腈的水解

腈（R–C≡N）是另一類含羰基碳的活性物，可以逐步水解：

R–C≡N + H₂O → R–C(=NH)–OH → R–CONH₂ → R–COOH 腈 (酸催化) 亞胺酸（中間體） 醯胺（可分離） 羧酸 控制條件可停在醯胺（半水解）或繼續至羧酸（全水解）

腈可由以下方式製備：R–X + NaCN → R–CN（SN2，碳鏈延長 1C）；醯胺脫水 → 腈。

醯氯的合成——活化羧酸

羧酸直接與醇反應困難，需要先將羧酸活化為醯氯（最活潑的衍生物）：

試劑反應副產物
SOCl₂（亞硫醯氯，thionyl chloride）RCOOH + SOCl₂ → RCOCl + SO₂ + HClSO₂ 和 HCl 均為氣體，容易除去
PCl₅（五氯化磷）RCOOH + PCl₅ → RCOCl + POCl₃ + HClPOCl₃ 需蒸餾除去
草醯氯（(COCl)₂）RCOOH + (COCl)₂ → RCOCl + CO + CO₂ + HCl氣體副產物易除，但需催化
SOCl₂ 的優勢

SOCl₂ 是最常用的羧酸 → 醯氯試劑，因為副產物（SO₂ 和 HCl）都是氣體，反應結束後直接從反應混合物中逸出，純化簡單。加入少量 DMF 可以加速反應（Vilsmeier 型催化）。

格氏試劑與酯——過度反應問題

嘗試用格氏試劑將酯轉化為酮時，存在「過度反應」問題：

R¹–COOR + R²MgBr → R¹–CO–R² （酮，中間體） ↓ + R²MgBr（格氏試劑繼續攻擊！） R¹–C(R²)₂–OH （三級醇） 問題：酮的反應性 > 酯的反應性，所以格氏試劑 會先消耗酯，生成酮，酮立刻被第二當量的格氏試劑取代 → 最終得到三級醇，而不是酮（即便酯只加 1 equiv 格氏）
解決方案：Weinreb 醯胺

為了從有機金屬試劑製備酮，使用 Weinreb 醯胺（N-甲氧基-N-甲基醯胺）。Weinreb 醯胺與格氏試劑或有機鋰反應後，生成一個穩定的螯合四面體中間體（N-Me 和 O 與 Mg 螯合），阻止酮離去直到水解。後處理時，酮被釋放，且不再受格氏試劑攻擊（已用完）。

紅外光譜（IR）鑑定羧酸衍生物

C=O 的 IR 伸縮振動（ν C=O）是鑑定羰基的最直接方法，不同衍生物有特徵頻率：

化合物類型ν C=O（cm⁻¹）說明
醯氯（acyl chloride）1790–1815最高頻率；Cl 吸電子，C=O 鍵強
酸酐（anhydride）1800 和 1750（兩個峰）不對稱/對稱伸縮耦合，特徵雙峰
酯（ester）1735–1750比醯氯低；OR 給電子少
羧酸（carboxylic acid）1710–1725廣泛的 O–H 吸收（2500–3300 cm⁻¹）
醯胺（amide）1680–1690最低頻率；N 孤對電子共軛，C=O 鍵弱
頻率規律的解釋

C=O 的伸縮頻率反映 C=O 鍵的強度（鍵越強，頻率越高）：
（1）離域化削弱 C=O 鍵 → N 的孤對電子共軛最強，醯胺頻率最低
（2）吸電子基增強 C=O 鍵 → Cl 拉電子，醯氯頻率最高
（3）OR 有中等的共軛效應 → 酯頻率居中

本章總結

核心概念回顧
  • 加成 vs 取代：四面體中間體若有合適的離去基（LG⁻），則 LG⁻ 離去，恢復 C=O，完成取代；否則質子化得到加成產物
  • 離去基能力：由 HLG 的 pKa 決定；pKa 越低，LG⁻ 越穩定，越容易離去：Cl⁻ > RCO₂⁻ > RO⁻ ≫ NH₂⁻
  • 反應性順序：醯氯 > 酸酐 > 酯 > 醯胺；可以從高活性轉化到低活性，反之不行（或需強條件）
  • 酸催化：質子化羰基氧 → 增強親電性；酯化反應可逆（K ~1），需過量醇或除水
  • 鹼催化：HO⁻ 作親核劑；皂化不可逆（生成羧酸根鹽）
  • 醯胺水解：需強酸或強鹼加熱；穩定性是蛋白質存在的基礎
  • SOCl₂：羧酸 → 醯氯；副產物 SO₂ 和 HCl 均為氣體，純化方便
  • Weinreb 醯胺：解決格氏試劑 + 酯 = 三級醇的問題；通過螯合固定四面體中間體，水解後得酮
  • IR 特徵：ν C=O 頻率：醯氯（~1800）> 酸酐（雙峰）> 酯（~1740）> 羧酸（~1715）> 醯胺（~1685）
