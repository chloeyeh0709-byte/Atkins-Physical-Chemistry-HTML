第11章 羰基氧的親核取代

Nucleophilic Substitution at C=O with Loss of Carbonyl Oxygen

加成-消除機制概覽

在第六章中，我們討論了親核加成至羰基（Nu 攻擊後 O 保持），而本章的關鍵區別在於：親核劑攻擊後，羰基的氧原子以離去基的形式離開，形成新的雙鍵或杂原子取代物。

整體機制為加成再消除（addition-then-elimination）：

C=O + Nu-H → [加成中間體：C(OH)(NuH)] → C=Nu + H₂O
關鍵規則：這類反應只在酸催化條件下進行（將 OH 轉化為良好的離去基 H₂O⁺）；鹼催化無法協助消除水。

參與反應的親核劑通常帶有孤對電子的 N 或 O 原子，且它們本身也可作為離去基（pKₐ 足夠低，使對應的中性分子可以被消除）。

半縮醛與縮醛的生成

步驟一：半縮醛（Hemiacetal）

醇在酸或鹼催化下對醛或酮進行親核加成，生成半縮醛（hemiacetal）。平衡偏向醛側（K < 1），除非生成穩定的環狀結構。

R-CHO + R'OH ⇌ R-CH(OH)(OR') 半縮醛

步驟二：縮醛（Acetal）— 僅酸催化

在酸催化下，半縮醛的 OH 被質子化為氧鎓離子（oxonium ion），成為好的離去基，然後另一個醇分子進行 SN1 型取代，生成縮醛（acetal）。

R-CH(OH)(OR') + H⁺ → R-CH(OH₂⁺)(OR') ↓ -H₂O（SN1） R-CH⁺(OR') ↓ + R'OH, -H⁺ R-CH(OR')₂ 縮醛
為何只有酸催化？
消除 OH 需要先將其質子化為 H₂O（pKₐ = −1.7），使之成為好的離去基。鹼無法催化此步驟，因為 OH⁻ 的 pKₐ 約 15.7，是極差的離去基。

縮醛的穩定性

縮醛在中性或鹼性條件下穩定（不受親核劑攻擊），但在酸性水溶液中可水解回到醛和醇。這使得縮醛成為重要的保護基。

化合物條件穩定性
醛/酮─可被親核劑攻擊
半縮醛平衡通常不穩定，環狀除外
縮醛中性、鹼性穩定；酸性水溶液中水解

環狀縮醛與保護基策略

環狀縮醛的優勢

使用二醇（如乙二醇）與醛/酮反應，生成五員環狀縮醛（1,3-二氧戊環）。環狀縮醛比鏈狀縮醛更穩定，因熵利於（兩分子→一分子＋一分子水）且環應變較小。

R₂C=O + HOCH₂CH₂OH ⇌ [環狀縮醛] + H₂O (乙二醇) 1,3-二氧戊環

保護基策略

在多步合成中，若只想對分子中某一羰基進行反應，可先將另一個保護為縮醛：

  1. 用乙二醇在酸催化下保護目標羰基 → 縮醛
  2. 對其他官能基進行所需反應
  3. 酸性水溶液水解，去保護，恢復羰基
範例：分子中含有醛和酮，若只想還原酮，先將醛保護為縮醛，還原酮後，再水解去保護醛。

亞胺與烯胺的生成

亞胺（Imine）—— 以伯胺（R-NH₂）生成

伯胺與醛/酮在酸催化下先生成甲醇胺（hemiaminal），再消除水生成亞胺（Schiff鹼，C=N）。pH 需控制：過酸則胺被質子化而活性降低；過鹼則水不易消除。

R₂C=O + H₂N-R' → R₂C(OH)(NHR') → R₂C=N-R' + H₂O 甲醇胺（hemiaminal） 亞胺（imine）

烯胺（Enamine）—— 以仲胺（R₂NH）生成

仲胺與醛/酮反應，甲醇胺中間體無法消除 NH 形成亞胺（N 無孤 H），而是脫去 α-碳的氫，生成烯胺（enamine）。

R₂C=O + HN(R')₂ → R₂C(OH)[N(R')₂] → RC=CH + H₂O 甲醇胺 烯胺（C=C-N）
亞胺 vs 烯胺：
  • 伯胺（一個 N-H）→ 生成亞胺（C=N）
  • 仲胺（無 N-H）→ 生成烯胺（C=C-NR₂）

亞胺鎓離子（Iminium Ion）

烯胺在酸中質子化 α 碳，生成亞胺鎓離子（C⁺=N），為重要的親電性中間體，可與親核劑反應。

含氮衍生物：肟、腙、縮胺脲

多種含氮親核劑可與羰基反應，產物均為類亞胺的 C=N 化合物，穩定且可結晶，常用於鑑定醛酮。

試劑產物名稱結構
羥胺（NH₂OH）肟（Oxime）R₂C=N-OH
苯肼（PhNHNH₂）苯腙（Phenylhydrazone）R₂C=N-NHPh
2,4-二硝基苯肼2,4-DNP 衍生物（橙色晶體）R₂C=N-NHAr
縮胺脲（NH₂NHCONH₂）縮胺脲（Semicarbazone）R₂C=N-NHCONH₂
2,4-DNP 測試（Brady's Test）：醛酮加入 2,4-二硝基苯肼試劑，若出現橙黃色沉澱，代表含有羰基（C=O）。

還原胺化與Strecker合成

還原胺化（Reductive Amination）

醛/酮與胺生成亞胺（或亞胺鎓離子），再用NaCNBH₃（氰基硼氫化鈉）選擇性還原 C=N 為 C-N，直接生成胺。

R₂C=O + R'NH₂ → R₂C=N-R' → R₂CH-NH-R' 亞胺 NaCNBH₃ 胺
為何選用 NaCNBH₃ 而非 NaBH₄？
NaCNBH₃ 在 pH 6–7 的弱酸性條件下選擇性還原亞胺鎓離子，不還原未反應的醛/酮（後者需要 pH < 3 才被還原），避免醛酮被還原為醇的副反應。

Strecker合成（合成α-胺基酸）

Strecker 合成是以醛為起點，經氰化氫加成和水解，一步得到 α-胺基酸外消旋混合物。

R-CHO + NH₃ → R-CH(OH)(NH₂) → R-CH(NH₂)(CN) → R-CH(NH₂)(COOH) 甲醇胺 HCN H₂O/H⁺ α-胺基腈 α-胺基酸（外消旋）

LiAlH₄ 還原醯胺

LiAlH₄（四氫化鋁鋰）可直接還原醯胺（R-CO-NR₂）為相應的胺（R-CH₂-NR₂），是合成胺的重要方法。

R-CO-NHR' →[1. LiAlH₄]→ R-CH₂-NHR' [2. H₂O]

Wittig反應

原理與試劑

Wittig 反應用磷葉立德（phosphonium ylide，Ph₃P⁺-CH⁻R）與醛/酮反應，以C=C 取代原來的 C=O，生成烯烴和三苯基氧化膦（Ph₃P=O）。

Ph₃P=CH-R + R'₂C=O → R'₂C=CH-R + Ph₃P=O (磷葉立德) (烯烴) (副產物)

葉立德的製備

Ph₃P + R-CH₂X → [Ph₃P-CH₂R]⁺X⁻ → Ph₃P=CHR 三苯基膦 烷基鹵 磷鎓鹽 葉立德（強鹼去質子）

Wittig反應的立體化學

穩定化葉立德（含有 EWG 如 CO₂Et）通常給出 trans（E）烯烴，非穩定化葉立德傾向給出 cis（Z）烯烴。Horner-Wadsworth-Emmons（HWE）改良版（使用磷酸酯葉立德）選擇性更高。

機制

葉立德的碳原子（C⁻）攻擊羰基碳，形成氧磷環丁烷（oxaphosphetane）四員環中間體，再消除生成烯烴和 Ph₃P=O。此步骤稱為逆 [2+2] 反應。

Ph₃P=CHR + R'₂C=O → [四員環中間體] → R'₂C=CHR + Ph₃P=O 氧磷環丁烷
第11章重點回顧
  • 縮醛生成需酸催化（將 OH 活化為離去基）；鹼不能催化
  • 縮醛在中性/鹼性中穩定，酸性水中水解 → 重要保護基
  • 環狀縮醛（乙二醇保護）比鏈狀縮醛更穩定
  • 伯胺 + 羰基 → 亞胺；仲胺 + 羰基 → 烯胺
  • NH₂OH → 肟；PhNHNH₂ → 腙；NH₂NHCONH₂ → 縮胺脲
  • 還原胺化：亞胺 + NaCNBH₃ → 胺（溫和選擇性還原）
  • Strecker 合成：醛 + NH₃ + HCN → α-胺基酸（外消旋）
  • Wittig 反應：Ph₃P=CHR + C=O → C=C（以烯烴取代羰基）
