第十二章

平衡、速率與機制

Equilibria, rates and mechanisms

12.1 熱力學控制 vs 動力學控制

有機反應常能形成多種可能的產物。哪種產物主導，取決於反應條件：熱力學控制讓最穩定的產物累積；動力學控制讓活化能最低的產物佔優勢。

  • 熱力學控制：反應可逆；長時間或高溫下，最穩定的產物（ΔG° 最低）比例最大。
  • 動力學控制：低溫、短時間，活化能（Ea）最小的產物先累積，不一定是最穩定的。

範例：1,3-丁二烯與 HBr 加成

CH₂=CH-CH=CH₂ + HBr 低溫 (–80 °C)：動力學控制 → CH₃-CHBr-CH=CH₂ (1,2-加成，~80%) 高溫 (40 °C)：熱力學控制 → CH₃-CH=CH-CH₂Br (1,4-加成，~80%)

中間體為共振穩定的烯丙基碳陽離子。低溫下 Br⁻ 攻擊近端碳（1,2）；高溫下可逆，最終由熱力學較穩定的 1,4-加成產物主導。

判斷要點

  • 低溫、短時間、不可逆條件 → 動力學控制
  • 高溫、長時間、可逆條件 → 熱力學控制
  • 若動力學最快產物 ＝ 熱力學最穩定產物，則兩種控制給出相同結果

12.2 Gibbs 自由能與平衡

反應方向和平衡位置由 Gibbs 自由能 ΔG° 決定：

ΔG° = ΔH° − TΔS°
ΔG° = −RT ln K

其中 K 為平衡常數，R = 8.314 J mol⁻¹ K⁻¹，T 為絕對溫度。

  • ΔG° < 0：反應自發，K > 1，產物占優
  • ΔG° > 0：反應不自發，K < 1，反應物占優
  • ΔG° = 0：K = 1，反應物與產物各半

溫度對平衡的影響

由 ΔG° = ΔH° − TΔS° 可知：

  • 放熱反應（ΔH° < 0）：升溫使 −TΔS° 項貢獻增大，若 ΔS° < 0 則升溫不利產物；若 ΔS° > 0 效果視大小而定。
  • 吸熱反應（ΔH° > 0）：升溫使 ΔG° 降低（若 ΔS° > 0），有利反應。

消去 vs 取代的溫度效應

消去反應產生多個分子（氣態烯烴），ΔS° > 0；取代反應 ΔS° 接近零。升溫有利消去（−TΔS° 對 ΔG° 的貢獻更顯著），這是高溫傾向消去的熱力學根據。

平衡常數 K 的計算

K = [products]/[reactants] (適用於稀溶液)

12.3 速率方程式

反應速率以速率定律描述，速率依賴於反應物濃度和速率常數 k：

速率 = k[A]ᵐ[B]ⁿ （m, n 為反應級數，由實驗決定）

常見反應級數

  • 一級（First order）：速率 = k[A]，半衰期 t₁/₂ = ln2/k，與[A]無關
  • 二級（Second order）：速率 = k[A][B] 或 k[A]²
  • 偽一級（Pseudo first-order）：當[B]大量過量時，k[A][B] ≈ k'[A]（k' = k[B]為表觀速率常數）

SN1 vs SN2 的速率差異

SN2（雙分子，二級）： 速率 = k₂[RX][Nu⁻] 機制：一步協同，Nu⁻ 在背面攻擊的同時 X 離去 SN1（單分子，一級）： 速率 = k₁[RX] （與 Nu⁻ 濃度無關） 機制：RX 先形成碳陽離子（慢步驟），然後 Nu⁻ 快速攻擊

速率決定步驟

多步反應中，速率決定步驟（rate-determining step）是最慢的一步，其前的步驟在速率決定步驟的時間尺度上已達到平衡（前平衡假設）。

前平衡假設（Pre-equilibrium）

若第一步快速可逆（K₁），第二步緩慢（k₂），則：

A ⇌ B (K₁ = k₁/k₋₁) B → C (k₂，速率決定步驟) 觀測速率 = k₂ × K₁ × [A] = k_obs[A]

Arrhenius 方程式

速率常數 k 與溫度的關係：

k = A × exp(−Ea/RT) 或 ln k = ln A − Ea/RT

Ea 為活化能，A 為指前因子（頻率因子）。升溫使 k 增大，反應加速。

12.4 能量圖與過渡態

反應能量圖（energy profile）描述反應沿反應座標（reaction coordinate）的位能變化。

關鍵特徵

  • 過渡態（Transition state，TS）：能量最高點，是不穩定的極大值，不能被分離。用 ‡ 標記（如 ΔG‡）。
  • 中間體（Intermediate）：能量的局部極小值，比過渡態穩定，原則上可分離（但通常壽命短）。
  • 活化能 Ea（ΔG‡）：反應物到過渡態的能量差；越低，反應越快。
  • 反應焓 ΔH（ΔG°）：反應物到產物的能量差；決定平衡位置。

過渡態 vs 中間體的辨別

特徵過渡態中間體
能量圖局部最高點（極大值）局部最低點（極小值）
壽命無（約 10⁻¹³ s，振動時間尺度）短暫（可偵測）
可分離性不可理論上可（通常困難）
典型例子SN2 的五配位碳SN1 的碳陽離子

多步反應的能量圖

多步反應在能量圖上出現多個極大值（每步一個 TS）和中間體（極小值）。速率決定步驟對應最高的活化能屏障。

12.5 Hammond 假說

Hammond 假說（Hammond postulate，1955）提供過渡態結構的洞見：

Hammond 假說陳述

若兩個相鄰的物種在反應座標上能量相近，它們的結構也相近。

  • 放熱步驟：過渡態能量接近反應物 → TS 結構類似反應物（early TS）
  • 吸熱步驟：過渡態能量接近產物 → TS 結構類似產物（late TS）

實際應用

對 SN1 中碳陽離子的形成（吸熱步驟）：TS 類似碳陽離子。因此，任何穩定碳陽離子的因素（超共軛、共振、溶劑化）也穩定 TS，降低 Ea，加快反應。

親電加成的 Hammond 分析

烯烴 + H⁺ → 碳陽離子（吸熱，late TS） Markovnikov 規則：H⁺ 加到較少取代的碳 → 形成較穩定的三級碳陽離子（TS 似碳陽離子） → 較低 TS 能量，較快反應 反 Markovnikov 方向：形成較不穩定的一級碳陽離子 → 較高 TS 能量，較慢

12.6 酸鹼催化

催化劑提供活化能較低的替代路徑，加速反應但不改變平衡位置（不影響 ΔG°）。

廣義酸催化（General acid catalysis）

任何質子供體（不限於 H₃O⁺）都能催化反應：

HA + 底物 → HA-底物複合物 → 產物 + A⁻

速率 = k[底物][HA]，多種酸同時存在時速率加成（Brønsted 酸催化）。

廣義鹼催化（General base catalysis）

任何質子受體都能催化：

B + 底物-H → [BH⁺...底物⁻]‡ → BH⁺ + 產物

特定酸/鹼催化 vs 廣義酸/鹼催化

類型催化劑速率依賴
特定酸催化僅 H⁺（H₃O⁺）k[S][H⁺]
廣義酸催化任何酸 HAk[S][HA]
特定鹼催化僅 OH⁻k[S][OH⁻]
廣義鹼催化任何鹼 Bk[S][B]

酵素與緩衝液的角色

生物體中許多酵素同時提供廣義酸（His-H⁺、Tyr-OH）和廣義鹼（His、Asp⁻），在近中性 pH 實現高效率催化。緩衝液中改變緩衝劑濃度而維持 pH 不變，可以區分廣義催化 vs 特定催化。

12.7 Curtin-Hammett 原理

當底物存在兩種可快速互換的構形（如可旋轉的單鍵），且各自通過不同 TS 反應時，產物比例不由構形比例決定，而是由兩條路徑的 ΔΔG‡ 決定。

Curtin-Hammett 原理

設 A 和 B 為兩個快速平衡的構形異構物，分別以速率常數 k_A 和 k_B 反應生成 P 和 Q：

k_A A ----→ P | K_eq（快速） | B ----→ Q k_B 產物比 [P]/[Q] = (k_A/k_B) × K_eq

即使 B（低能構形）遠多於 A（高能構形），只要從 A 到 TS_A 的絕對能量低於從 B 到 TS_B 的絕對能量，P 仍是主要產物。

實際意義

  • 不能僅從分子模型或構形比例預測立體選擇性，必須知道各 TS 的能量。
  • 在鏈狀分子、環的翻轉等情況均適用。
  • 解釋了某些反應為何從「不穩定」構形反應效率更高。

應用：含氮化合物的反應立體選擇性

手性胺的 N-烷化或 N-氧化：氮的快速翻轉（氮反轉，N-inversion）使兩種構形快速平衡，產物比由 TS 能量差決定，而非由平衡構形比例預測。

第12章 核心概念

  • 動力學控制：快速、低溫、不可逆 → 活化能最低的產物
  • 熱力學控制：緩慢、高溫、可逆 → 最穩定的產物
  • ΔG° = ΔH° − TΔS°；ΔG° = −RT ln K
  • 速率定律：由實驗決定級數；一級 t₁/₂ = ln2/k
  • 過渡態（TS）：能量極大，不能分離；中間體：能量極小，原則上可分離
  • Hammond 假說：放熱步驟 → early TS（像反應物）；吸熱步驟 → late TS（像產物）
  • 酸鹼催化：提供替代路徑，降低 Ea，不改變 ΔG°
  • Curtin-Hammett 原理：快速平衡構形的產物比由 ΔΔG‡ 決定，非構形比
