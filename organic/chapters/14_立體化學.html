第14章 立體化學

Stereochemistry

手性與鏡像異構物

若一個分子與其鏡像不可重疊（non-superimposable），則稱此分子具有手性（chirality），如同左右手。具有手性的分子稱為手性分子（chiral molecule）。

一對互為鏡像卻不可重疊的分子稱為鏡像異構物（enantiomers）。

手性的來源：最常見的情況是碳原子連接四個不同的取代基，稱為立體中心（stereogenic centre）或手性碳（chiral carbon）。但手性也可由軸（axis）或平面（plane）產生，無需立體中心。

自然界中的手性非常普遍：氨基酸幾乎全是 L 型，糖幾乎全是 D 型。兩個鏡像異構物的所有物理和化學性質完全相同，除了：（1）旋光方向相反；（2）與其他手性物質反應的速率不同。

立體中心的辨認

要辨認立體中心，尋找連接四個不同取代基的 sp³ 碳。

辨認練習：
  • 乙醇（CH₃CH₂OH）：無，因為 CH₂ 連有兩個 H
  • 丙醇（CH₃CH(OH)CH₃）：無，因為中間 C 的兩個 CH₃ 相同
  • 乳酸（CH₃CH(OH)COOH）：有，C2 連接 CH₃、OH、COOH、H — 全不同
  • 葡萄糖：有四個立體中心（C2、C3、C4、C5）

若分子含有 n 個不同的立體中心，最多有 2ⁿ 個立體異構物（但對稱性可能使實際數目更少）。

R/S 命名法（CIP 優先規則）

由 Cahn、Ingold、Prelog 制定的CIP 優先順序規則，用於指定每個立體中心的絕對構型為 R 或 S。

CIP 優先順序的四個規則

  1. 原子序越大優先：直接連接立體中心的原子，原子序越大則優先（I > Br > Cl > O > N > C > H）
  2. 相同原子則比下一層：若第一層相同，依次比較下一個原子直到有區別
  3. 雙鍵/三鍵展開：C=O 視為 C 連 (O)(O)；C=C 視為 C 連 (C)(C)；C≡C 視為 C 連 (C)(C)(C)
  4. 同位素：質量數大的優先（D > H）

指定 R 或 S

  1. 依 CIP 規則排列四個取代基優先順序：1 > 2 > 3 > 4
  2. 將優先順序最低的基團（4）指向遠離觀察者（放在後方）
  3. 觀察 1→2→3 的旋轉方向：順時針 = R（Rectus）；逆時針 = S（Sinister）
技巧：若最低優先基（通常是 H）在前方（楔形鍵），則最終結果取反：若看到順時針旋轉應為 S，逆時針為 R。

費雪投影（Fischer Projection）中的 R/S

費雪投影中，水平鍵指向觀察者（向前），垂直鍵指向後方。若最低優先基在垂直鍵上（如 H 在上或下），觀察 1→2→3 旋轉方向不用取反；若最低優先基在水平鍵（向前），則取反。

旋光性與比旋光度

手性分子能旋轉平面偏振光的偏振方向，此性質稱為旋光性（optical activity）。

  • (+) 或 d（dextrorotatory）：旋轉方向為順時針（右旋）
  • (−) 或 l（levorotatory）：旋轉方向為逆時針（左旋）
重要區別：R/S 是絕對構型（absolute configuration），由 CIP 規則決定；(+)/(−) 是旋光方向（optical rotation），由實驗測定。兩者之間沒有簡單的對應關係——R 構型不一定是右旋！

比旋光度（Specific Optical Rotation）

標準化的旋光測量值：

[α]²⁰_D = 測量旋光度（α°） / (濃度 c(g/mL) × 管長 l(dm))

一對鏡像異構物的比旋光度大小相等、符號相反：(R)-乳酸 [α] = +3.8°，(S)-乳酸 [α] = −3.8°。

外消旋混合物（racemic mixture, ±）：等量的兩個鏡像異構物混合，旋光度互相抵消，[α] = 0，無旋光活性。

D/L 命名法

D/L 命名法主要用於氨基酸和糖類，以甘油醛（glyceraldehyde）為參考標準（費雪投影）：

  • D-甘油醛：費雪投影中 OH 在右側（(+)-甘油醛，[α] = +13.5°）
  • L-甘油醛：費雪投影中 OH 在左側（(−)-甘油醛）

氨基酸費雪投影中，NH₂ 在右 → D 型；NH₂ 在左 → L 型。自然界中蛋白質氨基酸幾乎全是 L 型。

D/L 與 R/S 無直接對應：D-甘油醛是 R 構型；L-甘油醛是 S 構型。但 D-絲氨酸（D-serine）是 L 構型（因取代基不同改變了 CIP 優先順序）。

非鏡像異構物與內消旋化合物

非鏡像異構物（Diastereoisomers）

含有2個或以上立體中心的分子，不是鏡像關係的立體異構物，稱為非鏡像異構物。它們具有不同的物理化學性質（沸點、熔點、溶解度等），可用色譜法分離。

酒石酸的四個「立體異構物」：
(R,R)-酒石酸；(S,S)-酒石酸（互為鏡像異構物）；meso-酒石酸（內消旋）

內消旋化合物（Meso Compounds）

含有立體中心，但因分子具有對稱面（plane of symmetry）或對稱中心，使整體分子與其鏡像完全重疊 → 為非手性（achiral）化合物，無旋光活性。

内消旋酒石酸：(2R,3S)-酒石酸含有一個對稱面，雖然兩個碳都是立體中心，但整體分子無手性，[α] = 0。

阻轉異構物（Atropisomers）

某些分子即使沒有立體碳，也可因旋轉受阻（restricted rotation）而產生手性。典型例子是聯萘（BINAP）等聯苯類化合物，兩個芳環之間的旋轉受到鄰位取代基的空間阻礙。

BINAP（2,2'-雙（二苯基膦）-1,1'-聯萘）是重要的手性配體，廣泛用於不對稱催化。其 (R)- 和 (S)-BINAP 形成穩定的阻轉異構物，因單鍵旋轉需克服很高的能障。

阻轉異構物可透過手性 HPLC 分離；高溫下旋轉能障降低，異構物可互相轉化（消旋化）。

對稱性分析

以對稱性判斷分子是否為手性：

手性的對稱性條件：
  • 具有對稱面（plane of symmetry）或對稱中心（centre of symmetry）的分子 → 非手性（achiral）
  • 只有旋轉軸（axis of symmetry）（無對稱面或對稱中心）的分子 → 手性

這解釋了為何有些含立體中心的分子（如 meso 化合物）無手性——它們具有對稱面；而某些無立體中心的分子（阻轉異構物、螺環化合物）卻具有手性。

對稱元素結論
有對稱面（σ）非手性（achiral）
有對稱中心（i）非手性（achiral）
只有 Cn 旋轉軸手性（chiral）
C₁ 無任何對稱手性（chiral）

外消旋混合物的拆分（Resolution）

化學合成通常產生等量的兩種鏡像異構物（外消旋混合物，±）。拆分（resolution）是將它們分開的過程。

方法一：生成非鏡像異構物鹽

外消旋酸（±酸）與光學純的鹼反應，生成兩種非鏡像異構物鹽（物理性質不同），然後用色譜或結晶分離，再分別水解回純鏡像異構物酸。

(±)-酸 + 光學純鹼 → (RS)-鹽 + (SS)-鹽（非鏡像異構物） ↓ 分離 各自水解 → (R)-酸 和 (S)-酸

方法二：手性色譜（Chiral Chromatography）

以手性固定相（如氨基酸衍生物鍵合在矽膠上）進行色譜分離。外消旋混合物的兩個鏡像異構物與手性固定相的親和力不同（形成不同的非共價相互作用），因此以不同速度通過柱子而分離。

Naproxen（萘普生）的拆分案例

萘普生是 NSAID（非類固醇抗炎藥），只有 (S)-鏡像異構物具有抗炎活性。工業上用糖衍生物 N-丙基葡萄糖胺的胺鹽選擇性結晶 (R)-萘普生鹽，留在溶液中的為 (S)-萘普生鈉鹽。

手性藥物的重要性：Darvon（止痛藥）和 Novrad（止咳藥）互為鏡像異構物，但有截然不同的藥理效果。這說明藥物受體（蛋白質，本身就是手性的）能明確區分兩個鏡像異構物。

手性藥物

藥物受體通常是蛋白質，由 L-氨基酸構成，本身具有手性。因此，兩個鏡像異構物與受體的結合方式不同，藥效和副作用可能相差甚遠。

藥物活性鏡像異構物非活性/有害鏡像異構物
萘普生（Naproxen）(S)-(+)，抗炎(R) 無活性，但體內可消旋化
布洛芬（Ibuprofen）(S)-(+)，止痛(R) 也有部分活性，售為外消旋
Darvon止痛Novrad（鏡像異構物），止咳
消旋化（Racemization）的問題：即使藥廠只賣純鏡像異構物，若該化合物在體內容易消旋化（如布洛芬），效果等同賣外消旋混合物。
第14章重點回顧
  • 手性 = 分子與鏡像不可重疊；最常見原因是四個不同取代基的 sp³ 碳（立體中心）
  • CIP 規則指定 R/S（原子序大優先）；(+)/(−) 由實驗測定旋光方向
  • R/S 與 (+)/(−) 無直接對應關係
  • D/L：主要用於氨基酸和糖，以費雪投影為基礎
  • n 個立體中心 → 最多 2ⁿ 個立體異構物；meso 化合物因對稱面使實際數目減少
  • 非鏡像異構物物理性質不同，可用一般色譜分離
  • 阻轉異構物（BINAP）：由旋轉受阻產生手性，無立體碳
  • 有對稱面/中心 → achiral（非手性）；只有旋轉軸 → chiral（手性）
  • 拆分：生成非鏡像異構物鹽（結晶分離）或手性色譜
  • 手性藥物：受體為手性蛋白質，鏡像異構物效果常截然不同
