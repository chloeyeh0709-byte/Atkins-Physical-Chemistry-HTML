第15章 飽和碳的親核取代

Nucleophilic Substitution at Saturated Carbon

SN1 與 SN2 的動力學區別

SN2（雙分子親核取代）

速率同時依賴親核劑和底物濃度（二級動力學）。

速率 = k [RX][Nu] 反應進行在一個協同步驟中（鍵的斷裂與生成同時發生）
  • 一步機制，無中間體
  • 過渡態為三角雙錐（trigonal bipyramidal）構型
  • 親核劑從離去基的背面（backside）進攻
  • 結果：立體構型完全翻轉（Walden inversion）

SN1（單分子親核取代）

速率只依賴底物濃度（一級動力學）。

速率 = k [RX] 步驟一（慢，決速）：RX → R⁺ + X⁻（離子化） 步驟二（快）：R⁺ + Nu → R-Nu
  • 兩步機制，中間體為碳陽離子（carbocation）
  • 親核劑從碳陽離子的兩面進攻，通常得到外消旋化（racemization）產物（但在手性離子對存在下可有部分立體選擇性）

比較

項目SN2SN1
速率法則k[RX][Nu]（二級）k[RX]（一級）
中間體無（協同）碳陽離子
立體化學構型完全翻轉外消旋化（±）
底物偏好伯碳（少阻礙）叔碳（穩定碳陽離子）
溶劑偏好極性非質子性（DMF、DMSO）極性質子性（EtOH、H₂O）

碳陽離子的穩定性

SN1 反應的關鍵是碳陽離子的穩定性，穩定性越高，反應越快。

取代基效應

穩定順序（烷基碳陽離子）：叔 (3°) > 仲 (2°) > 伯 (1°) >> 甲基

烷基的推電子效應（超共軛和誘導）穩定正電荷。

特殊穩定化碳陽離子

類型穩定化原因相對活性
烯丙型（allylic R-CH=CH-CH₂⁺）共振穩定（正電荷離域至烯烴）高
苄型（benzylic ArCH₂⁺）共振穩定（正電荷離域至苯環）高
氧鎓離子（oxocarbenium，R-O⁺=CHR）氧孤對電子離域（p→p 共振）非常高
亞胺鎓離子（iminium，R₂N⁺=CHR）氮孤對電子離域高
乙縮醛在酸中的水解機制：縮醛水解時，先生成氧鎓離子（oxocarbenium ion）中間體，其穩定性使 SN1 反應快速進行——這正是縮醛在酸性條件下（而非鹼性）水解的原因。

SN2 的立體化學：Walden 翻轉

SN2 反應中，親核劑從離去基的對面（180° backside attack）進攻，過渡態為三角雙錐：

Nu⁻ ... C ... X (三角雙錐過渡態，Nu 和 X 在軸位， 三個保留基在赤道位)

產物的立體構型完全翻轉（如同雨傘翻面）。此翻轉稱為 Walden 轉化，是 SN2 反應最關鍵的立體化學特徵。

空間阻礙對 SN2 的影響

背面進攻需要接近碳原子，阻礙越大越慢：

底物類型SN2 活性
CH₃X（甲基）最快（無阻礙）
RCH₂X（伯碳）快
R₂CHX（仲碳）較慢
R₃CX（叔碳）SN2 幾乎不發生（但 SN1 可以）
新戊基（Me₃C-CH₂X）極慢（β-阻礙）

離去基的能力

好的離去基：其對應的共軛酸 HX pKₐ 越低（酸性越強），離去基越好。

規則：pKₐ(HX) 越低 → X⁻ 越穩定 → X 越是好的離去基

羥基的活化：轉化為好的離去基

OH⁻ 是極差的離去基，醇不能直接進行 SN 反應。需先活化：

酸活化（HBr、HCl）

R-OH + H⁺ → R-OH₂⁺ →（Nu:）→ R-Nu + H₂O （水是好的離去基，pKₐ = -1.7）

PBr₃（磷酸溴化物）

醇與 PBr₃ 反應，先在磷上發生 SN2（O 攻擊 P），再在 C 上發生 SN2（Br 攻擊 C，構型翻轉），得到烷基溴（產率高，構型翻轉）。

R-OH + PBr₃ → R-OPBr₂ → R-Br + Br₂P=O SN2（Br 攻擊 C）

磺酸酯（Tosylate、Mesylate）

醇 + TsCl（甲苯磺醯氯）+ 吡啶 → 甲苯磺酸酯（OTs），立體構型保留（O-C 鍵未斷），OTs 是極好的離去基。

R-OH + TsCl + 吡啶 → R-OTs （構型保留） R-OTs + Nu⁻ → R-Nu （SN2，構型翻轉） 淨結果：從 ROH 到 R-Nu，構型翻轉
磺酸酯（TsO⁻，MsO⁻）pKₐ 約 -1 至 -2，是絕佳的離去基，幾乎任何親核劑都能取代它們。

Mitsunobu 反應

Mitsunobu 反應將醇的 OH 直接替換為親核劑，且立體構型完全翻轉（SN2 機制）。試劑為 Ph₃P（三苯基膦）和 DEAD（偶氮二甲酸二乙酯，EtO₂C-N=N-CO₂Et）。

R-OH + HNu + Ph₃P + DEAD → R-Nu（構型翻轉） + Ph₃P=O + DEAD-H₂

機制關鍵（四個步驟）：

  1. Ph₃P 攻擊 DEAD 的 N=N，形成磷鎓中間體，脫質子給親核劑（如苯甲酸）
  2. 親核劑提供 Nu⁻
  3. 醇的 O 攻擊磷，形成 R-O-PPh₃⁺（磷活化了 OH）
  4. Nu⁻ 從背面 SN2 攻擊 C，構型翻轉，磷氧化物離去
Mitsunobu 的重要性：一步從醇直接得到構型翻轉的產物，無需先製備離去基再取代，是合成手性分子的強大工具。

SN1 中的親核劑

SN1 反應的速率決定步驟是碳陽離子的形成，與親核劑無關。因此：

  • 親核性強弱不影響反應速率（但影響競爭性副反應）
  • 很弱的親核劑也可參與 SN1 反應（如水、醇等）
  • SN1 反應常在酸性條件下進行（質子化促進離去基離去）

Ritter 反應

叔醇在強酸中形成碳陽離子，即使腈（nitrile）這種極差的親核劑也能反應，生成醯胺。

R₃COH + H⁺ → R₃C⁺ + H₂O R₃C⁺ + R'C≡N → R₃C-N⁺=CR' → (+ H₂O) → R₃C-NH-CO-R' 仲醯胺（Ritter 反應）

SN2 中的親核劑

氮親核劑的問題

胺是好的親核劑，但胺與烷基鹵反應常得到混合物：伯胺可再烷化為仲胺、叔胺，直至季銨鹽。

NH₃ + RX → RNH₂ → R₂NH → R₃N → R₄N⁺X⁻（混合物）

解決方案一：疊氮化物（Azide，N₃⁻）

疊氮離子（N₃⁻）只烷化一次（因為產物 RN₃ 不再是親核劑），再用 LiAlH₄ 或 H₂/Pd 還原疊氮為伯胺：

RX + NaN₃ → R-N₃ → (LiAlH₄ 或 H₂/Pd) → R-NH₂（伯胺，乾淨）

硫親核劑

硫醇鹽（RS⁻）在 SN2 反應中比對應的氧親核劑（RO⁻）更有效，原因是硫的 3sp³ 孤對電子軌道能量更高，與 C-X σ* 的 HOMO-LUMO 重疊更好。

PhSH + NaOH + n-BuBr → PhS-Bu + NaBr （高效 SN2）

解決方法：硫代乙酸鹽路線

用硫代乙酸鉀（KSAc）代替 NaSH，避免雙硫化物生成；再用鹼水解得到硫醇：

RX + KSAc → RS-Ac → (NaOH/H₂O) → RSH（硫醇）

硬性與軟性親核劑

親核劑對「飽和碳」和「羰基碳」的親和力不同：

特性硬性親核劑（Hard）軟性親核劑（Soft）
大小小大
電荷帶電（離子型）中性或電荷分散
鹼性強（HX 的 pKₐ 大）弱（HX 的 pKₐ 小）
HOMO 能量低高（更好的軌道重疊）
攻擊目標羰基碳（C=O，靜電控制）飽和碳（HOMO-LUMO 控制）
範例HO⁻、RO⁻、NH₂⁻、MeLiRS⁻、I⁻、R₃P
規律：
  • 軟性親核劑（RS⁻、I⁻、R₃P）對飽和碳的 SN2 特別有效
  • 硬性親核劑（HO⁻、RO⁻）對羰基碳（C=O）更有效
  • 相對速率（與 MeBr 反應，H₂O = 1）：I⁻: 1.2×10⁵；PhS⁻: 5×10⁷；F⁻: 0.0

碘化物作為親核催化劑

碘化物（I⁻）既是最好的 SN2 親核劑之一，也是最好的離去基之一。利用這一雙重性質，碘化物可催化其他 SN2 反應：

R-Cl →（I⁻）→ R-I →（Ph₃P）→ R-PPh₃⁺ Cl⁻ （I⁻ 先取代 Cl，再被 Ph₃P 取代 I；I⁻ 催化循環回收）
催化範例：苄溴與 Ph₃P 在二甲苯中反應需要數天，但加入催化量 LiI 後 2 小時即完成。I⁻ 先形成苄碘（快），再由 Ph₃P 取代 I⁻（也快），I⁻ 不斷循環再生。
第15章重點回顧
  • SN2 = 二級動力學（k[RX][Nu]），協同，背面進攻，構型翻轉
  • SN1 = 一級動力學（k[RX]），通過碳陽離子，常外消旋化
  • SN1 偏好叔碳、烯丙型、苄型、氧鎓離子（穩定碳陽離子）
  • SN2 偏好伯碳（少阻礙）、軟性親核劑（I⁻、RS⁻、R₃P）
  • 離去基：I > Br > Cl >> F；OTs⁻、OMs⁻ 極好；OH⁻ 極差
  • 活化 OH：質子酸、PBr₃（翻轉）、TsCl（保留），再 SN2 翻轉
  • Mitsunobu：ROH + HNu + Ph₃P + DEAD → R-Nu（構型翻轉）
  • 氮親核劑問題：多烷化；用 NaN₃ + 還原 → 乾淨的伯胺
  • 軟性親核劑（RS⁻、I⁻、R₃P）對飽和碳更有效；硬性（HO⁻）對 C=O 更有效
  • I⁻ 催化：以 I⁻ 作親核催化劑，加速 SN2 反應
