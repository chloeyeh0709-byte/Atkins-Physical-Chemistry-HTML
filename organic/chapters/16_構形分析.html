構形分析

Conformational analysis

16.1 構形 vs 構型

這兩個術語容易混淆，但有根本區別：

構形（Conformation）vs 構型（Configuration）

特徵構形（Conformation）構型（Configuration）
定義由可旋轉單鍵的不同空間排列由鍵的空間排列決定，需打斷化學鍵才能改變
互換條件旋轉單鍵即可（室溫下可快速互換）需化學反應（打斷/形成鍵）
可分離性通常不可分離（轉換速率快）可分離（鏡像異構物、非鏡像異構物）
例子乙烷交叉式/重疊式；環己烷椅式/船式R/S 立體中心；cis/trans 雙鍵

16.2 旋轉能障

圍繞單鍵旋轉並非完全自由，存在能障（torsional barrier）：

鍵能障 (kJ mol⁻¹)來源
乙烷 C-C12H-H 交錯排斥（扭轉張力）
1,3-丁二烯 C-C 單鍵30π 電子的共軛效應
醯胺 C-N85N-C=O 共振（部分雙鍵性質）
C=C 雙鍵260需打斷 π 鍵

醯胺鍵的受阻旋轉

由於醯胺 N-C(=O) 具有共振式 N⁺=C-O⁻，C-N 鍵帶有部分雙鍵性質，旋轉能障達 85 kJ mol⁻¹，足以在室溫下 NMR 觀察到兩個獨立的訊號（如 DMF 中兩個甲基信號在室溫可分辨）。

16.3 Newman 投影圖

Newman 投影圖（Newman projection）沿 C-C 鍵軸方向觀察，是展示構形的標準工具：

Newman 投影圖規則： - 近端碳（closer carbon）= 三條線的交點（Y 形） - 遠端碳（farther carbon）= 圓圈 - 從交點延伸三條線表示近端碳上的三個取代基 - 從圓圈延伸三條線表示遠端碳上的三個取代基 乙烷的兩個極端構形： 交叉式（Staggered）： 重疊式（Eclipsed）： H H H H \ / | | C ← 近端 C / \ | | H H H H | | (O)← 遠端 (O) / | \ / | \ H H H H H H （能量最低） （能量最高，+12 kJ/mol）

二面角（Dihedral angle）

兩個鍵（在 Newman 投影中，前後各一個取代基）之間的角度稱為二面角（φ）：

  • φ = 0°：syn-periplanar（syn，重疊）
  • φ = 60°：synclinal（gauche，鄰式）
  • φ = 120°：anticlinal（次交叉）
  • φ = 180°：anti-periplanar（anti，對位交叉）

16.4 丁烷構形

n-丁烷（CH₃-CH₂-CH₂-CH₃）圍繞 C2-C3 旋轉，按二面角（兩個 CH₃ 之間）有四種極端構形：

二面角 φ 名稱 相對能量 ───────────────────────────────────────────────── 0° syn-periplanar（syn，全重疊） +19 kJ/mol（最高，兩 CH₃ 重疊） 60° synclinal（gauche，鄰式） +3.8 kJ/mol（gauche 排斥） 120° anticlinal（次交叉，重疊） +15 kJ/mol 180° anti-periplanar（anti） 0 kJ/mol（最穩定）
  • anti（φ = 180°）：兩個 CH₃ 相距最遠，最穩定
  • gauche（φ = 60° 或 300°）：兩個 CH₃ 相鄰，有 gauche 排斥（~3.8 kJ/mol）
  • 在液態正丁烷中，anti 與 gauche 的比例約 2:1（ΔG° ≈ 2.5 kJ/mol 有利 anti）

Gauche 排斥的物理來源

gauche 構形中，兩個甲基基團的 C-H 鍵在空間上較接近（van der Waals 排斥），並非電子層面的排斥。此效應稱為 gauche 交互作用（gauche interaction）。

16.5 環狀化合物與環張力

環狀化合物依環大小分類，各有不同的環張力：

環大小類別例子特點
3–4小環（Small）環丙烷、環丁烷高張力（角張力、扭轉張力）
5–7正常環（Normal）環戊烷、環己烷低張力，環己烷最穩定
8–14中環（Medium）環辛烷適度張力（跨環交互作用）
>14大環（Large）香料化合物接近無張力

小環的幾何特點

  • 環丙烷：所有 C-C-C 角 = 60°（sp³ 理想 109.5°），角張力大。C-H 鍵全重疊，扭轉張力高。特殊的「彎曲鍵（banana bond）」。
  • 環丁烷：非平面（蝴蝶形），C-C-C 角約 90°，比環丙烷角張力小，有部分扭轉張力。
  • 環戊烷：「信封構形（envelope）」，四個碳共面，一個碳翹起；無角張力，扭轉張力也小。

環丙烷的特殊性質

環丙烷的彎曲鍵電子密度在環外側，使其略具 C=C 的性質（可與親電試劑反應）。sp³ 碳上的 C-H 鍵偏向 s 特性較高（約 33% s），因此 pKa 較低（約 46）且 ¹H NMR 化學位移較高場（δ −0.44 至 0.22 ppm）。

16.6 環己烷的椅式構形

環己烷是有機化學中最重要的環，因為固醇類、萜類、醣類等大量天然物均含有此環。

椅式構形（Chair conformation）

  • 所有 C-C-C 角 = 111°（接近 sp³ 理想角 109.5°），幾乎無角張力
  • 相鄰 C-H 鍵全部交叉排列，無扭轉張力
  • 最穩定的構形，比船式低 25 kJ/mol
環己烷椅式構形（側視圖）： ax | eq---C---eq / \ / \ eq-C C-eq | | ax ax \ / \ / eq--C--eq | ax ax = 軸向鍵（axial，垂直） eq = 赤道鍵（equatorial，水平）

其他構形

  • 船式（Boat）：4 對重疊的 C-H 鍵 + 兩個旗桿 H 近距接觸；比椅式高 25 kJ/mol。是過渡態，不是穩定構形。
  • 扭曲船式（Twist-boat）：比船式低 4 kJ/mol（約比椅式高 21 kJ/mol）；是能量局部極小值，能在 −60°C 以下被 NMR 偵測。
  • 半椅式（Half-chair）：環翻轉的過渡態；比椅式高約 43 kJ/mol。

環翻轉（Ring flip）

從一個椅式翻轉到另一個椅式，需通過 43 kJ/mol 的活化能，室溫下快速發生（10⁵ s⁻¹）。翻轉後，原來的軸向鍵變赤道鍵，赤道鍵變軸向鍵。

繪製椅式構形的方法

步驟： 1. 畫一個 V 形（兩根向右斜線），兩端往左斜上接兩根線 2. 最右的 C 往左右各斜出一根線，形成 M 形 3. 左端的兩個 C 連接，完成椅式輪廓 4. 軸向鍵：交替向上（C1，C3，C5）和向下（C2，C4，C6） 5. 赤道鍵：與相鄰的兩個環鍵大致平行（W/M 形）

16.7 軸向鍵與赤道鍵

每個環己烷的碳原子都帶有一個軸向（axial，ax）和一個赤道（equatorial，eq）的取代基位置：

  • 軸向鍵（ax）：大致垂直於環平面，交替向上和向下
  • 赤道鍵（eq）：大致平行於環平面，略微傾斜（約 20°）

1,3-二直立交互作用

軸向取代基與兩個環上 C3 位置的軸向 H（同側）發生空間排斥，稱為 1,3-二直立交互作用（1,3-diaxial interaction）。這使得大基團傾向於占據赤道位置。

1,3-二直立交互作用示意（C1 有軸向甲基）： CH₃（C1，ax） | ----C1---- / \ C6 C2 / \ C5 C3 \ / C4--/ C1-ax CH₃ 與 C3-ax H 和 C5-ax H 的距離只有約 2.5 Å （van der Waals 半徑之和約 2.4 Å），產生排斥

16.8 取代環己烷

一取代環己烷（如甲基環己烷）存在兩種椅式構形：取代基軸向或赤道。大基團傾向赤道位置（避免 1,3-二直立排斥）。

t-Bu 基：鎖環劑（conformational lock）

t-Bu 基太大，只能占據赤道位置（K > 3000，> 99.9% 赤道）。含 t-Bu 環己烷的環幾乎不翻轉，是研究立體化學的理想模型。

二取代環己烷

1,4-二取代環己烷的 cis/trans 分析

trans-1,4-二甲基環己烷： 兩個 CH₃ 在環的兩側（一上一下） → 椅式A：C1 ax，C4 eq → 不利（一個 ax） → 椅式B：C1 eq，C4 ax → 不利（一個 ax） → 兩種構形等能，但都有一個 ax CH₃ 等等...實際上： trans-1,4 意味著 C1 和 C4 取代基在「同側」（對位取代）→ 更正：cis = 同側，trans = 反側 cis-1,4-二甲基環己烷： 兩 CH₃ 同側 → 一個 ax，一個 eq（兩個構形相同能量） trans-1,4-二甲基環己烷： 兩 CH₃ 反側 → 兩個 eq（有利）或兩個 ax（不利） → trans 構形以 diequatorial 為主（更穩定）

一般規律：trans-1,4（或 trans-1,2、cis-1,3）可以 diequatorial ≫ diaxial；cis-1,4（或 cis-1,2、trans-1,3）只能 ax+eq，兩種椅式能量相同。

16.9 十氫萘與固醇類

十氫萘（Decalin）

十氫萘是兩個環己烷稠合（融合）的雙環系統，環接合處（ring junction）的立體化學決定其構形行為：

  • cis-十氫萘：環接合處的兩個 H 在同側（一個 ax，一個 eq）；可以發生環翻轉，兩個椅式互換。
  • trans-十氫萘：環接合處的兩個 H 在反側（都 eq）；環翻轉後兩個 H 都 ax，能量大幅升高，因此幾乎不發生環翻轉，構形鎖定。

trans-十氫萘構形鎖定的原因

trans 融合的兩個環在 diequatorial 構形下非常穩定；翻轉到 diaxial 需克服約 60 kJ/mol 的能障（兩個 1,3-diaxial 交互作用），實際上構形固定。

固醇類（Steroids）

固醇骨架（如膽固醇）由 A、B、C、D 四個環組成（三個六元環 + 一個五元環）：

  • B-C 和 C-D 接合處：全為 trans
  • A-B 接合處：大多數固醇為 trans（如膽固醇），但某些（如 5β-固醇，如膽汁酸）為 cis
  • 由於三個 trans-融合的六元環，固醇骨架幾乎完全剛性（無法翻轉）
  • 在岩石中找到的固醇（約 1.5 × 10⁹ 年）仍保持環接合的立體化學，說明 trans-融合極度穩定

固醇與十氫萘的立體化學

固醇基本骨架： CH₃ CH₃ | | A--B---C---D (6) (6) (6)(5) A-B, B-C, C-D：反式稠合（trans） → 所有環都是 all-eq diequatorial → 整體幾乎平面（與 cis-固醇的「曲折」形對比）

本章摘要

第16章 核心概念

  • 構形 vs 構型：構形由旋轉改變；構型需打斷化學鍵
  • 旋轉能障：乙烷 12 kJ/mol；醯胺 C-N 85 kJ/mol；C=C 260 kJ/mol
  • Newman 投影：前碳為 Y 形，後碳為圓圈
  • 丁烷構形：anti（180°）最穩定；gauche（60°）高 3.8 kJ/mol；syn（0°）最不穩定
  • 環張力：小環（3-4）> 中環（8-14）> 正常環（5-7）；環己烷最穩定
  • 椅式環己烷：全交叉、無角張力；比船式低 25 kJ/mol
  • ax vs eq：大取代基偏好赤道位置（避免 1,3-diaxial）；t-Bu > 99.9% eq
  • trans-稠合（十氫萘、固醇）：構形鎖定，無法翻轉
