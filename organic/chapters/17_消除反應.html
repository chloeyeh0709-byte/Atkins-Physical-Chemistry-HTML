消除反應

Elimination reactions

17.1 消除反應概論

消除反應（β-elimination）從底物中同時移除兩個基團，形成不飽和鍵（通常是 C=C 雙鍵）。離去的兩個原子/基團必須在β 位（β-H 在 α-碳的隔壁，即 β-碳上）：

β-H 消除通式： H LG | | C(β)-----C(α) + 鹼 → C=C + HB + LG⁻ | | （α = 帶離去基的碳；β = 帶被消除 H 的碳）

消除反應有三種主要機制：E2（雙分子）、E1（單分子）、E1cB（共軛鹼型）。

17.2 E2 雙分子消去

E2 反應是協同的（concerted）、一步反應：鹼攻擊 β-H 的同時，離去基離去，形成雙鍵。

E2 機制（協同，一步）： B: H LG | | C(β)--C(α) → [B···H···Cβ=Cα···LG]‡ → BH + C=C + LG⁻ 速率 = k₂[RX][鹼] （二級速率定律）

E2 的必要條件

  • 需要鹼（不必是親核劑）
  • β-H 和離去基必須呈反式共面（anti-periplanar）排列，二面角 = 180°
  • 速率對鹼濃度和底物均為一級（整體二級）

E2 所需的鹼

試劑pKa（共軛酸）特點
KOH / NaOH15.7常用強鹼
NaOEt（乙醇鈉）16普通 E2 鹼
KOt-Bu（叔丁醇鉀）18大體積，傾向 Hofmann 產物
DBU（1,8-二氮雜雙環）12.5位阻大，不親核，適用於敏感底物
LDA（雙異丙基胺基鋰）36超強鹼，低溫不可逆消去

17.3 E1 單分子消去

E1 反應分兩步：先形成碳陽離子（慢步驟，速率決定），再失去質子（快步驟）：

E1 機制（兩步）： 步驟1（慢，速率決定）： R-C(α)-X → R-C(α)⁺ + X⁻ 步驟2（快）： B: + H-C(β)-C(α)⁺ → BH + C=C 速率 = k₁[RX] （一級速率定律，與鹼濃度無關）

E1 的底物要求

  • 需要能形成穩定碳陽離子的底物：三級、烯丙基、苄基
  • α-雜原子取代（增加鄰近效應）也有利
  • 一級碳不發生 E1（一級碳陽離子太不穩定）
  • E1 常伴隨 SN1（競爭反應）

E1 的立體選擇性

E1 形成的烯烴立體選擇性（E vs Z）由兩個過渡態（TS）的相對穩定性決定（Hammond 假說，late TS 近似中間體）：

  • 一般偏向 E（反式）烯烴（Saytzev 規則），因 E 比 Z 少位阻
  • Tamoxifen（乳癌藥）由 E1 生成，約 1:1 E/Z 混合物

17.4 消去 vs 取代的競爭

消去（E）和取代（SN）競爭同一底物，條件決定哪個為主：

條件有利消去有利取代
試劑強鹼（KOH、KOt-Bu）親核劑（I⁻、RS⁻）
試劑大小大體積（t-BuOK、DBU）小型親核劑（Cl⁻、OH⁻稀）
溫度高溫（ΔS 有利消去）低溫
底物三級底物一級底物
溶劑極性較低極性非質子（DMF、DMSO）

溫度選擇消去的熱力學根據

消去反應增加分子數（固體→液態烯烴 + HX），ΔS° > 0。

由 ΔG° = ΔH° − TΔS°，高溫使 −TΔS° 貢獻更大，消去在熱力學上更有利。取代反應 ΔS° ≈ 0，對溫度不敏感。

17.5 Bredt 定律

Bredt 定律規定：在橋接雙環（bicyclic）系統中，雙鍵不能形成在橋頭碳（bridgehead carbon）上。

Bredt 定律示意（雙環[2.2.1]庚烷即降冰片烷）： 橋頭碳 / \ / \ C---------C ← 不能在此形成雙鍵（空 p 軌道無法平面化） \ / \ / 橋頭碳

Bredt 規則的原因

橋頭碳若形成 C=C，需要 sp² 雜化（平面三角形），但橋接系統的幾何限制迫使鍵角遠小於 120°，導致 p 軌道無法互相平行重疊（π 鍵幾乎為零），應變能極高。環越小，違反程度越大。

推論：E2 不能在橋頭碳上發生；SN1 生成的橋頭碳陽離子也極不穩定（空 p 軌道不能平面化）。

17.6 E2 的立體化學

E2 要求 H 和 LG 呈反式共面（anti-periplanar），即二面角 φ ≈ 180°。這使 E2 具有立體專一性（stereospecific）：不同的起始非鏡像異構物給出不同立體化學的烯烴。

meso vs (±)-2,3-二溴丁烷的 E2

meso-2,3-二溴丁烷 + KOH（EtOH）: H 和 Br 呈 anti-periplanar → 只能形成 (Z)-但-2-烯 （因為 meso 物的 anti 排列讓兩個 CH₃ 在同側） (±)-2,3-二溴丁烷 + KOH（EtOH）: H 和 Br anti → 形成 (E)-但-2-烯 （(±) 物的 anti 排列讓兩個 CH₃ 在反側）

E2 的立體專一性可用來確定底物的相對立體化學。

syn-periplanar 排列（輔助方式）

少數情況（特別是五元環或剛性體系中無法達到 anti-periplanar）可發生 syn-periplanar（φ = 0°）E2，但效率大幅降低（通常慢 10–100 倍）。

17.7 環己烷上的 E2

在環己烷中，anti-periplanar 要求 H（β-C）和 LG（α-C）都在軸向（axial）位置——只有這樣，兩個軸向鍵才能互相反式共面（φ = 180°）：

E2 在環己烷的要求： H（ax，β-C） | C(β)---C(α) 只有 ax-ax 才能 anti-periplanar | LG（ax，α-C）

薄荷醇衍生物的 E2 速率差異

異構物 A：Cl 軸向，i-Pr 赤道（最穩定構形） → Cl 已在 ax；兩個 β-H 分別在 ax → 快速 E2，形成兩種烯烴（1:3 比） 異構物 B：Cl 赤道，i-Pr 赤道（稍穩定構形） → Cl 在 eq，必須翻轉到 Cl ax（不穩定構形） → 反應速率比 A 慢 ~250 倍

此例說明 E2 必須從「正確的構形異構物」反應，構形能量直接影響反應速率。

17.8 E2 的區位選擇性

當底物有多個 β-H 可選，E2 可形成不同的烯烴異構物：

  • Saytzev（Zaitsev）規則：普通鹼（NaOEt）傾向形成較多取代的烯烴（更穩定，熱力學控制）
  • Hofmann 規則：大體積鹼（KOt-Bu、DBU）傾向形成較少取代的烯烴（β-H 位阻較小）

2-溴-2-甲基丁烷的 E2

CH₃ | CH₃-C-CH₂CH₃ + 鹼 | Br Saytzev（NaOEt）: → (CH₃)₂C=CHCH₃（較多取代的 2-甲基-2-丁烯，主要） Hofmann（KOt-Bu）: → CH₂=C(CH₃)CH₂CH₃（較少取代的 2-甲基-1-丁烯，主要）

E1 的區位選擇性

E1 遵循 Saytzev 規則：形成最穩定（最多取代）的烯烴，因為碳陽離子先形成，再失去鄰近 H，選擇生成較穩定烯烴的路徑（late TS ≈ 烯烴）。

17.9 E1cB 消去反應

E1cB（elimination–unimolecular–conjugate base）在 β-H 特別酸性時（如鄰近吸電子基）發生：先去質子形成穩定的碳陰離子（速率決定步驟），再失去離去基。

E1cB 機制（兩步）： 步驟1（慢，速率決定）： 鹼 + H-C(β)-C(α)-LG → 鹼H⁺ + ⁻C(β)-C(α)-LG 步驟2（快）： ⁻C(β)-C(α)-LG → C=C + LG⁻ 速率 = k₁[底物][鹼] （看起來也是二級，但 β-H 的 pKa 決定機制）

E1cB 的特徵

  • β-H 的 pKa 低（~20 左右），因相鄰 C=O、CN、NO₂ 等使其酸性增強
  • OH⁻ 可以是離去基（E1cB 中可接受弱離去基）
  • 典型底物：β-羰基鹵化物（如 BrCH₂C(=O)R）、β-硝基鹵化物
  • 醛醇縮合的脫水（aldol dehydration）屬於 E1cB 機制

β-羥羰基的脫水（醛醇縮合後的消去）

OH O | || R-CH-CH₂-C-R' + OH⁻ E1cB 步驟1：OH⁻ 去掉 α-H（鄰近 C=O，pKₐ ~20） → ⁻CH-CH(OH)-... 或 更精確： OH⁻ 去掉 β-H（相對於 C=O 的 β 碳）→ 穩定陰離子 步驟2：OH⁻ 離去 → 形成 α,β-不飽和羰基（共軛烯酮）

三種消去機制比較

機制速率決定步驟鹼需求離去基需求立體化學
E2協同（一步）強鹼，高濃度好的離去基anti-periplanar，立體專一
E1C-LG 鍵斷（去碳陽離子）弱鹼或無好的離去基無（可自由旋轉後失 H）
E1cBC-H 鍵斷（去質子）強鹼，β-H 酸性可以是弱離去基（OH⁻）通常 syn 或無特定

本章摘要

第17章 核心概念

  • E2（協同）：速率 = k₂[RX][鹼]；需 anti-periplanar H 和 LG；立體專一性
  • E1（兩步）：速率 = k₁[RX]；需穩定碳陽離子（三級、烯丙、苄基）；立體選擇性（Saytzev）
  • 消去 vs 取代：強鹼、大體積試劑、高溫、三級底物 → 消去；親核劑、低溫、一級底物 → 取代
  • Bredt 定律：橋頭碳不能形成雙鍵（環太小時）
  • 環己烷的 E2：H 和 LG 都必須在軸向（axial-axial）
  • 區位選擇性：Saytzev（較多取代）= 正常鹼；Hofmann（較少取代）= 大體積鹼
  • E1cB：β-H 酸性高；先失 H 形成穩定碳陰離子；OH⁻ 可為離去基
