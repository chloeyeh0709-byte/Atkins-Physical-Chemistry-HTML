光譜學方法複習

Review of spectroscopic methods

18.1 ¹³C NMR 羰基化學位移

¹³C NMR 能區分不同類型的羰基化合物，但酸衍生物之間有重疊：

化合物類型¹³C δ (ppm)備註
酮（Ketone）195–215最低場羰基
醛（Aldehyde）195–205與酮重疊
酯（Ester）164–175酸衍生物範圍
羧酸（Carboxylic acid）170–185酸衍生物範圍
醯氯（Acid chloride）165–175酸衍生物範圍
醯胺（Amide）165–175酸衍生物範圍
酸酐（Anhydride）165–170酸衍生物範圍

¹³C 的限制

所有酸衍生物（酯、酸、醯氯、醯胺、酸酐）的羰基 ¹³C 都落在 164–185 ppm，互相重疊，無法僅靠 ¹³C 化學位移區分。需配合 IR 或 ¹H NMR 判斷。

18.2 ¹H NMR 醛基訊號

醛基（CHO）的質子在 ¹H NMR 出現在特徵性的低場位置，是區分醛與酮的最直接方法：

醛基 CHO 的 ¹H 化學位移：δ = 9.0–10.5 ppm
  • 此範圍遠離其他 H（最接近的是芳香 H 在 6.5–8.5 ppm）
  • 芳香醛（苯甲醛型）通常在 δ ≈ 9.8–10.0 ppm
  • 脂肪醛通常在 δ ≈ 9.4–9.8 ppm
  • 不飽和醛（α,β-不飽和）在 δ ≈ 9.2–9.5 ppm（共軛去屏蔽）

醛的完整鑑定

  • ¹H NMR：CHO 在 δ 9–10.5 ppm（通常單峰或 d，若鄰 H 存在）
  • IR：C-H 伸縮（兩個峰，~2720 和 2820 cm⁻¹）；C=O ~1720–1740 cm⁻¹
  • ¹³C NMR：C=O 在 195–205 ppm

18.3 IR 羰基伸縮頻率

羰基的 IR 頻率是快速鑑定官能基類型的強大工具：

化合物ν(C=O) (cm⁻¹)特點
醯氯~1815最高頻，強烈吸電子 Cl
酸酐~1790 + ~1810兩個 C=O 峰（對稱+不對稱伸縮）
酯~1745寬峰；C-O-C 伸縮在 ~1200 cm⁻¹
羧酸~1710–1725寬峰；O-H 伸縮寬峰 2500–3300 cm⁻¹
酮（六元環）~1715基準參考值
醛~1720–1740C-H 伸縮在 2720, 2820 cm⁻¹
醯胺~1650–1680最低頻，N-H 1580 cm⁻¹；N 的共振降頻

IR 頻率的決定因素

  • 電感效應（Inductive）：C=O 上的吸電子基（Cl、OR）降低 C 的電子密度，使 C=O 鍵增強，頻率升高
  • 共振（Resonance）：N 孤對電子共振到 C=O，降低 C=O 鍵級，頻率降低（醯胺最低）
  • 共軛（Conjugation）：C=C 或苯環與 C=O 共振，頻率降低約 30 cm⁻¹
  • 環張力（Ring strain）：五元環 +30；四元環 +65；三元環 +100 cm⁻¹

18.4 IR 羰基頻率修正規則

以六元酮（1715 cm⁻¹）為基準，加上各修正量估算任意羰基化合物的頻率：

修正項目修正量 (cm⁻¹)
取代 Cl（如醯氯）+85 → +100
取代 OCOR（如酸酐）+100（每個 C=O +50）
取代 OR（如酯）+30
取代 OH（如羧酸）+15（二聚效應拉低）
取代 H（如醛）+15
C=C 共軛−30
苯環共軛（芳香羰基）−30
NH₂ 取代（醯胺）−85
五元環（+ring strain）+30
四元環+65
三元環+100

β-內醯胺（β-Lactam，四元環醯胺）的計算

基準（六元酮）： 1715 cm⁻¹ + NH₂ 取代（醯胺效應）： −85 + 四元環張力： +65 ───────────────────────────── 估算值： 1695 cm⁻¹ 實際青黴素 β-內醯胺 C=O：約 1715 cm⁻¹ （高於普通六元環醯胺的 ~1680 cm⁻¹） → 四元環+共振作用相抵，最終比六元環醯胺高 ~35 cm⁻¹

18.5 小環化合物的 NMR 特點

環丙烷（Cyclopropane）

環丙烷的 C-H 氫出現在異常高場（比正常烷烴 CH₂ 更高場）：

環丙烷 CH₂ ¹H 化學位移：δ ≈ 0 至 −0.44 ppm

原因：環丙烷的 C-C 鍵有較高 s 字符（彎曲鍵），C-H σ 鍵電子密度增加（更多 s 特性 → 更大 Fermi 接觸 → C-H 電子在 C 附近聚集），屏蔽效應使 H 更高場。

¹³C 的 J 偶合

環丙烷 ¹J_CH ≈ 160 Hz（比正常 CH₂ ~125 Hz 大），也反映較高 s 字符。

18.6 炔烴的 NMR 特點

末端炔烴 ≡C-H

炔烴末端 C-H 在 ¹H NMR 出現在中高場（比烯烴更高場）：

末端炔 ≡C-H 的 ¹H δ ≈ 1.8–2.5 ppm

原因：炔烴 π 電子形成圓柱形（cylindrical）雲，在 C≡C 鍵軸方向產生反磁性各向異性（沿軸方向屏蔽）。末端 H 位於此軸上，受到屏蔽，比同類型烯烴 H（δ 4.5–6.5 ppm）更高場。

炔烴的 ¹³C 化學位移

炔烴 ≡C 的 ¹³C δ ≈ 60–90 ppm（sp 碳）
  • 比烯烴（sp² 碳 100–150 ppm）更高場
  • 比烷烃（sp³ 碳 0–50 ppm）更低場
  • 末端炔的兩個 C 在 NMR 中通常可以區分（≡CH 約 68–70 ppm；≡CR 約 80–90 ppm）

18.7 環己烷的偶合常數

在環己烷系統中，³J（H-C-C-H）偶合常數對構形分析極為有用（Karplus 方程）：

鄰H-H關係（在椅式環己烷）二面角 φ³J (Hz)
二直立（diaxial，ax-ax）~180°10–12
直立-赤道（ax-eq）~60°3–5
二赤道（diequatorial，eq-eq）~60°2–3

Karplus 方程

³J ≈ A cos²φ − B cosφ + C （A ≈ 10, B ≈ 1, C ≈ 0 為近似值） φ = 0° → ³J ≈ 9–10 Hz（syn-periplanar） φ = 90° → ³J ≈ 0 Hz φ = 180° → ³J ≈ 10–12 Hz（anti-periplanar）

環己烷 ax-ax 偶合（180°）≫ ax-eq 或 eq-eq（60°）；利用此差異可判斷 H 的軸向/赤道位置。

由偶合常數推論構形

若 C1-H 顯示大偶合（³J = 10 Hz 與相鄰 H），表示 C1-H 為軸向（ax-ax 關係）；小偶合（³J = 3 Hz）表示赤道。

18.8 異核偶合（¹⁹F 和 ³¹P）

¹⁹F（100% 天然豐度）和 ³¹P（100% 天然豐度）都是 I = 1/2 核，與 ¹H 和 ¹³C 均會偶合：

¹H-¹⁹F 偶合

  • ²J_HF（geminal）：通常 45–55 Hz
  • ³J_HF（vicinal）：通常 5–25 Hz
  • ¹⁹F NMR 本身範圍寬（CF₄ = 0 ppm 參考），化學位移差異大（CF₃ ≈ −65 ppm；ArF ≈ −115 ppm）

¹H-³¹P 偶合

  • ¹J_PH（直接 P-H 鍵）：高達 693 Hz（如 dimethyl phosphite）
  • ²J_PH（P-C-H）：通常 10–15 Hz
  • ³J_PH（P-C-C-H）：通常 5–12 Hz

¹³C-¹⁹F 偶合

偶合類型典型值（氟苯）
¹J_CF（直接 C-F 鍵）~244 Hz（ipso C）
²J_CF~21 Hz（ortho C）
³J_CF~8 Hz（meta C）
⁴J_CF~3 Hz（para C）

¹³C 常規記錄為寬帶去偶（Broadband decoupled）

標準 ¹³C NMR 使用 ¹H 寬帶去偶（BBD）照射所有頻率的 ¹H，移除 ¹H-¹³C 偶合，所有 ¹³C 訊號都顯示為單峰。但 ¹⁹F 和 ³¹P 的偶合不被 BBD 消除，因此仍可見 ¹³C-¹⁹F 和 ¹³C-³¹P 分裂。

18.9 ¹³C 衛星峰（Satellite peaks）

在 ¹H NMR 中，¹³C（1.1% 天然豐度）與 ¹H 的偶合產生「衛星峰（satellites）」：

  • 主峰兩側各有一個衛星峰，相距各 ¹J_CH/2
  • 每個衛星峰的強度約為主峰的 0.55%（= 1.1% × 1/2）
  • 一對衛星峰合計約 1.1% 的主峰高度
  • 在濃度高、測量精確時可見；通常用於確認高純度樣品或鑑定溶劑峰

TMS（四甲基矽烷）的衛星峰

TMS（參考峰）也有 ¹³C 衛星峰。¹J_CH(TMS) ≈ 120 Hz，衛星峰位於 δ 0 ± 60 Hz（在 500 MHz NMR 上即 ± 0.12 ppm）。

18.10 結構鑑定案例

案例：Lycorea 蝴蝶的性費洛蒙

分子式 C₇H₉NO，不飽和度 = (2×7 + 2 − 9 + 1)/2 = 4，含氮不計。高不飽和度暗示芳香環（3個不飽和度）＋一個 C=O（1個）。

¹H NMR 資料： δ 2.4 ppm (3H, s)：CH₃（甲基，與環相連） δ 2.5 ppm (3H, s)：COCH₃（乙醯甲基） δ 6.1 ppm (1H, m, J = 2.5, 3.5 Hz)：吡咯環 H δ 6.6 ppm (1H, m, J = 2.5, 3.5 Hz)：吡咯環 H δ 8.8 ppm (1H, 寬，NH)：吡咯 N-H 結構推論： → 吡咯環（J = 2.5 Hz 為相鄰 H，J = 3.5 Hz 為間位 H） → 帶甲基（δ 2.4）和乙醯基（δ 2.5 的 COCH₃） → 3-甲基-4-乙醯吡咯（N-甲基位置由化學位移和分子式確認）

本章摘要

第18章 核心概念

  • ¹³C 羰基：酮/醛 195–215 ppm；酸衍生物全部重疊在 164–185 ppm
  • 醛鑑定：¹H δ 9–10.5 ppm；IR 2720 + 2820 cm⁻¹（C-H 伸縮）
  • IR 羰基頻率：醯氯 1815 > 酸酐 1790+1810 > 酯 1745 > 酮 1715 > 醛 1725 > 醯胺 1650 cm⁻¹
  • IR 修正：共軛 −30；環張力 +30/+65/+100（五/四/三元環）；N 共振 −85
  • 環丙烷 ¹H：δ ≈ 0 至 −0.44 ppm（高場，高 s 字符）
  • 炔烴 ≡C-H：¹H δ ≈ 1.8–2.5 ppm；¹³C ≡C 在 60–90 ppm
  • 環己烷偶合：ax-ax ³J = 10–12 Hz；ax-eq = 3–5 Hz；eq-eq = 2–3 Hz
  • 異核偶合：¹⁹F 和 ³¹P 均為 I = 1/2，¹J 可達數百 Hz，不被 BBD 消除
  • ¹³C 衛星峰：¹H NMR 主峰兩側各 J/2 處，強度各 0.55%
