第十九章

親電加成至烯烴

Electrophilic addition to alkenes

19.1 烯烴作為親核劑

烯烴的 π 鍵是親核劑：HOMO 是填充的 π 軌道，可以提供電子給親電試劑（LUMO）：

π 電子 → 親電試劑（E⁺） HOMO（π） + LUMO（σ* of E-LG） ↓ E 與一個 C 形成新鍵，正電荷轉移到另一個 C ↓ Nu⁻ 攻擊碳陽離子

整體機制：親電試劑（E⁺）加到一個碳，親核試劑（Nu⁻）加到另一個碳，完成 1,2-加成。

烯烴的反應性（相對於 Br₂ 環氧化速率）

烯烴類型相對速率（m-CPBA 環氧化）
乙烯（CH₂=CH₂）1（基準）
一取代（RCH=CH₂）~24×
二取代（RCH=CHR 或 R₂C=CH₂）~500×
三取代（R₂C=CHR）~5000×
四取代（R₂C=CR₂）>6500×

取代基越多 → π HOMO 能量越高（超共軛效應）→ 與親電試劑 LUMO 能量差越小 → 更快反應。

19.2 溴加成與溴鎓離子

烯烴與 Br₂ 的加成是教科書中最重要的親電加成反應：

機制（兩步）： 步驟1：π 電子端攻擊 Br-Br σ*（LUMO） → 形成溴鎓離子（bromonium ion，三元環 Br⁺） → Br⁻ 離去 Br⁺ / \ C C （三元環，環張力大） （對稱，若兩個 C 不等價則不對稱） 步驟2：Br⁻ 由背面進行 SN2 攻擊（在位阻較小端） → 反式（anti）加成 Br 和 Br⁻ 整體：Br₂ 反式加成至 C=C

Bromonium 離子的立體化學後果

  • 溴鎓離子是環狀中間體，Br⁻ 只能從背面攻擊（SN2）
  • 結果：anti 加成（兩個 Br 在雙鍵的反面）
  • 立體專一性：Z-但-2-烯 + Br₂ → (±)-內消旋（anti 反式）；E-但-2-烯 + Br₂ → meso 化合物

Z-but-2-ene 與 E-but-2-ene 的 Br₂ 加成

Z-但-2-烯 + Br₂： bromonium 形成，Br⁻ 攻擊 → 一對鏡像異構物（(2R,3R) 和 (2S,3S)）[(±) 外消旋混合物] E-但-2-烯 + Br₂： → meso-2,3-二溴丁烷（有對稱面，光學活性消失）

不對稱烯烴的溴鎓離子開環

若兩個 C 不等價，溴鎓離子是非對稱的；Br⁻ 優先攻擊帶更多部分正電荷的碳（通常是較多取代的碳）：

CH₂=CHCH₃ + Br₂ → bromonium 離子（較多 δ⁺ 在 C2） Br⁻ 攻擊 C2（SN2） → BrCH₂-CHBr-CH₃（1,2-二溴丙烷）

19.3 環氧化（Peracid 法）

過酸（peracid，如 m-CPBA）將 O 轉移給烯烴，形成環氧化物（epoxide）：

m-CPBA（過間氯苯甲酸） O O⁻ ‖ / Ar-C-O-O-H + C=C → Ar-C=O + /C-C\ (epoxide，三元環)

機制：π 電子攻擊 O-O 鍵的 σ*（親電加成）；兩個 C-O 鍵在同一個面同時形成：

環氧化立體化學

  • syn 加成：O 從同一面加到兩個碳
  • 立體專一性：cis-烯烴 → cis-環氧化物；trans-烯烴 → trans-環氧化物

環氧化物的開環

酸性條件（H₃O⁺）：SN1-like，Nu 攻擊較多取代端 (但整體仍 anti 加成，因從外面進攻) 鹼性條件（NaOH/Nu⁻）：SN2，Nu 攻擊較少取代端 → anti 加成 總結：無論酸鹼，環氧化物開環的兩個新基團呈 trans（anti）關係

m-CPBA 環氧化 + NaOH 的整體立體化學

m-CPBA（syn 環氧化）→ 環氧化物（Nu⁻ 親核取代，anti）→ 最終 diol：syn 環氧化 + anti 開環 = trans-diol（anti 二醇）。

19.4 HBr 加成與 Markovnikov 規則

HBr 加成是最基本的親電加成，說明了區位選擇性（Markovnikov 規則）：

機制（兩步）： 步驟1（慢，速率決定）： H⁺ 加到 C=C（π 作為親核劑），形成碳陽離子 → H 加到取代基較少的碳（形成較穩定的碳陽離子） 步驟2（快）： Br⁻ 從外面攻擊碳陽離子 → Br 加到帶正電的碳

Markovnikov 規則

H 加到取代基較少的 C；Br（鹵素）加到取代基較多的 C。

根本原因：較多取代的碳陽離子（三級 > 二級 > 一級）更穩定（超共軛效應），因此 H 加到少取代碳形成的碳陽離子優先形成。

丙烯的 HBr 加成

CH₃-CH=CH₂ + HBr H⁺ 加到 C3（少取代端）→ CH₃-CH⁺-CH₃（二級碳陽離子，穩定） 或 H⁺ 加到 C2（多取代端）→ CH₃-CH₂-CH₂⁺（一級碳陽離子，不穩定） Br⁻ 攻擊二級碳陽離子 → CH₃-CHBr-CH₃ (Markovnikov 產物)

19.5 溴醇（Bromohydrin）

在 Br₂/H₂O 條件下，H₂O 作為親核劑攻擊溴鎓離子，形成溴醇（bromohydrin）：

烯烴 + Br₂/H₂O 1. 形成溴鎓離子 2. H₂O（而非 Br⁻）攻擊（SN2，anti） 3. 失去 H⁺ 結果： Br 和 OH 呈 anti 加成 OH 加到較多取代端（H₂O 攻擊較多 δ⁺ 的碳）

溴醇 → 環氧化物

溴醇（anti 加成的 Br 和 OH 相鄰） + NaOH → 分子內 SN2（O 攻擊 Cβ-Br） → 環氧化物（inverted at Br carbon） 整體：Br₂/H₂O 然後 NaOH = 環氧化

19.6 二烯的親電加成

共軛二烯（如 1,3-丁二烯）與親電試劑的加成可得到 1,2-加成或 1,4-加成產物：

CH₂=CH-CH=CH₂ + HBr H⁺ 加到 C1 → 烯丙基碳陽離子（共振穩定）： CH₃-CH=CH-CH₂⁺ ↔ CH₃-CH⁺-CH=CH₂ (C4+) (C2+) Br⁻ 攻擊 C4（1,2-加成）： CH₃-CHBr-CH=CH₂ (動力學，低溫) Br⁻ 攻擊 C2（1,4-加成）： CH₃-CH=CH-CH₂Br (熱力學，高溫，較穩定的內烯烴)

1,2 vs 1,4 加成的控制

  • 動力學控制（低溫）→ 1,2-加成（Br⁻ 攻擊更近的碳 C4，TS 能量較低）
  • 熱力學控制（高溫）→ 1,4-加成（較取代的、更穩定的烯烴）

19.7 二羥化反應

兩種路線將烯烴轉化為鄰二醇（vicinal diol），立體化學相反：

Anti 二羥化（反式二醇）

方法：m-CPBA → 環氧化物，然後 H₂O/H⁺ 或 NaN₃ 等親核劑 （syn 環氧化 + anti 開環 = anti 二醇） m-CPBA H₃O⁺ 烯烴 ────→ 環氧化物 ────→ trans-diol

Syn 二羥化（順式二醇）

方法1：OsO₄（四氧化鋨，化學計量） OsO₄ + 烯烴 → 環狀 osmate 酯（Os-O 同面 → syn 加成） H₂O 水解 → syn-diol + Os(VI) 方法2：OsO₄（催化量）+ NMO（N-甲基嗎啉-N-氧化物） NMO 再氧化 Os(VI) → Os(VIII)，循環使用 → 仍給 syn-diol（Upjohn 法）

Anti vs Syn 二羥化對比

方法試劑立體化學機制
Antim-CPBA → H₃O⁺/H₂OTrans diolEpoxide SN2 開環
SynOsO₄（+ NMO）Cis diol協同[3+2]環加成

碘酸鹽裂解（Periodate cleavage）

syn-diol + NaIO₄ → C-C 鍵斷裂 + 兩個羰基化合物（醛或酮） （可用於確認 diol 位置，或合成特定羰基） OsO₄ / NaIO₄ 一鍋反應： 烯烴直接裂解為兩個羰基（稱為「氧化裂解」）

19.8 臭氧化裂解（Ozonolysis）

O₃ 與烯烴反應，裂解 C=C 雙鍵形成兩個羰基化合物：

步驟： 1. O₃ + 烯烴 → 臭氧化物（molozonide）→ 重排為 ozonide 2. 還原/氧化開環 後處理試劑決定最終產物： + Me₂S（二甲基硫）： → 醛或酮（還原後處理） + PPh₃（三苯基磷）： → 醛或酮（溫和還原） + H₂O₂（過氧化氫）： → 羧酸（氧化後處理） + NaBH₄（硼氫化鈉）：→ 醇（強還原）

臭氧化的應用

CH₃CH=CHCH₂CH₃ + O₃，然後 Me₂S： → CH₃CHO（乙醛）+ OHC-CH₂CH₃（丙醛） 環狀烯烴的臭氧化： cyclohexene → OHC(CH₂)₄CHO（己二醛） （一個分子，但原來 C=C 兩端都變醛）

19.9 烯烴水合

直接酸催化水合

烯烴 + H₂SO₄(稀) + H₂O → 醇（Markovnikov） 適用：三級或穩定碳陽離子 限制：一級和二級烯烴常發生重排

氧汞化-去汞（Oxymercuration-demercuration）

步驟1：Hg(OAc)₂ / H₂O → 汞鎓離子（mercurinium，類似 bromonium） → H₂O anti 攻擊較多取代碳 → β-羥基有機汞化合物 步驟2：NaBH₄ → 還原 C-Hg 為 C-H（保留構形，未必） 整體：Markovnikov 加 OH，無重排 立體化學：形式上 anti（但 NaBH₄ 步驟可消去立體資訊）

氧汞化的優點

  • 沒有碳陽離子中間體 → 無重排
  • Markovnikov 選擇性
  • 適用各種烯烴底物

19.10 硼氫化反應

硼氫化（hydroboration）是烯烴最重要的反應之一，由 H. C. Brown 發展（諾貝爾獎 1979）：

步驟1（硼氫化）： BH₃（或 9-BBN、其他烷基硼烷）+ 烯烴 → 協同（concerted）[2+2] 環加成 → B 和 H 從同面加成（syn 加成） → B 加到取代基較少的碳（anti-Markovnikov 電子效應 + 立體效應） 步驟2（氧化）： NaOH + H₂O₂（or OOH⁻） → C-B 轉化為 C-OH（保留構形） 整體結果： anti-Markovnikov 的 syn 加成 OH 在取代基較少的碳（立體選擇且具 syn 特性）

硼氫化立體化學規則

  • B 加到取代基較少的碳（anti-Markovnikov，電子 + 空間效應）
  • H 和 B 從同面加成（syn）
  • 氧化保留構形（NaOH/H₂O₂ 是保留構形的氧化）
  • 最終：末端烯烴 → 一級醇（Markovnikov 只給二級醇）

1-甲基環戊烯的硼氫化

CH₃ CH₃ | | BH₃ 從同面（syn）加 B 和 H | | 1-methylcyclopentene → B 在 C2，H 在 C1（syn，少取代端 B） → NaOH/H₂O₂ → OH 在 C2，H 在 C1 → syn-2-methylcyclopentan-1-ol（順式）

9-BBN（9-Borabicyclo[3.3.1]nonane）

9-BBN 是更位阻更大的硼試劑，比 BH₃ 更具有區位選擇性：

  • 對末端烯烴選擇性更高（99% anti-Markovnikov）
  • 對內烯烴具有更高立體選擇性
  • 常用於天然物合成中需要精確控制立體中心的情況

19.11 炔烴的親電加成

炔烴的水合（Markovnikov，Hg²⁺ 催化）

R-C≡C-H + H₂O / H⁺ / Hg²⁺ 催化 → 烯醇（enol）中間體（Markovnikov：OH 在較多取代碳） → 互變異構（keto-enol tautomerism）→ 酮 R-C≡C-H → R-C(OH)=CH₂（烯醇）→ R-C(=O)-CH₃（甲基酮） 末端炔 → 甲基酮（Markovnikov）

炔烴的硼氫化（anti-Markovnikov）

R-C≡C-H + BH₃（或 9-BBN）→ 乙烯基硼烷（syn 加成） → NaOH/H₂O₂ → 烯醇（anti-Markovnikov 端） → 互變異構 → 醛（末端炔 → 醛） R-C≡C-H → RCH₂-CHO（醛，anti-Markovnikov）

炔烴水合的選擇性

方法試劑產物（末端炔）
Hg²⁺ 催化水合H₂O, H₂SO₄, HgSO₄甲基酮 R-CO-CH₃（Markovnikov）
硼氫化-氧化BH₃/THF 或 9-BBN, 然後 H₂O₂/NaOH醛 R-CH₂-CHO（anti-Markovnikov）
