第二十章

烯醇與烯醇酯的形成與反應

Formation and Reactions of Enols and Enolates

酮-烯醇互變異構現象

羰基化合物（酮、醛）與烯醇之間可以相互轉換，稱為酮-烯醇互變異構現象（keto-enol tautomerism）。兩者並非共振結構，而是真實存在的異構體，在質子溶劑中可以快速達到平衡。

例：二甲酮（dimedone）的互變異構

Dimedone（1,3-環己二酮衍生物）在 CDCl₃ 中：

  • 酮式（keto form）：67%
  • 烯醇式（enol form）：33%

1,3-二羰基化合物的烯醇含量遠高於一般酮，因為烯醇式可形成分子內氫鍵，且雙鍵與另一個羰基共軛，增加穩定性。

關鍵概念

互變異構體（tautomers）≠ 共振結構。互變異構體是真實的分子異構體，需要斷開和形成共價鍵（通常是 O−H 鍵和 C−H 鍵），且在適當條件下可以分離。

烯醇化機制

烯醇化（enolization）可由酸或鹼催化：

酸催化烯醇化

酸催化烯醇化： O OH ‖ | R-C-CH₂R' + H⁺ ——→ R-C-CH₂R' (共軛酸) | ↓ 去質子 OH | R-C=CHR' (烯醇) 步驟： 1. 質子先加到 O 上 → 形成氧陽離子（oxonium ion） 2. 再從 α-C 失去質子 → 烯醇 關鍵：先質子化 O，再去質子化 C

鹼催化烯醇化

鹼催化烯醇化： O ⊖O ‖ | R-C-CH₂R' + B: ——→ R-C=CHR' + BH 步驟： 1. 鹼從 α-C 奪取質子 → 形成烯醇鹽陰離子（enolate ion） 2. 烯醇鹽質子化 → 烯醇 關鍵：鹼從 α-C 移除質子，生成烯醇鹽
注意

α-碳（α-carbon）指緊鄰羰基碳的碳原子。α-C 上的氫稱為 α-氫，因鄰近羰基的電子吸引效應，具有較高酸性（pKa ≈ 20，遠低於一般烷烴 pKa ≈ 50）。

烯醇鹽離子的結構

烯醇鹽（enolate ion）是一個三原子四電子的離域系統：

烯醇鹽的共振結構： ⊖O O⊖ | ‖ R-C=CH-R' ←——→ R-C-CH:-R' 氧上帶負電荷的共振式 碳上帶負電荷的共振式 (主要共振式) (次要共振式) 電荷分布：負電荷主要在 O 上 HOMO（最高占有分子軌道）：主要在 C 上 → 烯醇鹽是兩可親核劑（ambident nucleophile）： 可從 O 或 C 進行親核反應
關鍵概念：兩可親核劑

烯醇鹽既可從 O（氧端） 反應，也可從 C（碳端） 反應：

  • O-烷基化：從 O 攻擊親電試劑 → 生成烯醇醚（vinyl ether）
  • C-烷基化：從 C 攻擊親電試劑 → 在 α-C 引入取代基
  • O-醯化：從 O 攻擊醯氯 → 生成烯醇酯（enol ester）

可烯醇化的羰基化合物

並非所有羰基化合物都能被烯醇化：

化合物是否可烯醇化原因
酮（ketone）✓ 可有 α-H，pKa ≈ 20
醛（aldehyde）✓ 可有 α-H，pKa ≈ 17
酯（ester）✓ 可有 α-H，pKa ≈ 25
醯氯（acyl chloride）✓ 可有 α-H
羧酸（carboxylic acid）✗ 否優先形成羧酸根（carboxylate），pKa ≈ 5
醯胺（amide）✗ 否（通常）優先去除 N-H（更酸，pKa ≈ 25）
注意

羧酸在鹼性條件下，O-H（pKa ≈ 5）遠比 α-C-H（pKa ≈ 30+）酸，因此鹼會優先奪取 O-H 形成羧酸根，而不會烯醇化 α-C。醯胺中 N-H 也比 α-C-H 酸（N-H pKa ≈ 25，C-H pKa ≈ 30+），故優先去除 N-H。

烯醇鹽的反應

烯醇鹽從 C 端進行親核反應是有機化學中建立 C-C 鍵的重要方法。

與醯氯反應：O-醯化 → 烯醇酯

烯醇鹽 + 醯氯 → 烯醇酯（O-醯化）： ⊖O O O | ‖ ‖ R-C=CH-R' + R''COCl → R-C-CH-C-R'' | (O-acylation product) 烯醇酯（enol ester）的用途： - 在有機合成中作為活化的醯基供體 - 可進一步水解或轉酯化

與烷基鹵化物反應：C-烷基化

烯醇鹽 + 烷基鹵 → α-烷基化產物（C-烷基化）： ⊖O O | ‖ R-C=CH-R' + R''-X → R-C-CH(R')-R'' ↑ α-碳上引入 R'' 基 這是建立 C-C 鍵的重要反應！ 條件：強鹼（LDA）在 -78°C，確保完全去質子化

穩定的烯醇

大多數烯醇在室溫下不穩定，會迅速轉換回酮式。但在某些特殊情況下，烯醇可以穩定存在：

動力學穩定的烯醇

例：乙烯醇（vinyl alcohol）

乙烯醇（CH₂=CHOH）在 900°C 下可以氣態存在（動力學穩定），在常溫溶液中壽命極短，迅速轉換為乙醛（ΔG° ≈ -40 kJ/mol 有利於酮式）。

熱力學穩定的烯醇

1,3-二羰基化合物（如乙醯丙酮 acetylacetone、dimedone）的烯醇式因兩個因素而穩定：

  • 分子內氫鍵：烯醇 O-H 與另一羰基 C=O 形成六元環氫鍵
  • 共軛：C=C-C=O 共軛體系使能量降低
乙醯丙酮的烯醇式（含分子內氫鍵）： O OH O ‖ | ‖ H₃C-C-CH=C-CH₃ ↕ 分子內氫鍵（六元環） 烯醇含量：約 80%（CDCl₃ 中） 其他穩定烯醇： - 維生素 C（烯二醇） - 苯酚（完全芳香化的烯醇，非常穩定）

互變異構現象的化學後果

雙鍵遷移至共軛位置

γ-質子化導致雙鍵遷移： O O ‖ ‖ R-CH=CH-CH₂-R' → R-CH₂-CH=CH-R' （α,β-不飽和酮） （β,γ-不飽和酮 → 遷移到共軛位置） 鹼催化下，γ-H 被奪去 → 烯醇鹽 → 質子化 → 雙鍵移至 α,β 位（共軛位置更穩定）

消旋化（Racemization）

例：布洛芬（Ibuprofen）的體內消旋化

布洛芬含有一個 α-C 手性中心（相鄰於羧基）。在體內酵素催化下，S-布洛芬（無活性）可通過烯醇中間體轉換為 R-布洛芬（活性）。這是一個有治療意義的體內消旋化過程。

羰基化合物的鹵化反應

酮的 α-C 可發生鹵化反應，反應條件不同，產物也不同：

酸催化鹵化（單鹵化）

酸催化鹵化 → 單鹵化（在更取代的 α-C）： O O ‖ ‖ CH₃-C-CH₃ + Br₂/H⁺ → CH₃-C-CH₂Br + HBr 機制： 1. 酸催化烯醇化（慢，RDS） 2. 烯醇攻擊 Br₂（快） → 產物一旦形成，不再進一步反應（因為 α-溴酮的烯醇化比原料慢） → 導向更取代的 α-C（因較取代的烯醇更穩定）

鹼催化鹵化（多鹵化 + 鹵仿反應）

鹼催化鹵化 → 多鹵化 → 鹵仿反應： O O O ‖ ‖ ‖ CH₃-C-CH₃ + Br₂/OH⁻ → CH₃-C-CBr₃ → CH₃-C-O⁻ + CHBr₃ 溴仿（bromoform） 機制： 1. OH⁻ 烯醇化 → 烯醇鹽 2. Br₂ 鹵化 → α-溴酮（更易被去質子，因 Br 是 EW 基） 3. 重複 → 三鹵化物 4. OH⁻ 進攻三鹵化物 → 四面體中間體 → CX₃⁻ 離去 → 鹵仿 碘仿反應（iodoform test）：用 I₂/NaOH 鑑別甲基酮 → CHI₃（黃色沉澱）

亞硝化反應

α-亞硝化反應（α-Nitrosation）： O O O O ‖ ‖ ‖ ‖ CH₃-C-R → NaNO₂/HCl → CH₃-C-CH(NO)-R → 水解 → CH₃-C-CO-R 亞硝基酮 二酮 (可轉換為肟 oxime) 步驟： 1. NaNO₂ + HCl → HNO₂（亞硝酸） 2. 酮烯醇化 → 烯醇攻擊 NO⁺ 3. 得到 α-亞硝基酮 → 互變為肟（oxime，-C=N-OH） 4. 酸水解 → α-二酮（α-diketone）

穩定烯醇鹽的等效物

有機合成中，常需要生成特定的烯醇鹽（動力學 vs 熱力學），這需要特殊試劑：

鋰烯醇鹽（Lithium Enolates）：LDA 法

使用 LDA（二異丙基醯胺鋰）生成動力學烯醇鹽： O OLi ‖ | R-C-CH₂R' + LDA, -78°C → R-C=CHR' 動力學烯醇鹽 （less substituted / kinetic） LDA 的特點： - 強鹼（pKa ≈ 36），可完全去質子化酮（pKa ≈ 20） - 空間位阻大（兩個異丙基），不進行親核反應 - 低溫（-78°C）：避免熱力學平衡 → 動力學控制 - 生成動力學（less substituted）烯醇鹽 比較： - NaH / KOtBu：熱力學烯醇鹽（more substituted） - LDA / -78°C：動力學烯醇鹽（less substituted）

矽基烯醇醚（Silyl Enol Ethers，TMS 烯醇醚）

製備矽基烯醇醚（穩定的烯醇等效物）： O OTMS ‖ TMS-Cl | R-C-CH₂R' + 弱鹼（Et₃N）→ R-C=CHR' 矽基烯醇醚（silyl enol ether） 特點： - TMS = trimethylsilyl，-Si(CH₃)₃ - 穩定存在（不像烯醇鹽在溶液中不穩定） - 可分離、儲存 - 水解（酸性條件）→ 酮 用途： - 保護特定的烯醇鹽位置 - 作為合成等效物（後續在 Lewis 酸存在下反應）
動力學 vs 熱力學烯醇鹽
條件生成特點
強鹼（LDA）, 低溫, 無平衡動力學烯醇鹽在較不取代的 α-C（去質子較快）
弱鹼, 高溫, 平衡條件熱力學烯醇鹽在較多取代的 α-C（較穩定）

烯醇醚（Enol Ethers）

烯醇醚（vinyl ether）是烯醇的醚衍生物（O-烷基烯醇），可作為穩定的烯醇等效物。

烯醇醚的製備

烯醇醚的製備： 1. 醇 + 乙烯乙炔（acid 催化 transetherification） 2. 醛/酮 + 醇 + TsOH → 縮醛（acetal，非烯醇醚） 3. 烯醇鹽 + 烷基鹵（O-烷基化） → 烯醇醚

烯醇醚的水解（酸催化）

烯醇醚的酸催化水解： OMe O⊕Me O | | ‖ R-C=CHR' + H⁺ → R-C-CH₂R' → R-C-CH₂R' + MeOH 氧鎓離子 (oxonium ion) 機制： 1. 雙鍵質子化 → 氧鎓離子（帶正電 O） 2. 水分子攻擊 C（親核加成） 3. 失去 MeOH → 得到半縮醛中間體 4. 失去 MeOH（酸催化）→ 最終羰基化合物 重要規則：雙鍵質子化遵循馬氏規則 → 質子加在雙鍵含 H 較多的 C 上（生成更穩定的碳陽離子）

本章摘要

第二十章核心要點
  • 酮-烯醇互變：可逆，需斷裂/形成 C-H 與 O-H 鍵；互變異構體 ≠ 共振結構
  • 烯醇化機制：酸催化（先質子化 O），鹼催化（先去質子化 α-C）
  • 烯醇鹽結構：3 原子 4 電子離域，O 上帶負電為主；HOMO 在 C，因此 C-烷基化動力學上優先
  • 可烯醇化：酮、醛、酯、醯氯；羧酸和醯胺因其他位置更酸而不易烯醇化
  • 穩定烯醇：1,3-二羰基化合物（分子內氫鍵 + 共軛）、苯酚（芳香性）
  • 鹵化：酸性條件 → 單鹵化；鹼性條件 → 多鹵化 → 鹵仿反應
  • LDA 法：強鹼 + 低溫 → 動力學烯醇鹽（less substituted）
  • 矽基烯醇醚：穩定的烯醇等效物，酸催化水解可還原
  • 烯醇醚水解：酸催化，經氧鎓離子中間體，得到酮和醇
