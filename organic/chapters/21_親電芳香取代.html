第二十一章

親電芳香取代

Electrophilic Aromatic Substitution (EAS)

苯的結構與芳香性

苯（benzene, C₆H₆）是所有 EAS 反應的基礎底物。理解其結構是理解 EAS 機制的前提。

苯的關鍵特徵： 1. 所有 C-C 鍵等長：1.39 Å（介於 C-C 1.54 Å 和 C=C 1.34 Å 之間） 2. 六個 H 全部等效（¹H NMR: δ 7.2，低場，芳環電流效應） 3. 平面型分子，所有 C 為 sp² 4. 環狀共軛（6π 電子）→ 芳香性（Hückel 規則：4n+2 π 電子，n=1） 5. 芳環去電子化比烯烴困難 → 苯傾向「保留芳香性」→ 取代而非加成 苯的氘交換（deuterium exchange）： PhH + D₂SO₄ → PhD + HDSO₄（快速，確認苯可被質子化） 苯酚在鹼性條件下氘交換更快（→ 說明 EAS 是可逆的 σ-complex 步驟）

EAS 通用機制

親電芳香取代（EAS）的通用機制分兩步：

EAS 通用機制： 步驟 1：親電試劑（E⁺）攻擊苯環 → 形成 σ-錯合物（arenium ion） （速率決定步驟 = 速率限制步驟，RDS） H E \ / [苯環]⁺ ← arenium ion（Wheland intermediate） sp³ 碳，非芳香，正電荷分散到三個 C 步驟 2：鹼（通常為共軛鹼 A⁻）奪取 H → 恢復芳香性 總反應：ArH + E⁺ → ArE + H⁺ 特點： - 速率決定步驟 = E⁺ 進攻 → 形成 arenium ion - 第二步快（芳香性恢復作為驅動力） - 取代（不是加成）：保留苯的芳香性
關鍵：arenium ion（Wheland 中間體）
  • sp³ 碳（帶 H 和 E 的碳）
  • 非芳香（不再是平面六元共軛環）
  • 正電荷離域到環上 3 個碳（1,3,5 位相對於 sp³ 碳）
  • 穩定性由中間體能量決定 → 取代基效應透過中間體穩定性解釋

硝化反應（Nitration）

苯的硝化反應： PhH + HNO₃/H₂SO₄（混酸）→ PhNO₂ + H₂O 親電試劑的生成： HNO₃ + H₂SO₄ → NO₂⁺ + HSO₄⁻ + H₂O 硝醯陽離子（nitronium ion） NO₂⁺ 的特徵： - 線形分子，N 帶正電 - 強親電試劑 - 由混酸（HNO₃ + H₂SO₄）生成 反應過程： 苯 + NO₂⁺ → arenium ion（正電荷離域）→ -H⁺ → 硝基苯 用途： - 苯 → 硝基苯（工業 → 還原 → 苯胺 → 染料、藥物） - 硝基苯 + HNO₃/H₂SO₄（更強，加熱）→ 間-二硝基苯（NO₂ 為間位導向）

磺化反應（Sulfonation）

苯的磺化反應： PhH + SO₃/H₂SO₄（發煙硫酸）→ PhSO₃H（苯磺酸） 親電試劑：SO₃ 或 H₂S₂O₇ 中的 SO₃H⁺ 重要特點： 1. 磺化反應是可逆的（reversible）！ PhSO₃H + H₂O → PhH + H₂SO₄（在稀酸、高溫下） 2. 可利用磺化的可逆性： - 先磺化 → 佔據某位置（保護） - 進行其他 EAS 取代 - 去磺化（去除磺基）→ 恢復 H 這讓磺基成為「臨時」取代基，用於區域選擇性合成！

Friedel-Crafts 反應

Friedel-Crafts 烷基化（Alkylation）

Friedel-Crafts 烷基化： PhH + R-Cl + AlCl₃ → Ph-R + HCl + AlCl₃（再生） 親電試劑的生成： R-Cl + AlCl₃ → R⁺ + AlCl₄⁻（碳陽離子） 問題： 1. 碳陽離子重排（rearrangement）： n-PrCl + AlCl₃ → 正丙基碳陽離子 → (1,2-H 遷移) → 異丙基碳陽離子 → 主要得到異丙基苯（不是正丙基苯） 2. 多烷基化（polyalkylation）： Ph-R 比苯更活化（烷基 = 活化基）→ 繼續被烷基化 用 t-BuCl 可避免重排（叔丁基陽離子本已是最穩定）

Friedel-Crafts 醯化（Acylation）

Friedel-Crafts 醯化： PhH + R-COCl + AlCl₃ → Ph-CO-R（芳酮）+ HCl 親電試劑的生成： R-COCl + AlCl₃ → [R-C≡O]⁺ + AlCl₄⁻（醯陽離子，acylium ion） 優點（相比烷基化）： 1. 醯陽離子不重排（sp 碳，沒有遷移途徑） 2. 不發生多醯化（苯酮比苯更去活化，因 C=O 是 EW 基） → 乾淨地得到單醯化產物！ 醯基的還原： Ar-CO-R → Ar-CH₂-R 方法：Clemmensen（Zn/HCl）或 Wolff-Kishner（NH₂NH₂/KOH） → 結合 F-C 醯化 + 還原，可間接引入烷基（避免重排）

活化基：羥基（OH）與胺基（NH₂）

羥基和胺基是強活化、鄰/對位導向基。

苯酚（Phenol）的 EAS

苯酚的活化與方向性： - OH 是強活化基（鄰/對位導向） - 機制：O 的孤對電子直接共振供電到鄰位和對位 → 穩定 arenium ion OH OH OH | → | → | [苯] 鄰位鹵化 對位鹵化 苯酚 + Br₂（不需要 AlCl₃！）→ 2,4,6-三溴苯酚（+ 3 HBr） 原因：苯酚已高度活化，Br₂ 本身即足夠強的親電試劑 控制在單溴化： 苯酚 + 1 eq Br₂（低溫，CCl₄）→ 4-溴苯酚（對位，85%）+ 2-溴苯酚（15%） → 低溫下動力學控制 → 主要得到對位（對位更穩定的 arenium ion） 反應箭頭的起點：由 O 的孤對電子出發！（不是從苯環 π 電子出發）

苯胺（Aniline）的 EAS

苯胺的反應性： - NH₂ 比 OH 更強的活化基（N 的電負性比 O 小，孤對電子更易供電） - 苯胺的活化程度 > 苯酚 問題：胺基太活化，可能過度反應 解決：先乙醯化（acetylation）→ 醯胺（amide）→ 適度降低活化程度 PhNH₂ + Ac₂O → PhNHCOCH₃（acetanilide） → EAS 反應（更溫和，主要對位） → 水解 → PhNH₂（恢復） 苯胺 + Br₂/H₂O → 2,4,6-三溴苯胺（直接反應，過度溴化） 乙醯苯胺 + 1 eq Br₂ → 4-溴乙醯苯胺（主要對位，84%）

烷基苯（甲苯等）的 EAS

烷基苯的活化與方向性： 甲苯（toluene）： - CH₃ 是活化基（鄰/對位導向） - 機制：CH₃ 的超共軛（hyperconjugation，σ-共軛） - 甲苯 EAS 速率 ≈ 苯的 25 倍（在硝化中） 甲苯 + HNO₃/H₂SO₄ → 鄰-硝基甲苯（58%) + 對-硝基甲苯（38%) + 間-硝基甲苯（4%) （鄰位 + 對位共佔 96%） 為何甲基是鄰/對位導向？ CH₃ → σ-共軛（超共軛）或誘導效應 → 在鄰位和對位 arenium ion 中，正電荷可傳遞到 CH₃，使中間體更穩定 → 間位 arenium ion 沒有這個優勢，能量較高

去活化基：吸電子基（EW groups）

吸電子基 → 間位導向 + 去活化： 典型 EW 基：-NO₂, -CF₃, -COR, -SO₃H, -NMe₃⁺, -CN 原因： - EW 基使苯環電子密度降低（去活化，比苯慢） - EW 基在鄰位/對位 arenium ion 中，正電荷與 EW 基直接相鄰 → 不穩定 - 間位 arenium ion 中，正電荷不與 EW 基直接相鄰 → 相對穩定 → 生成間位產物（meta product） 硝基苯 + HNO₃/H₂SO₄（更強條件）→ 間-二硝基苯（92%） EW 基的不同程度： 完全去活化（鄰/對位產物幾乎無）：-NO₂, -NR₃⁺, -CF₃ 部分去活化：-COR, -CN, -SO₃H（仍主要得間位，但可能有少量鄰/對位）

鹵素取代基的雙重性格

鹵素（F, Cl, Br, I）的特殊性： → 鄰/對位導向（指向性：透過共振供電） → 去活化（速率：比苯慢，因誘導吸電子效應） 這是一個矛盾的組合！原因如下： 1. 誘導效應（induction）：X 電負性強 → 透過 σ-鍵從苯環拉電子 → 去活化 2. 共振效應（resonance）：X 孤對電子 → 透過 π-共軛供電到苯環 → 鄰/對位 arenium ion 更穩定 最終結果： - 去活化（比苯慢）：誘導效應主導 - 鄰/對位導向：共振效應主導方向性 硝化相對速率（以苯 = 1）： PhF = 0.18（次活化） PhCl = 0.064（去活化） PhBr = 0.060（去活化） PhI = 0.12（輕微去活化） → F 的誘導吸電子最強（最小原子，σ-鍵最有效） → 但 F 的共振供電也最強（最小，p 軌道最有效重疊） → 淨效果：F 是最弱的去活化鹵素

EAS 取代基效應彙整

取代基電子效應方向性活化/去活化
-OH, -OR共振供電（O 孤對）鄰/對位強活化
-NH₂, -NR₂共振供電（N 孤對）鄰/對位最強活化
-alkyl（甲基等）超共軛/誘導供電鄰/對位活化（弱）
-F誘導吸電 > 共振供電鄰/對位輕微去活化
-Cl, -Br, -I誘導吸電 > 共振供電鄰/對位去活化
-NO₂, -CF₃, -NR₃⁺強誘導 + 無共振供電間位強去活化
-COR, -CHO, -CO₂R共振吸電間位去活化

鄰位 vs 對位比例

鄰/對位導向基通常同時生成鄰位和對位產物，但比例受到多種因素影響：

影響鄰/對位比例的因素： 1. 空間效應（steric effect）： - 取代基越大 → 鄰位空間位阻越大 → 更多對位產物 - 例：苯甲醚（PhOMe）+ HNO₃ → 鄰（30%) + 對（70%) 2. 誘導效應（induction）： - O 和 N 的誘導吸電效應在鄰位稍強 → 使鄰位 arenium ion 略不穩定 - → 偏向對位 3. 電子效應（對位 vs 鄰位）： - 對位通常比鄰位稍多（更穩定） - 但實際比例因底物和親電試劑而異 乙醯苯胺 + Br₂ → 84% 對位，只有 10% 鄰位（4% 間位） 說明：大體積 NHCOMe + 稀酸條件 → 幾乎完全對位

本章摘要

第二十一章核心要點
  • 苯的特性：所有 C-C 等長（1.39 Å），6π 芳香，¹H NMR δ 7.2（環電流）
  • EAS 機制：E⁺ → arenium ion（RDS）→ -H⁺ → 恢復芳香性；是取代，不是加成
  • 硝化：NO₂⁺ 由 HNO₃/H₂SO₄ 混酸生成
  • 磺化：可逆！可用作臨時保護基
  • F-C 烷基化：有碳陽離子重排風險；F-C 醯化更乾淨（醯陽離子不重排，不多醯化）
  • OH, NH₂：強活化，鄰/對位導向（共振供電），苯酚不需 Lewis 酸即可溴化
  • 烷基：弱活化，鄰/對位導向（超共軛）
  • NO₂, CF₃, NR₃⁺：強去活化，間位導向（吸電子使鄰/對位 arenium ion 不穩定）
  • 鹵素：去活化（誘導效應主導），但鄰/對位導向（共振效應主導方向）
  • 鄰/對位比例：受空間效應（取代基大 → 對位多）和電子效應影響
