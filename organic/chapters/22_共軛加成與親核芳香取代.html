共軛加成與親核芳香取代

Conjugate Addition and Nucleophilic Aromatic Substitution

α,β-不飽和羰基化合物

α,β-不飽和羰基化合物（α,β-unsaturated carbonyl compounds）包含 C=C-C=O 共軛體系，是有機化學中最重要的功能性底物之一。

α,β-不飽和羰基的命名和結構： β α | | H₂C=CH-C=O ← 丙烯醛（acrolein，最簡單的例子） R（R = H 為醛，R = R' 為酮） 術語： - α 碳：緊鄰羰基碳（C=O 的鄰碳） - β 碳：α 碳的隔壁（雙鍵的另一端） - C=C 和 C=O 共軛 → LUMO 和 HOMO 都是離域的 LUMO（最低未佔分子軌道）分析： - 共軛系統的 LUMO 最大係數在 β-C 上 - → 親核試劑（HOMO 豐富電子）傾向攻擊 β-C（共軛加成） 但也有 C=O 羰基 C 可被攻擊（直接加成） → 形成競爭：1,2-加成 vs 1,4-加成

直接加成（1,2-）與共軛加成（1,4-）

兩種加成模式： 直接加成（1,2-addition）= 攻擊羰基碳（C=O）： β α 1 | | ‖ H₂C=CH-C=O + Nu⁻ → H₂C=CH-C-Nu | O⁻ (β,γ-不飽和醇，動力學產物) 共軛加成（1,4-addition / conjugate addition / Michael addition）= 攻擊 β-C： 4 3 2 1 | | | ‖ H₂C=CH-C=O + Nu⁻ → Nu-CH₂-CH=C-O⁻ ↓ 質子化 Nu-CH₂-CH₂-C=O (烯醇 → 酮，熱力學產物) 數字標記： 1 = 羰基 C（O 端為位置 1） 2 = α-C 3 = β-C 4 = 等等 「1,4」指的是電荷從 Nu⁻ 加到位置 4（=β-C），H⁺ 最終加到位置 1（=O⁻）

熱力學 vs 動力學控制

例：HCN 對 α,β-不飽和酮的加成

HCN 對丁烯酮的加成展現了溫度對產物的控制：

HCN/NaCN 對丁烯酮（但酮烯）的加成： CH₂=CH-CO-CH₃（丁烯酮）+ HCN 低溫（動力學控制）： → CN⁻ 攻擊 C=O（位置 1,2） → 直接加成產物（β-羥基腈） → 可逆！（1,2-加成是熱力學不利的） 高溫，80°C（熱力學控制）： → CN⁻ 攻擊 β-C（位置 1,4） → 共軛加成產物（γ-氰基酮） → 不可逆！（共軛加成熱力學有利，且一旦質子化後不易逆轉） 關鍵：共軛加成（1,4）是熱力學更穩定的產物 在條件允許平衡時（高溫、可逆試劑），共軛加成占優 不可逆的試劑（RLi, RMgBr）→ 動力學控制 → 直接加成

硬親核劑 vs 軟親核劑的規則

預測 1,2- vs 1,4-加成的最有用規則是硬軟親核劑原則（HSAB 理論的有機化學應用）：

親核劑類型加成位置產物例子
硬親核劑（hard, charge-dense）C=O（直接，1,2）醇（動力學）RMgBr, RLi, OH⁻, H₂O
軟親核劑（soft, polarizable）β-C（共軛，1,4）酮（熱力學）RS⁻, R₂CuLi, NaCN（高T）
硬軟親核劑記憶法
  • 硬親核劑：電荷密度大、難極化、反應性高（charge-controlled）→ 攻擊電荷密度最高的原子（C=O 的 C，因 O 的電負性使 C 帶δ+）→ 1,2-加成
  • 軟親核劑：易極化、大原子（S, Cu）→ 攻擊 LUMO 係數最大的原子（β-C）→ 1,4-加成（共軛加成）

有機銅試劑（Organocuprates）

有機銅試劑（lithium dialkylcuprate, R₂CuLi）是進行共軛加成的最佳試劑。

有機銅試劑的製備和反應： 製備（Gilman 試劑）： 2 RLi + CuI → R₂CuLi + LiI （兩莫耳 RLi 與一莫耳 CuI 反應） 反應： R₂CuLi + α,β-不飽和酮 → 共軛加成產物 例： (CH₃)₂CuLi + CH₂=CH-CO-CH₃ → CH₃-CH₂-CH₂-CO-CH₃ （甲基加到 β-C，共軛加成） Grignard 試劑的改良（催化量 CuCl）： RMgBr → R₂CuLi（加入 1% CuCl 轉換） → 由直接加成（RMgBr 本身的特性）→ 共軛加成 有機銅試劑特點： ✓ 高度選擇性共軛加成（1,4 >> 1,2） ✓ 溫和條件（低溫 -78°C 到 0°C） ✓ 可容忍多種官能基 ✗ 不與酯、醯胺、羧酸反應 ✗ 對水敏感

NaBH₄ 對 α,β-不飽和羰基的還原

NaBH₄ 對α,β-不飽和羰基的還原行為： 1. 簡單烯醛（enal，如丙烯醛 CH₂=CH-CHO）： NaBH₄ + 烯醛 → 攻擊 C=O（直接，1,2-還原） → 烯丙醇（allyl alcohol） CH₂=CH-CHO + NaBH₄ → CH₂=CH-CH₂OH（烯丙醇） 2. 烯酮（enone，如丁烯酮）： NaBH₄ + 烯酮 → 先 1,4-還原（H⁻ 到 β-C）→ 烯醇鹽 → 再還原 C=O → 饱和醇（double reduction） 3. Luche 條件（NaBH₄ + CeCl₃）： → 強制 1,2-加成（直接還原 C=O），不管是醛或酮 → 得到不飽和醇（保留雙鍵） 記憶： - 「Luche = allylic alcohol」（保留 C=C，還原 C=O） - CeCl₃ 使 Ce³⁺ 活化 C=O，使其更親電 → H⁻ 攻擊 C=O

共軛取代（Conjugate Substitution）

當 β-C 帶有離去基（例如鹵素）時，共軛加成後可以發生消除，整體上是取代反應。

共軛取代機制： β-鹵代烯酮（β-halo enone）+ 親核試劑（Nu）： Nu⁻ O | ‖ → Cl-CH=CH-C-R + Nu⁻ ↓ 1,4-加成（Nu 到 β-C） Cl | Nu-CH₂-C=C-O⁻ ↓ Cl⁻ 消除（氯是好的離去基） Nu-CH=CH-C=O （β-Nu 烯酮：取代產物） 整體：Cl（離去基）被 Nu（新基團）取代，雙鍵得以保留 實例： β-氯烯酮 + MeOH → β-甲氧基烯酮（烯醇醚） Cl-CH=CH-CO-R + MeO⁻ → MeO-CH=CH-CO-R 應用：西咪替丁（cimetidine）、雷尼替丁（ranitidine）的合成步驟

親核環氧化（Nucleophilic Epoxidation）

α,β-不飽和羰基可被氫過氧根離子（HOO⁻）環氧化，產生 α,β-環氧羰基化合物。

親核環氧化（Weiss-Cook 型）： α,β-不飽和酮 + H₂O₂/NaOH（鹼性條件）→ α,β-環氧酮 機制： 1. H₂O₂ + OH⁻ → HOO⁻ + H₂O（HOO⁻ = 親核試劑） 2. HOO⁻ 攻擊 β-C（共軛加成，「α-效應」：α-nucleus 具有額外的驅動力） 3. 生成 β-烷氧負離子（β-alkoxide） 4. 分子內 SN2：O⁻ 攻擊 Oα-O 鍵 → 環氧化物 + OH⁻ 離去 產物： CH₂=CH-CO-R + HOO⁻ → [β加成中間體] → 環氧-CH-CH₂-CO-R 立體化學： - 兩步加成/環化 → 中間有自由旋轉 - 最終給 trans-環氧化物（與 m-CPBA 親電環氧化不同！） 比較： - m-CPBA（親電環氧化）→ 攻擊富電子烯烴，syn-加成，cis/trans 保留 - HOO⁻（親核環氧化）→ 攻擊缺電子烯烴（共軛），兩步，trans 優先

親核芳香取代（SNAr）

苯環通常是 EAS 底物，但在特殊條件下可以發生親核芳香取代（SNAr）：親核試劑攻擊苯環，離去基（通常是鹵素）被取代。

SNAr 的必要條件
  • 苯環上必須有強吸電子基（EW）在離去基的鄰位或對位
  • 常見 EW 基：-NO₂, -CN, -C=O（鄰或對）
  • 離去基：通常是 F, Cl, Br（F 最佳！雖然 C-F 鍵強，但 F 的 EW 誘導使環更易被親核攻擊）
  • 親核試劑：O（烷氧負離子、醇）、N（胺）、CN⁻ 等

SNAr 機制詳解

SNAr 機制（加成-消除，addition-elimination）： 底物：1-氯-2,4-二硝基苯（picryl chloride 衍生物）+ MeO⁻ 步驟 1：加成（親核試劑攻擊被鹵素取代的 C） Cl MeO Cl | \ / [苯環]-NO₂ + MeO⁻ → [苯環]⁻ | | NO₂ NO₂ NO₂ Meisenheimer 錯合物（σ-錯合物） 負電荷離域到鄰/對位的 NO₂ 基 步驟 2：消除（Cl⁻ 離去，恢復芳香性） Meisenheimer 錯合物 → [苯環]-OMe + Cl⁻ 速率決定步驟： - 若 LG 容易離去 → 步驟 1（加成）為 RDS - 若 LG 難離去 → 步驟 2（消除）為 RDS - F（雖難離去，但步驟 1 很快）→ F 通常步驟 2 為 RDS，但整體比 Cl 快 SNAr 的特點： ✓ F 是最佳離去基（違反直覺！） 原因：C-F 鍵最強（Meisenheimer 不易逆向分解），F 是最強 EW（使步驟 1 最快） ✓ 需要鄰位或對位 EW 基（間位 EW 無效） ✓ 不是碳陽離子機制（沒有 Ar⁺ 中間體）

例：西咪替丁（Cimetidine）的合成

抗胃酸藥物西咪替丁的合成包含共軛取代步驟：利用 β-氯乙烯基硫醚作為底物，胺類親核試劑進行共軛加成/消除，引入咪唑環所需的氮原子。

雷尼替丁（Ranitidine）的合成也採用類似的共軛取代策略，引入呋喃環和二甲胺基甲基基團。

本章摘要

第二十二章核心要點
  • α,β-不飽和羰基：LUMO 在 β-C（共軛加成優先），也可在 C=O（直接加成）
  • 1,4-（共軛）加成：熱力學優先，不可逆；1,2-（直接）加成：動力學（常可逆）
  • 硬親核劑（RMgBr, RLi）：1,2-加成（攻擊 C=O）
  • 軟親核劑（RS⁻, R₂CuLi）：1,4-共軛加成（攻擊 β-C）
  • 有機銅試劑 R₂CuLi：最佳共軛加成試劑；Grignard + 催化量 CuCl 也可
  • NaBH₄：通常在 C=O 直接還原（烯醛）或雙還原（烯酮）；Luche（+CeCl₃）強制 1,2-還原
  • 共軛取代：β-鹵代烯酮 + Nu → Nu 共軛加成 → 鹵素消除 → β-取代烯酮
  • 親核環氧化：HOO⁻ 對 α,β-不飽和酮共軛加成 → 分子內 SN2 → trans-環氧酮
  • SNAr：加成-消除機制；需 EW 基在 LG 鄰/對位；Meisenheimer 錯合物為中間體；F 最佳 LG
