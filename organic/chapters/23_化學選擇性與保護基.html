化學選擇性與保護基

Chemoselectivity and Protecting Groups

選擇性的概念

有機合成中，選擇性（selectivity）是核心挑戰：當分子含有多個官能基時，如何讓試劑只與所需官能基反應？

三種選擇性
  • 化學選擇性（Chemoselectivity）：哪個官能基反應（例如：只還原酮，不還原酯）
  • 區位選擇性（Regioselectivity）：在同一官能基中哪個位置反應（例如：Markovnikov vs 反 Markovnikov）
  • 立體選擇性（Stereoselectivity）：生成哪個立體異構體（syn vs anti，R vs S）

本章專注於化學選擇性。

羰基化合物的反應性順序

不同類型的羰基化合物對親核試劑的反應性不同，這決定了化學選擇性：

羰基反應性（對親核試劑）從高到低： 醛（aldehyde） > 酮（ketone） > 酯（ester） > 醯胺（amide） > 羧酸根（carboxylate） 原因（活化程度）： 1. 醛/酮：無 O/N 孤對電子共振 → 羰基 C 電正性強 → 最易被親核攻擊 R-CHO > R-CO-R'（醛 > 酮，因酮有兩個 R 供電） 2. 酯：O 孤對電子共振入羰基 → 部分去活化 C=O RCOOC-: O 共振使 C=O 的 C 較不親電 3. 醯胺：N 孤對電子比 O 更強的共振供電 → C=O 幾乎不親電 R-CO-NR₂: N 的孤對電子更有效共振（N 電負性 < O） 4. 羧酸根（RCOO⁻）：帶負電，親核試劑排斥 → 幾乎不反應 記憶口訣：「醛 > 酮 > 酯 > 醯胺 > 酸根」 （活化從左到右遞減，難以被親核進攻從右到左遞增）

NaBH₄ 的選擇性還原

硼氫化鈉（NaBH₄）是最常用的溫和還原劑之一。

NaBH₄（硼氫化鈉）： - 溶劑：醇（MeOH, EtOH）或 THF/水 - 可還原：酮、醛 → 對應醇 - 不可還原：酯、醯胺、羧酸 機制：H⁻ 從 NaBH₄ 傳遞到羰基 C（SN2 型 H⁻ 轉移） → 四面體烷氧基中間體 → 質子化 → 醇 選擇性： ✓ 酮 → 仲醇 ✓ 醛 → 伯醇 ✗ 酯不反應（羰基 C 較不親電） ✗ 醯胺不反應 ✗ 羧酸不反應（且 NaBH₄ 與 NaO₂CR 不相容） 例：含酮基和酯基的化合物 + NaBH₄ → 只有酮被還原

LiAlH₄ 的強力還原

氫化鋁鋰（LiAlH₄）是比 NaBH₄ 強得多的還原劑。

LiAlH₄（氫化鋁鋰，LAH）： - 溶劑：無水乙醚（Et₂O）或 THF（絕對無水！） - 危險：遇水劇烈反應（2 LiAlH₄ + 2 H₂O → H₂↑ + AlO₂Li...） 可還原的官能基： ✓ 醛 → 伯醇 ✓ 酮 → 仲醇 ✓ 酯 → 伯醇 + 醇（兩個當量 H⁻） ✓ 醯胺 → 胺（C=O 變成 CH₂，N 留下） ✓ 羧酸 → 伯醇（先質子化，再兩步還原） ✓ 環氧化物 → 醇（H⁻ 攻擊較不取代的 C） ✓ 腈 → 伯胺（C≡N → CH₂-NH₂） 酯的還原機制（兩步）： RCOOR' + [H⁻] → R-CHO（醛，中間體）+ R'O⁻ ↓ 再加一個 [H⁻] R-CH₂OH（伯醇） 醯胺的還原： R-CO-NR₂ + LiAlH₄ → R-CH₂-NR₂（胺） （C=O 完全去氧為 CH₂；N 被保留）

BH₃（硼烷）的特殊選擇性

BH₃（硼烷，borane）或其 THF 錯合物 BH₃·THF： 特殊選擇性： ✓ 羧酸 → 伯醇（選擇性還原羧酸！NaBH₄ 無法） ✓ 醯胺 → 胺（選擇性還原） ✓ 烯烴（氫硼化反應，見第 19 章） 不還原：酯（相對選擇性） 原因： - BH₃ 是路易斯酸，先與 C=O 的 O 配位 → 活化羰基 - 羧酸的 C=O 對 BH₃ 最親和（因 O-H 鍵和 BH₃ 反應生成 H₂，使羧酸更易反應） - 電子最豐富的 C=O 先被 BH₃ 活化 選擇性比較： BH₃ 可還原 COOH 和 CONH₂，而 NaBH₄ 不可 → 含多種羰基時，BH₃ 可選擇性還原羧酸

DIBAL：選擇性還原酯至醛

DIBAL（DIBAL-H, diisobutylaluminium hydride，氫化二異丁基鋁）： 條件：-70°C（低溫！），無水有機溶劑（CH₂Cl₂ 或甲苯） 1 eq DIBAL 還原酯 → 醛（在 -70°C 停留在四面體中間體）： RCOOR' + DIBAL（-70°C）→ RCHO（醛） 機制： - H⁻ 從 DIBAL 加到酯羰基 C - 生成四面體烷氧基鋁中間體（Al 配位穩定，不易再分解） - 在 -70°C，中間體被「凍結」（不進一步反應） - 水解（workup）→ RCHO 若溫度升高（如 0°C）→ 四面體中間體分解 → 醛 → 繼續被還原 → 醇 DIBAL 還可還原： ✓ 腈 → 醛（-70°C 水解）：R-CN + DIBAL → R-CHO ✓ 醛 → 醇（若用過量 DIBAL）

BH₃ 的選擇性獨特（羧酸優先），不屬於直接的強弱比較序列。

催化氫化（Catalytic Hydrogenation）

催化氫化：H₂ + 催化劑 最常用條件： H₂/Pd/C（在醇溶劑中）： - 烯烴（alkene）→ 烷烴（syn-加成） - 芳香族硝基（ArNO₂）→ 芳胺（ArNH₂） - 炔烴（alkyne）→ 烷烴（完全還原） - 脫苄基（benzyl ether → free alcohol） H₂/Pt（氧化鉑，Adams 催化劑）： - 以上所有 + 苯環（arene → cyclohexane） - 比 Pd/C 更強 H₂/Raney Ni（骨架鎳）： - 脫硫（thioether, thiol → C-H） - 一般烯烴還原 立體化學：syn-加成（H₂ 從催化劑表面同面加成）

Lindlar 催化劑：炔烴→順烯

Lindlar 催化劑：Pd/CaCO₃/Pb(OAc)₂ 功能：炔烴（alkyne）→ 順式烯烴（cis-alkene） 選擇性：不繼續還原烯烴（毒化催化劑） R-C≡C-R' + H₂/Lindlar → R R' \ / C=C（cis/Z） / \ H H 機制： - Pb(OAc)₂ 毒化 Pd 表面 → 降低對烯烴的活性（選擇性） - H₂ 在 Pd 表面 syn-加成 → cis-烯烴 對比：Na/NH₃（Birch 還原）→ 炔 → trans-烯烴（互補！）

Birch 還原（Birch Reduction）

Birch 還原用溶解金屬（Na 或 Li）在液氨中還原苯環，區域選擇性獨特。

Birch 還原條件： Na（或 Li）/ NH₃(l) / EtOH（或 t-BuOH） 還原苯環： 苯 + Birch → 1,4-環己二烯（非共軛雙鍵） 機制： 1. Na 提供 e⁻ → 苯環獲得 e⁻（自由基陰離子） 2. EtOH 提供 H⁺ → 質子化 3. 重複 → 1,4-二氫產物（1,4-cyclohexadiene） Birch 還原的區域選擇性： 含吸電子基（EW, 如 -COOH, -COOR）的苯環： → 雙鍵「避開」EW 基（EW 基在雙鍵外） → 還原發生在 ipso + para 位（含 EW 的 C） → 雙鍵留在 ipso-meta 位（遠離 EW 基） 含供電子基（ED, 如 -OMe, -NR₂）的苯環： → 雙鍵「保留」靠近 ED 基的位置 → 還原發生在 ortho + meta 位（遠離 ED 基） → 雙鍵留在靠近 ED 基的 C 記憶： - EW 基：雙鍵在 EW 基的「外面」（ipso/meta 位） - ED 基：雙鍵在 ED 基的「旁邊」（ipso/ortho 位） 類比：Birch 還原炔烴 → trans-烯烴（Na/NH₃ → 反式）

醛的合成：特殊還原

Rosenmund 還原（酸氯化物 → 醛）： R-COCl + H₂/Pd/BaSO₄/喹啉（quinoline）→ R-CHO 原理： - BaSO₄ 和喹啉毒化 Pd（防止繼續還原醛） - H₂ 還原 C-Cl 鍵（不還原 C=O 鍵本身） - 得到 RCHO（醛） 比較 DIBAL 法（酯 → 醛）和 Rosenmund（酸氯化物 → 醛）： - 兩者都是合成醛的「中斷還原」 - Rosenmund：需要酸氯化物（活性酯），條件溫和 - DIBAL：需要低溫（-70°C），適用範圍更廣

去氧反應（Deoxygenation）：C=O → CH₂

羰基完全去氧（C=O → CH₂）： 1. Wolff-Kishner 還原： R-CO-R' + NH₂NH₂（聯胺，hydrazine）→ R-C(=NNH₂)-R'（腙, hydrazone） KOH / 熱（或 DMSO, NaH） → R-CH₂-R' + N₂↑ 機制：腙 + 鹼 → 失去 N₂（驅動力）→ 碳負離子 → 質子化 條件：強鹼（KOH），高溫（或 DMSO） 2. Clemmensen 還原： R-CO-R' + Zn/conc.HCl（濃鹽酸）→ R-CH₂-R' + H₂O 條件：酸性（濃 HCl），鋅汞齊 互補性： - Wolff-Kishner：適用於鹼性條件穩定的底物 - Clemmensen：適用於酸性條件穩定的底物 - 兩者都去除 C=O，「縮減氧化態」

氧化反應的選擇性

醇的氧化

醇的氧化（選擇性控制的鍵）： 伯醇（R-CH₂OH）的氧化： → 醛（aldehyde, R-CHO）：溫和且無水條件 - PCC（吡啶氯鉻酸, pyridinium chlorochromate）/ CH₂Cl₂（無水） - TPAP（四丙基過釕酸銨）+ NMO（催化量 TPAP） - Dess-Martin（超碘醯苯衍生物, DMP）/ CH₂Cl₂ → 羧酸（R-COOH）： - Jones（Cr(VI)/丙酮水溶液） - KMnO₄（強氧化劑） 仲醇（R-CHOH-R'）的氧化： → 酮（ketone, R-CO-R'）：以上任何條件 叔醇（R₃COH）：不可被氧化 選擇性： PCC / Dess-Martin → 停在醛（不繼續氧化到羧酸） Jones / KMnO₄ → 繼續氧化到羧酸

Swern 氧化（溫和、無水氧化醇）

Swern 氧化： (COCl)₂（草醯氯）/ DMSO / Et₃N（三乙胺）/ CH₂Cl₂ R-CH₂OH → R-CHO（伯醇→醛，或 仲醇→酮） 特點： ✓ 極溫和（低溫，-60~-78°C） ✓ 無水（適合對水敏感的底物） ✓ 不過度氧化（停在醛） ✗ 生成 DMSO 和甲硫醚（有臭味，需真空除去） 機制（簡化）： DMSO + (COCl)₂ → 活化 DMSO → 與醇形成 sulfonium 中間體 → Et₃N 去質子 → [2,3]-sigmatropic → 醛 + DMSO 副產物

其他氧化反應

常用氧化反應彙整： 烯烴 → 環氧化物：m-CPBA（間氯過苯甲酸） 烯烴 → 順二醇（cis-diol）：OsO₄（osmium tetroxide，+NMO 催化量） 烯烴 → 反二醇（trans-diol）：先環氧化（m-CPBA），再鹼性開環 烯烴 → 醛/酮（斷裂）：O₃（臭氧化），再 Me₂S（Zn/AcOH）或 H₂O₂ 後處理 芳香族 → 苯酚：使用 m-CPBA（特殊條件） 伯醇 → 醛：PCC / Dess-Martin / Swern 伯醇 → 酸：Jones / KMnO₄ 仲醇 → 酮：任何 Cr(VI) 試劑

動力學 vs 熱力學化學選擇性

例：胺基醇與苯甲醯氯的反應

含有 OH 和 NH₂ 基團的化合物（胺基醇）與 PhCOCl（苯甲醯氯）的反應：

  • 動力學控制（低溫、快速加入、短反應時間）：OH 先反應 → 酯（ester）為主要產物
  • 熱力學控制（長時間、高溫、加熱）：NH₂ 反應（較強親核，更穩定的醯胺鍵）→ 醯胺（amide）為主要產物
動力學 vs 熱力學化學選擇性的原理： 醯化試劑（如 RCOCl）+ 含 OH 和 NH₂ 的底物： 動力學：OH 更快反應（速率更快，因為 OH 先碰到試劑；熱力學不穩定） → 主要得酯（kinetic product） 熱力學：醯胺（amide）比酯（ester）更穩定（N 更好的供電基穩定 C=O） → 長時間/高溫 → 轉酯化（→ 醯胺） 一般規律： - 短時間、低溫、過量試劑：動力學選擇性 - 長時間、可逆條件：熱力學選擇性

保護基策略（Protecting Groups）

當分子有多個官能基，而只需對其中一個進行選擇性反應時，可以用保護基暫時遮蔽不需要反應的官能基。

保護基的基本要求
  1. 安裝（protection）：高效，不影響其他官能基
  2. 穩定：在後續步驟的條件下穩定
  3. 去除（deprotection）：高效，不影響目標官能基和其他已有取代基

二價陰離子（Dianions）

二價陰離子（dianions）的化學選擇性： 含羥基和炔烴的底物（如炔醇）可生成二價陰離子： HC≡C-CH₂OH + 2 n-BuLi → ⁻C≡C-CH₂O⁻ 二價陰離子 選擇性： - 最後形成的負離子（alkynyl anion，更碳基負離子）比先形成的（alkoxide, O⁻）反應性更高 - 與親電試劑（RX, RCHO）→ 主要在 alkynyl 端反應（更碳基的 α 端） 規律：「後形成的負離子先反應」（last in, first out） 原因：alkynyl anion（sp-C）比 alkoxide（O⁻）更強的碳基親核劑 → 可控制反應的化學選擇性：在多功能底物中定點進行反應

本章摘要

第二十三章核心要點
  • 羰基反應性順序：醛 > 酮 > 酯 > 醯胺 > 羧酸根（對親核試劑）
  • NaBH₄：溫和，只還原醛/酮 → 醇；不還原酯、醯胺、羧酸
  • LiAlH₄：強力，還原幾乎所有羰基；酯 → 伯醇，醯胺 → 胺，酸 → 醇；絕對無水
  • BH₃：選擇性還原羧酸（COOH 優先），也還原醯胺；是氫硼化試劑
  • DIBAL（-70°C）：酯 → 醛（停住！），腈 → 醛；溫度升高 → 繼續還原到醇
  • Lindlar：炔 → 順式烯烴（cis，Z）；Na/NH₃：炔 → 反式烯烴（trans，E）
  • Birch 還原：苯環 → 1,4-環己二烯；EW 基 → 雙鍵遠離 EW；ED 基 → 雙鍵靠近 ED
  • Wolff-Kishner：C=O → CH₂（鹼性，聯胺，N₂ 離去）
  • Clemmensen：C=O → CH₂（酸性，Zn/HCl）
  • 醇氧化：PCC/Dess-Martin/Swern → 醛；Jones/KMnO₄ → 酸
  • 保護基策略：安裝→反應→去除；不同官能基有不同保護基，正交保護可同時保護多個基團
