Regioselectivity

區位選擇性的定義

區位選擇性（Regioselectivity）指在同一官能基（或同類型官能基）內，反應優先發生在哪個位置。它不同於化學選擇性（哪個官能基反應）和立體選擇性（生成哪個立體異構體）。

三種選擇性的比較
選擇性問題例子
化學選擇性（chemoselectivity）哪個官能基反應？酮 vs 酯 + NaBH₄ → 只還原酮
區位選擇性（regioselectivity）官能基中哪個位置？丙烯 + HBr → 哪個 C 得到 Br？
立體選擇性（stereoselectivity）生成哪個立體異構體？氫硼化 → syn 加成

EAS 的區位選擇性（複習與深化）

EAS 的區位選擇性由取代基效應決定（第 21 章），在此複習並加深理解策略性應用。

EAS 取代基效應與區位選擇性（彙整）： ED 基（供電子）→ 鄰/對位導向： -OH, -OR, -NR₂：強活化，鄰/對位 -R（烷基）：弱活化，鄰/對位 EW 基（吸電子）→ 間位導向： -NO₂, -CN, -COR, -CF₃：去活化，間位 -NR₃⁺（帶正電）：最強去活化，間位 鹵素（特殊）→ 鄰/對位導向 + 去活化 策略性應用（磺化作為封閉基）： 例：合成 1-chloro-2-nitrobenzene 和 1-chloro-4-nitrobenzene 的混合物？ → 先硝化（間位導向如果有 Cl） → 再磺化（封閉鄰位） → 再氯化 → 去磺化 磺化（可逆）作為臨時封閉位置的策略： 1. 硝化苯 → 硝基苯 2. 磺化 → 佔據某位置（例如鄰位） 3. 引入第二取代基（位置被控制） 4. 去磺化（水/酸，加熱）→ 得到特定位置的二取代苯 官能基互相轉換改變定向： -NO₂（間位導向）→ 還原 → -NH₂（鄰/對位導向） → 允許合成兩種不同定向在同一分子的雙取代苯

鄰位鋰化（Directed Ortho Metalation）

除了 EAS，苯環上的直接 C-H 金屬化也可實現區域選擇性取代。

鄰位鋰化（Ortholithiation / Directed Metalation）： 原理：含 O 或 N 的導向基（DMG, directed metalation group）螯合 BuLi， 使鋰化發生在 DMG 的鄰位。 底物 + n-BuLi（強鹼）→ 鄰位 C-H 去質子 → 鄰位芳基鋰（aryllithium） DMG 例子： - -OMe（甲氧基） - -NR₂（胺基、醯胺） - -CONR₂（醯胺）：最強的 DMG - -SO₂NR₂（磺醯胺） 機制（以 -OMe 為例）： OMe OMe | + n-BuLi → | [苯環] [苯環] | Li （鄰位 C-Li） → C-Li 再與親電試劑反應（R-X, RCHO, CO₂ 等） → 在鄰位引入官能基（高區位選擇性！） 優點： ✓ 高鄰位選擇性（> 95:5） ✓ 不需要苯環預先活化 ✓ 可引入各種官能基（醛基、酯基、鹵素等）

萘的區位選擇性

萘（naphthalene）的 EAS 區位選擇性： 萘有兩種不等效碳：α 位（C-1）和 β 位（C-2） 4 3 / \ / 5 | 2 | | | 6 | 1（α 位） \ / \ 7 8 α 位（C-1, C-4, C-5, C-8）：通常動力學優先 β 位（C-2, C-3, C-6, C-7）：在某些條件下熱力學優先 硝化萘（HNO₃/H₂SO₄）： 主要產物：α-硝基萘（1-硝基萘，> 90%） 原因：α 位的 arenium ion 中間體更穩定（保留一個完整的苯環，6π 芳香） 磺化萘（可逆！）： 低溫（60°C）：α-萘磺酸（動力學） 高溫（160°C）：β-萘磺酸（熱力學，較穩定，更大基團較少空間阻礙） 萘磺化的可逆性應用： 1. 低溫磺化 → α-磺酸（→ 換用其他試劑 → α-取代） 2. 高溫磺化（再異構化）→ β-磺酸（→ 去磺化 → β 位 H 回來） 萘的鄰位導向 EAS： 已有 ED 基的萘 → 鄰/對位導向（優先在同環 peri 或鄰位） 已有 EW 基的萘 → 反應在另一環的 α 位

分子內環化的區位選擇性

分子內 Friedel-Crafts 烷基化

分子內 Friedel-Crafts 給鄰位產物： 底物：鏈狀分子，一端有芳環，另一端有烷基鹵（或羥基） 例：4-苯丁酸氯化物 + AlCl₃ → 分子內 F-C 醯化 → 四氫萘酮（tetralone，六元環，鄰位 = 動力學） 規律： - 5 元環 > 6 元環 > 7 元環（反應性和穩定性的平衡） - 分子內環化偏好形成 5 或 6 元環（Baldwin's rules 的有機版） - 鄰位攻擊（ortho attack）比對位攻擊在分子內更容易（因鏈長優先到鄰位）

鹵素內酯化（Halolactonization）

溴內酯化（Bromolactonization）： 底物：γ,δ-不飽和羧酸（或 δ,ε-）+ Br₂/NaHCO₃ 機制： 1. Br₂ 與雙鍵反應 → 溴鑤離子（bromonium ion） 2. 羧酸根（CO₂⁻，分子內）攻擊 C → 內酯（lactone）形成 3. Br⁻ 離去（外界 Br⁻ 提供 Br 到另一 C 不正確；是先羧酸進攻） 區位選擇性： - 5 元環（γ-內酯）優先於 6 元環（δ-內酯）和 7 元環 - 羧酸根作為分子內親核劑，形成最優化的環張力 立體化學： - 溴鑤離子（三元環，兩面電子）被從背面攻擊 - 反式（anti）加成 - 兩個新立體中心的構型由 anti 加成決定

Markovnikov 規則與反馬氏加成

Markovnikov 規則（HBr 加到烯烴）： HBr + CH₂=CH-CH₃（丙烯）→ CH₃-CHBr-CH₃（2-溴丙烷，主要） CH₃-CH₂-CH₂Br（1-溴丙烷，少量） Markovnikov：H 加到 H 較多的 C（= Br 加到更取代/更穩定碳陽離子的 C） 機制： 1. H⁺ 加到丙烯（C1）→ 生成 2° 碳陽離子（在 C2，更穩定） 2. Br⁻ 攻擊 C2 → 2-溴丙烷（Markovnikov 產物） 若 H⁺ 先加到 C2 → 生成 1° 碳陽離子（不穩定）→ 不優先 氫硼化（反 Markovnikov）： 烯烴 + BH₃ → H 加到更取代的 C，B 加到較少取代的 C → 氧化（H₂O₂/NaOH）→ OH 在較少取代的 C（反 Markovnikov 醇） 反應：丙烯 + BH₃ → B 在 C1 → 氧化 → 1-丙醇（anti-Markovnikov）

HBr 的自由基加成（過氧化物條件）

自由基加成 HBr（反 Markovnikov）： 條件：HBr + 過氧化物（ROOR，提供自由基引發劑） 或光照（hν） 結果：反 Markovnikov 產物！ CH₂=CH-CH₃ + HBr（ROOR）→ CH₃-CH₂-CH₂Br（1-溴丙烷） 機制（鏈式反應，chain mechanism）： 1. 引發（initiation）：ROOR → 2 RO·（加熱或光） RO· + HBr → ROH + Br· 2. 傳遞（propagation）： Br· + CH₂=CH-CH₃ → BrCH₂-·CH-CH₃（1° 自由基，因 Br 加到 C1） 等等 → 為什麼？ Br· 加到 CH₂=（末端 C, C1）→ 生成 2° 自由基（在 C2）→ 更穩定！ Br· 加到 C2 → 生成 1° 自由基（在 C1）→ 較不穩定 2° 自由基（在 C2）+ HBr → CH₃-CH₂-CH₂Br（Br 在 C1 的最終產物） + Br· 3. 終止（termination）：自由基結合 自由基添加 Br·： - Br 先加到末端（更少取代的 C）→ 生成更穩定的內部自由基 - 然後從 HBr 奪 H → Br 最終在末端（1-溴丙烷） 比較： - 離子機制（H⁺ 先）：Markovnikov → Br 在內部（2-溴丙烷） - 自由基（Br· 先）：反 Markovnikov → Br 在末端（1-溴丙烷） 注意：只有 HBr 有這種「過氧化物效應」（HCl 和 HI 沒有）！

NBS 烯丙位溴化

NBS（N-溴代琥珀醯亞胺）的烯丙位溴化： 條件：NBS / CCl₄ / hν（或 AIBN 引發劑） 底物：烯烴（有烯丙位 C-H） 反應：在烯丙位（allylic position）引入 Br，保留雙鍵位置 CH₂=CH-CH₃ + NBS → CH₂=CH-CH₂Br（烯丙溴） 機制（低 [Br₂]，自由基）： 1. NBS 提供低濃度 Br₂ → Br· 自由基 2. Br· 從烯丙位 C-H 奪 H（烯丙自由基最穩定） 3. 烯丙自由基 + Br₂（NBS 分解）→ 烯丙溴 + Br·（鏈式傳遞） 為什麼 NBS 而不是 Br₂（高濃度）？ - 高 [Br₂]：離子加成到雙鍵（→ 鄰二溴） - 低 [Br₂]（NBS 提供）：自由基選擇性烯丙 C-H 抽取 區位選擇性： - Br 引入到烯丙位（allylic C），雙鍵位置不變（但可能遷移！） - 烯丙自由基是對稱的 → 兩個可能的烯丙溴位置（Br 在雙鍵兩端） 例：丁烯 + NBS → 1-溴-2-丁烯（E/Z）和 3-溴-1-丁烯（烯丙位移位）

烯丙基取代反應的 SN 位置

烯丙基鹵（allylic halide）的親核取代區位選擇性： 底物：RCH=CH-CH₂-X（烯丙基鹵，X = Br 或 Cl） 可能的 SN 位置： α 位（直接取代，SN2）：Nu 攻擊 CH₂-X → Nu-CH₂-CH=CH-R γ 位（SN2'，遠端取代）：Nu 攻擊末端 C（CH=CH-R 那端）→ X-CH₂-CH=CH-Nu 選擇性決定因素： 1. 一級烯丙基（primary allylic）： SN2 直接取代（在較少位阻的 α-C）優先 但 SN2' 也可能（取決於試劑和溶劑） 2. 三級烯丙基（tertiary allylic）： 傾向 SN1 → 烯丙基碳陽離子（兩端都可以被 Nu 攻擊） → 得到 SN2 和 SN2' 混合物（平衡） 3. 有機銅試劑（R₂CuLi）： 強烈偏好 SN2'（遠端攻擊）> 98:2 ！

有機銅試劑與 SN2'

有機銅試劑（organocuprates）與 SN2' 反應： R₂CuLi + 烯丙基親電試劑（R'-CH=CH-CH₂-X）→ SN2'（遠端攻擊）>> SN2（直接）： → R-CH=CH-CH₂-R'（Br 位移，R 加在遠端，雙鍵移位） → > 98% SN2' 選擇性！（在某些條件 RCu/BF₃ 中更高） 為什麼有機銅偏好 SN2'？ - Cu 是「軟」的金屬（d 電子多，極化大） - 軟親核劑攻擊「軟」的位置（共軛末端，LUMO 係數大） - → 符合 HSAB 理論 實際例子： 烯丙基氯 + Me₂CuLi → 3-甲基-1-丙烯（SN2' 產物，Cl 在 1，Me 在 3） 合成應用： 烯丙基轉位（allylic transposition）+ 有機銅 → 精確控制位置 → 合成具有指定雙鍵位置和取代基位置的烯烴

共軛二烯的 1,2- vs 1,4-加成

共軛二烯（conjugated diene）與親電試劑（如 HBr）的加成： 1,3-丁二烯 + HBr： 兩種產物： 1,2-加成：CH₂=CH-CHBr-CH₃（3-溴-1-丁烯） 1,4-加成：CH₃-CHBr-CH=CH₂ → CH₃-CHBr-CH=CH₂... 等等 實際：BrCH₂-CH=CH-CH₃（1-溴-2-丁烯，1,4 產物） 但也 CH₂=CH-CHBr-CH₃（3-溴-1-丁烯，1,2 產物） 機制： 1. H⁺ 加到末端 C（C1）→ 烯丙基碳陽離子（在 C2/C4 共振） 2. Br⁻ 攻擊 C2（SN2 型，直接，1,2 加成）或 C4（SN2' 型，遠端，1,4 加成） 溫度控制（動力學 vs 熱力學）： 低溫（-80°C，動力學控制）： → 1,2-加成（3-溴-1-丁烯）優先（速率快：Br⁻ 在 C2 的活化能低） → 較不穩定的產物（端基烯烴，末端雙鍵） 高溫（0-40°C，熱力學控制）： → 1,4-加成（1-溴-2-丁烯）優先（熱力學穩定：內部烯烴更穩定） → 較穩定的產物（內部雙鍵） 類比（回顧）： - 軟親核劑（RS⁻, R₂CuLi）+ α,β-不飽和酮 → 1,4-加成（軟攻軟，β-C） - 共軛二烯 + 親電試劑 → 也有 1,2 vs 1,4 競爭，溫度決定
動力學 vs 熱力學 1,2/1,4 加成彙整
條件產物雙鍵位置穩定性
低溫（-80°C）、短時間1,2-（動力學）末端（end）較不穩定
高溫（0°C+）、長時間1,4-（熱力學）內部（internal）較穩定

本章摘要

第二十四章核心要點
  • 區位選擇性：決定反應在官能基中的哪個位置，由電子效應、空間效應、溫度和試劑類型控制
  • EAS 取代基策略：磺化（可逆）用作臨時封閉基；NO₂ → NH₂ 轉換導向基，實現複雜位置的二取代苯合成
  • 鄰位鋰化：BuLi + DMG 螯合 → 高鄰位選擇性 C-H 活化，引入各種官能基
  • 萘：α 位動力學優先（EAS）；磺化可逆 → 低溫 α，高溫 β（熱力學）
  • Markovnikov：H⁺ 先，生成更穩定碳陽離子，Bu 在更取代的 C → Markovnikov 產物
  • 反馬氏（HBr + 過氧化物）：Br· 先攻末端，生成更穩定自由基，H 來自 HBr → Br 在末端（反 Markovnikov）
  • NBS 烯丙位溴化：低 [Br₂]，自由基，選擇性在烯丙 C-H；NBS 提供可控的 Br₂ 濃度
  • SN2'：有機銅（R₂CuLi）強烈偏好烯丙位遠端攻擊（SN2' >> SN2）
  • 共軛二烯：低溫 → 1,2-（動力學）；高溫 → 1,4-（熱力學，更穩定的內部烯烴）
