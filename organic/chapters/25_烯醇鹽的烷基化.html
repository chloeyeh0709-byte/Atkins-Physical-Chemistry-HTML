第二十五章

烯醇鹽的烷基化

Alkylation of Enolates

烯醇鹽烷基化簡介

在第二十章我們學習了如何生成烯醇鹽（enolates）。本章的重點是利用烯醇鹽作為親核劑，與烷基化試劑（electrophilic carbon, SN2）反應，在羰基的 α 位引入新的碳-碳鍵，這是有機合成中最重要的 C-C 鍵形成反應之一。

兩步驟機制

烯醇鹽烷基化可概括為兩個步驟：

  1. 形成烯醇鹽：以鹼（強鹼或弱鹼）去質子化羰基 α 位
  2. SN2 烷基化：烯醇鹽碳作為親核劑，攻擊烷基化試劑（RX）的碳，發生背面攻擊
步驟 1：形成烯醇鹽 O O⁻ ‖ | R—C—CH₂R' + Base → R—C=CHR' (烯醇鹽) 步驟 2：SN2 烷基化 O⁻ O | ‖ R—C=CHR' + R''X → R—C—CHR'R'' + X⁻ (α-烷基化產物)
關鍵概念

烯醇鹽是兩性親核劑（ambident nucleophile）：可從 C 或 O 進行反應。在烷基化中通常以 C 親核（C-烷基化），因為碳比氧更具親核性（軟-軟匹配）。在強電子吸引基存在下，O-烷基化（得到烯醇醚）也可能發生。

其他類型的烯醇鹽

除了簡單酮、醛，許多含活潑 C-H 的官能基也可以形成類似烯醇鹽的陰離子：

腈與硝基烷的烷基化

腈（nitrile, R-CN）的 α-H 也具有相當酸性（pKₐ ≈ 25），可被強鹼去質子化，形成腈穩定的碳負離子，進行烷基化：

CH₃CN + LDA → ⁻CH₂CN → + RX → R-CH₂CN (pKa~25) (腈穩定陰離子) (烷基化腈)

硝基烷（nitroalkane, R-NO₂）的 α-H 酸性極強（pKₐ ≈ 10），因為一個硝基相當於兩個吸電子基（N 帶正電荷），可在弱鹼（如 NaOH、K₂CO₃）條件下形成陰離子：

CH₃NO₂ + NaOH → ⁻CH₂NO₂ → + RX → R-CH₂NO₂ (pKa~10) (硝基穩定陰離子) (烷基化硝基烷)
pKa 比較

硝基烷 (RCH₂NO₂)~10弱鹼 (NaOH, K₂CO₃)

腈 (RCN)~25強鹼 (LDA)

烷基化試劑的選擇

烷基化試劑必須能發生 SN2 反應，因此反應活性取決於碳的位阻與離去基的離去能力。

反應活性順序（SN2）

甲基（CH₃X）≈ 烯丙基（allyl, CH₂=CHCH₂X）≈ 苄基（benzyl, PhCH₂X）
>> 伯碳（1° RCH₂X）
>> 仲碳（2° R₂CHX）
✗ 叔碳（3° R₃CX）— 不適合（位阻過大，轉為 E2）

常見烷基化試劑包括烷基碘（RI）、烷基溴（RBr）、對甲苯磺酸酯（OTs）、甲磺酸酯（OMs）等。

LDA 與強鹼烯醇鹽

二異丙基胺基鋰（LDA）是製備動力學烯醇鹽最常用的強鹼（pKₐ~36），其特點是位阻大、非親核性，在 THF、-78°C 下使用。

O OLi ‖ LDA | R—C—CH₂R' ————→ R—C=CHR' THF, -78°C (定量去質子化，動力學烯醇鹽)

其他常用強鹼：

  • LTMP（二甲基哌啶基鋰）：更大位阻
  • LiHMDS / LHMDS（雙(三甲矽基)胺基鋰）：常用於酯與醛烯醇鹽
  • NaH：強鹼但有時會引起副反應（Claisen 縮合），適用於 β-二羰基化合物

酯與羧酸的烷基化

酯的烷基化

酯（pKₐ~25）的 α 位烷基化較困難，需注意避免 Claisen 縮合（自身反應）。解決方法：

  • 使用叔丁酯（t-Bu ester）：立體位阻阻止 Claisen，利用 LDA 在 -78°C 去質子化後烷基化
  • 低溫、快速加入烷基化試劑

羧酸的烷基化（二鋰鹽法）

羧酸（RCOOH）可與 2 當量 LDA 反應，生成二鋰鹽（dilithio enolate），再與烷基化試劑反應，避免了酯化等副反應：

RCH₂COOH + 2 LDA → RCH⁻CO₂Li⁻ (二鋰鹽) | + R'X → RCH(R')COOH

醛的烷基化

醛（pKₐ~17）的 α 位烷基化是個挑戰，原因在於：醛自身容易在 LDA 條件下發生自縮合（aldol condensation）。解決方案：

  • 烯胺（enamine）：用仲胺（吡咯烷、嗎啉）與醛縮合，形成烯胺後烷基化，酸水解還原得醛
  • aza-enolate（腙型烯醇鹽等效物）：利用 RCHO + RNH₂ 形成亞胺，再以 LDA 去質子化
  • 矽烯醇醚（silyl enol ether）：先將醛轉為矽烯醇醚，再以 Lewis 酸活化後烷基化

1,3-二羰基化合物的烷基化

1,3-二羰基化合物（如丙二酸二乙酯、乙醯乙酸乙酯）的亞甲基 H 有極高酸性（pKₐ = 10–15），可在弱鹼條件下形成穩定烯醇鹽：

EtO₂C—CH₂—CO₂Et + NaOEt → EtO₂C—CH⁻—CO₂Et 丙二酸二乙酯 (pKa~13) (穩定陰離子) + R-X → EtO₂C—CHR—CO₂Et 酸/熱水解、脫羧 → RCH₂CO₂H (合成一元酸)
乙醯乙酸乙酯合成（acetoacetic ester synthesis）

乙醯乙酸乙酯（EtO₂C-CH₂-COCH₃，pKₐ~11）在 NaOEt 作用下形成穩定陰離子，經烷基化後，再以酸/鹼水解並加熱脫羧，可製備各種甲基酮（R-COCH₃）：

  1. NaOEt，R-X → EtO₂C-CHR-COCH₃
  2. NaOH/H₂O 水解 → HOOC-CHR-COCH₃
  3. Δ（加熱脫羧）→ R-CH₂-COCH₃（甲基酮）

烯醇鹽的區位選擇性

對於不對稱酮（如 2-甲基環己酮），兩側都有 α-H，但酸性不同，可控制烯醇鹽的形成位置：

動力學烯醇鹽 vs. 熱力學烯醇鹽
類型條件形成位置原因
動力學烯醇鹽LDA，-78°C，THF，快速取代基較少側（空間位阻小）去質子化速率快
熱力學烯醇鹽KH（或 KOt-Bu），高溫，平衡條件取代基較多側（更穩定的烯醇鹽）熱力學穩定性高
2-甲基環己酮烯醇鹽區位選擇性 LDA, -78°C OLi OLi | | 2-Me-cyclohexanone → 較少側烯醇鹽 or 較多側烯醇鹽 (動力學) (主產物) (次要) KH, 高溫 (熱力學) (次要) (主產物，更穩定烯醇鹽)

烯酮作為區位特異性烯醇鹽來源

利用共軛烯酮（enone）作為區位特異性（regiospecific）烯醇鹽來源，繞開動力學/熱力學問題：

  • 金屬溶解還原（dissolving metal reduction）：Li/NH₃ 或 Na/NH₃ 還原烯酮 → 特定區位的烯醇鹽
  • 共軛加成後捕獲：有機銅試劑（R₂CuLi）1,4-加成 → 烯醇鹽
  • Me₂CuLi + Me₃SiCl：共軛加成同時捕獲為矽烯醇醚，保留區位資訊

合成實例

α-Chamigrene 的合成（螺環酮烯醇鹽）

螺環酮通過烯醇鹽烷基化高效建構，關鍵步驟：

  1. 烯酮 + Me₂CuLi → 共軛加成 → 引入甲基，同時以 Me₃SiCl 捕獲為矽烯醇醚（區位保持）
  2. 矽烯醇醚 + MeLi → 去矽保護，得鋰烯醇鹽
  3. KH 轉為熱力學烯醇鹽 → 與烷基化試劑反應 → α-chamigrene 螺環骨架
前列腺素 E₂（Prostaglandin E₂）的合成（Noyori，1978）

Noyori 採用以下關鍵步驟完成 PGE₂ 的合成（78% 整體產率）：

  1. 環戊酮衍生物以 LDA 形成區位特異性烯醇鹽
  2. 有機銅試劑（organocopper）共軛加成引入長碳鏈
  3. 烯醇鹽 + 烯丙基碘（allylic iodide）烷基化，引入另一鏈

Michael 加成（1,4-加成）

Michael 加成是烯醇鹽（或其他軟性親核劑）對α,β-不飽和羰基化合物（Michael 受體）的 1,4-共軛加成。

O O⁻ ‖ | Nu⁻ + CH₂=CH—C—R → Nu—CH₂—CH=C—R → [H⁺] → Nu—CH₂—CH₂—C—R ‖ O Michael受體 烯醇鹽中間體 1,5-二羰基產物

Michael 受體（Michael acceptors）

常見 Michael 受體（α,β-不飽和化合物）包括：

Michael 受體名稱
CH₂=CH-COR甲基乙烯基酮（MVK）
CH₂=CH-CO₂R丙烯酸酯
CH₂=CH-CN丙烯腈（acrylonitrile）
CH₂=CH-CHO丙烯醛（acrolein）
環狀外亞甲基酮/酯exo-methylene ketone/lactone
Michael vs. 直接加成（Aldol）

烯醇鹽親核性強弱決定反應位置：

  • 穩定的烯醇鹽（1,3-二羰基、硝基烷）→ 軟性親核劑 → 偏好 1,4-共軛加成（Michael）
  • 活潑的烯醇鹽（簡單酮/酯）→ 硬性親核劑 → 偏好 1,2-直接加成（aldol）
1,3-二羰基 + Michael 受體

丙二酸二乙酯（diethyl malonate）+ 反丁烯二酸二乙酯（diethyl fumarate）→ 產率 93%。這是因為兩個 EWG（CO₂Et × 2）使丙二酸二乙酯的烯醇鹽為軟性親核劑，偏向 Michael 加成。

分子內 SN2 → 環丙烷化

當烯醇鹽分子中同時含有離去基（如 Br），可發生分子內 SN2，直接形成三員環（cyclopropane）：

O⁻ O | ‖ R—C=CH—CH₂—Br → R—C—[cyclopropane] + Br⁻ (分子內 SN2，形成環丙烷)

烯胺的 Michael 加成

烯胺（enamine）作為烯醇鹽等效物，可對 Michael 受體進行 1,4-加成，酸水解後得到 1,5-二羰基產物：

O O O pyrrolidine + R₂C=O → 烯胺 → + Michael受體 → [酸水解] → R₂C—CH₂—CH₂—C—R' (1,5-二羰基)

烯胺的優點：在溫和條件下反應，不需要強鹼，避免自縮合，且常給出良好的區位選擇性。

矽烯醇醚 + TiCl₄ 的 Michael 加成

矽烯醇醚（silyl enol ether）在 Lewis 酸（TiCl₄）活化下，可對 Michael 受體進行 1,4-加成，得到 1,5-二羰基產物：

OSiR₃ O O O | ‖ TiCl₄ ‖ ‖ R—C=CH₂ + CH₂=CHC—R' → R—C—CH₂CH₂C—R' 矽烯醇醚 Michael受體 (1,5-二羰基)

矽酮縮醛（silyl ketene acetal）（來自酯）亦可在 TiCl₄ 條件下進行 Michael 加成。

各類活化基的應用

丙烯腈作為 Michael 受體

丙烯腈（CH₂=CHCN）是常用的 Michael 受體，CN 基活化雙鍵，且後續可水解為羧酸或還原為胺：

甘胺酸（glycine）合成

利用丙烯腈的 Michael 加成，可合成胺基酸前驅體（80% 產率）。CN 基後經水解/還原即得 α-胺基酸。

硝基烷的 Michael 加成

硝基烷（pKₐ~10）作為穩定烯醇鹽等效物，可在溫和鹼（Al₂O₃、Cs₂CO₃）條件下進行 Michael 加成：

  • Al₂O₃ 固相反應，0-25°C，92% 產率
  • Cs₂CO₃/DMF 條件下可進行分子內環化
  • Nef 反應：硝基烷 → 醛/酮（重要的官能基轉化）
  • 硝基丙烷 + MVK → Nef 反應 → 1,4-二酮（臭氧分解法）
Vivalan 藥物合成（4 步）
  1. 共軛加成 CN
  2. H₂/Pd-C 氫化還原
  3. 環化反應
  4. 烷基化 + 還原
