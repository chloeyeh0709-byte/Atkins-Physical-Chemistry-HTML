第二十六章

烯醇鹽與羰基化合物的反應

Reactions of Enolates with Carbonyl Compounds: Aldol and Claisen

羥醛反應（Aldol Reaction）

當烯醇鹽攻擊另一個羰基化合物（醛或酮）的親電性羰基碳時，發生羥醛反應，產生 β-羥基羰基化合物（aldol product）：

烯醇鹽攻擊醛： O⁻ OH O | | ‖ R-C=CHR' + R''CHO → R''-CH—CHR'—C—R β-羥基羰基（aldol 產物）

機制與脫水（E1cB）

在鹼性條件下，aldol 產物可脫水（E1cB 機制）生成 α,β-不飽和羰基化合物（烯酮）：

OH O O | ‖ -H₂O ‖ R''-CH—CHR'—C—R ————→ R''-CH=CR'—C—R β-羥基羰基 E1cB (鹼) α,β-不飽和羰基（烯酮） 在酸性條件下：E1 機制脫水

酸催化羥醛反應

酸催化羥醛的機制與鹼催化不同：酸先質子化羰基，活化其親電性；另一羰基化合物的烯醇式（enol form）作為親核劑進攻：

酸催化： R₂C=O + H⁺ → R₂C(OH)⁺ （活化親電性） + R'CH₂COR → R'CH=C(OH)R （烯醇形式，親核劑） → aldol 產物

交叉羥醛反應（Cross-Aldol）

使用兩種不同的羰基化合物進行羥醛，但必須避免自縮合。成功的交叉羥醛需滿足：

交叉羥醛成功的兩個條件
  1. 一方提供烯醇鹽（可烯醇化）、另一方提供電子親受體（不可烯醇化，或更親電）
  2. 電子親受體更易被親核攻擊（更強親電性）

常見不可烯醇化的醛：甲醛（HCHO）、苯甲醛（PhCHO）、三氯乙醛（CCl₃CHO）

Mannich 反應

Mannich 反應是烯醇化羰基化合物（或烯醇等效物）、甲醛（HCHO）和仲胺（R₂NH）三組分縮合，生成 Mannich 鹼（β-胺基羰基）：

HCHO + R₂NH + RCH₂COR' → R₂N-CH₂-CHR-COR' (Mannich 鹼) E1cB (-NR₂H) → R'CO-CR=CH₂ (烯酮)

Mannich 鹼在鹼性條件下可進一步發生 E1cB 消除，生成 α,β-不飽和羰基（烯酮），是有機合成中引入亞甲基的常用方法。

特定烯醇鹽等效物在羥醛中的應用

鋰烯醇鹽（-78°C 環化）

LDA 在 -78°C 下對環酮生成動力學鋰烯醇鹽，再與醛反應，得到特定區位的 aldol 產物。鋰烯醇鹽結構（環狀過渡態通過六員環 Li 配位）決定立體選擇性。

矽烯醇醚 — Mukaiyama aldol

Mukaiyama aldol 使用矽烯醇醚（silyl enol ether）+ Lewis 酸（TiCl₄）與醛反應。這種方法可獨立控制烯醇鹽的區位及立體化學，是現代不對稱合成的重要工具：

OSiR₃ O | ‖ TiCl₄ OH O R-C=CH₂ + R'CH ——→ R'-CH—CH₂-C-R 矽烯醇醚 醛 CH₂Cl₂ (β-羥基羰基產物)
Manicone 合成

以矽烯醇醚 + TiCl₄ 完成昆蟲費洛蒙 manicone 的高效合成，立體選擇性好。

Knoevenagel 縮合

活潑亞甲基化合物（1,3-二羰基）與醛（或酮）在仲胺（R₂NH）或乙酸催化下縮合，直接得到 α,β-不飽和產物（加脫水），稱為 Knoevenagel 縮合：

EtO₂C-CH₂-CO₂Et + RCHO → EtO₂C-CR=CHO + ... → 脫羧 → R-CH=CH-CO₂Et 丙二酸二乙酯 醛 R₂NH/HOAc (Knoevenagel + 脫羧)

若使用含兩個 EWG 的活潑亞甲基化合物，縮合後可再脫羧，得到單活化的 α,β-不飽和產物（特別適合製備丙烯酸衍生物）。

酯烯醇鹽等效物

酯的羥醛反應較困難，常用三種等效物：

  • 鋰烯醇鹽（LDA/LiHMDS）：直接去質子化酯
  • 矽烯醇醚：Lewis 酸活化
  • Reformatsky 鋅試劑

Reformatsky 反應

Reformatsky 反應使用 α-溴代酯與鋅在溫和條件下生成有機鋅烯醇鹽，再與醛（或酮）反應，得到 β-羥基酯：

BrCH₂CO₂Et + Zn → BrZn-CH₂CO₂Et （Reformatsky 試劑） + R'CHO THF, Δ → HO-CHR'-CH₂CO₂Et （β-羥基酯）

優點：鋅烯醇鹽活性溫和，不會自縮合，適合對醛/酮進行選擇性加成。

控制酮的羥醛反應

不對稱酮的兩側都可形成烯醇鹽，需控制烷基化位置：

  • 動力學條件（LDA，-78°C）：優先在取代少側去質子化（甲基側）
  • 熱力學條件（Me₃SiCl，HMPA）：優先得到取代多側（更穩定）的矽烯醇醚

Gingerol 合成

薑辣素（Gingerol）的合成

以羥醛反應策略合成薑辣素（生薑辛辣成分）：

  • 路線 A：保護羥基，LiHMDS 動力學烯醇鹽（甲基側）+ 戊醛，57% 產率
  • 路線 B：TiCl₄ + 矽烯醇醚（Mukaiyama），92% 產率（更優）

分子內羥醛反應

二羰基化合物可通過分子內羥醛形成環，優先生成 5 或 6 員環：

代表性例子
  • 環癸-1,6-二酮（cyclodeca-1,6-dione）分子內羥醛，100% 產率（形成 6-5 稠環）
  • 壬-2,8-二酮（nona-2,8-dione）在 NaOH 下環化，85% 產率（6 員環）
  • 複雜二酮環化，90% 產率（雙環骨架）

Robinson 環化（Robinson Annulation）

Robinson 環化 = Michael 加成 + 分子內羥醛，是構建六員環（特別是甾體 A-B 環）的經典反應：

O O O ‖ ‖ ‖ 酮 + CH₂=CH-C-Me → Michael 加成 → 1,5-二酮 → 分子內 aldol (鹼) → 環烯酮 （6-員含 α,β-不飽和羰基）
Robinson 環化的應用
  • Hajos-Parrish 酮（甾體 A-B 環前驅體）
  • 廣泛用於天然產物合成（如甾體、萜烯）
  • R₂NH 催化（烯胺路徑）可得高對映選擇性
  • Darzens 反應（縮水甘油酸酯縮合）

Claisen 酯縮合（Claisen Condensation）

兩分子酯（含 α-H）在強鹼（NaOEt）下縮合，生成 β-酮酯（β-keto ester）。這是一個親核加成-消除反應（酯的羥醛類似物）：

2 EtOAc ——NaOEt——→ EtO₂C-CH₂-COCH₃ + EtOH 乙酸乙酯 乙醯乙酸乙酯 (β-酮酯) 機制： 1. NaOEt 去質子化 α-H → 烯醇鹽 2. 烯醇鹽攻擊另一酯分子的 C=O → 四面體中間體 3. 消除 EtO⁻ → β-酮酯 (還有 α-H, pKa~11) 4. NaOEt 去質子化 β-酮酯 → 穩定烯醇鹽 → 驅動平衡（不可逆）
Claisen 平衡驅動

Claisen 縮合的熱力學驅動力：β-酮酯（pKₐ~11）可被 NaOEt 完全去質子化，形成熱力學穩定的烯醇鹽，使反應不可逆。若 β-酮酯沒有活潑 α-H，則縮合可逆（問題！）

阻斷 Claisen（Blocked Claisen）

當酯無 α-H（如苯甲酸酯 PhCO₂Et），無法發生自縮合，可利用更強鹼（三苯甲基鈉，Ph₃C⁻Na⁺）作為鹼進行跨縮合：

PhCH₂CO₂Et + Ph₃C⁻Na⁺ → PhCH⁻CO₂Et (烯醇鹽) + EtO₂C-CO₂Et (草酸酯，無 α-H，不競爭) → 縮合產物 (74%)

交叉 Claisen（Crossed Claisen）

使用無 α-H 的電親性酯（不可烯醇化）+ 可烯醇化酯，可成功進行選擇性交叉 Claisen：

常見電親性酯的親電活性順序

草酸酯（oxalate）> 甲酸酯（formate）> 碳酸酯（carbonate）> 苯甲酸酯（benzoate）

苯乙酸酯 + 碳酸二乙酯 → 苯丙二酸二乙酯

苯乙酸乙酯（PhCH₂CO₂Et）+ 碳酸二乙酯（EtO₂C-OEt，無 α-H）+ NaOEt → 苯丙二酸二乙酯（diethyl phenylmalonate，兩個 CO₂Et 基），產率良好。

酮 + 酯縮合（生成 β-酮酯）

酮烯醇鹽 + 酯發生跨 Claisen 縮合，生成 β-酮酯；碳酸酯比苯甲酸酯更親電：

環辛酮 + 碳酸二乙酯 → β-酮酯（NaH，91-94%）

環辛酮（cyclooctanone）在 NaH 作用下形成烯醇鹽，與 EtO₂CO（碳酸二乙酯）縮合，主要得到取代少側的 β-酮酯（91-94% 產率）。

Acifran 藥物合成

利用不對稱酮 + 酯縮合，精確控制區位選擇性，高效合成降脂藥 Acifran。

醯化位置控制（C- vs O-醯化）

烯醇鹽是兩性親核劑，醯化時可發生C-醯化（產物為 β-二羰基化合物）或O-醯化（產物為烯醇酯）。控制選擇性的方法：

條件偏好原因
Li/Zn 烯醇鹽 + 醯氯/酐C-醯化金屬配位活化碳，螯合控制
1,3-二羰基（Mg 螯合型烯醇鹽）C-醯化Mg²⁺ 與兩個氧配位，降低 O 反應性
高活性醯化劑（酸酐）+ 硬性烯醇鹽O-醯化風險O 更硬，與硬親電體優先反應
烯胺 + 醯氯C-醯化（不可逆）C-醯化為不可逆，熱力學驅動
BF₃ + 酸酐C-醯化（6-員環 TS）硼烯醇鹽通過六員 TS 形成 1,3-二酮
烯胺 C-醯化 — Longifolene 合成（82%）

利用烯胺（pyrrolidine enamine）的不可逆 C-醯化反應，引入醯基後酸水解，高效合成天然倍半萜 longifolene 的環骨架（82% 產率）。

Aza-enolate（二甲腙型烯醇鹽）的 C-醯化

使用二甲腙（dimethylhydrazone, RCHO→RCH=NNMe₂）作為醛的烯醇鹽等效物，LDA 去質子化後進行 C-醯化，整體產率 83%，區位選擇於取代少側。

分子內交叉 Claisen 縮合（Dieckmann 縮合）

雙酯化合物在鹼（NaOEt）下進行分子內 Claisen 縮合，生成環狀 β-酮酯，稱為 Dieckmann 縮合，是合成 5 或 6 員環的高效方法：

CO₂Et O CO₂Et | ‖ | EtO₂C—(CH₂)n—CH₂ + NaOEt → 環 (CH₂)n (Dieckmann 縮合) (β-酮酯環)
代表性例子
  • 酮酯（keto-ester）NaH，82% 產率（5 員環，混合烯醇位置）
  • 四酯化合物 Dieckmann，91% 產率（對稱策略避免區位問題）
  • 二胺二酯（symmetrical strategy with diamine diester）以對稱性消除區位選擇性問題
