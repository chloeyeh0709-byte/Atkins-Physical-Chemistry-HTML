Sulfur, Silicon, and Phosphorus in Organic Chemistry

硫在有機化學中的應用

硫原子在有機化學中表現出獨特的性質：它是軟性親核劑/親電劑，可形成多種氧化態的官能基（從硫醇到磺酸），且能穩定相鄰的碳負離子。

含硫官能基的氧化態

氧化態官能基名稱
最低R-SH硫醇（thiol）
R-S-R'硫醚（sulfide）
R-S(=O)-R'亞碸（sulfoxide）
R-SO₂-R'碸（sulfone）
最高R-SO₂Cl磺醯氯（sulfonyl chloride）

硫醇鹽（thiolate, RS⁻）是軟性親核劑，反應性高於 RO⁻。氯化硫醯（sulfenyl chloride, RSCl）是軟性親電劑，可對烯烴進行親電加成。

硫穩定的碳陰離子

硫原子（特別是多氧化態）能有效穩定相鄰碳的負電荷，酸性（α-H 的 pKₐ）比較：

硫穩定陰離子的酸性
  • 碸（sulfone，R-SO₂-CHR'₂）：pKₐ ≈ 29
  • 亞碸（sulfoxide，R-S(=O)-CHR'₂）：pKₐ ≈ 35
  • 硫醚（sulfide，R-S-CHR'₂）：pKₐ ≈ 48

穩定化機制：硫的 3d 軌域接受碳負離子的電子（p-d π 鍵）；穩定性：碸 > 亞碸 > 硫醚。

1,3-二硫環（Dithiane）— Umpolung 反應

1,3-二硫環（1,3-dithiane）由 1,3-丙二硫醇與醛縮合生成，其 C2 位 H 可被 n-BuLi 去質子化，形成d¹ 試劑（umpolung 試劑），即「反極性」的類醛碳負離子：

RCHO + 1,3-丙二硫醇 → [1,3-dithiane-R] （環縮醛） n-BuLi → C2 碳陰離子 （d¹ 試劑，umpolung） + R'X → C2 被烷基化 水解（Hg²⁺ 或氧化法）→ R'-CHR-CHO （羰基重生，兩端相連）

Umpolung 策略改變了醛碳的正常反應極性（原本為 a¹ 親電劑），使其成為 d¹ 親核劑，可在醛碳上引入新的碳鏈。

生物素（Biotin）合成中的 Dithiane 應用

生物素（維生素 B₇）合成利用 1,3-二硫環作為 umpolung 試劑，建構含硫的雜環骨架，關鍵步驟高效且立體選擇性好。

硫葉立德（Sulfur Ylids）

硫葉立德（sulfur ylid）含有相鄰的正電荷 S 和負電荷 C，有兩種類型：

硫葉立德的兩種類型與產物
類型結構與醛/酮反應產物
硫鎓葉立德（sulfonium ylid）R₂S⁺-CH₂⁻α,β-不飽和羰基環氧化物
亞碸鎓葉立德（sulfoxonium ylid）R₂S(=O)⁺-CH₂⁻α,β-不飽和羰基環丙烷
硫鎓葉立德 + 醛 → 環氧化物（Corey-Chaykovsky）： Me₂S⁺—CH₂⁻ + R-CHO → 環氧化物（epoxide） 亞碸鎓葉立德 + α,β-不飽和酮 → 環丙烷（Johnson-Corey-Chaykovsky）： Me₂S(O)⁺—CH₂⁻ + CH₂=CH-COR → 環丙烷酮

Swern 氧化

Swern 氧化利用草醯氯（(COCl)₂）活化 DMSO（二甲亞碸），再與醇反應，生成醛或酮（醇 → 醛/酮），在溫和條件（-78°C）下進行，無 Cr 污染：

Swern 氧化機制： DMSO + (COCl)₂ → Me₂S⁺-Cl （活化型 DMSO） + R-CH₂-OH → R-CH₂-O-S⁺Me₂ （烷氧基硫鎓鹽） + Et₃N (鹼) → [5-員環 TS：Ei 消除] → R-CHO + Me₂S + Et₃N·HCl （醛）

矽在有機化學中的應用

矽（Si）在有機化學中的主要應用：保護基、立體選擇性烯烴合成（Peterson 消除、Wittig 磷）、穩定相鄰碳正離子（β-矽效應）。

矽保護基（Silicon Protecting Groups）

矽保護基通過 Si-O 鍵保護醇羥基，用 F⁻ 或酸水解脫保護：

保護基縮寫穩定性（相對）脫保護
三甲基矽基TMS最低F⁻、稀酸
三乙基矽基TES低F⁻
叔丁基二甲基矽基TBS/TBDMS中（最常用）TBAF（F⁻）
三異丙基矽基TIPS高TBAF
叔丁基二苯基矽基TBDPS最高TBAF

所有矽保護基均可被 F⁻（如 TBAF）脫保護（Si-F 鍵能比 Si-O 強），是矽保護基脫保護的普遍試劑。

Peterson 消除（Peterson Elimination）

Peterson 消除：β-羥基矽烷（β-hydroxysilane）在酸或鹼條件下消除，生成烯烴，且完全區位選擇性（regiospesific）：

SiR₃ OH SiR₃ O⁻ | | 鹼（-OH⁻） | | R—CH—CH—R' ———→ R—CH—CH—R' → syn 消除 → 特定 E/Z 烯烴 SiR₃ OH | | 酸（-H₂O） R—CH—CH—R' ———→ 抗式消除（anti elimination） → 相反 E/Z 烯烴

Peterson 消除是完全立體特異性（stereospecific）的：同一非對映異構體 + 不同反應條件 → 不同烯烴幾何異構體。

β-矽效應（Beta-Silicon Effect）

矽原子可穩定相鄰（β 位）的碳正離子，原因是 Si-C 鍵的 σ 鍵軌域與空的碳正離子 p 軌域形成超共軛（hyperconjugation）：

β-矽效應： SiR₃ SiR₃ | | R—CH—CH₂⁺ ←→ R—CH=CH₂ + SiR₃⁺ (穩定碳正離子) (矽基離去後生成烯烴)

應用：芳基/乙烯基矽烷的 ipso 取代（親電試劑攻擊矽所在碳，Si 作為離去基）。

Fleming-Tamao 氧化

Fleming-Tamao 氧化（Tamao-Fleming oxidation）：將有機矽基（ArSiR₂ 或含 F/OMe 的矽基）氧化為羥基（Si → OH），相當於 C-Si 到 C-OH 的轉化：

C—SiR₂Ph →（氧化：KF/H₂O₂）→ C—OH (ArSi 或 FSi) (等效於 C-H → C-OH)

Fleming-Tamao 氧化與前期的有機矽烷合成結合，可實現對特定碳的立體選擇性羥化。

烯丙基矽烷（Allylsilane）

烯丙基矽烷（allylsilane, CH₂=CH-CH₂-SiR₃）是重要的親核試劑，比乙烯基矽烷（vinyl silane）更活潑：

烯丙基矽烷的反應規律
  • Lewis 酸（TiCl₄、BF₃）活化親電體（如醛）
  • 親核攻擊發生在 γ 碳（遠離 Si 的末端碳）
  • 中間體：β-矽基碳正離子（β-silyl cation）
  • Si 基最終脫去，產物為高烯丙醇（homoallylic alcohol）
烯丙基矽烷 + RCHO（TiCl₄）： SiR₃ OH | TiCl₄ | CH₂=CH-CH₂ + RCHO → R-CH-CH₂-CH=CH₂ （高烯丙醇） γ端攻擊 （β-矽中間體消除）
矽縮醛（Silyl Acetal）

醛/酮與 TMSOTf（三甲矽基三氟甲磺酸酯）反應，生成矽縮醛，可進行類似烯丙基矽烷的 Lewis 酸活化反應。

立體選擇性烯烴合成

立體選擇性合成特定 E 或 Z 烯烴的四種主要策略：

  1. 環系限制（ring constraint）：用小環限制幾何構型
  2. 平衡法（equilibration）：利用熱力學使 E/Z 互轉達到平衡
  3. 立體選擇性法（stereoselective）：反應的過渡態偏好某一立體化學
  4. 立體特異性法（stereospecific）：機制決定唯一的立體化學結果

E/Z 平衡化策略

利用異構化（isomerization）達到熱力學最穩定的 E 烯烴：

  • 非共軛烯烴：I₂ 催化 Z→E（碘自由基使雙鍵旋轉）
  • Michael 受體（共軛烯烴）：鹼（胺/MeOH）催化加成-消除異構化（E 更穩定）
  • 光化學：光照（hv）使 E→Z，達到光穩態（photostationary state），富含 Z 異構體

從炔烴合成 Z 或 E 烯烴

炔烴還原是製備立體純烯烴的重要方法：

還原方法機制產物
Lindlar 催化氫化（H₂/Pd/CaCO₃/Pb(OAc)₂）syn 加氫Z 烯烴
Na 或 Li 溶於液氨（Birch 型）anti 還原（電子加成）E 烯烴
LiAlH₄ 還原炔丙醇syn 加氫E 烯丙醇（含 OH 導向）
Red-Al（DIBAL 類）syn 加氫E 烯丙醇
炔醇的親核加成（MeOH/鹼）

醇對炔烴的 anti-Markovnikov 加成得到 Z 烯醇醚（Z-vinyl ether），機制為鹼催化的 anti-加成。

亞碸消除 → E 烯烴

β-羥基亞碸或 β-氫亞碸在加熱下發生周環消除（pericyclic syn elimination），得到 E 烯烴：

H S(O)Ph | | Δ（pericyclic syn elim） R-CH—CH-R' ———→ R-CH=CH-R'（E 為主）+ PhSOH β-氫亞碸 （5-員環 TS，syn 消除）
Queen Bee Substance 合成

蜜蜂蜂王物質（E-9-oxodec-2-enoic acid）的合成利用亞碸消除建立 E 雙鍵，立體選擇性高。

Julia 烯烴化（Julia Olefination）

Julia 烯烴化利用苯碸陰離子與醛反應，生成 E 烯烴，是合成長鏈 E 烯烴的重要方法：

傳統 Julia（3步）： PhSO₂-CH₂R + BuLi → PhSO₂-CHR⁻ + R'CHO → β-羥基碸 + AcCl → 乙酸酯化 + Na/Hg（還原消除）→ E 烯烴 機制：乙酸酯中間體 → 自由基陰離子（via Na/Hg）→ 碸基消除（E2）→ E 烯烴
Julia-Kocienski 改良（一步法）

使用四唑基碸（tetrazolyl sulfone）取代苯碸，加入 KHMDS 和醛，直接一步得到 E 烯烴（不需要還原步驟，SO₂ 直接脫去）。這是現代合成中廣泛使用的一步 Julia 烯烴化。

Peterson 反應的立體化學

Peterson 消除的立體化學完全立體特異：同一 β-羥基矽烷的非對映異構體，酸/鹼條件下得到相反的 E/Z 烯烴：

Peterson 立體化學規則
β-羥基矽烷鹼（anti 消除）酸（syn 消除）
syn（erythro）Z 烯烴E 烯烴
anti（threo）E 烯烴Z 烯烴

機制：鹼 → anti-periplanar 消除（E2 型，Si/OH 反式）；酸 → syn-periplanar 消除（Ei 型，Si/OH 順式）。

Wittig 反應

Wittig 反應：磷葉立德（phosphorus ylid，Ph₃P=CHR）與醛/酮反應，生成烯烴 + Ph₃P=O（三苯基膦氧化物）：

Ph₃P=CHR + R'CHO → RCH=CHR' + Ph₃P=O 磷葉立德 (烯烴) (副產物)
Wittig 反應的立體選擇性
葉立德類型R 基E/Z 選擇性原因（過渡態）
非穩定化（unstabilized）烷基Z（cis）syn 氧磷雜環丁烷（oxaphosphetane）
穩定化（stabilized）CO₂R、CORE（trans）anti 氧磷雜環丁烷
Bombykol（蠶蛾費洛蒙）合成

利用非穩定化 Wittig 葉立德（R=烷基）→ Z 烯烴，合成蠶蛾性費洛蒙 bombykol（含 Z,E 二烯）。

Capsaicin（辣椒素）E/Z 異構體

辣椒素分子含烯基側鏈；穩定化 Wittig（R=NHCO）→ E 異構體（天然型）；非穩定化 → Z 異構體（無辣感）。

HWE 反應（Horner-Wadsworth-Emmons）

HWE 反應使用磷酸酯葉立德（phosphonate ester ylid，(EtO)₂P(O)-CHR⁻）代替三苯基膦，有以下優點：

  • 反應條件更溫和（可用 NaH 或 K₂CO₃ 去質子化）
  • 副產物（磷酸二酯）水溶性高，易分離
  • 穩定化（含 EWG）時高選擇性得到 E 烯烴
HWE 反應： (EtO)₂P(O)—CHR⁻ + R'CHO → RCH=CHR'（E 為主）+ (EtO)₂P(O)O⁻ 磷酸酯葉立德 烯烴（穩定化 → E）

HWE 是合成 α,β-不飽和酯/酮的首選方法（對應穩定化的磷酸酯葉立德，E 選擇性好）。
