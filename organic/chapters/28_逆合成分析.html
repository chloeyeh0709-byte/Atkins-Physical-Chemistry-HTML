逆合成分析

Retrosynthetic Analysis

逆合成的基本概念

逆合成分析（retrosynthetic analysis）是由 E.J. Corey 發展的系統化合成規劃方法，以逆合成箭頭（⟹）表示「目標分子可由哪些前驅物合成」，從目標（target）反向推導至已知起始物。

目標分子 ⟹ 中間體 A ⟹ 中間體 B ⟹ ··· ⟹ 起始物 （逆合成箭頭，表示「可由...合成」，非反應方向）

術語定義

術語英文說明
斷鍵disconnection在目標分子中切斷一個鍵，得到兩個片段
合成等效物synthon斷鍵後得到的理想化片段（通常帶電荷）
試劑reagent實際使用的化合物，對應合成等效物
官能基互換FGI改變官能基類型，便於斷鍵或反應

五條逆合成準則

Corey 的五條逆合成準則
  1. 選擇已知可靠的反應：只斷開可用高產率反應來形成的鍵
  2. 在雜原子旁邊斷鍵：O、N 等雜原子提供極性，通常是 C-C 鍵斷開的最佳位置
  3. 避免化學選擇性問題：選擇不需區分多個相似官能基的斷鍵方式
  4. 兩基團同時斷鍵：儘量一次斷開能由一個反應形成的兩個鍵
  5. 轉化為含氧官能基：N 的類似物常可回溯至 O 官能基（較易取得）

供體與受體合成等效物

每個斷鍵產生一個受體（acceptor, a）合成等效物（缺電子）和一個供體（donor, d）合成等效物（富電子）。

合成等效物的標記規則

下標數字代表官能基到斷裂位置的碳數：

  • a¹：醛的親電碳（CHO 的 C1，受體）→ 實際試劑：醛
  • d²：烯醇鹽（α 碳，供體）→ 實際試劑：酮/LDA
  • a²：環氧化物（β 碳，受體）→ 實際試劑：環氧化物
    • a³：烯酮的 β 碳（Michael 受體，受體）→ 實際試劑：烯酮
  • 奇數下標 → 受體（acceptor）；偶數下標 → 供體（donor）

1,2-二官能基的逆合成

1,2-二官能基化合物（如 1,2-二醇、α-氨基醇）的逆合成通常回溯至烯烴（二羥基化或環氧開環）：

1,2-二醇 ⟹ 烯烴（OsO₄ 二羥基化正向） 1,2-氨基醇 ⟹ 環氧化物（胺開環正向） α-羥基酮 ⟹ 烯烴（Rubottom 氧化正向）

1,3-二官能基的逆合成

1,3-二官能基（1,3-diX）是自然極性（natural polarity）反應的典型產物，可回溯至：

  • 羥醛反應（a¹ + d²）：1,3-羥基羰基 ⟹ 醛 + 烯醇鹽
  • Michael 加成中的 a³ 受體：1,3-二羰基 ⟹ 烯酮（a³）+ 烯醇鹽（d²）
  • Claisen 縮合：β-酮酯 ⟹ 兩個酯

1,4-二官能基的逆合成（Umpolung 策略）

1,4-二官能基（1,4-diX）是不自然極性，需要 umpolung 策略：

  • 烯胺 + α-溴羰基（d¹ + a³）：1,4-二羰基 ⟹ 烯胺（d¹） + α-鹵羰基
  • Friedel-Crafts + 環狀酸酐：可避免 umpolung（Friedel-Crafts 醯化 + 環酐直接給出 1,4-關係）

1,5-二官能基的逆合成

1,5-二羰基（1,5-diCO）是 Michael 加成（a³ + d²）的典型產物：

1,5-二羰基逆合成： O O ‖ ‖ R—C—CH₂CH₂CH₂—C—R' ⟹ 烯酮（a³）+ 烯醇鹽（d²） （Michael 加成正向）

1,1-C-C 斷鍵（Grignard/FGI 策略）

在羰基旁的 C-C 鍵可以斷開，回溯至 Grignard 加成（a¹ + d 試劑）：

OH | R—C—R'R'' ⟹ R-CHO (或酮) + R'MgBr（或 R'Li） 醇（1,1 關係） （Grignard 正向）

有時需先進行 FGI（官能基互換）：醇 → 酮（氧化），再對酮進行 1,1 C-C 斷鍵。

胺的合成策略

胺在逆合成中常用兩種策略：

  1. 醯胺還原（LiAlH₄）：胺 ⟹ 醯胺 ⟹ 羧酸 + 胺（縮合）→ 醯胺 → LiAlH₄ 還原 → 胺
  2. 還原胺化（reductive amination）：胺 ⟹ 酮（或醛）+ 胺 → 亞胺 → 還原 → 胺

藥物合成逆合成範例

普萘洛爾（Propranolol，β-受體阻斷劑）

1,2-二氧關係：逆合成回溯至環氧化物（由萘酚和環氧氯丙烷合成）。正向：萘酚 + 環氧氯丙烷 → 芳基環氧化物 → 異丙胺開環 → 普萘洛爾。

Ocfentanil（阿片類）、Fenfluramine（食慾抑制劑）、Nafimidone（抗癲癇）

各含 1,2 關係的 C-N 鍵：逆合成均可回溯至還原胺化或醯胺還原策略。

Arildone（抗病毒藥）

含 1,2-二羰基前驅體，逆合成回溯至烯烴功能化（Rubottom 氧化或親電環氧化）。

1,3-二氧關係的逆合成

1,3-二氧化合物（如 β-羥基酯、β-羥基酮）的逆合成回溯至羥醛反應或 Reformatsky：

血栓素拮抗劑（Thromboxane Antagonist）

含 1,3-羥基酯關係；逆合成：1,3-二氧 ⟹ 環酸酯 + 格氏試劑（或烯醇鹽 + 醛）。正向通過 Reformatsky 或分子內 aldol 建構。

Cinflumide（肌肉鬆弛劑）、Doxpicomine（鎮痛劑）

均含 1,3-二氧關係；逆合成回溯至羥醛縮合（aldol）或 Reformatsky 反應。

N,O 的 1,3 關係

β-氨基醇（1,3-N,O 關係）的逆合成策略：回溯至腈的加成（nitrile aldol），或 Mannich 反應，或環氧開環：

Venlafaxine（抗憂鬱藥）

含 1,3-N,O 關係；逆合成：1,3-氨基醇 ⟹ 芳香酮 + 胺（Mannich 策略）或腈加成策略。

Clobutinol、Nisoxetine 類似物

均含 β-氨基醇（1,3-N,O）：逆合成通過 Mannich 反應或還原胺化回溯到酮前驅體。

1,3-二羰基的 Claisen 斷鍵

β-酮酯（1,3-二羰基）的逆合成可用 Claisen 斷鍵，回溯至兩個酯：

Tazadolene（鎮靜藥）、Bropirimine（免疫調節劑）

均含 1,3-二羰基關係；逆合成通過 Claisen 斷鍵，回溯至酮 + 碳酸酯或酯 + 酯（Claisen 縮合或 Dieckmann）。

1,5-二羰基的逆合成

Rogletimide（鎮靜藥）

含 1,5-二羰基關係；逆合成：Michael 加成（a³+d²）+ 丙二酸酯烷基化。正向通過 Michael 加成 + 環化合成哌嗪骨架。

Umpolung 策略

對於不自然極性的 C-C 關係（如 1,2-二羰基、1,4-二官能基），需要 umpolung 試劑：

常見 Umpolung 等效物
合成等效物實際試劑適用關係
d¹（umpolung 醛碳）1,3-dithiane（CN⁻ 也可）1,2 或 1,4 二羰基
a²（umpolung 烯醇）環氧化物1,2 二官能基
CN⁻（等效 d¹）HCN、NaCN1,2 羥基腈
苯硫醇二醇（Phenaglycodol 鎮靜劑）

含 1,2-二功能化關係（兩個 OH）；逆合成：1,2-二醇 ⟹ 芳酮（OsO₄ 二羥基化）或環氧化物。正向通過 BH₃ 氫硼化或其他方法。

1,2-二官能基的天然合成

1,2 關係在自然合成中可用：

  • 二羥基化（dihydroxylation）+ FGI：得到 1,2-二醇，再轉化其他基
  • 腈 + 酮（umpolung）：得到 α-羥基腈（cyanohydrin），再轉化

1,4-二官能基的逆合成

1,4-二官能基（umpolung 極性）策略：

  • 烯胺 + α-溴羰基（d¹ + a³）：1,4-二羰基 ⟹ 烯胺（醛等效 d¹）+ α-鹵代酮（a³）
  • Friedel-Crafts + 環狀酐：芳環 + 環酐（如順丁烯二酸酐）→ 1,4-芳基羰基酸（避免 umpolung）
