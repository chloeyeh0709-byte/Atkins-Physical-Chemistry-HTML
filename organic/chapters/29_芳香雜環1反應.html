第二十九章

芳香雜環（一）— 反應

Aromatic Heterocycles 1: Reactions

芳香雜環概論

雜環（heterocycle）是含有非碳原子（N、O、S 等）的環狀化合物。芳香雜環符合 Hückel 4n+2 規則，具有環狀共軛 π 電子系統。根據雜原子對芳香性的貢獻方式，雜環分為兩大類：

兩大類芳香雜環
類型代表雜原子孤對電子反應性
吡啶型（pyridine-type）吡啶、喹啉不在 π 系統中（平面外）親電芳香取代較弱（缺電子）
吡咯型（pyrrole-type）吡咯、呋喃、噻吩參與 π 系統（貢獻兩個 π 電子）親電芳香取代活潑（富電子）

等效地：「用 N 取代 C-H」得到吡啶型；「用 N 取代 C=C（N 的孤對電子在 π 中）」得到吡咯型。

吡啶（Pyridine）

吡啶（C₅H₅N）是最重要的含氮六員芳香雜環。N 原子的孤對電子在平面內（sp²雜化），不參與 π 系統，故吡啶是良好的鹼（pKₐ(BH⁺) = 5.5）且是親核劑（在 N 上）。

DMAP（4-二甲胺基吡啶）

DMAP 是吡啶的強親核性衍生物（4 位有 NMe₂ 供電子基），常用作醯化反應的催化劑（親核催化）。

吡啶的親電芳香取代（EAS）

吡啶的 EAS 非常困難，原因：

  1. N 原子的電子吸引效應使苯環缺電子（特別是 2、4 位）
  2. 親電試劑容易在 N 上先發生親電攻擊，使環帶正電，更難進行 EAS
  3. EAS 中間體（arenium ion，Wheland 中間體）能量高

吡啶本身幾乎不進行 EAS。要在吡啶環上進行 EAS，必須先在3 位引入強給電子基（如 NH₂、OMe）來活化環。

3-胺基吡啶的 EAS： NH₂ NH₂ | Br₂/H₂O | Br N (3位給電子) → N (取代發生在富電子位置) 吡啶 EAS 需活化

吡啶的親核芳香取代（SNAr）

吡啶的 2 位和 4 位對親核取代活潑（N 穩定 Meisenheimer 中間體）：

2-氯吡啶 + NaNH₂ → 2-胺基吡啶 (2 位親核取代) 4-氯吡啶 + NaOMe → 4-甲氧基吡啶 (4 位親核取代) 機制：親核劑攻擊 2/4 位 → Meisenheimer 中間體（N 穩定）→ 消除 Cl⁻

吡啶酮（Pyridone）

2-羥基吡啶存在互變異構平衡，但以2(1H)-吡啶酮（酰胺型）為主（類似醯胺，穩定），而非 2-羥基吡啶（烯醇型）：

OH O | ‖ N H-N 2-羥基吡啶（烯醇型） ⇌ 2(1H)-吡啶酮（酰胺型，主要形式）

用 POCl₃ 可將 2-吡啶酮轉化為 2-氯吡啶（OH → Cl），這是製備含氯吡啶的重要方法。

吡啶 N-氧化物

吡啶用 mCPBA 氧化可得吡啶 N-氧化物。N-氧化物既可進行 EAS（在 2/4 位），也可進行親核取代（N-O 使 2 位更親電），後續脫氧（用 PCl₃ 或 (EtO)₃P）可得 2/4-取代吡啶。

吡咯（Pyrrole）

吡咯（C₄H₄NH）的 N 孤對電子完全參與芳香 π 系統（貢獻 2 個 π 電子），因此：

  • 吡咯 N 的鹼性極弱（pKₐ(BH⁺) = -4）——質子化會破壞芳香性
  • 吡咯 N-H 具有一定酸性（pKₐ(NH) = 16.5）
  • 吡咯環富電子，EAS 活性遠高於苯

吡咯的親電芳香取代

吡咯的 EAS 優先發生在 2 位（α 位），原因是 2 位的過渡態中間體（arenium ion）更穩定（線性共軛 vs. 3 位的交叉共軛）：

N-H / \ 2 3 / \ (α) (β) EAS 優先 → 2 位（α）：中間體為線性共軛，更穩定
吡咯的典型反應
  • 溴化：Br₂ → 四溴吡咯（過度溴化，無選擇性），但在 -78°C 可控制在 2 位
  • 強酸條件：吡咯在強酸下會在 2 位質子化，並迅速聚合
  • Vilsmeier 甲醯化：POCl₃/DMF → 2-甲醯吡咯（CHO 在 2 位）

脫羧策略：如果需要在 3 位引入取代基，可先在 2 位引入 CO₂H（羧基），待反應後再加熱脫羧，利用 2 位選擇性間接實現 3 位取代。

呋喃（Furan）

呋喃（C₄H₄O）是含氧的五員芳香雜環，O 孤對電子參與 π 系統。呋喃比苯更活潑，但比吡咯穩定，因 O 電負性較高。

呋喃的特殊反應
  • Br₂/MeOH 反應：得到 2,5-二甲氧基-2,5-二氫呋喃（縮醛產物）而非 EAS，因為 1,4-加成更有利
  • 酸水解：呋喃環水解為 1,4-二羰基化合物（丁二醛衍生物）——烯醇醚水解
  • Diels-Alder 反應：呋喃可作為二烯體，與親二烯體反應（可逆！需低溫，exo 為熱力學產物）

噻吩（Thiophene）

噻吩（C₄H₄S）是含硫的五員芳香雜環，是類似苯的穩定芳香族化合物，比呋喃和吡咯更穩定：

噻吩的典型反應
  • Friedel-Crafts 醯化：Ac₂O/SnCl₄ → 2-乙醯噻吩（2 位選擇性）
  • Raney Ni 脫硫：噻吩環在 Raney Ni 催化下去硫，轉化為烷烴（用於去硫保護）
  • 噻吩碸 Diels-Alder：噻吩砜（thiophene sulfone, SO₂ 形式）可作 Diels-Alder 二烯體（不可逆，SO₂ 脫去）

呋喃與噻吩的直接金屬化（Directed Metalation）

呋喃和噻吩可用 n-BuLi 在 2 位選擇性鋰化（C-H 直接取代），形成有機鋰試劑，再進行親電取代（加 E⁺）：

呋喃 + n-BuLi → 2-鋰呋喃（2-lithiofuran） + E⁺（如 CO₂、醛、RX） → 2-取代呋喃

吡咯陰離子（Pyrrole Anion）的反應

吡咯 N-H 的 pKₐ = 16.5，可被強鹼（KH、NaH）去質子化，形成吡咯陰離子（pyrrole anion）。吡咯陰離子是兩性親核劑：

  • 軟性親電體（如烷基鹵）→ N-烷基化（N 為親核劑）
  • 硬性親電體（如 CO₂、甲醯氯）→ C-烷基化（2 位）

金屬（K、Na）的吡咯鹽在親電底物的選擇上展現獨特的 N vs C 選擇性，是合成 N-取代與 C-取代吡咯的重要工具。

咪唑（Imidazole）

咪唑（C₃H₄N₂）含兩個 N：一個為吡咯型（N-H，孤對電子在 π 中）、一個為吡啶型（孤對電子在平面外，可質子化）：

咪唑的性質
  • pKₐ(BH⁺) = 7.0（比吡啶強鹼）
  • pKₐ(NH) = 14.5（比吡咯弱酸）
  • 快速 N-H 互變異構（tautomerism），使 N1 = N3（除非一個 N 被取代）
咪唑的重要應用
  • CDI（羰基二咪唑）：縮肽/醯胺化試劑；咪唑作為離去基
  • 矽基化催化：咪唑催化 TMS 等矽保護基的引入
  • 組胺酸（Histidine）：含咪唑側鏈的氨基酸，在酶的催化活性位點中作廣義酸/鹼

咪唑的硝化：在 H₂SO₄/HNO₃ 下，硝基進入4 位（最少受 N 吸電子影響的位置）。甲硝唑（Metronidazole）合成即利用此反應。

三唑與四唑

含三個 N 的五員環稱為三唑：

  • 1,2,3-三唑：可由疊氮化物 + 炔烴（Huisgen 環加成，「點擊化學」）合成
  • 1,2,4-三唑：用於製備殺菌劑，許多重要抗黴藥含此環（如 fluconazole）
氟康唑（Fluconazole）合成

氟康唑（抗黴藥）含 1,2,4-三唑環，由 1,2,4-三唑 + 含 F 的環氧化物開環後合成。

四唑（Tetrazole）含四個 N，pKₐ ≈ 5（類似羧酸，可作 CO₂H 生物等效體（bioisostere））。四唑極度不穩定（高氮含量），具爆炸危險，在藥物設計中作為羧酸的非代謝性等效體。

Indomethacin 四唑類似物

將消炎藥 Indomethacin 的 COOH 替換為四唑，得到代謝更穩定的類似物（四唑的 pKₐ ≈ 5 ≈ 羧酸）。

吲哚（Indole）

吲哚（C₈H₇N）是苯環與吡咯稠合的雙環芳香化合物（10π 電子），是重要的天然產物骨架：

  • 色胺酸（Tryptophan）：含吲哚的必需胺基酸
  • LSD（麥角醯二乙胺）
  • 士的寧（Strychnine）
  • 血清素（Serotonin）

吲哚的親電芳香取代

吲哚的 EAS 發生在 3 位（C3，β 位），而非 2 位：

吲哚 EAS 機制： E⁺ → 攻擊 3 位 → spiro（螺環）中間體（有實驗證據） → N-H 去質子化 → 3-取代吲哚（芳香性恢復） 原因：3 位親電加成的中間體能量低於 2 位（3 位中間體可由相鄰 C2=C3 鍵參與穩定）
吲哚的典型 EAS 反應
  • Vilsmeier 甲醯化：POCl₃/DMF → 3-甲醯吲哚（3-CHO）
  • Friedel-Crafts（分子內）：含 γ,δ-不飽和吲哚進行分子內 Friedel-Crafts
  • Mannich 反應：吲哚 + HCHO + 胺 → 3-Mannich 鹼，98% 產率

吲哚 N 的 NaCN 反應：在特定條件下，N 上的 NMe₂ 基可被 NaCN 取代（N-脫烷基化/置換），用於製備 N-氰基吲哚。

HOBt — 1-羥基苯並三唑（縮肽試劑）

HOBt（1-hydroxybenzotriazole）是苯環與 1,2,3-三唑稠合的雜環，含有 N-OH 基，是縮肽合成（peptide coupling）中防止消旋化的重要試劑：

縮肽反應： DCC（二環己基碳醯亞胺）+ R-COOH → O-醯基異脲 （活性太高，易消旋） → + HOBt → HOBt 活化酯（N-氧基酯，活性適中，不消旋） → + H₂N-R' → 醯胺 (不消旋化的縮肽)

二嗪類（Diazines）

含兩個 N 的六員芳香雜環稱為二嗪，有三種異構體，鹼性（pKₐ）依序降低：

化合物位置pKₐ(BH⁺)用途
嗒嗪（Pyridazine）1,2-N2.3農藥、藥物
嘧啶（Pyrimidine）1,3-N1.3DNA/RNA 鹼基（胞嘧啶、尿嘧啶、胸腺嘧啶）
吡嗪（Pyrazine）1,4-N0.65香味化合物（甜椒香）

二嗪類的 2/4 位含 Cl（磺酰氯等）可進行親核取代（SNAr），用胺/醇置換 Cl，是合成藥物類嘧啶衍生物的重要方法。

馬來醯肼（Malehydrazide）→ 二氯嗒嗪

馬來醯肼（malehydrazide）用 POCl₃ 轉化為 3,6-二氯嗒嗪，再用不同胺進行依序取代（先取代活性高的位置，再取代活性低的位置），合成多種嗒嗪衍生物。

喹啉（Quinoline）與異喹啉（Isoquinoline）

喹啉和異喹啉是苯環與吡啶稠合的 benzo 雜環，共 10 π 電子：

EAS 位置選擇
  • 喹啉：EAS 在苯環側（5 位和 8 位，N 影響較弱），SNAr 在吡啶環 2/4 位
  • 異喹啉：5 位硝化（72%，0°C 控制條件）

喹啉 N-氧化物：可進行 N-氧化物驅動的 2 位親核取代（如 NaCN/Ac₂O → 2-氰基喹啉）。

喹啉的氧化反應：KMnO₄ 等強氧化劑可破壞苯環，得到吡啶-2,3-二羧酸（Quinolinic acid）；臭氧化可切斷特定雙鍵。

吲哚里西（Indolizine）

吲哚里西是 N 在環連接處的稠合雙環（10π），其 EAS 優先在 5 員環一側（富電子）。

嘌呤類（Purines）

嘌呤（Purine）是嘧啶與咪唑稠合的雙環含氮雜環（9 個原子，4 個 N），是核酸中的重要組成：

嘌呤衍生物功能/特點
腺嘌呤（Adenine）DNA、RNA、ATP 的組成部分
鳥嘌呤（Guanine）DNA、RNA 的組成部分
咖啡因（Caffeine）黃嘌呤衍生物，中樞神經興奮劑
尿酸（Uric acid）嘌呤代謝終產物（痛風相關）
Allopurinol黃嘌呤氧化酶抑制劑，治療痛風

含混合雜原子的五員環

一個芳香環中最多可容納一個 O 或 S（兩個 O 或兩個 S 在同一環中不穩定，但 N+O 或 N+S 可以）：

化合物雜原子重要性
噁唑（Oxazole）N + O（1,3）天然產物
噻唑（Thiazole）N + S（1,3）Vitamin B₁（硫胺素）
異噁唑（Isoxazole）N-O（1,2，N-O 鍵不穩定）農藥
異噻唑（Isothiazole）N-S（1,2）藥物
1,2,5-噻二唑N + N + S（1,2,5）含於 Timolol（β-受體阻斷劑）
甜椒香氣成分

甜椒（green pepper）的特徵香氣來自2-甲氧基-3-烷基吡嗪，通過 NMR 鑑定結構（甲氧基 + 吡嗪 + 烷基）。這是雜環化合物在食品化學中的著名例子。

卟啉類（Porphyrins）

卟啉是由 4 個吡咯環與 4 個醛通過甲橋（-CH=）連接成的大環芳香化合物（18π 電子，4n+2 規則），是生命中最重要的金屬配體：

  • 血紅素（Heme）：Fe-porphyrin，攜帶 O₂
  • 葉綠素（Chlorophyll）：Mg-porphyrin，光合作用
  • Vitamin B₁₂：Co-corrin（類卟啉）

卟啉的合成：4 個吡咯 + 4 個醛 → 卟啉（酸催化縮合）。

葉酸與磺胺藥物

葉酸（Folic acid）由三部分組成：

  1. 蝶啶（Pteridine，嘌呤 + 嘧啶稠合雙環）
  2. 對胺苯甲酸（PABA，para-aminobenzoic acid）
  3. 麩胺酸（Glutamic acid）
磺胺藥（Sulfa drugs）與 DHFR 抑制劑
  • 磺胺藥：結構類似 PABA，抑制細菌合成葉酸（競爭抑制 PABA）
  • Trimethoprim：抑制二氫葉酸還原酶（DHFR），阻止葉酸活化為四氫葉酸（THF）
  • Trimethoprim + 磺胺（聯用）→ 雙重阻斷葉酸合成（協同殺菌）
