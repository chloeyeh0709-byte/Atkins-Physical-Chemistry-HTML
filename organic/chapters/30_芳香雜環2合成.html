第三十章

芳香雜環（二）— 合成

Aromatic Heterocycles 2: Synthesis · pp. 757–788

合成策略概論

合成芳香雜環時，首要步驟是切斷含雜原子的鍵（C–N、C–O、C–S），以雜原子充當親核試劑，碳框架作為親電試劑（雙官能基化合物）。此策略使我們能從簡單的開鏈前驅物出發，以離子型成環反應構建雜環。

核心策略 合成芳香雜環的三大方法：
（1）離子型成環：切斷雜原子—碳鍵，以雙親電試劑（如1,4-或1,5-二羰基化合物）與含雜原子親核試劑反應
（2）環加成：1,3-偶極環加成（[3+2]）構建五員雜環
（3）現有環的改造：親電/親核芳香取代、鋰化後與親電試劑反應

五員雜環的離子合成

吡咯的合成

吡咯由1,4-二羰基化合物（琥珀醛衍生物）與伯胺（RNH₂）或氨（NH₃）縮合環化而得。

1,4-二羰基化合物 + RNH₂ → 吡咯 O O R ‖ ‖ | R¹-C-CH₂-CH₂-C-R² + RNH₂ → N / \ R¹ R² (吡咯)

機制：胺首先與一個羰基縮合形成半縮胺（hemiaminal）→ 脫水成亞胺 → 另一端親核環化 → 脫水芳香化。

呋喃與噻吩

同樣的1,4-二羰基骨架，改變試劑即可合成其他雜環：

  • 呋喃：酸催化環化（雜原子為 O，已存在於骨架中）
  • 噻吩：以 P₂S₅（或 Lawesson 試劑）將羰基 C=O 置換為 C–S，再環化
範例 己二酮（1,4-丁二酮） + H⁺ → 呋喃（脫兩分子水）
己二酮 + P₂S₅ → 噻吩（硫代后環化）
己二酮 + CH₃NH₂ → N-甲基吡咯

Knorr 吡咯合成

Knorr 合成是製備 1,4-二羰基前驅物的精妙方法：先以亞硝化（HNO₂）將酮 α-位轉化為亞硝基化合物，再以鋅/AcOH 還原成胺，胺立即與另一分子酮縮合環化，原位完成吡咯合成（產率可達 87%）。

EtO₂C-CH₂-CO-CH₃ →[HNO₂]→ EtO₂C-C(=NOH)-CO-CH₃ [Zn/AcOH] 還原 → 胺基中間體 → 分子內縮合 → 吡咯衍生物 (87% 產率)

六員雜環的合成

吡啶由1,5-二羰基化合物與氨反應，形成二氫吡啶中間體，再氧化（以 DDQ、HNO₃ 或空氣/MnO₂）芳香化而得。

1,5-二羰基化合物 + NH₃ → 1,2-二氫吡啶 →[氧化]→ 吡啶 O O ‖ ‖ R¹-C-...-C-R² + NH₃ → [Ar-H] → Ar (芳香化)

Hantzsch 吡啶合成

Hantzsch 合成是最重要的吡啶製備方法之一：以兩分子 β-酮酯 + 一分子醛 + 氨「一鍋」縮合環化，得到對稱的二氫吡啶，再氧化。

2 EtO₂C-CH₂-CO-CH₃ + RCHO + NH₃ ↓ [醛醇縮合 → Michael 加成 → 氨與羰基縮合 → 環化] ↓ 二氫吡啶（dihydropyridine） ↓ [O] 取代吡啶
醫藥應用 二氫吡啶類化合物本身是重要藥物！氨氯地平（amlodipine）和非洛地平（felodipine）是鈣離子通道阻斷劑，用於治療高血壓和心絞痛。其不對稱版本可通過不對稱 Hantzsch 合成（手性烯胺 + 烯酮 + NH₃）獲得。

機制細節：第一步是醛醇縮合（keto-ester 對醛），第二步是 Michael 加成（第二分子 keto-ester 對 Michael 受體），然後 NH₃ 對羰基縮合，最後分子內成環並脫水。

若用羥胺（NH₂OH）代替 NH₃，對 1,5-二酮環化，可直接得到吡啶，無需氧化步驟（羥胺提供了多餘的氧化當量）。

吡啶酮的合成

吡啶酮不必從吡啶氧化而來：以甲酸乙酯（Claisen 縮合）激活甲基酮的 α-位，再與含活性亞甲基的試劑（如氰基乙酰胺）環化，可直接構建吡啶酮骨架。

含兩個相鄰雜原子的五員環

吡唑與異噁唑

含兩個相鄰雜原子的五員雜環（吡唑 N-N、異噁唑 O-N）由1,3-二羰基化合物與含 N-N 或 N-O 鍵的試劑縮合得到：

  • 吡唑（pyrazole）：1,3-二酮 + 肼（H₂N-NH₂）→ 吡唑（N-N 鍵由肼直接提供）
  • 異噁唑（isoxazole）：1,3-二酮 + 羥胺（HO-NH₂）→ 異噁唑
  • 噻嗪類（isothiazole）：「硫醯胺」（thioamine）不存在，故此策略不適用
1,3-二酮 + H₂N-NH₂ → 吡唑 1,3-二酮 + HO-NH₂ → 異噁唑 1,3-二酮 + HS-NH₂ → ✗（硫醯胺不存在）

噻唑與硬軟酸鹼選擇性

噻唑（thiazole）含有非相鄰的 N 和 S，由硫代醯胺（thioamide，R-C(=S)-NH₂）與 α-鹵代酮（haloketone）縮合得到：

R-C(=S)-NH₂ + Br-CH₂-CO-R' ↓ （N 攻擊 C=O：硬-硬；S 攻擊 烷基 Br：軟-軟） ↓ 噻唑（thiazole）
硬軟酸鹼（HSAB）選擇性 反應具有精妙的區位選擇性：
• 氮（較硬親核試劑）→ 攻擊羰基碳（C=O，較硬親電試劑）
• 硫（較軟親核試劑）→ 攻擊烷基鹵（C–Br，較軟親電試劑）
這種 HSAB 匹配使噻唑合成的區位選擇性極高。

1,3-偶極環加成：四唑與三唑

1,3-偶極環加成（[3+2]）是構建多雜原子五員環的利器：

  • 四唑（tetrazole）：腈（RCN）+ 疊氮化鈉（NaN₃）→ 四唑（熱條件下的 1,3-偶極環加成）
  • 三唑（triazole）：疊氮 + 炔 → 三唑；用 Cu(I) 催化（「點擊化學」click chemistry）可高度區位選擇地得到 1,4-取代三唑（產率 95%）
  • 異噁唑：也可由腈氧化物（nitrile oxide）+ 炔的 1,3-偶極環加成得到
點擊化學（Click Chemistry） Cu(I) 催化的叠氮-炔 Huisgen 環加成是最著名的「點擊反應」：
R–N₃ + R'–C≡C–H → 1,4-二取代-1,2,3-三唑（>95% 產率，高度區位選擇性）
此反應在水相中即可進行，條件溫和，廣泛用於藥物化學和生物正交標記。

Viagra 吡唑核心的合成

Sildenafil（Viagra）中的吡唑環由一步 Claisen 縮合 → 再與甲基肼環化得到。完整路線：

  1. 酯 Claisen 縮合 → β-酮二酯（keto-diester）
  2. β-酮二酯 + 甲基肼（CH₃NHNH₂）→ 吡唑羧酸（脫 CO₂）
  3. 吡唑酸 → 硝化、還原 → 胺 → 磺醯胺化 → Viagra

含兩個非相鄰雜原子的六員環

嘧啶與甲氧苄啶（Trimethoprim）

嘧啶（pyrimidine）含 1,3 位的兩個氮，由1,3-二羰基化合物與脒（amidine，H₂N-C(=NH)-R）縮合得到：

1,3-二羰基化合物 + H₂N-C(=NH)-NH₂（胍 guanidine） ↓ NaCl 脫羧（decarboxylation） 氨基嘧啶（aminopyrimidine）
甲氧苄啶（Trimethoprim）的合成 甲氧苄啶是一種抗菌藥，其 2,4-二胺基嘧啶核心由含三甲氧苄基的 1,3-二羰基化合物與胍縮合， 再用 NaCl/DMF 脫羧而得。

噠嗪與吡嗪

  • 噠嗪（pyridazine）：1,4-二羰基化合物 + 肼（H₂N-NH₂）→ 二氫噠嗪 → 氧化
  • 吡嗪（pyrazine）：1,2-二酮 + 1,2-二胺 → 吡嗪

Fischer 吲哚合成

Fischer 吲哚合成是最重要的吲哚合成方法，自 Emil Fischer 於 1883 年發現至今仍廣泛應用。苯基肼（phenylhydrazine）與酮（或醛）在酸催化下生成腙（hydrazone），再重排成吲哚。

機制：[3,3]-σ 遷移重排

Fischer 吲哚合成的關鍵步驟是[3,3]-σ 遷移重排（sigmatropic rearrangement）：

PhNH-NH₂ + R-CO-CH₂-R' ↓（酸催化） 腙（hydrazone）: Ph-NH-N=C(R)-CH₂-R' ↓（酸催化烯胺化） 烯胺腙: Ph-NH-N=CR-...（雙鍵移位） ↓ [3,3]-σ 遷移重排（六員環 TS） 新的 C-C 鍵生成，N-N 鍵斷裂（打開） ↓ 再芳香化（失去 H⁺） 縮胺（aminal）中間體 ↓ 脫 NH₃ 吲哚（indole）
Fischer 吲哚合成總結 苯基肼 + 酮 → [酸] → 腙 → 烯胺 → [3,3] 重排 → 縮胺 → –NH₃ → 吲哚
整個過程：一個新 C–C 鍵、一個新 C–N 鍵形成；N–N 鍵斷裂。

應用：藥物合成

Fischer 合成廣泛應用於藥物吲哚的製備：

區位選擇性的控制：若苯環只有一個可用的 ortho 位，環化必然發生在該位，其他取代基不影響結果。若苯環為對稱性取代，則從對稱起始物直接得到預期產物。

血清素類藥物的合成 血清素（Serotonin）是5-羥色胺，許多重要藥物（如曲坦類）具有類似骨架。

舒馬曲坦（Sumatriptan）的合成：
  1. 芳香胺重氮化（NaNO₂/HCl）→ 重氮鹽
  2. SnCl₂/HCl 還原 → 苯基肼鹽酸鹽
  3. 加入 3-氰基丙醛的縮醛（防止自身縮合）→ 酸性條件釋放醛並形成腙
  4. 多磷酸（PPA）催化 Fischer 環化 → 含腈基的吲哚
  5. H₂/Rh 還原腈 → 胺；HCHO/HCO₂H（Eschweiler-Clarke 法）雙甲基化 → NMe₂
昂丹司瓊（Ondansetron）— 止吐藥 ondansetron 含有吲哚和咪唑兩個雜環。吲哚部分的 1,3-位關係提示 Mannich 反應引入咪唑， 再用 Fischer 切斷（ZnCl₂ 催化）從不對稱二酮構建吲哚（二酮只向一側烯胺化）， 再 K₂CO₃ 甲基化、Mannich 反應引入二甲胺基和甲醛、甲基化得目標物。
吲哚美辛（Indomethacin）— 非甾體抗炎藥 含有不對稱取代的吲哚（苯环 + 烷鏈兩側均有取代基）。需控制酸催化条件使烯胺化發生在 烷基鏈一側（遠離甲基的方向），採用 t-Bu 酯防止脫羧，最後在 N 上醯化 → 得吲哚美辛。

Reissert 吲哚合成

Fischer 合成給出 R₅ 位取代的吲哚，而 Reissert 合成給出 R₆ 位取代的吲哚——兩者互補。Reissert 合成從鄰硝基甲苯出發：

鄰硝基甲苯 + (EtO₂C)₂（草酸二乙酯） + EtO⁻（強鹼） → α-硝基酮酯（甲基去質子→C-醯化） → H₂/Pt/AcOH 還原硝基 → 胺 → 胺與酮基 分子内縮合 → 吲哚酯 （65% 產率）

由於吲哚环来自苯环的硝化，苯环的取代模式（第6位）与 Fischer 合成（第5位）不同，两者互为补充。

喹啉與異喹啉的合成

喹啉（quinoline）是金雞納樹皮中奎寧（quinine）的核心骨架，亦是一大類抗生素（喹啉酮類）的基礎。喹啉的合成切斷與嗪環相似：切斷吡啶環的 C–N 鍵，需要一個 C₃ 親電合成子（兩端均為親電），最合適的是 1,3-二羰基化合物。

Skraup 反應

Skraup 反應是最著名的喹啉合成方法，歷史上曾是「最暴烈」的有機反應之一：

傳統 Skraup： 芳香胺 + 甘油 + H₂SO₄(濃) + 硝基苯 →[>100°C]→ 喹啉 （甘油脫水原位生成丙烯醛；硝基苯為氧化劑） 現代改進（Doebner-von Miller 型）： 芳香胺 + α,β-不飽和羰基化合物（如丙烯醛） ↓ 共軛加成 β-胺基羰基化合物 ↓ 酸催化環化（EAS 型） 二氫喹啉 ↓ DDQ 或 Fe(III) 氧化 喹啉（芳香化）
8-羥基喹啉（Oxine） 由鄰胺基苯酚 + 丙烯醛，在 Fe₂(SO₄)₃、B(OH)₃ 催化、痕量 H₂SO₄ 下反應， 90% 產率得 oxine。Oxine 可形成穩定的 Cu(II) 等金屬配合物，用於防腐蝕。

喹啉酮抗生素

含 3-位羧酸的喹啉酮類是重要抗生素（如氧氟沙星、環丙沙星）。其核心骨架可由烯胺環化得到：

芳香胺 + HC(OEt)₃（原甲酸三乙酯）/ Ac₂O → 烯醚型烯胺 芳香胺 + EtO₂C-CH₂-CHO（丙二酸半酯醛） → 芳香胺加成 → 烯胺 → 加熱環化（分子内 Knoevenagel/醯胺型）→ 喹啉酮酯 → NaOH 水解 → 喹啉酮羧酸
Rosoxacin 的合成 Rosoxacin 含喹啉酮和吡啶兩個雜環。吡啶部分用 Hantzsch 乙炔酯变体从 3-硝基苯甲醛合成， 含两个炔酯和氨（醋酸铵）的特殊 Hantzsch；硝化 → 水解/脱羧 → Fe(II)/HCl 还原 → 得到含氨基的吡啶；再以喹啉酮标准环化（草酸二乙酯烯胺 + N-乙基化）即可得到 rosoxacin。

喹啉酮可用 POCl₃ 轉化為氯化物，再通過親核取代引入各種取代基，進一步豐富喹啉骨架。

異喹啉的合成

異喹啉可由苯乙胺衍生物的分子內 Vilsmeier 反應（以 POCl₃ 生成亞胺鹽）合成，再 Pd(0) 脫氫芳香化（Pd 催化加氫的逆反應）得到異喹啉：

PhCH₂NH₂ + RCOCl → 醯胺 醯胺 + POCl₃ → 分子內 Vilsmeier（亞胺鹽）→ 二氫異喹啉 二氫異喹啉 + Pd(0) → 異喹啉（芳香化）

多雜原子稠環

許多藥物含有稠合雙雜環系統，可利用第29章中制备單環的化學逐步構建。

咪唑並[1,2-b]吡嗪（Imidazo[1,2-b]pyridazine） 從二氯吡嗪（第29章制備）出發：
  1. NH₃/EtOH → 一个 Cl 被胺置換 → 胺基吡嗪
  2. ROH/鹼 → 另一个 Cl 被醚置換 → 二取代吡嗪
  3. 胺基用溴代醯基溴（2-bromo-acid derivative）→ N-C=O 鍵（氮攻击碳）+ S_N2（氮攻击烷卤）→ 雙環化

Timolol 的合成（β-阻斷劑）

Timolol 含有 1,2,5-噻二唑（thiadiazole）和飽和嗎啡啉（morpholine）。噻二唑環的製備依靠S₂Cl₂ 作為環化試劑與「氰胺」（cyanamide）反應：

H₂N-C≡N（氰胺）+ S₂Cl₂ →（N 攻擊親電 S）→ 氯代中間體 →（氯離子歧化提供 Cl⁻ 攻擊 CN）→ 硫雜唑啉 → 分子內環化 → 1,2,5-噻二唑（帶 –NH 和 –Cl 官能基） → 環氧氯丙烷（epichlorohydrin）開環 → 引入側鏈 OH 和 Cl → 嗎啡啉取代 Cl → Timolol

三大合成策略總結

一、離子型成環（Ionic Cyclization） 以雜原子為親核試劑 + 雙親電碳框架

一個雜原子的五員環
• 吡咯、噻吩、呋喃 ← 1,4-二羰基 + RNH₂ / P₂S₅ / H⁺

一個雜原子的六員環
• 吡啶 ← 1,5-二羰基 + NH₃ + [O]

兩個相鄰雜原子的五員環
• 吡唑、異噁唑 ← 1,3-二羰基 + H₂N-NH₂ / HO-NH₂
• 噻唑 ← 硫代醯胺 + α-鹵代酮（HSAB 選擇性）

兩個相鄰雜原子的六員環
• 噠嗪 ← 1,4-二羰基 + H₂N-NH₂ + [O]

兩個非相鄰雜原子的五員環
• 咪唑、噻唑 ← α-鹵羰基 + 脒或硫代醯胺

兩個非相鄰雜原子的六員環
• 嘧啶 ← 1,3-二羰基 + 脒（amidine）
二、環加成（Cycloaddition） 1,3-偶極環加成 [3+2]：
• 腈氧化物 + 炔 → 異噁唑（芳香）
• 疊氮化物 + 炔 → 1,2,3-三唑（Cu(I) 點擊 → 1,4-選擇性）
• RCN + NaN₃ → 四唑

σ 遷移重排（sigmatropic rearrangement）：
• 苯基肼腙 → [3,3] 重排 → 吲哚（Fischer 合成的關鍵步驟）
三、現有環的改造（Ring Modification） 親電芳香取代（EAS）：
• 吡咯、噻吩、呋喃：優先在 2-位和 5-位（α 位）
• 吲哚：優先在 3-位（但親電試劑可遷移至 2-位）
• 吡啶、喹啉：EAS 不推薦（電子不足）

親核芳香取代（SNAr）：
• 吡啶、喹啉：優先攻擊 2-位和 4-位（負電荷可落在 N 上穩定）
• 嘧啶、吡嗪：所有位置均適合 SNAr
• 喹啉酮 → POCl₃ → 氯化 → 親核取代

金屬化後與親電試劑反應：
• 吡咯（N 需保護）、噻吩、呋喃：BuLi 在 2-位鋰化，再與各種親電試劑反應
• 需阻斷所有含 NH 的酸性質子
學習建議 記憶雜環合成時，先問：需要什麼官能基切斷？雜原子—碳鍵斷裂後，需要幾個碳的 親電子合成子？1,4-二羰基 → 五員環（雜原子提供1個原子）；1,5-二羰基 → 六員環（雜原子提供1個原子）； 1,3-二羰基 → 含2個相鄰雜原子的五員環（兩個雜原子相鄰，來自肼/羥胺）。
