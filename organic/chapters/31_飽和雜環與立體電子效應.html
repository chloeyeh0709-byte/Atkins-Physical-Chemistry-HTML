飽和雜環的親核性

飽和環狀胺通常比相應的無環胺親核性更強。原因是環狀結構的烷基「向後綁定」（tied-back），空間阻礙減小，氮原子孤對電子更易接近親電試劑。

化合物相對速率（krel）備注
三乙胺（Et₃N）1開鏈，空間阻礙大
奎寧環（Quinuclidine）63剛性双環，烷基全向後
DABCO40雙氮橋環，一個N為親核端
Baylis-Hillman 反應 DABCO 作為催化劑催化醛與活化烯烴（Michael 受體）的偶聯： DABCO 的一個 N 首先對 Michael 受體發生共軛加成 → 生成烯醇鹽 → 烯醇鹽攻擊醛（醛醇型） → E1cB 機制消除 DABCO → 得 α-亞甲基醇（Baylis-Hillman 產物）。

氮丙環（Aziridine）

三員含氮雜環稱氮丙環（aziridine），與環氧化物類比，具有以下特性：

  • 鹼性比預期低（pKₐ = 8.0）：因 C–N 鍵帶有更多 sp² 特徵，氮的孤對軌道 s 成分增加 → 電子靠近核 → 不易給出
  • N 構型翻轉慢：三員環限制了 N 的「雨傘翻轉」，使氮可成為立體中心

氮丙環的開環

氮丙環因環張力大，容易開環。環氮上的醯化（acylation）將正電荷引入 N，使其成為「氮鎓離子」型的好離去基，容易被親核試劑開環：

氮丙環 + RCOCl（醯氯）→ 醯化氮丙環 親核試劑（Nu:）攻擊較少取代的碳 → 開環（SN2 型） → 得 β-胺基衍生物

若以溴代反應，可生成溴代胺（氮鎓鹽中間體）：

氮丙環 + Br₂ → [氮鎓鹽 aziridinium] → Br⁻ 開環 → 溴代胺

含氧雜環

環氧化物與四元環

含氧雜環的環張力決定其反應性：環氧化物（三員）張力最大，四氫呋喃（THF，五員）幾乎無張力，氧雜環丁烷（oxetane，四員）介於其間。

BF₃ 可活化環醚對親核攻擊：氧配位 BF₃ 後，環醚變成好離去基。氧雜環丁烷（四員）在 BF₃ 作用下定量開環；THF 在 BF₃ 作用下只開環 20%（五員環張力小）。

BuLi 在 >0°C 下可使 THF 分解（逆[2+3]）：半衰期約40 min（20°C）——因此 BuLi 反應需在低溫（–78°C）進行。

THF 與 THP 作溶劑/保護基

四氫呋喃（THF）和四氫吡喃（THP）不僅作溶劑，其衍生物（縮醛 acetal 形式）也廣泛用作醇的保護基（THP ether, MOM ether 等）。

Karplus 方程式與 NMR

NMR 偶合常數 ³J（vicinal）與二面角 φ 的關係由 Karplus 方程描述：

³J ≈ A·cos²φ − B·cosφ + C φ = 0° 或 180° → ³J 大（~10–14 Hz） φ = 90° → ³J ≈ 0 Hz φ = 60° 或 120° → ³J 中等（~3–5 Hz）
Karplus 的應用 若兩個質子的二面角接近 0° 或 180°（反式/重疊），偶合常數大； 若二面角接近 90°，偶合常數接近零。 固定環的構象使二面角可測，藉此確定順/反構型。
順/反縮醛的 NMR 判斷 1,3-二醇與醛縮合形成六員縮醛（1,3-二氧雜環己烷）。 cis-2,4-二甲基-1,3-二氧雜環己烷：兩 Me 均直立（大偶合）； trans-異構體：一個 Me 直立一個平伏（不同偶合）。 NOE（Nuclear Overhauser Effect，1/r⁶）通過空間確定立體化學。

異頭效應（Anomeric Effect）

異頭效應是 C2 位（THP 中 C2）的電負性取代基（如 OR、Cl）傾向佔據直立鍵（axial）而非等轉鍵（equatorial）的立體電子現象——與簡單取代基的偏好相反。

異頭效應的軌道解釋 直立鍵的 C–X（X = OR、Cl 等）σ* 軌道與環氧的孤對 (lone pair) 反平行排列， 允許 n → σ* 超共軛： O 孤對（軸向） → 直立 C–X 鍵的 σ* 此能量穩定化使直立鍵成為偏好構象。

葡萄糖的異頭效應

葡萄糖在水溶液中平衡：α-葡萄糖（C1-OH 直立）36%，β-葡萄糖（C1-OH 平伏）64%。單純從空間效應預測應全部 β（平伏），但異頭效應使 α 體佔有更大比例。在極性較低的溶劑中（及葡萄糖衍生物中），異頭效應更強，可使 α 體比例大幅增加。

螺縮酮與雙異頭效應

螺縮酮（spiroketal）含兩個共享一個碳（螺原子）的環，常見於昆蟲信息素中。螺原子同時連接兩個 C–O 鍵，每個 O 各自貢獻一個異頭效應 → 雙異頭效應（double anomeric effect），使特定螺縮酮構象極度穩定。

立體電子效應

分子幾何形狀（軌道取向）對反應性和偏好構象的影響稱立體電子效應（stereoelectronic effect）。

酯與內酯的構象

  • 酯（開鏈）：偏好 s-trans（E）構象（C=O 與 O–C 呈反式）
  • 縮醛（開鏈）：高斯效應（gauche effect）使 O–C–O 偏好gauche（O 孤對與 C–O 相互穩定）
  • 內酯（環內酯）：環強制 s-cis 構象，使 C=O 比開鏈酯更具親電性 → 反應性增加

成環速率與 Baldwin 法則

分子內成環反應的速率取決於環大小：五員環 > 六員環 > 三員環 > 七員環 > 四員環 > 八到十員環。此順序由活化焓（ΔH‡）與活化熵（ΔS‡）共同決定。

Thorpe-Ingold 效應

Thorpe-Ingold 效應 環上的gem-二取代（同碳雙取代）可顯著加速成環速率（動力學） 以及增大環化平衡常數（熱力學）。
原因：取代基的排斥使鏈的鍵角變小，使兩端更靠近彼此，降低成環所需的熵損失。
化合物Krel（相對環化常數）
琥珀酸（succinic acid）→ 琥珀酐1
甲基取代琥珀酸類似物14
四甲基取代類似物24000

Thorpe-Ingold 效應既是動力學現象（減少 ΔS‡），也是熱力學現象（增加 ΔS 差值）。gem-二取代使可用構象變少，起始物熵較低，成環 ΔS‡ 較小 → 環化更快。

Baldwin 法則

Baldwin 於 1976 年提出一套系統性分類方法，描述不同類型的分子內環化反應的有利性（favoured）或不利性（disfavoured）。

分類基於三個因素：

  1. 環的大小（形成的環有多少個原子，包括兩端）
  2. endo 或 exo：斷裂的鍵在環內（endo）還是環外（exo）
  3. tet / trig / dig：被攻擊碳的雜化（sp³=tet，sp²=trig，sp=dig）
Baldwin 分類示例 • 3-exo-tet：形成三員環，斷裂鍵在環外，被攻擊碳為 sp³
• 5-exo-trig：形成五員環，斷裂鍵在環外，被攻擊碳為 sp²（如 C=O 或 C=C）
• 6-endo-dig：形成六員環，斷裂鍵在環內，被攻擊碳為 sp（三鍵）

exo-tet 與 exo-trig：均有利

有利的環化類型 • 所有 exo-tet 均有利（立體電子無問題，孤對與 C–X σ* 容易重疊）
• 所有 exo-trig 均有利（孤對容易與 C=X π* 重疊）
• 5~7 endo-dig 均有利（炔的 π* 在環平面內，孤對容易到達）

5-endo-trig 的不利性（最重要！）

5-endo-trig 不利（disfavoured） endo-trig：斷裂的 C=X 鍵在環內 → 被攻擊的碳（sp²）在環的另一端
對於五員環：親核試劑的孤對需彎向面外才能接觸 π*，但這樣它就離親電碳太遠—— 如「被鏈條栓住剛好搆不到的骨頭的狗」。
核心：N 孤對需要指向 π* 軌道，但彎出平面後離得太遠；不彎曲則方向錯誤。
5-endo-trig 實例 胺基丙烯酸酯的共軛加成看起來合理（胺 + C=C-CO₂Et），但實際上不發生； 胺改為攻擊羰基碳（5-exo-trig，有利）→ 生成內醯胺。
這是因為 5-endo-trig 的軌道幾何不利，而 5-exo-trig 完全合理。

6-endo-trig 則有利（89% 產率）：鏈長增加一個碳使幾何問題消失，軌道可以良好重疊。

endo-dig 均有利

炔的 π* 軌道有兩個，其中一個始終在環平面內 → 無論從哪個方向接近，孤對都能與平面內的 π* 重疊。因此所有 endo-dig 環化均有利（4-endo-dig 也能工作！）。

exo-dig：3, 4-exo-dig 不利（碳太遠）；5~7 exo-dig 有利。

Baldwin 法則的例外

Baldwin 法則描述的是動力學有利性，當反應熱力學驅動力很強或無其他路徑時，「不利」的環化也可能發生：

  • 5-endo-trig 在熱力學極有利時可進行（如1,3-二氧雜環戊烷的形成，即從醛或酮與乙二醇縮合）
  • 陽離子反應常不遵守 Baldwin 法則
  • 硫原子（3d 軌道）和大二元環體系例外較多
Baldwin 法則速查表 tet（sp³）：endo 5, 6 不利；exo 均有利
trig（sp²）：3, 4, 5-endo 不利；6, 7-endo 有利；exo 均有利
dig（sp）：endo 均有利；3, 4-exo 不利；5~7 exo 有利
最重要記憶點：5-endo-trig 不利！

環大小與 NMR 偶合

環大小影響 H–H 夾角（和二面角），進而影響偶合常數。碳環中環平面的幾何使相鄰 H 的二面角趨近於特定值：

環大小H–C–C–H 夾角（ring plane）典型 ³J (Hz)
三員環（環丙烷）120°0.5–1.5
四員環90°2.5–4.0
五員環72°5.0–7.0
六員環60°8.5–11.0
七員環51°9.0–12.5

H 越「分散」（鍵在環平面內夾角越大），偶合常數越小（分子的「螺旋槳效應」：夾角增大使等效二面角變小）。

三員環

三員環中所有鍵均重疊（二面角 0°），cis 偶合 > trans 偶合（與烯烴相反！）。電負性原子（如 O）通過抽走電子密度進一步減小偶合常數。

除蟲菊酯（Chrysanthemic Acid） 含環丙烷，cis 酸和 trans 酸均重要。cis: J = 8 Hz（環上 cis）；trans: J = 5 Hz。 環氧化物偶合更小（J ≈ 2–5 Hz，因 O 奪電+「擴散效應」）。

四員環（青黴素）

四員環（β-內酰胺）偶合常數比六員環小。青黴素（penicillin）的 β-內酰胺環：cis 偶合 ~5 Hz。與之相比，硫黴素（thienamycin）為 trans（J ~2.5 Hz）。

五員環

五員環（信封形，envelope）cis 和 trans 偶合約相同（~8–9 Hz）。快速構象平衡使所有 H 的位置時均化。

孿偶合（Geminal, ²J）

孿偶合（²J）發生於同一碳上的非等效（diastereotopic）兩個 H 之間。化學位移相同的 H（homotopic 或 enantiotopic）不顯示偶合信號。

影響 ²J 的因素：

  • 鍵角：二面角最大（0°/180°）時 ²J 最大
  • 環大小：小環的鍵「向外展開」→ ²J 偏小
  • 電負性原子：鄰近電負性原子使 ²J 和 ³J 均減小
  • π 系統：相鄰 π 鍵（C=C、C=O、芳香環）顯著增大 ²J（可達 14–20 Hz）
Frontalin（蟻信素） Frontalin 是螞蟻和大象的信息素。其 NMR 中 CH₂ 的兩個非等效 H 形成 AB 系統， J = 7 Hz（²J，五員環 + 鄰近 O 使 J 偏小）。 可從兩峰之間的距離（以 Hz 計）直接讀出偶合常數。

非等效質子：同位、對映位、非對映位

CH₂ 基團的兩個 H 有三種可能的對稱關係：

關係類型區分方法NMR 表現
同位（Homotopic）：換 H 為 G 得相同分子任何方法均不可區分完全相同化學位移，無偶合
對映位（Enantiotopic）：換 H 為 G 得對映體手性試劑/酶可區分NMR 中相同化學位移（消旋條件）
非對映位（Diastereotopic）：換 H 為 G 得非對映體任何試劑（含非手性）均可區分可能有不同化學位移，可偶合（AB 系統）
判斷方法 將分子中待判斷的兩個 H 依次替換為虛構基團 G，畫出兩個結構， 判斷兩個結構的關係：
• 相同 → 同位（homotopic）
• 對映體 → 對映位（enantiotopic）
• 非對映體 → 非對映位（diastereotopic）
重要結論 在含有手性中心的分子中，所有 CH₂ 基團的兩個 H（無論距離手性中心多遠） 均為非對映位，在原理上（和通常在實踐上）具有不同的化學位移，可能呈現 AB 系統。

非對映位質子的 AB 系統偶合常數（²J）通常很大（~14 Hz），而化學位移差（Δδ）通常很小（<1 ppm），使信號呈「屋頂形」（rooftop pattern）。
