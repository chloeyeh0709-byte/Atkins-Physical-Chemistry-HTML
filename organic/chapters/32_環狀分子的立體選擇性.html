環狀分子的立體選擇性

Stereoselectivity in Cyclic Molecules · pp. 825–851

環狀立體選擇性原理

環狀分子的優勢在於構象固定——一旦分子框架固定，就可以準確預測試劑從哪一面進攻。此章研究各種環系統的立體選擇性規律，並介紹利用臨時成環策略來控制非環分子的立體化學。

核心原則 • 三、四、五員環或帶有兩個以上 sp² 碳的六員環 → 平坦，試劑攻擊較不擁擠的一面
• 帶一個 sp² 碳的六員環（如環己酮）→ 試劑攻擊成為直立鍵（axial）取代的椅式構象的方向
• 雙環化合物 → 試劑攻擊外面（exo 或 outside）

環己酮的親核加成

親核試劑大小的影響

環己酮的親核加成反應立體選擇性取決於試劑的大小：

  • 小的親核試劑（如 LiAlH₄）→ 從直立方向（axial attack）進攻 → 得平伏鍵 OH（equatorial），即 trans 醇（對 4-t-Bu-環己酮，90%）
  • 大的親核試劑（如 L-Selectride，(sec-Bu)₃BH⁻）→ 從平伏方向（equatorial attack）進攻（直立方向空間太擠）→ 得直立鍵 OH，即 cis 醇（95%）
為什麼小試劑從直立方向攻擊？ 直立進攻時，羰基碳的鍵角從平面型（120°）轉變為四面體（109°）， 環己酮中的直立 1,3-H 阻礙比平伏阻礙小（直立方向的環骨架柔性讓開）。 這也稱為Anh-Eisenstein 效應的環系體現。

烯醇鹽與共軛加成的直立進攻

環己烯酮（cyclohexenone）的共軛加成（Michael 加成）中，烯醇鹽總是從直立方向進攻 β-碳，因為這能使新生成的碳直接進入椅式構象（而非扭船式）。

小員環的立體選擇性

四員內酯（β-内酰胺）

四員環近乎平面，親電試劑從兩面之一進攻，選擇遠離現有取代基的一面。若在一面有異丙基（bulky isopropyl），親電試劑幾乎完全（>98:2）從對面進攻。

五員環

五員環是靈活的「信封（envelope）」構象，預測較難。LiAlH₄ 通常給 3:1 的非對映選擇性；更大的 LiBH(s-Bu)₃（Super-H）可達 98.5% cis。

含 sp² 碳的平坦五員環（如丁烯內酯，butenolide）則攻擊從較不擁擠的一面，預測容易。

苦杏仁酸（Mandelic acid）的五員縮醛 苦杏仁酸形成五員縮醛後： • 用 LDA 去質子化 → 平坦烯醇鹽 • MeI 從對面（t-Bu 的反面）攻擊 → 84% 產率，>97:3 非對映選擇性

環戊烯的親電加成

環戊烯的環氧化（m-CPBA）從較不擁擠的一面100% 選擇性發生。溴化（生成溴鎓離子）從外面，而水（親核試劑）必然從另一面（裡面）攻擊 → 反式（trans）加成。

環己烯氧化物的開環

環己烯氧化物（cyclohexene oxide）的親核開環始終以對二面體直立鍵（diaxial）方式進行——SN2 反應使攻擊在 180° 方向，對位置直立的 C–O 鍵，兩個開環原子直接進入椅式構象中的直立鍵位置。

環己烯氧化物 + Nu: → 反式直立開環（trans-diaxial opening） → 兩個取代基均為直立鍵，位置反式（trans） → 鬆弛到平伏鍵 → 最終產物（trans-1,2 取代環己烷）
NaN₃ 開環含哌啶的環氧化物 兩個不同的含哌啶環的環己烯氧化物被 NaN₃ 開環時，疊氮根的區位選擇性由對二面體直立開環規則決定。無論哪個碳被攻擊，兩個產物的取代基均為 trans。

橋環化合物

降冰片烷（Norbornane）

降冰片烷的上橋（exo）位比下橋（endo）位擁擠，但試劑主要從 exo 面進攻（~90%）：因為 endo 進攻需要試劑穿越邊界——2-碳橋在 endo 面形成阻礙。

樟腦（Camphor）

樟腦（camphor）的endo 面進攻較多（~95%），與降冰片烷相反！原因是兩個甲基將 exo 面封死，試劑只能從 endo 面進攻。

橋環化合物的規律 沒有阻礙 → exo 進攻（試劑避開內橋）
exo 面被甲基封閉 → endo 進攻（無選擇，只能走 endo）
橋環化合物不能有橋頭雙鍵（Bredt 規則）。

稠合雙環化合物

反式十氫萘（trans-Decalin）

反式十氫萘（trans-decalin）是剛性的「兩把椅子」結構，不能翻轉。試劑始終從外面（outside）進攻，即與稠合氫相反的方向。

Wieland-Miescher 酮的合成 Wieland-Miescher 酮是甾醇合成的重要中間體（第26章 Robinson 環化的產物）。其含 6-5 稠合酮， NaBH₄ 從外面（bottom face）還原共軛酮 C1 → 生成 equatorial OH（更穩定）→ 後續步驟均從外面進行。

順式十氫萘（cis-Decalin）

順式十氫萘（cis-decalin）能在兩個全椅式構象間快速翻轉（「蝴蝶」翻轉）。翻轉時取代基在兩個構象中的相對位置互換。試劑仍然從外面（outside）進攻，但「外面」因翻轉而可能改變。

順式稠合環反應總結 1. 外面的反應（對面稠合氫）：
• 羰基的親核加成
• 烯醇鹽與親電試劑（烷基化、醛醇、Michael）
• cis-雙鍵的加成：氫化、硼氫化、環氧化
2. 外面然後裡面：
• trans-加成：溴化、環氧化和環氧開環
3. 裡面的反應（跨環的成鍵）：
• 成環反應（鍵在兩個環之間形成）

螺環化合物

螺環化合物的兩個環通過一個螺原子連接，兩個環互相垂直。即使外表對稱，螺環化合物也常是手性的（無對稱面）。

手性螺環二烯的合成 螺環二酮（雙羰基）+ LiAlH₄ → 主要一種非對映體螺環二醇 → 拆分（解析）→ 消除（E2 或 E1cB）→ 1,6-螺[4.4]壬二烯（1,6-spiro[4.4]nonadiene） 此化合物雖然無手性碳，但因缺乏對稱面而具有手性（軸手性類似物）。

繫鏈策略與環過渡態

有時可以利用「臨時成環（temporary ring formation）」——即使最終產物不是環狀——在過渡態中引入環形限制，從而控制立體化學。

碘內酯化反應（Iodolactonization）

非共軛不飽和羧酸 + I₂/NaHCO₃(水) → 碘內酯（iodolactone）。機制：

  1. 碘鎓離子（iodonium）可逆形成於雙鍵上
  2. 羧基酸根（親核試劑）只能攻擊靠近的碳 → 選擇 cis-內酯（碘必須 trans 于 O）
  3. SN2 開環使 I 和 O 呈反式
環狀底物的碘內酯化 環狀不飽和羧酸的碘內酯化：碘鎓離子可逆，只有 I 和 CO₂H 為 trans 的碘鎓才能環化。 因此，儘管碘鎓是可逆的，立體選擇性由「哪個碘鎓能環化」決定 → 單一非對映體。

碘內酯可用作臨時繫鏈：固定構象 → E2 消除（選取唯一可用軸向 H）→ 環氧化（僅從底部）→ HBr 開環（反式直立）→ TMS 保護 → 第二個消除 → Michael 加成（直立）→ Zn 還原去橋 → Claisen 酯化 → 反式稠合 5,6-環——「欺騙」分子形成本不易形成的 trans-fused 結構。

環過渡態逆轉立體選擇性

環過渡態（cyclic transition state）是通過過渡態中的環形幾何（而非環形中間體）控制立體化學的方法。環氧化就是一例：

  • 普通取代基（如 OAc）→ m-CPBA 攻擊對面（anti），因為取代基擋住了 syn 面
  • 羥基（OH）→ m-CPBA 優先從 syn 面攻擊（24:1，或用 CF₃CO₃H 50:1）
    原因：OH 通過氫鍵與過氧酸形成六員環過渡態，將過氧酸「遞送」到 syn 面

VO(acac)₂ 環氧化

當羥基距離烯烴較遠，m-CPBA 效果不好時，可改用釩酸乙酰丙酮（VO(acac)₂）+ t-BuOOH：釩金屬螯合醇 OH 並遞送氧，syn 環氧化選擇性 >95:5。另一方面，保護 OH 為大基團 TBDMS 後，m-CPBA 從另一面（anti）進攻（83:17）。

本章摘要

環狀立體選擇性規律 1. 平坦環（3, 4, 5 員或帶多個 sp² C 的 6 員）→ 從較少阻礙面進攻
2. 帶兩個以上 trig C 的六員環→ 試劑從 axial 進攻（使產物成椅式），不直立方向需扭船
3. 雙環（橋環）→ 從 exo 面（外面）進攻
4. 稠環→ 從外面（outside，與稠合氫反面）進攻
5. 逆轉選擇性的策略：
(a) 繫鏈親核試劑（如 COO⁻ 在碘內酯化中）
(b) 環過渡態（如 OH 導向的環氧化，VO(acac)₂）
