第三十三章

非對映選擇性

Diastereoselectivity · pp. 853–876

立體專一性與立體選擇性回顧

立體專一性（stereospecific）反應：反應機制決定立體結果，如 SN2（翻轉），E2（anti），環氧化物（syn）。立體選擇性（stereoselective）反應：從兩種可能結果中偏好一種，但無法100%保證。

前手性與 Re/Si 面

羰基化合物的前手性（prochiral）——兩個面雖然在非手性分子中等同（對映位），但在手性環境中（手性試劑、手性基團存在）就可區分。

面的命名：將 C=O 按優先順序（CIP 規則）排列，順時針 → Re 面，逆時針 → Si 面。

Felkin-Anh 模型

Felkin-Anh 模型預測帶有 α-手性中心的醛（或酮）遭親核試劑攻擊的非對映選擇性。模型基於羰基的最穩定構象：

Felkin-Anh 模型規則 1. 羰基（C=O）所在的鍵（C1-C2）被「展開」（Newman 投影式）
2. α-手性碳（C2）上最大基團（L）或最具電負性基團（X）垂直於 C=O 鍵
（L/X 置於「側方」，使其 σ* 與 C=O π* 反平行，達到最大 n → σ* 穩定）
3. 親核試劑從最不擁擠的一面（遠離 L/X 的方向）進攻 → Felkin 產物
4. 若 M（中等基團）在大基團一側，且 Nu 可以從 M 側進攻，得anti-Felkin 產物
Felkin-Anh 構象（Newman 式，沿 C1-C2 鍵看）： O（C=O 垂直） | H -- C1 -- Nu（攻擊方向：由小面進入） | C2：L（大）在後，X（電負性）垂直，S（小）在前 → 親核試劑從 S 一側（最小阻礙）攻擊 → Felkin 主產物

Felkin-Anh 的應用

Dolastatin 胺基酸的合成 Dolastatin 含有帶 α-甲基的胺基酸片段。利用 Felkin-Anh 模型（N 最具電負性，垂直排列）， 親核試劑從遠離 N 的一面攻擊，得 >96:4 的非對映選擇性。

螯合控制（Chelation Control）

當 α-OR 基的 O 能與金屬離子（如 Mg²⁺、Li⁺）螯合時，金屬將整個碳框架固定成一個剛性螯合物，親核試劑從另一面（非螯合的 equatorial 方向）進攻 → 得到與 Felkin 模型相反的非對映體（稱 anti-Felkin 或 chelation-controlled 產物）。

保護基 R主導控制de（非對映超量）
Me（甲基，小）螯合控制>99:1
TMS（三甲基矽，中）過渡~80:20
Si(i-Pr)₃（大）Felkin 控制~42:58（幾乎無選擇性）
結論 • 小的 OR（可螯合）→ 螯合控制 → anti-Felkin 產物
• 大的 OR（不可螯合）→ Felkin-Anh 控制 → Felkin 產物
• Luche 還原（Ce³⁺/NaBH₄）：Ce³⁺ 螯合，即使大基團也可螯合控制

Houk 模型（手性烯烴）

對帶有 α-手性中心的烯烴（而非羰基），Houk 模型預測親核試劑從哪一面加成：

  • H 與雙鍵共平面（最低能量構象），cis-取代基固定分子只存在一個低能量構象
  • 親電試劑從遠離 cis-取代基的一面加成

立體選擇性環氧化

烯烴的環氧化（m-CPBA）攻擊較不擁擠的一面，而烯丙基醇的環氧化由 OH 氫鍵導向（第32章，syn 95:5）。

烯丙基應變（Allylic Strain）控制 α,β-不飽和化合物的烯丙基位（allylic position）周圍的立體化學通過控制 A(1,3)-烯丙基應變（allylic strain）引導親電試劑方向，可得 77:23 到 95:5 的選擇性。

烯醇鹽烷基化的立體選擇性

烯醇鹽本身是平坦的（sp²），但若烯醇鹽的 α-碳帶有手性中心，烷基化剂從較不擁擠的一面進攻。利用烯丙基應變可固定烯醇鹽的構象，使選擇性顯著提高（77:23 → 95:5）。

立體選擇性醛醇反應

醛醇反應生成兩個新手性中心，可能得到 syn（赤式）或 anti（苏式）醛醇加成物：

  • syn 醛醇：兩個新基團（OH 和 R）在同一側
  • anti 醛醇：兩個新基團在對側

Zimmermann-Traxler 過渡態

金屬烯醇鹽（Li、B 等）的醛醇反應通過六員環椅式過渡態（Zimmermann-Traxler 模型）進行：

六員環過渡態（Zimmermann-Traxler）： O R O---M---O | | （M = Li、B）| | M---O C=C C(enolate)-C(aldehyde) | | | H R' R'' Z-烯醇鹽（cis）→ syn 醛醇：R 在 equatorial → 兩個 R 同側（syn） E-烯醇鹽（trans）→ anti 醛醇：R 在 axial → 兩個 R 異側（anti）
烯醇鹽幾何與醛醇產物的對應 • Z（cis）烯醇鹽 → syn（赤式）醛醇產物
• E（trans）烯醇鹽 → anti（蘇式）醛醇產物
此規律非常重要，可利用已知幾何的烯醇鹽預測醛醇立體化學。

硼烯醇鹽的選擇性

試劑（生成烯醇鹽類型）主要產物選擇性
LDA（Li 烯醇鹽，大R → Z型）syn 醛醇~98% syn
9-BBN/Bu₂BOTf（B 烯醇鹽，Z型）syn 醛醇>99:1
(c-Hex)₂BCl（B 烯醇鹽，E型）anti 醛醇>97:3

硼原子與氧的 B–O 鍵較強（比 Li–O 緊湊），使六員環過渡態更緊密 → 選擇性更高。

從非對映選擇反應得到單一對映體

若起始物為對映純（enantiopure）化合物，則所有後續非對映選擇性反應引入的新手性中心，其絕對構型也由起始手性中心決定。因此，結合非對映選擇反應和對映純起始物，可得到對映純的複雜產物。

手性池（Chiral Pool）

手性池是自然界提供的對映純化合物的來源：氨基酸（丙胺酸、絲胺酸等）、糖類（葡萄糖、乳酸）、萜類（樟腦、薄荷醇）等。從手性池選取合適的起始物，可以借助自然的手性信息。

甲基麥賽奈苷（Methyl Mycaminoside）的合成

甲基麥賽奈苷含有五個手性中心，只有一個來自手性池（(S)-乳酸）。其餘四個通過非對映選擇性反應逐步引入：

  1. (S)-乳酸 → 乙酰化 → 酸氯 → Grignard + 甲氧炔基溴化鎂 → 炔基醇
  2. Lindlar 氫化（炔 → Z-烯）→ 異構純 Z-烯醇乙酸酯
  3. 環化（酸催化，異頭效應 → OMe 伸向軸向）→ 六員 THP（第二個手性中心）
  4. LiAlH₃ 還原 → 直立進攻 → equatorial OH（第三個手性中心）
  5. OH 導向環氧化（m-CPBA，syn）→ 環氧化物（第四、五個手性中心）
  6. Me₂NH 以 SN2 開環（翻轉）→ 甲基麥賽奈苷

派那裡西定 A（Penarisidin A）的合成

派那裡西定 A 是從日本海綿中分離的天然產物，含有四員氮丁環（azetidine ring）和一條長鏈，共有多個手性中心。確定其立體化學需要合成所有可能的非對映異構體再比對 NMR。

左端（azetidine 端，3個手性中心）的合成——以 L-絲胺酸（serine）為起始物：

  1. L-絲胺酸 → Boc 保護 NH₂ → 縮醛保護 OH + NH₂ → 游離酯 LiBH₄ 還原 → 醛（Swern 氧化）
  2. 醛 + 炔基陰離子（Felkin-Anh，N 垂直）→ 從無阻礙面攻擊 → 炔基醇（第三個手性中心）
  3. 溶解金屬還原（Li/EtNH₂）→ E-烯 + 開環保護基
  4. m-CPBA 環氧化，但 OH 導向 syn 面（錯誤立體化學！）
  5. 修正：TBDMS 保護 OH → m-CPBA 從 anti 面環氧化 → DIBAL-H 還原環氧化物 → 正確非對映體
  6. OH → 甲磺酸酯（OMs）→ NaH 使 N 以 SN2（翻轉）攻擊 → 形成 azetidine 環

右端（長鏈，2個手性中心）的確定——以 L-異亮胺酸（L-isoleucine）為起始物：

  1. L-異亮胺酸 → 重氮化（NaNO₂/HCl）→ α-乳酸（雙翻轉 → 保留）→ 酯化 → LiAlH₄ → 二醇
  2. TsCl → 環氧化物（保留兩個手性中心）
  3. 炔基陰離子開環 → 右端鏈合
  4. 連接左端與右端 → 比較 NMR 譜 → 確認天然派那裡西定 A 的立體化學
α-乳酸形成的雙翻轉 重氮化通常使 C–N → C–OH 翻轉，但這裡有鄰基參與（neighboring group participation）： 羧基攻擊 α-碳（翻轉一次）形成 α-內酯，再被水（第二次翻轉）打開 → 淨保留構型！

本章摘要

非對映選擇性的關鍵模型
1. Felkin-Anh 模型（開鏈醛酮親核加成）
最大基團（L）或電負性基團（X）垂直於 C=O；Nu 從最小阻礙面進入 → Felkin 產物

2. 螯合控制（Chelation Control）
α-位有可螯合 OR（如 OMe）+ 金屬（Mg²⁺、Li⁺、Ce³⁺）→ 螯合固定構象 → anti-Felkin 產物

3. Houk 模型（手性烯烴）
H 與雙鍵共平面；親電試劑從遠離 cis-取代基的一面進攻

4. Zimmermann-Traxler TS（醛醇反應）
Z-烯醇鹽 → syn 醛醇（椅式 TS 中 R 在 eq）
E-烯醇鹽 → anti 醛醇（椅式 TS 中 R 在 ax）

5. 手性池策略
從自然對映純化合物出發（氨基酸、糖）→ 只需一個手性中心，其餘由非對映選擇反應建立 → 全程對映純
