第三十四章

周環反應（一）— 環加成

Pericyclic Reactions 1: Cycloadditions · pp. 877–908

周環反應概論

周環反應（pericyclic reactions）是電子在環形路徑中同時移動的協奏反應，無中間體，無離子，通過鍵合的過渡態進行。本章介紹環加成（cycloaddition），即兩個 π 系統生成兩個新 σ 鍵的反應。

周環反應的特徵 • 協奏（concerted）：沒有中間體，一步完成
• 立體専一（stereospecific）：立體化學忠實保留在產物中
• 無離子：不受酸鹼、極性溶劑影響（但 Lewis 酸可調控）
• 由軌道對稱性決定熱允許/禁止（Woodward-Hoffmann 規則）

[4+2] Diels-Alder 反應

Diels-Alder 反應是最重要的環加成，由二烯（diene，4π）+ 親二烯體（dienophile，2π）生成六員環。

  • 二烯必須在 s-cis 構象（兩個雙鍵為順式）
  • 親二烯體通常需要吸電子基（EWG）活化（降低 LUMO 能量）
  • 反應立體専一：同面（suprafacial），二烯體的 Z/E 構型完整保留至產物

機制與前沿軌道理論（FMO）

Diels-Alder 反應的反應性由前沿軌道（FMO）解釋：

HOMO（二烯，ψ₂）+ LUMO（親二烯體，π*） 二烯 ψ₂ 軌道： + - + - ← 兩端相位 親二烯體 π*： + - ← 兩端相位 在六員環 TS 中，相鄰位點相位匹配 → 鍵合成功（熱允許）

相位匹配使反應在熱（基態）條件下順利進行。而兩個烯烴的 [2+2] 環加成（HOMO+LUMO）相位不匹配（一端成鍵，另一端反鍵）→ 熱禁止。

endo 規則與立體専一性

Diels-Alder 反應的立體化學由兩個規則控制：

  1. 立體専一：親二烯體上的基團（Z/E）在產物中保持原有構型（suprafacial 成環，新的兩個 σ 鍵均在同一面）
  2. endo 規則：動力學產物為 endo（親二烯體的取代基指向二烯，有次級軌道穩定）；熱力學產物為 exo（空間阻礙小）
苯炔（Benzyne）的捕獲 苯炔是反應性極強的中間體，可以作為一種親二烯體被 Diels-Alder 捕獲， 生成稠合芳香環產物。此反應也用於確認苯炔的存在。

區位選擇性（「鄰/對規則」）

不對稱親二烯體 + 不對稱二烯的 Diels-Alder 有區位選擇性，傾向生成「ortho」（1,2-）和「para」（1,4-）類似的產物，而非「meta」（1,3-）：

1-取代二烯 + 1-取代親二烯體 → 主要得到「鄰」產物（1,2-取代的六員環） 規律：最大 HOMO 係數的原子與最大 LUMO 係數的原子優先成鍵

水中加速與 Lewis 酸催化

  • 水溶劑加速 Diels-Alder ~700 倍：疏水效應（hydrophobic effect）使二烯和親二烯體聚集，有效濃度增加
  • Lewis 酸（如 BF₃、AlCl₃）：配位親二烯體的 C=O（或 EWG），降低 LUMO 能量，縮小 HOMO/LUMO 能量差 → 加速反應，同時提高區位選擇性

Woodward-Hoffmann 法則

對稱性守恆與允許/禁止

Woodward-Hoffmann（W-H）法則基於分子軌道對稱性守恆：反應坐標上所有軌道的對稱性必須守恆。

W-H 法則的總判斷 熱允許條件：(4q+2)s + (4r)a 的總電子數為奇數
（s = suprafacial，a = antarafacial；q, r 為非負整數）

• [4+2]（6π）：一個 (4×1+2) = 6 電子的同面組分 → 奇數 → 熱允許
• [2+2]（4π）：4 電子全同面 → 偶數 → 熱禁止，但光化學允許
反應類型電子數熱光
[4+2] Diels-Alder6π允許禁止
[2+2] 環加成4π禁止允許
[4+3] 環加成6π（oxyallyl）允許禁止
[4+6] 環加成10π允許禁止

其他環加成：[4+3]、[4+6]

[4+3] 環加成：烯丙基陽離子（oxyallyl cation，2e × 3C = 2π）+ 二烯（4π）→ 七員環。苯炔也可作為[4+3]的對象。

[4+6] 環加成：二烯（4π）+ 三烯（6π）→ 十員環。例子較少見。

Alder ene 反應

Alder ene 反應是周環過程，涉及C–H 鍵的烯丙基重排 + π 鍵遷移，六員環 TS，不形成新環：

H | ene: C=C-C-H + enophile（C=X） ↓（六員環 TS，3個組分） 新 C-C 鍵形成 + H 轉移 + ene 雙鍵移位

Alder ene 反應涉及 3 個鍵的打斷/生成（對比 Diels-Alder 的 2 個），「3」為奇數 → 熱允許（遵守 W-H 規則）。

薄荷醇（Menthol）的工業合成 R-香葉醛（R-citronellal）在 ZnBr₂ 催化下，對羰基 ene 反應： 醛的 C=O 為 enophile，分子內 ene → 形成新的六員環 → 生成 isopulegol（薄荷醇前驅體） → 催化氫化 → (-)-薄荷醇（工業合成的主流路線）。

光化學 [2+2] 環加成

熱化學禁止的 [2+2] 在光化學條件下允許：光激發使一個烯烴進入激發態（π → π*），激發態改變了前沿軌道，使 [2+2] 成為可能。

機制與軌道解釋

UV 光（hν）將一個烯烴激發：一個電子從 π 躍遷至 π*。激發烯烴的 HOMO 變為 π*，與基態烯烴的 π（=HOMO）相互作用：

  • 激發烯烴 π* 軌道 + 基態烯烴 π 軌道 → 在六員環過渡態中，相位相同的一端均成鍵
  • 結果：[2+2] 熱化學禁止的相位問題在光化學條件下消失

光化學 [2+2] 產物沒有 endo 規則（無次級軌道相互作用），最不擁擠的 TS 控制。

光化學區位選擇性

光化學 [2+2] 的區位選擇性與熱化學相反：若用 HOMO（基態）/LUMO（基態）邏輯，預期熱化學結果；光化學中，激發態 enone 的 LUMO 和基態烯烴的 LUMO 相互作用，兩個 LUMO 的較大係數端優先成鍵 → 與熱化學反應的區位選擇性互反。

熱化學 [2+2]：烯酮與異氰酸酯

儘管如此，某些特殊的「雙 π 鍵直角」分子可在熱條件下發生 [2+2]：烯酮（ketene）和異氰酸酯（isocyanate）的兩個 π 鍵成直角，允許熱化學 [2+2]。

烯酮 [2+2] 與 β-內酰胺合成

烯酮 [2+2]：烯酮（R₂C=C=O）的 C=C（一個 π）與親核烯烴的 π 進行 [2+2]，生成環丁酮（四員環）：

R₂C=C=O（烯酮）+ R'CH=CH₂（烯烴） → [2+2]（熱，因烯酮的兩個 π 垂直） → 環丁酮（cyclobutanone） 典型製備： (CH₃)₂C=C=O（二甲基烯酮，熱解丙酮或 2-氯醯氯/Et₃N 消除） + 烯烴 → 環丁酮

β-內酰胺（β-lactam）的 [2+2] 合成有兩種方式：

  • 烯酮 + 亞胺（imine）：N（親核）攻擊 C=O → β-內酰胺（100% 產率，N-Ar 亞胺較穩定）
  • 異氰酸酯 + 烯烴：N（親核）攻擊 alkene → β-內酰胺（選用氯磺酰異氰酸酯，商業可得，EWG 可在反應後水解去除）
二氯烯酮法合成 β-內酰胺 二氯乙酰氯 + Et₃N → 二氯烯酮（dichloroketene，原位生成）
+ 苯基亞胺（Ph-CH=N-Ph）→ [2+2]（100% 產率）
→ β-內酰胺（若兩個組分各含一個取代基，最終在四員環中為 trans 構型，空間阻礙最小）

1,3-偶極環加成 [3+2]

1,3-偶極（1,3-dipole）是一個三原子的共振穩定的兩性離子（如硝酮、腈氧化物、疊氮化物），相當於 Diels-Alder 的「二烯」，與「親二烯偶極體（dipolarophile，通常為烯烴或炔）」發生 [3+2] 環加成生成五員雜環。

硝酮（Nitrone）

硝酮（R₂C=N⁺(R')O⁻）的四個電子（兩個 π + 一個 O 孤對）提供「二烯」的 4e 組分；烯烴（2e）為親偶極體：

⊕ ⊖ R₁-CH=N-O \ / C=C ← dipolarophile（烯烴） ↓ 二氫異噁唑（isoxazolidine，五員環） ↓ [Zn/AcOH 選擇性還原 N-O 鍵] 1,3-胺基醇（amino-alcohol）

環狀硝酮（cyclic nitrone）的分子內 [3+2] 環加成給出精美的籠型（cage）產物，立體化學由最少阻礙的接近方式決定。N–O 鍵可選擇性被 Zn/AcOH 或 H₂/Ni 還原，保留 C–C 和 C–O 鍵，得到胺基醇（或 H₂/Ni 還原 C=N 再水解 N–O → 羥基酮）。

腈氧化物（Nitrile Oxide）

腈氧化物（R–C≡N⁺–O⁻）是線型 1,3-偶極，比硝酮多一個 π 鍵。製備方法：

  1. 醛 + NH₂OH → 肟（oxime）→ Cl₂ 氯化 → 氯肟（chloro-oxime）→ Et₃N → γ 消除 → 腈氧化物
  2. 硝基烷 + PhN=C=O（脫水）→ 腈氧化物（機制通過卡宾型中間體）
腈氧化物 + 烯烴 → [3+2] → 二氫異噁唑（立體専一，Z-烯 → cis） 腈氧化物 + 炔 → [3+2] → 異噁唑（isoxazole，芳香六 π） 產物用途： → LiAlH₄ → 胺基醇（1,3-關係） → H₂/Ni → 羥基酮（只還原 C=N，N-O 水解）

生物素（Biotin，維生素 B₇）的合成

生物素的合成精妙地利用了分子內腈氧化物 [3+2] 環加成確立關鍵立體中心：

  1. 環烯基溴化物 + 硫醇鹽 → S 烷基化（SN2 或 SN2'，均得同一產物）→ 硫醚
  2. 酯裂解 → 硫醇鹽再生 → 共軛加成（Michael）到硝基烯 → 硝基硫醚
  3. 硝基烷 + PhNCO → 腈氧化物（原位）→ 分子內 [3+2]（唯一可能的折疊方式）→ 籠型雙環
  4. LiAlH₄ 還原（先 C=N 再 N–O）→ 胺基醇 → 再 LiAlH₄ 裂解 N–O → 全面還原
  5. Beckmann 重排開七員環 → 再 7 步 → 生物素（biotin）

OsO₄ 二羥基化（Dihydroxylation）

四氧化鋨（OsO₄）對烯烴的syn（同面）二羥基化是 [3+2] 環加成（OsO₄ 視為 1,3-偶極 / O=Os=O 作 4e 組分）：

O O ‖ ‖ Os-O O + C=C ↓（[3+2]，syn） 5-員 osmate ester（osmate 酯） ↓ H₂O 水解 syn-二醇（兩個 OH 在同一面）

OsO₄ 本身昂貴且有毒，催化量 OsO₄ + NMO（N-甲基嗎啡啉 N-氧化物）或 Fe(III) 可使 Os(VI) 再氧化回 Os(VIII) → 循環催化。與 m-CPBA 環氧化不同，OsO₄ 對電子富足與貧乏的烯烴均有效（選用最佳 HOMO/LUMO 組合）。

臭氧分解（Ozonolysis）

臭氧（O₃）是另一個重要的 1,3-偶極：

臭氧（結構）：⊕O-O-O⊖（彎曲形，共振穩定的 1,3-偶極） 步驟： 1. 臭氧 + 烯烴 → [3+2] → 初級臭氧化物（molozonide，不穩定） 2. 逆 [3+2] 分解（molozonide 極不穩定，O–O 鍵能量低 140 kJ/mol） → 醛 + 羰基氧化物（carbonyl oxide） 3. 羰基氧化物再次 [3+2] 環加成（反向，另一端）→ 臭氧化物（ozonide，穩定） 臭氧化物分解： → Me₂S（DMS）→ 醛（保留 C=O 不進一步氧化） → H₂O₂ → 羧酸（進一步氧化） → NaBH₄ → 醇（還原）
臭氧分解的用途 臭氧分解是切割雙鍵最常用的方法：一個碳碳雙鍵 → 兩個羰基官能基。 選擇不同的後處理可以得到醛、酸或醇：
烯烴 → (1) O₃ (2) Me₂S → RCHO + R'CHO（醛）
烯烴 → (1) O₃ (2) H₂O₂ → RCO₂H + R'CO₂H（酸）
烯烴 → (1) O₃ (2) NaBH₄ → RCH₂OH + R'CH₂OH（醇）

本章摘要

環加成反應總結
[4+2] Diels-Alder：最重要的環加成；s-cis 二烯 + EWG 親二烯體；熱允許；endo 為動力學產物；水中加速；Lewis 酸催化；立體専一（suprafacial）

[2+2] 光化學：UV 激發一個烯烴 → 允許；熱條件禁止；無 endo 規則；烯酮和異氰酸酯例外可熱化學 [2+2]（兩個 π 垂直）

[3+2] 1,3-偶極環加成：硝酮、腈氧化物、疊氮化物等 + 烯/炔 → 五員雜環；立体専一（suprafacial）；用於合成複雜立體中心

OsO₄：[3+2] 機制，syn 二羥基化，催化 + NMO 再生；
臭氧分解：連續三步（[3+2] → 逆 [3+2] → [3+2]）→ 臭氧化物 → 醛/酸/醇

Woodward-Hoffmann 規則：(4q+2)s + (4r)a 為奇數 = 熱允許；光化學與熱化學結論相反
