第36章 鄰基參與、重排與斷裂

Clayden Organic Chemistry · Ch 36 (pp. 931–969)

鄰基參與（Neighbouring Group Participation）

當分子中的一個親核性基團，在離去基團離去時就近參與，形成橋式中間體，再被外部親核試劑攻擊，稱為鄰基參與（NGP）。整體立體化學為保留（retention）——因為發生了兩次SN2反轉，淨效果是構型保留。

硫化物的鄰基參與

β-硫化物的NGP MeS-CH₂-CH₂-OTs + Nu⁻ → MeS⁺ MeS Nu \ [SN2 ×2] | | CH₂-CH₂ CH₂-CH₂ 橋式硫離子 → 淨效果：保留構型

羧酸根的鄰基參與

反式-2-溴環己基乙酸鹽在水解時，鄰位羧酸根參與形成環氧內酯（lactonium橋），再被水攻擊，得到反式（保留）二醇。

NGP的核心標誌：
1. 速率加快（內部親核試劑比外部有效）
2. 立體化學：兩步SN2 = 保留（retention）
3. 中間體可能可分離或以特殊產物比例出現

氮丙啶（Aziridinium Ion）的NGP

β-氨基醇的NGP經由氮丙啶鎓離子進行；Payne重排則是環氧醇通過1,2-環氧重組達到熱力學更穩定的異構體。

π電子的鄰基參與

苯環可作為親核試劑參與鄰基作用，形成苯鎓離子（phenonium ion）中間體，導致：

  • 速率大幅加快（苯基相比飽和C-C有更強的NGP）
  • 骨架重排（Wagner-Meerwein型）
  • 構型保留
苯鎓離子形成 Ph-CH-CH₂-OTs → [Ph橋接鎓離子] → 外部Nu攻擊 | 重排產物與保留構型

頻哪醇重排（Pinacol Rearrangement）

鄰二醇（pinacol）在酸催化下，一個OH離去生成碳正離子，鄰位的烷基或芳基遷移，生成酮（羰基化合物）：

頻哪醇重排 HO OH OH O | | H⁺ | 遷移 ‖ R₂C-CR₂ → R₂C⁺-CR₂ → R₃C-CR (碳正離子) (酮)
遷移選擇性：能夠最大穩定化碳正離子的基團優先遷移（Ph > 3° > 2° > 1° > H）。遷移基團保留其原有構型（electrophilic attack with retention）。

1,2-氫或烷基遷移的立體化學

在所有1,2-遷移中，遷移基團保持其立體化學。σ軌道的最大葉與目標σ*軌道在同一面重疊（與SN2的後面攻擊/反轉相比，1,2-遷移是前面攻擊/保留）。

半頻哪醇重排（Semipinacol）

只有一個OH（或相當的離去基）的1,2-二醇類似物也能重排，稱為半頻哪醇重排。最重要的例子是Tiffeneau-Demjanov重排：

Tiffeneau-Demjanov重排 環酮 →(1. KCN, 2. HNO₂)→ α-氨基-α-羥腈 NH₂-C-OH →(NaNO₂/HCl)→ → 重氮鎓離子 [diazonium] → 遷移+N₂離去 → 環擴張酮（增加一個碳）
環己酮 → Tiffeneau-Demjanov → 環庚酮（六→七員環擴張）
此方法是製備中環酮的實用方法，每次增加一個碳，精準環擴。

二烯酮-苯酚重排（Dienone-phenol Rearrangement）

環己二烯酮在酸催化下，烷基或芳基遷移至羰基鄰位，再芳香化得苯酚：

二烯酮-苯酚重排 4,4-二取代環己二烯酮 →(H⁺)→ [碳正離子] →(遷移)→ 重排中間體 →(去質子)→ 苯酚衍生物

遷移基團選擇性複雜：電子推基（Ph）通常優先遷移，但帶有強吸電基（CO₂Et）的基團因不願留在碳正離子鄰位，也可能優先遷移。

苯亞甲酸重排（Benzilic Acid Rearrangement）

二苯基乙二酮（benzil）在強鹼（KOH）中，氫氧根加到一個羰基，另一個苯基帶著電子對遷移到第二個碳，最終得苯亞甲酸（benzilic acid）：

苯亞甲酸重排 Ph-C(=O)-C(=O)-Ph →(KOH)→ [OH⁻加到C=O] → Ph遷移帶電子對 → Ph₂C(OH)-CO₂⁻ (苯亞甲酸鹽)
此重排是1,2-遷移到羰基碳（類比頻哪醇中遷移到碳正離子），在鹼條件下通過四面體中間體進行。

Favorskii重排

α-鹵代酮（α-halo ketone）在親核試劑（如甲醇/MeO⁻）作用下，重排生成酯。機制涉及環丙酮中間體（cyclopropanone）：

Favorskii重排機制 Ph-CH₂-C(=O)-CH₂-Cl →(MeO⁻)→ 1. MeO⁻拔去α-H → 烯醇化 2. 烯醇自身烷基化 → 環丙酮中間體 3. MeO⁻攻擊環丙酮 → 開環 → 酯 淨效果：R¹-C(=O)-CHX-R² → R¹CH₂-CO₂R（酯）

兩種異構體給同一產物

兩種不同的α-氯取代異構體（Cl在不同位置）在MeO⁻作用下得到同一種酯，因為它們共用相同的對稱環丙酮中間體。

環狀Favorskii：環收縮

環酮溴化（α位）後加入甲醇鈉，發生Favorskii重排，環收縮一個碳：

環狀Favorskii重排 環己酮 →(Br₂, HOAc)→ 2-溴環己酮 →(NaOMe)→ 環戊甲酸甲酯（61% 收率） 六員環 → 五員環（環收縮）
Cubane的合成：
Favorskii重排是合成立方烷（cubane）的關鍵步驟——用它將五員環收縮為四員環，再脫羧得到立方烷（1964年，Eaton&Cole）。

沒有α-H的Favorskii

無α-H時，環丙酮路徑被迫轉為類苯亞甲酸型機制（OH直接加到羰基，再遷移）。哌替啶（pethidine）的合成用此機制。

Baeyer-Villiger反應

酮與過酸（peracid，RCO₃H）反應，氧插入（C-C→C-O-C），生成酯或內酯。m-CPBA（間氯過苯甲酸）是最常用試劑。

Baeyer-Villiger反應機制 O O OH O O O ‖ | | | 遷移 ‖ -H⁺ ‖ R-C-R² + RCO₃H → R-C-O-O-COR → R-O-C-R² (過酸加合物) (Criegee中間體) → 酯 C-O-O鍵弱，C遷移與-O-COR⁻同步（concerted）

哪個基團遷移？（I）事實

遷移能力順序（以CF₃CO₃H/苯甲酮類比較）：

R基Ph遷移（%）R遷移（%）
Me900
Et876
i-Pr3363
t-Bu277

遷移能力（大→小）：t-Bu > sec-alkyl ≈ Ph > Et > Me

哪個基團遷移？（II）理由

過渡態帶正電（carboxylate離去），能穩定正電荷的基團優先遷移。苯環通過π參與穩定正電荷（如五環戊二烯基陽離子），形成橋式中間體，比單純的烷基更穩定。

立體化學：保留

遷移基團的立體化學在Baeyer-Villiger中100%保留。sp³遷移碳從一個σ鍵滑到另一個σ鍵，最小限度重組，大葉軌道使新舊鍵在同面。

合成應用

  • L-多巴合成：L-酪氨酸→Friedel-Crafts醯化→Baeyer-Villiger→水解→L-多巴（帕金森病藥物）
  • 前列腺素中間體：環丁酮的B-V反應（小環優先反應）提供關鍵內酯
  • MeCO+等效物：Ph-CO-Me中苯環遷移，MeCO⁺相當於「OH+」
  • Dakin反應：ArCHO + H₂O₂，Ar遷移→ArO-（苯酚），電子豐富芳環特有

遷移選擇性的機理解釋

在Baeyer-Villiger和相關1,2-遷移中，遷移基團必須與離去基anti-periplanar以獲得最佳軌道重疊（σ與σ*的軌道交疊）。

1,2-遷移中遷移基團保留其立體化學：
因為遷移碳原子的σ充填軌道（而非空σ*軌道）作為親核體。遷移碳以electrophilic方式接受，保留構型；而SN2中碳以nucleophilic方式攻擊，倒轉構型。

anti-periplanar要求

構象限制的分子（如剛性環系）中，anti-periplanar要求至關重要：

  • 氨基醇Tiffeneau-Demjanov重排：OH提供電子推，N₂⁺離去，只有anti-periplanar的基團（環碳鏈或H）遷移
  • 四個非對映體給出四種不同產物（環縮醛、醛、酮或環氧），完全由anti-periplanar關係決定

Beckmann重排（Beckmann Rearrangement）

肟（oxime，由酮+NH₂OH製得）在酸（H₂SO₄、PCl₅、SOCl₂、Al₂O₃等）催化下，OH轉為離去基，trans位的烷基遷移到氮，得到醯胺（amide）。

Beckmann重排機制 N-OH N-OH₂⁺ N≡C⁺R² +H₂O O | H⁺ | -H₂O ↑ → ‖ R¹-C-R² → R¹-C-R² → R¹遷移 → HN-C-R¹ (linear nitrilium) (醯胺)

哪個基團遷移？

C=N雙鍵有幾何異構（cis/trans），trans位於OH的基團遷移。幾何異構體比例直接反映在產物醯胺比例中。

工業應用：Nylon-6的合成
環己酮肟 →（H₂SO₄, Beckmann）→ ε-己內醯胺（caprolactam）→（鹼聚合）→ Nylon-6
這是全球最大規模的Beckmann重排應用。

Beckmann斷裂（Beckmann Fragmentation）

當遷移基團為tertiary烷基時，穩定性過高，直接斷裂形成穩定碳正離子和腈（nitrile），而非生成醯胺。這稱為Beckmann斷裂：

Beckmann斷裂 R³C-N-OH →(H⁺)→ R³C⁺ + N≡C-R（腈） （叔烷基trans） （穩定正離子） 碳正離子+腈重組 → 4種醯胺（非Beckmann產物）

樟腦（camphor）的肟在醯氯處理下發生Beckmann斷裂，環張力釋放，腈無法形成8員環而導致開鏈腈副產物。

C-C鍵極化使斷裂成為可能

C-C鍵很強（339 kJ/mol）但難以通過親核/親電方式斷裂，原因在於它無法被極化。然而，若C-C鍵一端有電子推（源）、另一端有電子拉（槽），C-C鍵可被極化而斷裂：

1,2,3,4斷裂框架 電子源—C(1)—C(2)—C(3)—C(4)—電子槽 C2-C3鍵斷裂 → 兩個片段 源（如孤對電子，lone pair）推動電子 槽（如離去基離去）拉動電子

常見電子源：孤對電子（OH、NR₂）、碳陰離子
常見電子槽：離去基離去（OTs→H₂O）、質子化羰基（C=OH⁺）

環丁酮的環擴斷裂：
甲氧基環戊酮在酸中，質子化C=O作為槽，醚氧孤對電子作為源，斷裂C-C形成7員環（五→七員環擴張）。

Retro-aldol：
醛醇縮合的逆反應——羰基作槽，OH作源，在酸或鹼中斷裂C-C。

Eschenmoser斷裂

Albert Eschenmoser（1960年代）設計的環擴法：α,β-環氧酮（epoxyketone）與甲苯磺醯肼反應，形成甲苯磺醯腙，不穩定→消除開環→1,2,3,4斷裂→產生酮-炔（keto-alkyne）：

Eschenmoser斷裂 α,β-環氧酮 →(TsNHNH₂)→ 甲苯磺醯腙 →(消除開環)→ 3,4-烯醇-甲苯磺醯腙 →(斷裂+N₂+ArSO₂H)→ 酮-炔（環擴產物） 應用：12員環 → 15員環（muscone, exaltone的合成）
Eschenmoser斷裂的精妙在於三個鍵同步斷裂（C-O, C-C, N-N），且斷裂鍵必須互相anti-periplanar。此條件自動滿足，因為消除步驟已設置了正確幾何。

環擴張斷裂

六、六稠環（decalin）可視為一個10員環被中間的C-C鍵「閉合」。斷裂該鍵（附有合適的推-拉取代基）可釋放10員環。

去卡林環擴斷裂 OH OTs OTs | | 鹼 | O [6-6]環 → [6-6]-OTs → [10員酮]（73%） OTs必須anti-periplanar於斷裂C-C鍵

斷裂的立體化學控制

  • 斷裂鍵（C-C）必須anti-periplanar於離去基（OTs），類似E2消除
  • 斷裂立體特異性：反應與E2一樣選擇anti排列
  • 雙鍵幾何（E/Z）由斷裂過渡態中黑色鍵的相對位置決定
Caryophyllene的合成（Corey）：
利用環擴斷裂從雙環前驅物出發，得到含E型三取代雙鍵的9員環天然物caryophyllene。起始物的相對立體化學直接決定雙鍵幾何。

控制雙鍵斷裂（juvenile hormone合成）

青幼素（juvenile hormone）需要精確控制三個三取代雙鍵，利用環狀前驅物的斷裂可從容易控制的環立體化學轉化為難以控制的開鏈雙鍵幾何。

合成展示：Nootkatone的三條路線

Nootkatone是葡萄柚香氣化合物（最初誤認），三條合成路線均以斷裂反應為核心：

三員環的斷裂

從天然(–)-carone出發，共軛加成引入側鏈，形成雙環二酮，HCl催化下三員環斷裂（由烯酮拉、叔碳正離子穩定性推）→ 雙環烯酮 → 進一步轉化為nootkatone骨架。

四員環的斷裂

天然萜類二酮前驅物，HCl催化，醛醇縮合關六員環，四員環同時斷裂（釋放環張力），得到雙環氯代烯酮，再消除完成nootkatone。

六員環的斷裂

Diels-Alder加合物（橋接雙環），甲酸（HCO₂H）作為質子源，叔醇質子化後形成叔碳正離子，醚提供推力，斷裂六員環C-C，中間體環化（熱力學控制），再水解、消除甲酸酯得nootkatone（50%收率）。

儘管合成所有樣品均不含葡萄柚香氣，後來發現真正的葡萄柚香氣物質是一種簡單硫醇（1-p-menthene-8-thiol），人類嗅覺可偵測至2×10⁻⁵ ppb！合成研究糾正了此誤解。

本章摘要

  • NGP：內部親核試劑在離去基離去時參與，淨構型保留（兩次SN2）
  • 1,2-遷移：烷基/H從碳正離子鄰位遷移，遷移基團保留構型，anti-periplanar要求
  • 頻哪醇：鄰二醇→酮；遷移能力：Ph>3°>2°>1°>H
  • Tiffeneau-Demjanov：α-氨基腈脫重氮→環擴一個碳
  • Favorskii：α-鹵代酮→環丙酮中間體→酯（環收縮）
  • Baeyer-Villiger：酮+過酸→酯；t-Bu>sec>Ph>Et>Me遷移；保留構型
  • Beckmann：肟+酸→醯胺（trans基遷移）；叔烷基→斷裂
  • C-C斷裂：需要電子源（推）和電子槽（拉），1,2,3,4框架，anti-periplanar
  • Eschenmoser斷裂：環氧酮+TsNHNH₂→酮炔（環擴）
  • 立體化學控制斷裂：E/Z雙鍵幾何由起始物立體化學決定（如E2）
