第37章 自由基反應

Clayden Organic Chemistry · Ch 37 (pp. 969–1002)

均裂與自由基生成

共價鍵的斷裂有兩種方式：

  • 均裂（Homolysis）：每個原子各得一個電子，生成兩個自由基（radical）。以「魚鉤箭頭（single-headed arrow）」表示單電子移動。
  • 異裂（Heterolysis）：兩個電子均轉移到同一原子，生成離子。以雙頭彎箭頭表示。
均裂 vs 異裂 均裂： A—B → A• + •B （自由基） 異裂： A—B → A⁺ + :B⁻ （離子） 表示法： 均裂：魚鉤箭頭（→ 單電子） 異裂：全箭頭（→ 電子對）

產生自由基的方法

  1. 熱均裂：加熱弱鍵（Cl-Cl, O-O, N-N等）
  2. 光均裂（hν）：光子能量使鍵均裂（Cl₂ + hν → 2Cl•）
  3. 氫抽提（abstraction）：X• + H-C → H-X + C•
  4. 加成（addition）：X• + C=C → X-C-C•
  5. 消除（elimination/β-scission）：C-C• → C=C + •C

引發劑（Radical Initiators）

引發劑是容易均裂生成初始自由基的化合物：

AIBN（偶氮二異丁腈）

AIBN的均裂 NC-C(CH₃)₂-N=N-C(CH₃)₂-CN →(66-72°C)→ 2× •C(CH₃)₂CN + N₂ 引發原因：1. N-N鍵弱 2. N₂是優良離去基 3. 腈穩定自由基 AIBN不分解O-H或普通C-H鍵 → 選擇性引發

過氧化二苯甲醯（Dibenzoyl peroxide，BPO）

BPO的均裂 (PhCOO)₂ →(hν或加熱)→ 2 PhCOO• →(脫CO₂)→ 2 Ph• O-O鍵弱（約150 kJ/mol）→ 容易均裂

穩定自由基（Persistent Radicals）

  • 三苯甲基自由基（trityl radical）：Ph₃C• 在溶液中穩定存在，由Gomberg於1900年首次分離
  • TEMPO：四甲基哌啶-N-氧化物，因氮-氧位阻和離域而穩定，用作自由基清除劑（scavenger）
  • 維生素E（α-Tocopherol）：生物抗氧化劑，苯酚O-H以H轉移終止不飽和脂質自由基鏈式反應

自由基的穩定性

結構特徵

碳自由基為sp²雜化（平面），單電子在p軌道（SOMO，Singly Occupied Molecular Orbital）中。

穩定性順序

3° > 2° > 1° > 甲基，原因是超共軛（hyperconjugation）。烯丙基/苄基自由基因離域而特別穩定。

FMO觀點：
SOMO + 吸電基（EWG）：EWG降低SOMO能量 → 親電性自由基（electrophilic radical）
SOMO + 給電基（EDG）：EDG升高SOMO能量 → 親核性自由基（nucleophilic radical）

特殊穩定化物種

  • 酮基自由基（ketyl radical）：羰基C得一電子後與O-電荷共振穩定（Mg/苯中生成，McMurry反應）
  • McMurry反應：TiCl₃/LiAlH₄ → Ti(II)，還原酮生成酮基自由基→結合→脫氧→烯烴
  • Acyloin反應：酯+Na（甲苯）→酮基自由基→結合→α-羥酮（acyloin）
McMurry反應 2 R₂C=O →(TiCl₃/LiAlH₄)→ 2 R₂C•-O⁻[Ti] →(偶聯+脫氧)→ R₂C=CR₂ （烯烴）

自由基鏈式反應

鏈式反應（chain reaction）分三個階段：

鏈式反應三階段 引發（Initiation）： In-In →(hν)→ 2 In• 引發劑均裂 增殖（Propagation）： In• + Cl-Cl → In-Cl + Cl• Cl• + H-R → H-Cl + R• R• + Cl-Cl → R-Cl + Cl• （鏈循環） 終止（Termination）： R• + R• → R-R 自由基偶聯 R• + Cl• → R-Cl 捕獲 Cl• + Cl• → Cl₂ 重組
增殖步驟中，每個步驟都再生一個自由基，保持鏈式循環。引發劑只需微量（催化量），所有消耗的增殖試劑（如Cl₂）均在鏈傳遞中被消耗。

鹵素自由基取代的選擇性

氯化和溴化是典型的自由基鏈式反應，但選擇性差別顯著：

自由基選擇性原因
Cl•（氯自由基）低選擇性Cl•活性高、過渡態早（Hammond：放熱）
Br•（溴自由基）高選擇性Br•活性低、過渡態晚（Hammond：接近自由基）
Hammond假說：
放熱步驟 → 過渡態像反應物（早TS），活化能差異小，選擇性低
吸熱步驟 → 過渡態像產物（晚TS），活化能差異大，選擇性高

烯丙基溴化（NBS法）

NBS（N-溴琥珀醯亞胺）在光或引發劑存在下，以低濃度Br₂進行烯丙基位選擇性溴化：

NBS烯丙基溴化 環己烯 + NBS →(hν, CCl₄)→ 3-溴環己烯 （85%） 機制： Br₂光解 → Br• Br• + 烯丙C-H → HBr + 烯丙基自由基（共振穩定） 烯丙基自由基 + Br₂ → 烯丙溴化物 + Br•（鏈循環） NBS作用：維持低[Br₂]，避免加成副反應
低[Br₂]的重要性：若[Br₂]高，Br₂優先加成到雙鍵（極性反應），而非抽取烯丙H（自由基）。NBS作為Br₂的緩慢釋放源，同時CCl₄非極性溶劑不利於極性加成中間體（溴離子橋）。

三丁基錫氫化物（Bu₃SnH）還原脫鹵

Bu₃SnH可將鹵代烷還原為C-H，形成脫鹵代烷：

Bu₃SnH脫鹵機制 引發：Bu₃Sn-H →(hν)→ Bu₃Sn• + H• 增殖： Bu₃Sn• + R-Br → Bu₃SnBr + R• R• + H-SnBu₃ → R-H + Bu₃Sn•（循環） 淨反應：R-Br + Bu₃SnH → R-H + Bu₃SnBr

AIBN引發Bu₃SnH的還原

AIBN（而非過氧化物）是理想引發劑，因其生成的腈穩定自由基（低活性），不會抽取非弱鍵的H，只有Bu₃SnH的弱Sn-H鍵被抽取，確保選擇性。

反應活性：C-I > C-Br > C-Cl（C-F不反應）

碳-碳鍵的自由基形成

1975年後，自由基在有機合成中的應用大幅擴展。最重要的突破是利用自由基形成C-C鍵：

烷基自由基加成到丙烯腈 R-I + CH₂=CH-CN →(Bu₃SnH, AIBN)→ R-CH₂-CH₂-CN 機制（增殖）： Bu₃Sn• + I-R → Bu₃SnI + R• R• + CH₂=CHCN → R-CH₂-•CHCN （加成） R-CH₂-•CHCN + H-SnBu₃ → R-CH₂-CH₂CN + Bu₃Sn•
錫法（tin method）的成功要素：
  • Bu₃SnH需緩慢加入（或催化量+NaBH₄回收）
  • 起始原料含弱C-X鍵（C-I或C-Br）
  • 自由基陷阱為親電性烯烴（CH₂=CHCN、CH₂=CHCO₂Me等），濃度至少10倍於Bu₃SnH

BrCCl₃ + 苯乙烯在hν下也形成C-C鍵（Cl₃C• 加成到烯烴），但不能廣泛應用（限於有特殊弱C-Br的底物）。

前線軌道效應

自由基的SOMO能量決定其親電/親核性，從而決定其選擇的反應夥伴：

  • 親核性自由基：SOMO能量高（EDG鄰位），偏好與LUMO低的親電性烯烴反應（如丙烯腈）
  • 親電性自由基：SOMO能量低（EWG鄰位），偏好與HOMO高的親核性烯烴反應（如乙烯基醚）
自由基類型SOMO能量偏好的烯烴
烷基自由基 R•高（EDG超共軛）親電性（CN、CO₂R）
腈穩定自由基 •CCN低（EWG離域）親核性（乙烯基醚、烯丙位）
丙二酸酯自由基低乙烯基醚（親核性烯烴）

共聚合（Copolymerization）

乙酸乙烯酯（親核性，EDG）和丙烯酸甲酯（親電性，EWG）在自由基引發下生成交替共聚物：

  • 乙酸乙烯酯的自由基（親核）優先加成到親電性丙烯酸甲酯
  • 丙烯酸甲酯的自由基（親電）優先加成到親核性乙酸乙烯酯
  • 結果：沿鏈交替排列（alternating copolymer）

自由基與極性試劑的反應性差異

底物類型極性試劑（典型）自由基（典型）
不飽和C=O親核加成到C=O（1,2或1,4）加成到C=C（β-碳），不攻擊C=O
X-H鍵（O-H, N-H）質子轉移（酸鹼）H抽取（C-H，弱鍵）
烷基鹵SN2於碳（取代）抽取鹵素（不於碳反應）
自由基是「軟」物種——反應由軌道強度和鍵能決定，而非電荷密度。因此O-H和C=O（極化）不被自由基攻擊，C-H（非極化，但弱）被廣泛抽取。

硼烷-氧氣法

三烷基硼（trialkylborane, R₃B）與O₂反應，通過自由基機制將烷基加成到親電性烯烴：

硼烷-氧法機制 R₃B + O₂ → R₂B-O-O-R• + R• （SH2 at B） R• + CH₂=CH-C=O → R-CH₂-•CH-C=O （加成） → +R₃B → 硼烯醇 → +H₂O → 酮 整體：R₃B + CH₂=CHC=OR² + H₂O → R-CH₂CH₂-COR² 氧氣驅動鏈反應，水解硼烯醇得到酮

優點：可在水中進行；無需有機錫（環保）；Et₃B/O₂/H₃PO₂系統也可引發分子內環化。

分子內自由基環化

分子內自由基環化比間分子反應效率更高，原因：

  • 自由基陷阱（雙鍵）始終靠近自由基，環化速率極快
  • 不需陷阱過量，無需高[陷阱]/[錫]比
  • Bu₃Sn•無法競爭，可用更高濃度Bu₃SnH
  • C-Cl和C-SPh等強鍵也可使用（因環化速率快）
5-exo-trig優先形成五員環（Baldwin規則）：
ω-鹵代烯烴在Bu₃SnH/AIBN下優先生成五員環（而非六員環），即使六員環在熱力學上更穩定，因為五員環的環化速率更快。
5-exo-trig環化 Br-(CH₂)₄-CH=CH₂ →(Bu₃SnH)→ [5員環•] → 環戊烷（98%） + [6員環•（2%）] Br-(CH₂)₅-CH=CH₂ →(Bu₃SnH)→ [5員環•（90%）] + [6員環（10%）]

分子內環化的立體化學

有時構象約束（如縮醛「繩套」）決定新生成環節點的立體化學——cis環節點是必然結果。

Et₃B/O₂/H₃PO₂法

無錫（tin-free）方法：Et₃B + cat. O₂ 生成Et•，抽取C-I，自由基環化；H₃PO₂提供最後的H（類似Bu₃SnH的功能），形成的P自由基再抽取Et₃B中的Et，恢復鏈循環。

本章摘要

  • 自由基生成：均裂（熱、光），引發劑（AIBN 66-72°C，BPO光或熱），魚鉤箭頭（單電子）
  • 穩定性：3° > 2° > 1° > CH₃，烯丙基/苄基離域穩定；EWG使SOMO低（親電）；EDG使SOMO高（親核）
  • 鏈式反應：引發→增殖（每步再生一個自由基）→終止
  • Cl• vs Br•：Cl• 選擇性低（早TS，放熱）；Br• 選擇性高（晚TS，吸熱，Hammond假說）
  • NBS烯丙基溴化：低[Br₂]維持、自由基機制、烯丙位選擇性
  • Bu₃SnH脫鹵：Sn-Br(552)和C-H(418)生成比C-Br(280)+Sn-H(308)強；鏈反應；AIBN引發
  • C-C鍵形成：R• + 電性烯烴（CN, CO₂R）→ 錫法；需低[Bu₃SnH]
  • 前線軌道：親核自由基+親電烯烴；親電自由基+親核烯烴
  • 分子內環化：比間分子快，偏好5員環（5-exo-trig）；Et₃B/O₂替代方案
