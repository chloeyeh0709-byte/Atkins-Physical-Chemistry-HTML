第38章 卡賓的合成與反應

Clayden Organic Chemistry · Ch 38 (pp. 1003–1028)

重氮甲烷（Diazomethane）

重氮甲烷（CH₂N₂）是最簡單的重氮化合物，為有毒黃色氣體，但在醚中可作溶液使用。

重氮甲烷的反應

  • 羧酸甲基化：RCOOH + CH₂N₂ → RCOOMe + N₂（立即，無需催化劑）
  • 酚的甲基化：ArOH + CH₂N₂ → ArOMe + N₂（溫和條件）
  • 光解→卡賓：CH₂N₂ →(hν)→ :CH₂（卡賓）+ N₂
N₂是極佳離去基（N₂逸出驅動反應），加上重氮基中N⁺提供的親電碳，使重氮甲烷成為溫和甲基化試劑。烷基鹵（如MeI）會使某些底物產生N-烷基化副產物，CH₂N₂更為選擇性。

卡賓的生成方法

卡賓（Carbene）是中性的二價碳活性中間體（:CR₂），碳只有6個價電子。主要生成方法：

1. 光解或熱解重氮化合物

重氮化合物→卡賓 R₂C=N₂ →(hν 或 金屬催化)→ :CR₂ + N₂ 例：CH₂N₂ →(hν)→ :CH₂（methylene） PhCHN₂ →(Rh₂(OAc)₄)→ PhCH:（苯卡賓）

2. α-消除（Bamford-Stevens法）

Bamford-Stevens（甲苯磺醯腙→卡賓） R₂C=NNHTos →(強鹼或加熱)→ R₂C=N-N:⁻ → :CR₂ + N₂ 也稱Bamford-Stevens條件；可生成烯烴（重排路徑）或直接得卡賓

3. α-消除（CHCl₃/強鹼）

α-消除生成二氯卡賓 CHCl₃ →(NaOH)→ ⁻CCl₃ →(消除Cl⁻)→ :CCl₂ （二氯卡賓）

4. α-內酯脫羧

α-內酯→卡賓+CO₂ O=C-O-CR₂ → :CR₂ + CO₂ （α-propiolactone的脫羧）

5. N-雜環卡賓（NHC）的去質子化

咪唑鹽（imidazolium salt）用強鹼去質子後，得到穩定的N-雜環卡賓（N-heterocyclic carbene, NHC），兩個氮上的孤對電子n→p施予穩定單線態。這是Grubbs催化劑中的重要配體。

NHC的生成 Ar-N N-Ar Ar-N N-Ar \ / \ / C-H →(鹼)→ C: [+] (NHC，穩定) 咪唑鹽 兩個N提供孤對穩定

單線態與三線態卡賓

:CR₂有兩個非鍵合電子，可有不同自旋排列：

類型電子排列幾何鍵角性質
三線態（triplet）兩個未配對電子（↑↑）類sp², 彎曲130-150°ESR活性；類雙自由基
單線態（singlet）電子配對在sp²軌道sp², 彎曲100-110°空p軌道；類兩性（Lewis酸）
哪種是基態？
• :CH₂（甲烯）：三線態為基態（Hund定則）
• :CCl₂（二氯甲烯）：單線態為基態（Cl的n→p施予穩定單線態，能隙變小）
• NHC：單線態為基態（兩個N均施予，大幅穩定單線態）

n→p（lone pair→空p軌道）施予：鄰原子的孤對電子充填卡賓空p軌道，降低空p能量，穩定單線態。

環丙烷化（Cyclopropanation）

卡賓加成到烯烴的雙鍵（C=C），形成三員環（環丙烷）：

單線態卡賓：同面（concerted），立體特異性

單線態卡賓環丙烷化 :CH₂ + cis-2-丁烯 → cis-1,2-二甲基環丙烷（100%，保留構型） :CH₂ + trans-2-丁烯 → trans-1,2-二甲基環丙烷（100%） 機制：協同[1+2]，suprafacial，卡賓空p + 填充π → 兩鍵同步形成

三線態卡賓：分步（stepwise），非立體特異性

三線態卡賓環丙烷化 :CH₂（三線態）+ cis-2-丁烯 → [1,3-二自由基（triplet）] →(自旋翻轉)→ [singlet 1,3-二自由基] → 環丙烷（cis + trans 混合物） 非立體特異性！因需自旋翻轉（spin-flip），時間夠長使鍵旋轉
環丙烷化立體化學是判斷卡賓自旋態的最佳工具：
立體特異性 → 單線態卡賓（或金屬卡賓複合物協同反應）
非立體特異性（cis+trans混合）→ 三線態卡賓（雙自由基中間體）

Simmons-Smith反應

ICH₂ZnI（碘甲基鋅碘化物，由CH₂I₂+Zn(Cu)製備）是「卡賓等效體」，通過有機鋅配合物（而非自由卡賓）對烯烴進行立體特異性環丙烷化：

Simmons-Smith反應 CH₂I₂ + Zn(Cu) → ICH₂ZnI （Simmons-Smith試劑） 烯烴 + ICH₂ZnI → 環丙烷 （保留烯烴立體化學，>99% de） 鄰位OH導向：OH與Zn配位，在OH同側遞送CH₂
烯丙醇的導向效果：
烯丙醇（allylic alcohol）中，OH上的O與Zn配位，CH₂優先從OH所在的面遞送，立體選擇性>99:1（同面）。不含OH時，選擇性大幅降低。

C-H插入（C-H Insertion）

單線態卡賓可插入C-H鍵，立體化學保留（concerted，三中心過渡態）：

C-H插入 :CR₂ + C-H → C-CR₂-H （插入C-H，保留構型） 機制：三中心協同 R₂C: + C—H → [R₂C...C...H]‡ → C-CR₂-H

Rh₂(OAc)₄催化的分子內C-H插入

醋酸銠（rhodium acetate dimer, Rh₂(OAc)₄）催化重氮化合物分解，生成金屬卡賓複合物，進行高選擇性的分子內C-H插入，優先形成五員環（類似自由基環化的偏好）：

Rh₂(OAc)₄催化C-H插入（β-內醯胺合成） N-H + N₂-CHR →(Rh₂(OAc)₄)→ [Rh-CHR錯合物] → C-H或N-H插入 → β-內醯胺 Merck合成碳青黴素（carbapenems）： 重氮酸酐 →(Rh₂(OAc)₄)→ 金屬卡賓 →(N-H插入)→ β-內醯胺（五員環）
金屬催化卡賓的C-H插入通常生成保留構型的產物，且分子內選擇性遠優於間分子，如Rh卡賓優先進行5-exo-trig型（生成五員環γ-內酯、γ-內醯胺等）。

Wolff重排與Arndt-Eistert增碳

Wolff重排

α-重氮酮（α-diazoketone）光解或熱解，先生成α-酮卡賓，再快速重排（Wolff重排）得到烯酮（ketene）：

Wolff重排 R-C(=O)-CHN₂ →(hν或Ag)→ [R-C(=O)-CH:] →(Wolff)→ R-CH=C=O （α-重氮酮） （α-酮卡賓） （烯酮）

Arndt-Eistert增碳（Homologation）

利用Wolff重排，將羧酸（RCOOH）轉化為多一個碳的羧酸（RCH₂COOH）：

Arndt-Eistert增碳 RCOOH →(1. SOCl₂)→ RCOCl →(2. CH₂N₂)→ RCOCH N₂ →(3. hν, H₂O)→ Wolff→ R-CH=C=O →(H₂O)→ RCH₂COOH 每次操作增加一個碳（CH₂）
Arndt-Eistert的應用：
從氨基酸出發，每次增加一個碳，可逐步建構高級胺基酸或多肽側鏈。不破壞現有手性中心（Wolff重排為分子內，立體化學得以保留）。

氮賓（Nitrene）及相關重排

氮賓（Nitrene, :NR）是氮的卡賓類似物，亦為活性中間體，可由醯基疊氮（acyl azide）光解或 Curtius/Hofmann 重排產生：

Curtius重排

Curtius重排 RCOOH →(1. ClCO₂Et)→ RCOC(O)OEt混合酐 →(2. NaN₃)→ RCON₃（醯基疊氮） →(加熱)→ [R-N=C=O（異氰酸酯）] →(H₂O)→ RNH₂（胺，減少一個碳）

Hofmann重排

Hofmann重排 RCONH₂ →(Br₂, NaOH)→ [RN:（氮賓）] → [RNCO] →(H₂O)→ RNH₂ （醯胺） （氮賓中間體） （異氰酸酯）

兩種重排的結果相同：羧酸（或醯胺）→ 比原來少一個碳的胺（降級）。

Curtius與Hofmann重排中，遷移基團（R）的立體化學完全保留（類似Baeyer-Villiger，1,2-遷移保留機制）。

卡賓對孤對電子的攻擊

除了加成到C=C，卡賓也可插入O-H和N-H鍵，或攻擊孤對電子形成ylid：

卡賓插入O-H鍵 :CH₂ + R-O-H → [R-O⁺H-CH₂⁻（ylid）] → R-O-CH₃ （氧鎓ylid中間體） （甲醚）

Ylid的生成與應用

若雜原子（O、S、N）上沒有H，ylid不能重排，可被分離並用於其他反應（如不可由其他方法合成的ylid）。羰基取代卡賓（親電性）插入N-H是合成β-內醯胺（β-lactam）的重要策略。

Merck的碳青黴素合成：
β-內醯胺類抗生素的四員環（β-lactam）難以形成（環張力）。Merck選擇用Rh₂(OAc)₄催化卡賓插入N-H鍵（分子內），高效建構四員環：
醯胺N-H + 重氮乙酸酯（鄰近） →(Rh₂(OAc)₄)→ β-內醯胺（75%收率）

重氮化合物卡賓插入的底物兼容性

金屬卡賓（Rh催化）可容忍酸性N-H和O-H鍵，而有機金屬試劑（如有機鋰、Grignard）則不能，顯示了卡賓反應的溫和特性。

烯烴複分解反應（Alkene Metathesis）

金屬卡賓（尤其是Ru卡賓，Grubbs催化劑）催化的烯烴複分解（olefin metathesis）是現代有機合成最重要的C=C鍵形成方法之一，獲2005年諾貝爾化學獎（Chauvin、Schrock、Grubbs）。

機制：[2+2]環加成-逆反應

烯烴複分解機制（Grubbs催化劑） [Ru]=CHR + CH₂=CH-R' →([2+2])→ 金屬環丁烷（metallacyclobutane） →(逆[2+2])→ [Ru]=CH-R' + CH₂=CHR 關鍵特徵： • 大多數步驟可逆 • 不可逆步驟：乙烯（CH₂=CH₂）逸出氣相 • 驅動力：乙烯逸出

常見Grubbs催化劑

催化劑結構特點特性
Grubbs I（第一代）(PCy₃)₂Cl₂Ru=CHPh穩定，適用範圍廣
Grubbs II（第二代）一個PCy₃換為NHC配體活性更高，適用受阻烯烴
Hoveyda-Grubbs苯亞甲基Ru，配體為苯基醚可回收，空氣穩定

環關閉複分解（Ring-Closing Metathesis, RCM）

RCM（形成環狀烯烴） 二烯 →(Ru催化劑, 2 mol%)→ 環狀烯烴 + H₂C=CH₂ 例：N-Ts二丙烯胺 →(2 mol% Grubbs I)→ N-Ts吡咯啉（98%收率）

RCM特別適合形成5~20員環，Grubbs催化劑也能在O-H和N-H官能基存在下工作（與有機金屬試劑不同）。

交叉複分解（Cross Metathesis）

兩種不同烯烴交換各自的兩個碳，生成新的烯烴（作為E異構體）和乙烯副產物。當兩種烯烴在空間或電子性質上差異足夠大時，交叉複分解才具有選擇性。

交叉複分解 R¹-CH=CH₂ + R²-CH=CH₂ →(Ru)→ R¹-CH=CH-R² + CH₂=CH₂ （較少反應性） （較多反應性） (E異構體優先)

Ene-yne複分解

當一個反應物是炔烴（而非烯烴）時，兩個C=C鍵相互換位後，炔烴中仍有一個C=C鍵與烯烴相連，結果產物是1,3-二烯，這恰好是Diels-Alder反應所需的二烯。Ene-yne複分解是製備Diels-Alder二烯底物的優雅方法。

Ene-yne複分解 R¹-C≡C-R² + CH₂=CH₂ →(Ru)→ R²-C(=CH₂)-CH=CH-R¹ （1,3-二烯） 隨後Diels-Alder環化，再氧化芳構化 → 多環芳香化合物

本章摘要

  • 重氮甲烷：甲基化羧酸/酚；光解→:CH₂卡賓
  • 卡賓生成：重氮化合物分解（金屬催化或hν），α-消除（CHCl₃/鹼），Bamford-Stevens（甲苯磺醯腙），NHC去質子
  • 自旋態：:CH₂基態三線態；:CCl₂、NHC基態單線態；n→p施予穩定單線態
  • 環丙烷化：單線態→concerted [1+2]，立體特異性保留；三線態→stepwise via二自由基，非立體特異性
  • Simmons-Smith：ICH₂ZnI，立體特異性，烯丙OH定向（>99% de）
  • C-H插入：單線態卡賓三中心協同，保留構型；Rh₂(OAc)₄催化，優先五員環分子內插入
  • Wolff重排：α-酮卡賓→烯酮；Arndt-Eistert增碳（+1 CH₂）
  • 氮賓：Curtius（醯基疊氮→異氰酸酯→胺，-1C）；Hofmann（醯胺+Br₂→胺，-1C）
  • 孤對電子攻擊：O-H/N-H插入；ylid生成；β-內醯胺合成
  • 烯烴複分解：Grubbs Ru催化劑；[2+2]-逆[2+2]機制；RCM製環，交叉複分解，ene-yne複分解
