第39章 反應機制的測定

Clayden Organic Chemistry · Ch 39 (pp. 1029–1070)

機制的兩種類型

有機反應的「機制」可分為兩個層次：

  1. 機制的辨認（Mechanism recognition）：依據教科書中的模式，看到底物和產物，推測可能的機制步驟（類比已知反應）。本書前幾十章主要是這個。
  2. 機制的實驗測定（Experimental determination）：透過動力學、同位素、催化、立體化學等實驗手段，以科學方式確認（或排除）某個機制。本章介紹這個層次。
機制永遠不能被「證明」，只能被「支持」或「排除」。我們追求的是一組相互一致、難以同時滿足其他機制的實驗結果。

案例研究：Cannizzaro反應

苯甲醛（ArCHO）在濃NaOH中不發生縮合，而是歧化（disproportionation）：一半氧化為羧酸，一半還原為醇。

Cannizzaro反應 2 ArCHO →(NaOH)→ ArCOOH + ArCH₂OH

實驗排除錯誤機制

  1. 自由基機制排除：TEMPO或過氧化物均不影響速率 → 無自由基鏈式反應
  2. 同位素標記（¹⁸O）：D₂O溶劑中，氧不與溶劑交換 → O原子留在分子內
  3. 雙標記（D/¹⁸O）：D₂O加到ArCHO後，D出現在醇（ArCH₂OD）而非酸（ArCOOH）→ 氫從醛轉移至另一醛的羰基碳

正確機制：雙陰離子（dianion）機制

Cannizzaro正確機制 Step 1: ArCHO + OH⁻ → ArCH(OH)O⁻ （加到C=O） Step 2: ArCH(OH)O⁻ → Ar-C(=O)-O⁻ + H⁻ （氫化物轉移） + ArCHO + ArCH₂O⁻ 淨結果：ArCOO⁻ + ArCH₂OH（歧化） 速率 = k[ArCHO]²[OH⁻]（三分子，二級ArCHO + 一級OH）

動力學證據

速率方程（rate law）揭示過渡態的成分：

  • 速率 = k[A][B] → 二分子反應，A和B均在速率決定步驟的過渡態中
  • 速率 = k[A]² → A的二聚體（或A與A的碰撞）在過渡態
  • 速率 = k[A][B][C] → 三分子（罕見，熱力學上不利）
速率方程只能告訴我們速率決定步驟（rate-determining step）的過渡態成分，不能直接告訴我們慢步驟之後發生了什麼。

交叉實驗（Crossover Experiment）

混合兩種有差異標記的底物，若觀察到「交叉」產物（含另一底物的標記原子），說明中間體是自由的（intermolecular）；若無交叉，說明機制是分子內的。

同位素標記

用穩定同位素（D, ¹³C, ¹⁸O, ¹⁵N等）或放射性同位素（¹⁴C）標記特定原子，追蹤其在反應中的去向：

同位素用途偵測方法
D（氘）H遷移追蹤，C-H鍵斷裂偵測質譜、NMR
¹⁸OO原子來源追蹤，酯水解位置質譜
¹⁴C（放射）C骨架重排追蹤放射性計數
¹³CC重排（¹³C NMR）¹³C NMR
雙標記實驗（Double Labeling）：
同時用兩種不同同位素（如D和¹³C）標記同一底物，提供更強的機制證據，排除多種可能機制。

Hammett σ-ρ關係

Hammett關係是研究間位和對位取代基對苯環反應速率或平衡的定量線性關係：

Hammett方程 log(k_X / k_H) = σ · ρ σ（sigma）：取代基常數（由苯甲酸解離常數定義） ρ（rho）：反應常數（直線斜率，反應靈敏度）

σ值的定義

  • σ由苯甲酸pKa測量：σ_X = pKaH - pKa_X
  • EWG（吸電基，NO₂, CF₃）：σ > 0
  • EDG（給電基，NMe₂, OMe）：σ < 0

ρ值的解釋

ρ值意義
ρ > 0（正）EWG加速反應，負電荷在苯環附近積聚（如親核加成到羰基）
ρ < 0（負）EDG加速反應，正電荷在苯環積聚（如SN1, EAS）
|ρ| 大（>4）電荷直接在苯環上（如芳環陰離子、苄基陽離子）
|ρ| 中（2-4）電荷在苯環鄰原子（與苯環共軛連接）
|ρ| 小（<1）苯環遠離反應位點
案例：Cannizzaro反應 ρ = +3.8
正的ρ值表示苯環附近積聚負電荷，符合OH⁻加到C=O（生成烷氧陰離子）的機制。

Hammett圖的彎曲（改變速率決定步驟）

若Hammett圖在某σ值處出現彎曲，表示在那個取代基附近速率決定步驟發生改變：

  • 一個步驟對EWG敏感（ρ₁），另一個對EDG敏感（ρ₂），此二步驟的速率在某取代基時互換
  • 同一分子沿最快的機制路徑反應，受最慢步驟限制
重要原理：
「反應沿最快的可能機制路徑進行，但速率受該機制最慢的步驟限制。」
Hammett圖彎曲 → 在彎曲處兩個步驟速率相當，之後改由另一步驟為RDS。
案例：偶極苯基甲醇分子內Friedel-Crafts烷基化
EWG-Ar加速碳正離子生成（ρ = +2.67，慢步驟是環化）；EDG-Ar加速碳正離子生成更快，但環化成為RDS（ρ = -2.51）。
Hammett圖呈倒V形，在σ = +0.5處有折點。

動力學同位素效應（KIE）

動力學同位素效應（KIE）是同位素取代造成的速率變化：

KIE定義 KIE = k_H / k_D 若C-H鍵在速率決定步驟中斷裂 → k_H > k_D → KIE = 2–7 原因：零點能（zero-point energy）差異 C-H zero point energy > C-D zero point energy → C-H 需要較少能量達到鍵斷裂 → C-H 比 C-D 快

零點能解釋

根據量子力學（Heisenberg不確定性原理），振動鍵即使在最低能量狀態仍有零點能。較輕的H質量使C-H零點能高於C-D，即C-H處於較高的基態能量，須克服較低的活化障礙→反應更快。

KIE值的解釋：
  • k_H/k_D = 2–7（正常KIE）→ C-H鍵在RDS中斷裂（E2消除、去質子化等）
  • k_H/k_D ≈ 1 → C-H鍵不涉及RDS
  • k(D₂O)/k(H₂O) < 1（溶劑同位素效應）→ 見酸/鹼催化一節
E2 vs E1 的KIE區分：
α-D₂取代的苄溴，E2（C-H在RDS）→ k_H/k_D = 7.1
E1（RDS = 碳正離子生成，C-H不斷）→ KIE ≈ 1
可以此判定消除機制。

芳香親電取代的KIE

苯硝化（nitration）：k_H/k_D = 1.0 → RDS不斷C-H（RDS是NO₂⁺攻擊）
苯酚碘化：k_H/k_D = 4.1 → RDS斷C-H（苯氧陰離子去質子化比加成慢）

活化熵（Entropy of Activation, ΔS‡）

ΔS‡反映反應過渡態的有序程度改變：

ΔS‡意義典型反應
大正值（> +20 J/mol·K）一分子→多個（有序↓）斷裂反應（fragmentation）
中等值（±10-20）單分子or雙分子（溶劑飽和）SN1, SAC
大負值（-100以下）高度有序過渡態Diels-Alder（-120至-160 J/mol·K）
斷裂反應 ΔS‡ = +36.8 J/mol·K：
磺酸酯碎裂為CO₂ + 烷烴 + 磺酸鹽（三個分子），熵增大，ΔS‡正值。

Diels-Alder ΔS‡ ≈ -144 J/mol·K：
環戊二烯 + 順丁烯二酸酐，兩分子組合，且過渡態幾何要求嚴格（endo規則），熵大幅降低。

SAC（特定酸催化）典型：ΔS‡接近0或稍負（SH1+H型）；GBC（一般鹼催化）：ΔS‡ = -120至-180 J/mol·K（三分子RDS，高度有序）。

酸鹼催化

特定酸催化（SAC，Specific Acid Catalysis）

反應需要底物先被快速完全質子化（快速酸鹼平衡），然後質子化的底物經過RDS反應。速率只依賴[H₃O⁺]（pH），不依賴其他酸的濃度。

SAC機制框架 X + H⁺ →(K, fast)→ XH⁺ XH⁺ →(k, slow)→ products rate = k·K·[H⁺][X] ∝ [H⁺] 特徵：1. RDS不斷C-H鍵 2. k(H₂O)/k(D₂O) < 1（逆溶劑同位素）
逆溶劑同位素效應（k(H₂O) < k(D₂O)）是SAC的標誌：
D₃O⁺比H₃O⁺是更強的酸（D₂O溶劑中），使底物更容易被質子化，K更大，速率更快。

特定鹼催化（SBC，Specific Base Catalysis）

速率只依賴[OH⁻]，底物先被快速去質子化（K），去質子化的底物在RDS反應：

SBC機制框架 XH + OH⁻ →(K, fast)→ X⁻ + H₂O X⁻ →(k, slow)→ products rate ∝ [OH⁻] 特徵：逆溶劑同位素（k(D₂O) > k(H₂O)）

特定酸/鹼催化的特徵總結

  • 只有H₃O⁺（SAC）或OH⁻（SBC）有效，與其他酸/鹼濃度無關
  • RDS中不涉及質子轉移
  • 逆溶劑同位素效應（D₂O中更快）
  • pH-速率曲線直線（一段）

一般鹼催化（GBC，General Base Catalysis）

速率不僅依賴[OH⁻]，還依賴溶液中所有鹼的濃度；在恆定pH下，增加弱鹼濃度仍能加速反應。

  • 質子轉移在RDS中發生
  • 正常KIE（k_H/k_D > 1）
  • 大負ΔS‡（三分子RDS）

一般酸催化（GAC，General Acid Catalysis）

弱酸在RDS中直接給出質子，速率依賴各種酸的濃度：

  • 正常KIE
  • 大負ΔS‡
  • 在中性pH也可發生（不需極低pH）
SAC vs GBC的對比（五員環 vs 四員環環醚合成）：
HO(CH₂)₃Cl → 四氫呋喃（THF）：需要強鹼（SBC），過渡態高應變，只有OH⁻有效
HO(CH₂)₄Cl → 四氫吡喃：弱鹼ArO⁻也可（GBC），過渡態應變小，溫和鹼即可
→ GBC（溫和）適合容易的環化，SBC（強鹼）適合應變高的環化

中間體的偵測

確認中間體的金標準：

  1. 在反應混合物中直接偵測或分離中間體
  2. 獨立製備中間體，加入反應後可得到相同產物
  3. 動力學：中間體生成和消耗的速率合理
  4. 捕捉實驗（trapping reaction）

捕捉反應（Trapping）

設計一個捕捉試劑（trapping agent），只能與假設的中間體反應，若加入後得到預期的捕捉產物，有力支持中間體存在：

芳香硝化的中間體（Wheland中間體）捕捉：
將親核基（醯胺）引入芳環的特定位置，使其在硝化時能捕捉鄰位碳正離子中間體（Wheland中間體）→ 得到環化捕捉產物 → 確認中間體存在及位置。

苯炔（Benzyne）的捕捉

鄰氨基苯甲酸重氮化生成鄰位苯炔中間體，被分子內呋喃捕捉（Diels-Alder），得到橋式多環產物（86%），說明苯炔確實作為中間體。

Favorskii反應的oxyallyl陽離子

多個獨立實驗確認Favorskii的環丙酮和oxyallyl陽離子中間體：

  • MeOD溶劑中：底物α位引入D（快速可逆烯醇化）
  • ΔS‡ = +64 J/mol·K（一分子→兩分子RDS）
  • Hammett ρ = -5（oxyallyl陽離子離域到苯環）
  • Zn/Cu法直接生成oxyallyl陽離子，參與Diels-Alder → 確認

立體化學與機制

立體化學證據是最有力的機制工具之一：

立體化學觀察機制意涵
反應位點構型倒轉（inversion）SN2（後面攻擊）
構型保留（retention）鄰基參與（兩次SN2）或1,2-遷移
外消旋化平面碳正離子中間體（SN1）
立體特異性（超表面）協同反應（SN2、Diels-Alder、單線態卡賓）
非立體特異性自由基中間體或平面碳正離子
環氧乙烷開環的立體化學（Propranolol合成）：
NAph-O⁻ + 環氧氯丙烷（epichlorohydrin）：兩種可能機制（在Cl或在環氧的SN2），給出不同鏡像體產物。
以鏡像純底物確認：環氧先被攻擊（SN2），生成特定鏡像體的丙醇胺，再關環（另一個SN2）→ 確認攻擊位點。

Ritter反應和Beckmann斷裂的共同中間體

從不同起始物（tertiary alcohol 或 oxime）在酸中均生成相同的醯胺，且產物的立體化學一致（cis-decalin起始→trans-decalin產物，透過平面碳正離子中間體）：

  • Ritter：3°醇→碳正離子→腈捕捉→亞硝鎓離子→水解→醯胺
  • Beckmann斷裂：肟→亞硝鎓離子→水→醯胺
  • 兩個反應途徑通過相同中間體（碳正離子 + 腈）

機制研究方法總結

1. 確認產物結構
  • 光譜（NMR, MS等）確認結構
  • 同位素（D, ¹³C, ¹⁸O）追蹤原子命運
  • 立體化學（保留/倒轉/外消旋）
2. 動力學方法
  • 速率方程 → 過渡態成分
  • KIE（k_H/k_D = 2-7）→ C-H鍵是否在RDS中斷裂
  • ΔS‡正 → 單分子斷裂；大負 → 環加成或三分子
3. 結構-反應性關係
  • CF₃替換CH₃：電子探針（steric類似）
  • Hammett σ-ρ：ρ符號和大小揭示電荷類型和位置
  • Hammett圖彎曲 → RDS改變
4. 催化
  • SAC：只有H₃O⁺有效；k(D₂O) > k(H₂O)；無KIE
  • SBC：只有OH⁻有效；類似溶劑效應
  • GAC/GBC：弱酸/鹼也有效；正常KIE；大負ΔS‡
5. 中間體
  • 獨立製備 + 相同產物
  • 捕捉實驗（最有說服力）
  • 多個反應共同指向同一中間體（互鎖網絡）
