Clayden Organic Chemistry · 第40章（pp. 1069–1101）

導論：過渡金屬的優勢

有機金屬化學研究含有金屬-碳鍵的化合物及其在有機合成中的應用。過渡金屬能夠催化在普通有機化學條件下不可能發生的反應，例如：在孤立雙鍵上的親核取代、芳香族C–N鍵的形成，以及烯烴的複分解。

金屬催化的核心優勢在於金屬的氧化態可以在反應過程中靈活改變，使其能夠同時作為親電試劑（接受電子）和親核試劑（提供電子）。本章以鈀為主線，因其催化能力最廣泛、最重要。

18電子規則

過渡金屬錯合物中，穩定的18電子構型（滿殼層）是理解配位化學的基石，類似於有機化學中的八隅體規則。

電子計數

計算錯合物總電子數的方法：

  • 金屬本身貢獻的價電子數（查週期表族數）
  • 每個配位基貢獻的電子數（σ配位基貢獻2e，π配位基視貢獻而異）
  • 離子型配位基（如Cl⁻）貢獻2e；中性配位基（如CO、PR₃）貢獻2e
典型電子計數
  • 二茂鐵 Fe(η⁵-Cp)₂：Fe(0) 8e + 2×Cp(η⁵) 5e×2 = 8+10 = 18e（穩定）
  • Pd(PPh₃)₄：Pd(0) 10e + 4×PPh₃ 2e×4 = 10+8 = 18e（穩定，但易解離成14e的Pd(PPh₃)₂）
  • (MeCN)₂PdCl₂：Pd(II) 8e + 2×MeCN 2e×2 + 2×Cl⁻ 2e×2 = 8+4+4 = 16e（平面四方，常見於Pd(II)）
鈀(II)錯合物通常為16電子平面四方構型，這正是其催化活性的來源：空的配位位點可接受底物配位。

哈普托數（Hapto Numbers）

希臘字母η（eta）描述配位基中同時與金屬成鍵的原子數目：

  • η¹：單原子配位（如烷基）
  • η²：雙原子配位（如烯烴，π錯合物）
  • η³：三原子配位（如烯丙基，π-allyl）
  • η⁵：五原子配位（如環戊二烯基Cp，芳烴）

配位基特性

配位基電子對貢獻電子數特性
CO（羰基）σ供體+π受體2e強π受體，反鍵作用
PR₃（膦）σ供體2e易調節電子性和空間位阻
Cl⁻（氯離子）σ供體+π供體2e橋接配位基
烯烴（η²）π供體2e活化C=C供親核攻擊
Cp⁻（η⁵）π供體5e（或6e）形成夾心化合物

反鍵作用（Back-Bonding）

在金屬羰基錯合物中，金屬的充填d軌域可向CO的空π*反鍵軌域捐贈電子密度，稱為反鍵作用（π back-bonding）。此作用：

  • 削弱C≡O鍵（紅外伸縮頻率降低，從自由CO的2143 cm⁻¹降至錯合物的約1900 cm⁻¹）
  • 穩定低氧化態金屬
  • 強π受體配位基（CO > alkene > PR₃）使金屬更親電

配位基與錯合物

Vaska's 錯合物

trans-[IrCl(CO)(PPh₃)₂]（Vaska錯合物）是研究氧化加成反應的標準模型。16電子Ir(I)錯合物可加成H₂、O₂、HX等小分子，形成18電子Ir(III)產物。

Wilkinson 催化劑

[RhCl(PPh₃)₃]（Wilkinson催化劑）是第一個被廣泛使用的均相氫化催化劑，可在常溫常壓下將烯烴加氫。其催化循環包含解離一個PPh₃（形成14e活性種）→ 氫氣氧化加成 → 烯烴配位 → 遷移插入 → 還原消除。

氧化加成與還原消除

氧化加成（Oxidative Addition）

低氧化態金屬M(n)插入σ鍵（如C–X、H–X），金屬氧化態升高2，配位數增加2：

M(n) + A–B  →  A–M(n+2)–B
Pd(0)  + Ar–X  →  Ar–Pd(II)–X   (14e→16e)

反應性順序：C–I > C–Br > C–OTf > C–Cl（鍵能越低越易反應）。

還原消除（Reductive Elimination）

氧化加成的逆反應，兩個順式（cis）配位基結合形成新σ鍵，金屬氧化態降低2：

A–M(n+2)–B  →  M(n) + A–B
Ar–Pd(II)–R  →  Pd(0) + Ar–R
還原消除要求兩個配位基必須處於順式位置。這是為何許多催化反應設計中要確保兩個偶聯基團在同一側配位。

遷移插入與β-氫消除

遷移插入（Migratory Insertion）

金屬的配位基遷移到相鄰的不飽和配位基上，形成新的C–C或C–X鍵：

R–Pd–CO  →  R–C(=O)–Pd   (烷基遷移到CO)
R–Pd–alkene  →  R–CH₂–CH₂–Pd  (氫化鈀加成)

羰基化反應（OXO過程）：烯烴 + CO + H₂在Rh催化下→醛（Rh-BINAP配體可得到手性醛）。

β-氫消除（β-Hydride Elimination）

烷基金屬中，β碳上的氫轉移到金屬上，形成烯烴配位物，然後解離：

R–CH₂–CH₂–Pd–X  →  R–CH=CH₂ + H–Pd–X

要求：β碳上有氫；β氫與金屬必須順式；需要空的配位位點。這是Heck反應的終止步驟，也是許多副反應的來源。

Heck反應

Heck反應是鈀催化的芳基（或乙烯基）鹵化物與烯烴的偶聯反應，是有機合成中形成C–C鍵最重要的方法之一（Heck，2010年諾貝爾化學獎）。

催化循環

① Ar–X + Pd(0)  →  Ar–Pd(II)–X        氧化加成
② Ar–Pd–X + RCH=CH₂  →  配位 η²-烯烴錯合物
③ 烯烴插入: Ar遷移  →  Ar–CH₂–CH(R)–Pd–X
④ β-氫消除  →  Ar–CH=CHR + H–Pd–X
⑤ 鹼 + H–Pd–X  →  Pd(0) + 鹼·HX     再生催化劑

區域選擇性

  • 芳基通常接在末端碳（較少取代的那端），因為Pd較大，傾向佔據空間位阻較小的位置
  • 缺電子烯烴（丙烯酸酯等）選擇性更高（苯乙烯型端基最佳）
  • 通常為反式（E）立體選擇性（β-H消除通過syn消除再旋轉達到熱力學最穩定的E型）
Heck反應舉例 
PhI + CH₂=CHCOOEt  →[Pd(OAc)₂, PPh₃, Et₃N]→  Ph–CH=CH–COOEt
                                                  (E)-肉桂酸乙酯  ~90%

交叉偶聯反應

交叉偶聯反應通過轉金屬化（transmetallation）步驟，將不同有機基團通過金屬傳遞連接起來。一般催化循環：

① Ar¹–X + Pd(0)  →  Ar¹–Pd–X        氧化加成
② Ar¹–Pd–X + Ar²–M  →  Ar¹–Pd–Ar²   轉金屬化（M = Sn, B, Zn等）
③ Ar¹–Pd–Ar²  →  Pd(0) + Ar¹–Ar²   還原消除
反應名稱有機金屬試劑（R–M）特點與條件
Stille偶聯Bu₃Sn–R（有機錫）官能基耐受性好，但有毒
Suzuki偶聯RB(OH)₂（硼酸）+ 鹼最廣泛使用，低毒，穩定
Sonogashira偶聯末端炔烴 + CuI共催化劑形成C(sp)–C(sp²)鍵
Negishi偶聯RZnX（有機鋅）官能基耐受性好
Kumada偶聯RMgX（格氏試劑）簡單，但官能基限制多
Suzuki偶聯（2010年諾貝爾獎）使用硼酸，水/有機溶劑均可，空氣穩定，官能基耐受性極佳，是製藥工業首選的交叉偶聯方法。

π-烯丙基鈀錯合物

烯丙基親電試劑（X = OAc, OCO₂R, Cl, OPO₃R₂等）在Pd(0)催化下生成π-烯丙基鈀陽離子錯合物（η³-allyl Pd），再被親核試劑攻擊完成取代反應。

反應機制與立體化學

烯丙基–X + Pd(0)  →  [η³-allyl–Pd]⁺ + X⁻    (背面攻擊，構型翻轉)
[η³-allyl–Pd]⁺ + Nu⁻  →  Nu–allyl + Pd(0)   (背面攻擊，構型翻轉)
淨結果：構型保留（雙重翻轉）
整個反應經歷兩次反應（各自翻轉），因此整體構型保留。這與S_N2反應（構型翻轉）形成對比。

軟親核試劑最佳

  • C–C鍵形成：穩定的烯醇鹽（丙二酸酯、氰化物）效果最佳
  • C–X鍵形成：醇鹽、胺類、硫醇鹽（X = O, N, S）

乙烯基環氧化物作為特殊親電試劑

乙烯基環氧化物因三員環張力的釋放能驅動與Pd(0)的反應，產生兩性離子π-烯丙基鈀中間體（內建烷氧基鹼，無需額外加鹼），親核試劑優先攻擊位阻較小的端基（整體為1,4-加成產物）。

分子內烷基化成環

π-烯丙基鈀可用於分子內烷基化反應，製備各種含氮或含氧雜環：

  • 6/5稠合環優於橋接環（區域選擇性由鏈長決定）
  • 三員環也可以製備（留基遠離親核試劑）

芳香黴素的合成（Trost）

Trost等人利用兩個Pd催化的烯丙基取代反應，全合成了核苷類似物芳香黴素（aristeromycin），精確控制了兩個立體中心均為保留構型，充分展現π-烯丙基鈀化學的立體控制能力。

Buchwald-Hartwig胺化反應

鈀催化的芳基鹵化物與胺的偶聯，形成C–N鍵——一個在普通條件下幾乎不可能完成的反應（Buchwald和Hartwig，1990年代開發）。

催化循環

① Ar–X + Pd(0)  →  Ar–Pd(II)–X       氧化加成
② Ar–Pd–X + HNR₂  →  Ar–Pd–NR₂      胺配位（配體鹼輔助脫HX）
③ Ar–Pd–NR₂  →  Pd(0) + Ar–NR₂      還原消除（形成C–N鍵）
   鹼（NaOtBu等）再生Pd(0)催化劑

配位基設計

成功的Buchwald-Hartwig反應依賴於精心設計的膦配位基：

  • BINAP（軸手性雙膦）
  • Xantphos（大咬合角雙膦，有利於還原消除）
  • Davephos和RuPhos（二甲氨基聯苯磷配體，大空間位阻）
  • 預成型Pd/配體錯合物（催化量使用）

反應範圍

優點：電子給體和受體取代基均可；立體位阻大的苯酚可耐受；芳基氯化物（比碘或溴便宜）也可成功反應；芳香雜環鹵化物（無論缺電子或富電子）均適用。

伊曲康唑（itraconazole，抗真菌藥）的合成

分子中心含有哌嗪環，左右各一個苯環（一個通過O連接，一個通過N連接）。利用Buchwald-Hartwig C–N偶聯分兩步引入：先保護一個N，再依次偶聯。81%收率。

Wacker氧化

Pd(II)配位的烯烴對親核試劑的反應性大幅增強：電子密度從π軌域流向金屬，使烯烴碳變得親電（類似溴鎓離子）。

氧化鈀化（Oxypalladation）

RCH=CH₂ + PdCl₂(cat), H₂O →
  [氧化鈀化: H₂O攻擊較取代端] → enol → R–CO–CH₃
  + H–Pd–Cl → Pd(0) → [CuCl₂/O₂再氧化] → PdCl₂

Wacker氧化（工業上稱Hoechst-Wacker過程）：末端烯烴 + PdCl₂(cat)/CuCl₂/H₂O/O₂ → 甲基酮。水作親核試劑，攻擊較取代的末端，β-氫消除後烯醇互變成酮。

Wacker氧化的催化循環需要再氧化：Pd(0) → Pd(II)由CuCl₂完成，Cu(I) → Cu(II)再由空氣中O₂完成，整個過程是空氣氧化烯烴的高效方法。

矽基烯醇醚氧化（oxypalladation of silyl enol ethers）

矽基烯醇醚在Pd(OAc)₂作用下發生氧化鈀化，因無β-氫（另一側），只能消除至共軛位置，最終形成α,β-不飽和酮（烯酮）。這是由酮（via矽基烯醇醚）製備烯酮的區域選擇性方法。

醇作為分子內親核試劑

含羥基的二烯底物，在cat. Pd(OAc)₂/LiCl/AcOH條件下，分子內氧化鈀化形成四氫呋喃環（99:1 syn:anti立體選擇性），苯醌作為氧化劑再生Pd(II)。

金催化：炔烴活化

汞(II)催化炔烴水化歷史悠久，但因毒性已被金催化取代。金(I)和金(III)與炔烴形成強π錯合物，使炔烴對親核試劑極度活化：

R–C≡C–H + [Au]  →  R–C≡C–Au錯合物
H₂O攻擊更取代端  →  烯醇金 → 酮 + Au⁺再生

即使是催化量的AuCl（NaAuCl₄形式）就可完成水化，條件溫和（H₂O/MeOH，室溫至60°C），且可耐受各種官能基。

金催化炔烴水化 
環己基–C≡C–Me + 2 mol% NaAuCl₄, H₂O/MeOH →
  環己基–CO–CH₃  (83% 收率)
HO–Ph–C≡C–CH₂–CH₂–OH + 2 mol% AuCl, MeOH →
  五元環縮醛  (99% 收率)

釕催化：烯烴複分解

烯烴複分解（metathesis）是在釕卡賓催化劑下，兩個烯烴交換烯烴的兩端，釋放乙烯氣體形成新的烯烴：

R¹CH=CH₂ + R²CH=CH₂  →[Ru]→  R¹CH=CHR² + CH₂=CH₂
分子內：二烯  →[Ru]→  環烯 + 乙烯  (RCM環化複分解)

Grubbs催化劑

  • Grubbs I催化劑：Cl₂(PCy₃)₂Ru=CHPh（2 mol%，穩定，商業可得）
  • Grubbs II催化劑：Cl₂(PCy₃)(IMes)Ru=CHPh（更活潑，較少用量）
  • Hoveyda-Grubbs催化劑：含苯乙烯醚配體，更穩定（0.25 mol%即可）

藥物合成應用

  • 催眠藥（GlaxoSmithKline，Verona）：末端二烯→六員雜環（98%收率），再Simmons-Smith環丙烷化（反式選擇性）
  • 骨質疏鬆/骨關節炎藥（GlaxoSmithKline，美國）：七員環雜環，0.25 mol% Hoveyda-Grubbs
  • 馬來黴素A（malayamycin A，天然殺菌劑）：含4個手性中心的含氧雜環，Grubbs I催化RCM為核心步驟

本章摘要

  • 18電子規則：穩定過渡金屬錯合物的電子計數原則；η數描述配位基接觸點數
  • 反鍵作用：金屬d→CO π*，降低CO伸縮頻率，穩定低價金屬
  • 氧化加成：Pd(0) + Ar–X → Ar–Pd(II)–X，金屬氧化態+2，配位數+2
  • 還原消除：需順式配位；形成C–C、C–N、C–O等鍵
  • 遷移插入：烷基遷移至CO（羰基化）或烯烴（加氫鈀化）
  • β-氫消除：生成烯烴的終止步驟；需順式β-H及空配位點
  • Heck反應：Pd(0)催化；ArX + 烯烴 → 取代烯烴；通常E型立體選擇性
  • 交叉偶聯：Stille（有機錫）、Suzuki（硼酸）、Sonogashira（炔烴+CuI）
  • π-烯丙基鈀：雙重翻轉→整體保留；軟親核試劑最佳
  • Buchwald-Hartwig：Pd催化C–N鍵形成；需強鹼和特殊膦配體
  • Wacker氧化：末端烯烴→甲基酮；PdCl₂(cat)/CuCl₂/H₂O/O₂
  • 金催化：炔烴水化→酮；催化量AuCl即可
  • Grubbs複分解：環化複分解（RCM）合成各種大小環化合物
