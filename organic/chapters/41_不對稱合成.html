第41章 不對稱合成

Clayden Organic Chemistry · 第41章（pp. 1103–1133）

導論：自然界的手性

自然界幾乎完全是手性的：所有天然胺基酸均為L型（S構型，Cys除外），所有天然糖類均為D型。藥物分子中手性的重要性更是不言而喻：

  • L-多巴（L-dopa）：治療帕金森症，D型無效且有毒
  • Citalopram（百憂解類）：S型活性是R型的150倍
  • 沙利竇邁（thalidomide）：R型止吐，S型致畸；且在體內可互相轉化——必須避免外消旋體

「不對稱合成」的目標是製備高對映純（enantiopure）的化合物，方法可分為：手性池、拆分法、手性輔助基、手性試劑、手性催化劑。

手性池（Chiral Pool）

直接從自然界廉價易得的手性化合物出發，保留並傳遞其立體化學。常用手性池原料：

胺基酸

  • 幾乎所有天然胺基酸均為S構型（Cys因優先順序例外為R）
  • 丙胺酸（Ala）、纈胺酸（Val）、苯丙胺酸（Phe）、脯胺酸（Pro）等

羥基酸和多元醇

  • 乳酸（L-(+)-lactic acid, S）
  • 扁桃酸（mandelic acid）
  • 蘋果酸（malic acid）
  • 酒石酸（tartaric acid, L-(+) = (R,R)，天然界最豐富的手性化合物之一）

碳水化合物

甘露糖（D-mannose）→氫化→甘露醇→選擇性保護→甘油醛（glyceraldehyde，高ee的C₃手性合成子）。

手性池合成：伊普森（ipsenol）

從S-纈胺酸（S-leucine）出發，12步合成手性蛋白（ipsenol，松木甲蟲費洛蒙）。優點：高ee起始，缺點：需要繞道利用現有的手性。

拆分法（Resolution）

從外消旋混合物中分離對映異構體。最常用方法：與手性酸或鹼形成非對映異構體鹽，再利用物理性質差異（溶解度、熔點）分離。

外消旋胺 + (−)-麻黃鹼 →  (R)-胺·(−)-麻黃鹼鹽（難溶，結晶析出）
                          (S)-胺·(−)-麻黃鹼鹽（易溶，留在溶液）
各用鹼處理 → 分別得到(R)-胺和(S)-胺（最高50%收率）
拆分法理論最高收率50%，因為丟棄了一半材料。但如果能找到外消旋化條件（如某些胺基酸），可以循環再利用，達到接近100%理論收率（動力學拆分或動態動力學拆分）。另外，兩個對映體均可保留，各有用途。

測量對映選擇性

對映體過剩（enantiomeric excess, ee）和對映體比（enantiomeric ratio, e.r.）是評估不對稱反應的核心指標：

e.r. = R:S（如 94:6）
ee = (94−6)/(94+6) × 100% = 88%

測量方法：

  • 旋光計：測[α]，與純對映體的[α]比較
  • 手性HPLC/GC：直接分離對映體，積分峰面積
  • Mosher酸氯化物（MTPA-Cl）：與醇反應形成非對映體Mosher酯，¹H/¹⁹F NMR分析
  • TFAE（NMR手性位移試劑）：加入到溶液中，使對映體¹H NMR峰分離

手性輔助基（Chiral Auxiliaries）

暫時引入一個廉價易得的手性基團，控制反應的面選擇性，反應後再移除並回收。

Evans噁唑啉酮（Oxazolidinone）

最重要的手性輔助基之一，由S-纈胺酸或去甲麻黃鹼製備：

S-纈胺酸 → 氨基醇 → 噁唑啉酮（Evans輔助基）
輔助基接在醯基上 → N-醯基噁唑啉酮 →
  ① 烷基化（烯醇鹽+RX）  96:4 d.r.
  ② Diels-Alder（Lewis酸催化）  >95:5 d.r.

Diels-Alder反應的立體控制

N-丙烯醯基噁唑啉酮與Et₂AlCl（Lewis酸）配位後，雙烯體從輔助基較小基團那側進攻，達到高度的非對映選擇性。

烯醇鹽烷基化

N-醯基噁唑啉酮的鋰烯醇鹽是Z型（因噁唑啉酮的剛性），手性環境由輔助基的取代基提供，烷基化從空間位阻較小的一面進行。

移除輔助基

  • LiAlH₄/DIBAL：還原為醇，需控制過度還原
  • LiOH/H₂O₂：水解為酸（同時保留醇羥基）
  • 乾燥LiOBn：醇解為苄酯

CBS催化劑（Corey-Bakshi-Shibata）

由(S)-脯胺酸衍生的手性噁唑硼烷，用於BH₃還原酮製備手性醇，ee通常>95%（某些底物可達99%）。

機制

CBS催化劑 + BH₃ → 活化的CBS·BH₃複合物
酮配位至B（較大基團在遠端）→ 6員環過渡態
氫從B轉移到酮的Re或Si面 → 手性醇

關鍵：6員環椅式過渡態（類似Meerwein-Ponndorf-Verley還原），催化量使用（20–30 mol%），BH₃是實際的氫供體。

BINAP與Ru/Rh催化

BINAP的特性

BINAP（2,2'-雙(二苯膦)-1,1'-聯萘）是軸手性（axially chiral）化合物，沒有傳統的手性中心，手性來自聯萘環的受阻旋轉（阻轉異構，atropisomerism）。(R)和(S)-BINAP均可合成。

Rh/BINAP不對稱氫化

用於N-乙醯基-α-胺基酸的不對稱氫化，ee可達>95%：

Ph–CH=C(NHAc)–CO₂H + H₂ →[Rh/(R)-BINAP]→
  Ph–CH₂–CH(NHAc)–CO₂H  (S)-構型, >95% ee

催化循環涉及底物與Rh的雙齒配位（NH和C=O），固定了底物的配位取向，使H₂從特定一面加成。

Ru/BINAP不對稱氫化

  • 烯丙醇氫化：含OH基的烯烴通過OH配位固定面，ee >95%（(R)-香茅醇工業合成）
  • α,β-不飽和酸氫化：(S)-萘普生（naproxen）工業合成 >97% ee
  • Noyori Ru/TsDPEN轉移氫化（2001年諾貝爾獎）：異丙醇為氫供體，酮→手性醇；孟魯司特（montelukast）合成 83%收率 99.8% ee

Sharpless不對稱環氧化

（Sharpless，2001年諾貝爾獎）烯丙醇的不對稱環氧化，使用：

  • Ti(O-i-Pr)₄（Lewis酸催化劑，可催化量）
  • t-BuOOH（氧化劑，無毒的過氧化物）
  • 酒石酸二乙酯（DET，手性配體）

面選擇性記憶規則

    醇（OH）在右下角的烯丙醇：
L-(+)-DET（天然）→ 環氧化下面（β面）
D-(−)-DET（非天然）→ 環氧化上面（α面）
面選擇性可用Sharpless的「記憶術」預測：把烯丙醇OH放在右下角，L-(+)-DET的氧從下方攻擊，D-(-)-DET從上方攻擊。這使得Sharpless環氧化對任何不對稱合成學者都是可預測的。

反應特點

  • 僅適用於烯丙醇（需OH基配位鈦）
  • ee通常90-98%（催化量Ti和DET即可，4Å分子篩加速）
  • 工業案例：disparlure（舞毒蛾費洛蒙）不對稱合成；propranolol（普萘洛爾，β受體阻滯劑）

Propranolol合成（Sharpless）

含矽的烯丙醇 + t-BuOOH/Ti(OiPr)₄/D-(−)-DET →
  環氧矽烯丙醇（60%, 95% ee）
→ MsCl → ArO-Na → Bu₄NF（去矽）→ i-PrNH₂開環 →
  (S)-propranolol

Jacobsen環氧化

Jacobsen環氧化使用Mn(III)-salen催化劑（由Jacobsen和Katsuki開發），可用於簡單烯烴（不需烯丙醇）的不對稱環氧化：

催化劑製備

手性二胺 + 2×水楊醛衍生物 →[K₂CO₃, EtOH]→ 手性salen配體
salen配體 + Mn(OAc)₂·4H₂O + NaCl →
  穩定的Mn(III)-salen配合物

Mn(III)在四配位的salen口袋中，以NaOCl作為氧化劑（普通家用漂白劑！），對cis烯烴效果最佳。

茚的Jacobsen環氧化 
茚（indene）+ 0.6 mol% Mn-salen複合物 + NaOCl →
  (1S,2R)-環氧茚  79%收率, 84% ee
此環氧化物是HIV蛋白酶抑制劑印第那韋（indinavir）的關鍵中間體（見第43章）。

Sharpless不對稱二羥化（AD反應）

Sharpless AD是目前最廣泛適用的不對稱反應之一，基於OsO₄對烯烴的syn二羥化，配以手性配體控制面選擇性。

試劑體系

  • 催化量K₂OsO₄(OH)₄（毒性↓，但仍有毒，需通風）
  • K₃Fe(CN)₆：再氧化Os(VI)→Os(VIII)的計量氧化劑
  • K₂CO₃, MeSO₂NH₂：加速去複合步驟
  • 溶劑：2:1 H₂O/t-BuOH
  • 手性配體：DHQD₂PHAL或DHQ₂PHAL（兩種對映選擇性方向）

面選擇性記憶規則

二氫奎尼丁（DHQD，β面）和二氫奎寧（DHQ，α面）為一對「準對映體」（實際上不是真正對映體，但面選擇性相反）：

  • AD-mix-α（含DHQ₂PHAL）：從α面（底面）二羥化
  • AD-mix-β（含DHQD₂PHAL）：從β面（頂面）二羥化
trans-二苯乙烯的AD反應 
Ph–CH=CH–Ph + AD-mix-β, t-BuOH/H₂O, 0°C →
  (R,R)-1,2-二苯乙二醇  99.8% ee
Ph–CH=CH–Ph + AD-mix-α, t-BuOH/H₂O, 0°C →
  (S,S)-1,2-二苯乙二醇  >99.5% ee
這是文獻記載ee值最高的不對稱催化反應之一。

配體加速催化（Ligand-Accelerated Catalysis）

AD反應的精妙之處：手性胺配體不僅提供手性環境，還大幅加速反應（配體加速催化）。不加手性配體時，OsO₄也能緩慢反應，但生成外消旋產物。加速效應意味著大多數反應通過手性路徑進行，racemic背景反應幾乎可忽略。

二醇轉化為環氧化物

AD產物的二醇可進一步轉化為環氧化物，有多種途徑：

  • AcBr/MeC(OMe)₃ → 環狀原酸酯 → 溴代乙酸酯 → K₂CO₃/MeOH → 環氧化物（兩個區域異構體均給同一環氧化物）
  • SOCl₂ → 環狀亞磺酸酯 → NaIO₄/cat. RuCl₃氧化 → 環狀磺酸酯 → 環氧化物

不對稱C–C鍵形成

有機鋅試劑的不對稱加成

乙基鋅（Et₂Zn）與醛反應極慢，但加入手性胺基醇後反應速率大幅提升（配體加速催化），並以高ee生成手性醇：

R–CHO + Et₂Zn  →（無添加）→  極慢，外消旋
R–CHO + Et₂Zn + 1 mol% 手性胺基醇  →  ca. 90% ee

炔基鋅也可類似使用：Zn(OTf)₂/Et₃N活化末端炔烴，手性胺基醇催化（80% 95% ee）。

不對稱共軛加成

Cu催化的有機鋅與α,β-不飽和酮的共軛加成，配以BINOL-膦酰胺配體：

環己烯酮 + Et₂Zn, Cu(OTf)₂, 含(S)-BINOL的磷酰胺配體 →
  3-乙基環己酮 （良好ee）

Cu始終與手性配體結合，有機鋅轉金屬化到銅後才能發生共軛加成，確保手性環境的存在。

有機催化（Organocatalysis）

MacMillan（2021年諾貝爾獎）開創了有機催化領域：用小的有機分子（不含金屬）催化不對稱反應。

亞胺鎓離子有機催化（Iminium Catalysis）

手性二級胺（MacMillan催化劑，從L-苯丙胺酸衍生）與α,β-不飽和醛縮合形成手性亞胺鎓離子：

手性二級胺 + Ph–CH=CH–CHO →[縮合]→ 手性亞胺鎓離子
  （trans幾何體，由雙甲基屏蔽正面）
吡咯從背面攻擊（Friedel-Crafts烷基化） → 烯胺 →
  水解 → 93% ee手性醛 + 催化劑再生

關鍵：亞胺鎓離子的trans幾何體使雙甲基屏蔽分子的一面，吡咯只能從另一面攻擊。用量通常10–20 mol%。

COX-2抑制劑的有機催化合成

甲氧基吲哚 + 不飽和醛 →[20 mol% MacMillan催化劑]→
  吲哚-3-烷基化產物  87% ee, 82%收率

不對稱醛醇縮合

Evans輔助基醛醇反應（Evans Aldol）

Evans噁唑啉酮通過硼烯醇鹽控制非對映選擇性：

N-醯基噁唑啉酮 + Bu₂BOTf/Et₃N → cis硼烯醇鹽
  （trans被輔助基阻礙）
+ PhCHO →[Zimmermann-Traxler TS]→ 醛醇產物 95% >500:1 d.r.
  LiOH/H₂O₂ → 手性β-羥基酸 + 輔助基回收

硼配位至醛的機制（Zimmermann-Traxler過渡態）：硼需要讓輔助基的O解配位後再配位醛，迫使異丙基轉至烯醇的底面，固定了立體化學。

Discodermolide的合成（Novartis）

癌症治療劑discodermolide（僅能從深海海綿中微量提取）由Novartis以60g規模全合成，使用了4個Evans醛醇/烷基化反應（綠色鍵），完全在實驗室可控條件下操作。

脯胺酸催化的不對稱醛醇反應（有機催化）

L-脯胺酸（30 mol%）直接催化丙酮與醛的不對稱醛醇縮合：

丙酮（過量）+ RCHO →[30 mol% (S)-脯胺酸, DMSO, 25°C]→
  (S)-β-羥基酮  97%收率, 96% ee

機制：脯胺酸的氨基與丙酮形成烯胺；羧基通過H鍵組織六員過渡態（R基偽赤道）；水解烯胺，脯胺酸再生。此反應在25°C下進行，無金屬，無保護基，是「綠色化學」的典範。

脯胺酸也能催化anti醛醇反應：羥甲基酮形成trans烯胺（E雙鍵），要求OH在6員TS中赤道位，必然得到anti醛醇產物。

酶作為催化劑（生物催化）

酶是最高效的不對稱催化劑，利用特定的活性位點精確控制底物的取向：

  • 酮還原酶（ketoreductase）：使用NADPH為氫供體，還原酮為手性醇（91%收率, >98% ee, 25g規模）
  • 同一酮還原酶可在1/4噸規模製備某製藥中間體（phthalazine-based compound）
  • 酶的「亂交性」（promiscuity）使其可接受非天然底物——生物催化正成為製藥工業的重要工具
