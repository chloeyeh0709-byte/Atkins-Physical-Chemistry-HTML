Clayden Organic Chemistry · 第42章（pp. 1133–1168）

初級代謝概覽

生物的有機化學建立在少數核心代謝路徑上，通過相互轉化的小分子構建所有的複雜生物分子：

CO₂ → 葡萄糖 → 丙酮酸 → 乙醯CoA → 檸檬酸循環
                              ↘ 核酸、蛋白質、多糖、脂質

初級代謝（primary metabolism）幾乎存在於所有生物中，提供能量和建構材料。次級代謝（secondary metabolism）則在特定生物中產生天然產物。

核酸

ATP結構

腺苷三磷酸（ATP）是細胞的能量貨幣，由腺嘌呤（adenine）+ 核糖 + 三個磷酸基團構成。ATP水解（→ADP + Pi，ΔG = −30.5 kJ/mol）驅動大量生物合成反應。

五種鹼基

鹼基類型出現於配對
腺嘌呤（A）嘌呤DNA, RNAT（DNA）或U（RNA）
鳥嘌呤（G）嘌呤DNA, RNAC（3個H鍵）
胞嘧啶（C）嘧啶DNA, RNAG
胸腺嘧啶（T）嘧啶DNAA（2個H鍵）
尿嘧啶（U）嘧啶RNAA

Watson-Crick雙股螺旋

  • A–T：2個氫鍵
  • G–C：3個氫鍵（G–C更穩定）
  • DNA比RNA更穩定，原因是2'位無OH基（RNA的2'-OH可作分子內親核試劑水解磷酸酯）

SAM甲基化

S-腺苷甲硫胺酸（SAM）是生物的甲基供體，參與眾多甲基化反應：

可可鹼（theobromine）+ SAM → 咖啡因（caffeine）
  （7-N甲基化，SN2機制，SAM上S–CH₃鍵斷裂）

抗病毒核苷類藥物

  • AZT（齊多夫定）：3'位為疊氮基（N₃），阻礙DNA鏈延伸（HIV逆轉錄酶抑制劑）
  • 3TC/拉米夫定（lamivudine）：核糖環中O被S取代（S構型），抗HIV和HBV
  • 阿昔洛韋（acyclovir, Zovirax）：無糖環，僅保留甘油基鏈，對皰疹病毒的胸腺嘧啶激酶選擇性高

cAMP作為第二信使

環腺苷一磷酸（cAMP）由ATP環化而成（2',3'磷酸二酯鍵），作為荷爾蒙訊號的細胞內中繼分子，調控PKA（蛋白激酶A）等多種酶。

蛋白質

肽鍵形成

核糖體在mRNA的密碼子指導下，將氨醯-tRNA中的胺基酸連接成肽鏈。肽鍵（CO–NH）具有部分雙鍵特性（氮孤對電子共軛），限制了肽鏈的旋轉自由度。

重要肽和蛋白質的例子

  • 穀胱甘肽（glutathione, γ-Glu-Cys-Gly）：細胞抗氧化劑，含非常規γ-肽鍵（谷氨酸的γ-羧基成鍵）
  • 脯氨酸（Pro）在膠原蛋白中的作用：Gly-Pro-Hyp（Hyp = 羥基脯氨酸）三螺旋結構，維生素C缺乏→羥化受阻→壞血病
  • 賴諾普利（lisinopril）：ACE抑制劑，模擬底物肽段，含Lys殘基
  • 青黴素機制：青黴素模擬D-Ala-D-Ala肽段，不可逆地對絲胺酸蛋白酶（轉肽酶）的活性絲胺酸進行醯化，阻礙細菌細胞壁（肽聚糖）的交聯

糖類

葡萄糖的環化與異頭效應

葡萄糖（開鏈形式）的C-1醛基與C-5羥基環化形成六元吡喃糖環（類似半縮醛）：

  • α-葡萄糖：C-1的OH在赤道位（熱力學不利，但受動力學影響）
  • β-葡萄糖：C-1的OH在軸向位（由異頭效應穩定）
異頭效應（Anomeric Effect）：在吡喃糖環上，C-1位的電負性取代基（OH, OR, F）偏好軸向位（α），而不是通常預期的赤道位。原因：C-1的σ*軌域與環氧的n孤對電子重疊穩定（n→σ*相互作用），軸向構型時重疊最大。

縮醛的形成固定環形式

半縮醛（異頭OH）可與另一個醇形成縮醛（糖苷），固定特定構型，阻止變旋（mutarotation）：

  • 苯甲醛縮醛：保護葡萄糖的4,6-二OH（反式稠合雙環），4-OH被立體選擇性地阻擋
  • 丙酮縮醛：優先形成順式5-5融合環（1,2-或1,3-二醇），環的幾何構型更穩定
  • 二硫縮醛：固定開鏈形式（C-1為SR, SR），有利於開鏈反應

糖苷（Glycosides）

  • α-糖苷：OH在C-1的下方（軸向，D型糖的慣例）
  • β-糖苷：OH在C-1的上方（赤道）
  • 芥子苷（sinigrin）：β-糖苷，被酶水解後生成異硫氰酸烯丙酯（刺激性氣味，存在於芥末）；相關化合物蘿蔔硫素（sulforaphane）具抗癌活性
  • 纖維素：β-1,4-糖苷鍵（直鏈，人類無法消化）
  • 澱粉：α-1,4-糖苷鍵（螺旋形，可水解）
  • 几丁質（chitin）：N-乙醯葡萄糖胺的β-1,4聚合物（昆蟲外骨骼）

脂質

脂質主要為甘油的脂肪酸酯（三酸甘油酯）。典型脂肪酸：

  • 棕櫚酸（C₁₆, 飽和）：最常見的飽和脂肪酸
  • 油酸（C₁₈, 9Z-monoene）：橄欖油的主要成分

磷脂（phospholipids）和糖脂（glycolipids）組成細胞膜的雙層結構（脂質雙層膜）。肥皂（皂化）：脂肪酸鈉鹽，親水極性頭+疏水鏈→膠束清潔。

NAD⁺/NADH——自然界的NaBH₄

煙醯胺腺嘌呤二核苷酸（NAD⁺）是生物的氧化還原輔酶：

NAD⁺ + 2e⁻ + H⁺  →  NADH  （氧化型→還原型）

NAD⁺作為氫化物接受劑，氧化醇類；NADH作為氫化物供體，還原羰基：

乙醇 + NAD⁺ →[肝酒精脫氫酶]→ 乙醛 + NADH
  （酶從Re面轉移氫化物→(S)-乳酸，對映選擇性>99%）

通過吡哆醛/吡哆胺的還原胺化

氨基轉移酶（aminotransferase）使用磷酸吡哆醛（PLP）作輔酶，催化酮酸與胺基酸之間的互換：

α-酮戊二酸 + Ala →[轉胺酶/PLP]→ 谷氨酸 + 丙酮酸
機制：胺基酸-Schiff鹼 → 互變 → 新α-酮酸 + 吡哆胺 → 再與另一酮酸反應

每個步驟都是單面轉移（酶控制立體化學），生成單一對映體胺基酸。

輔酶A（CoA）——生物的硫酯

輔酶A（CoASH）通過其硫醇（−SH）與羧酸形成硫酯（thioester），活化醯基用於縮合反應：

  • 乙醯CoA（CH₃CO–SCoA）：中心代謝分子，連接糖、脂肪、蛋白質代謝
  • 硫酯比氧酯更易烯醇化（α-H酸性更強），是生物aldol和Claisen縮合的關鍵
  • 檸檬酸合酶（citrate synthase）：乙醯CoA + 草醯乙酸 → 檸檬酸（利用硫酯烯醇鹽的親核性）

賴胺酸烯胺（Aldolase）

醛縮酶利用賴胺酸（Lys）ε-胺基與底物酮形成亞胺，然後互變為烯胺（類似有機催化），催化1-6位果糖二磷酸的逆醛醇縮合（糖解途徑的關鍵步驟）。

磷酸烯醇丙酮酸（PEP）

磷酸烯醇丙酮酸（PEP）是丙酮酸的高能磷酸化烯醇形式，是糖解末端、胺基酸和莽草酸途徑中的關鍵中間體：

2-磷酸甘油酸 →[烯醇酶, E1cB機制]→ PEP + H₂O
  （不是移除磷酸，而是移除較難離去的OH——E1cB由烯醇負離子推動）
PEP + ADP →[丙酮酸激酶]→ 丙酮酸 + ATP  （能量回收）

莽草酸途徑

莽草酸途徑是植物（和某些細菌）合成苯丙胺酸（Phe）、酪胺酸（Tyr）、色胺酸（Trp）等芳香族胺基酸的唯一途徑，哺乳動物缺乏此途徑（故這些為必需胺基酸）：

PEP + 赤鮮糖-4-磷酸（C₄糖）→[aldol縮合]→ 7C α-酮酸中間體
→ 環化（形成莽草酸6員環）→ 多步 → 莽草酸
→ 莽草酸 → 分支酸 → 苯丙胺酸/酪胺酸
莽草酸是除草劑「農達（Roundup/glyphosate）」和抗流感藥「克流感（Tamiflu/oseltamivir）」的工業原料。草甘膦通過抑制莽草酸途徑的EPSP合酶殺死植物。

天然產物

天然產物（natural products）是生物次級代謝產生的特殊化合物，分類為：

  • 萜類（terpenes）：以C₅異戊二烯為單元（香味物質、固醇等）
  • 生物鹼（alkaloids）：含氮，通常為鹼性，由胺基酸合成
  • 聚酮類（polyketides）：由乙酸（乙醯CoA）鏈延伸，含多氧官能基

生物鹼（Alkaloids）

生物鹼由胺基酸合成，均含鹼性胺基，常有強烈生物活性。以鳥胺酸（ornithine）為出發點的吡咯烷生物鹼最具代表性。

吡咯烷生物鹼——來自鳥胺酸

包括：菸鹼（nicotine）、莨菪鹼（hygrine）、阿托品（atropine）、古柯鹼（cocaine）等：

鳥胺酸 →[吡哆醛脫羧]→ 腐胺（putrescine）
腐胺 →[SAM甲基化]→ 仲胺 →[分子內縮合]→ 四氫吡咯陽離子
+ 2×乙醯CoA（Claisen縮合→乙醯乙醯CoA）→ 莨菪鹼 →[氧化]→ 托品酮（tropinone）

Robinson的托品酮合成（1917）

Robinson（1917年）根據生物合成思路，在pH 7水溶液中以琥珀醛、甲胺和丙酮二羧酸合成了托品酮，條件與生物合成驚人相似。這個合成被稱為現代有機合成的里程碑。

苯基異喹啉生物鹼——來自酪胺酸

鴉片罌粟（Papaver somniferum）中的罌粟鹼（papaverine）、嗎啡（morphine）等都屬於苯基異喹啉生物鹼，均來自兩分子酪胺酸：

酪胺酸 →[轉胺]→ 二羥苯丙酮酸（DHPP）
酪胺酸 →[脫羧+羥化]→ 多巴（dopa）→ 多巴胺（dopamine）
多巴胺 + DHPP → Schiff鹼 →[Mannich/EAS環化]→ 四氫異喹啉
→[脫羧+4×SAM甲基化+氧化]→ 罌粟鹼
Pictet-Spengler反應（實驗室類比） 
多巴胺類 + 醛 →[pH 6, 25°C, 水]→ 還原型苯基異喹啉
  機制：亞胺形成 → 質子化 → 親電芳香取代（EAS）
實驗室在溫和水相條件可實現，充分體現生物合成仿生策略。

脂肪酸與聚酮類天然產物

脂肪酸的特徵

  • 碳鏈為偶數（兩碳為建構單位：乙酸/乙醯CoA）
  • 直鏈（酶的精確控制，無分支）
  • 不飽和鍵通常為cis（Z）構型
  • 多個不飽和鍵之間有飽和碳分隔（非共軛）

脂肪酸生物合成循環

乙醯CoA（starter）+ 丙二醯CoA →[縮合酶]→ 乙醯乙醯CoA + CO₂
乙醯乙醯CoA →[NADPH, 3-羥醯-ACP還原酶]→ β-羥基酸硫酯
β-羥基酸 →[脫水, E1cB, 3-羥醯-ACP脫水酶]→ trans-α,β-不飽和硫酯（E型）
不飽和酯 →[NADPH, 烯醯-ACP還原酶]→ 飽和C₄硫酯
每輪循環：鏈延長2個碳，共需8輪→C₁₆棕櫚酸

必需脂肪酸

哺乳動物無法在C9以遠插入cis雙鍵，因此亞油酸（C₁₈, ω-6）和α-亞麻酸（C₁₈, ω-3）必須從飲食中攝取。它們是花生四烯酸（C₂₀, ω-6）的前體，最終生成重要的信號分子：

  • 白三烯（leukotrienes）：過敏/哮喘介質
  • 前列腺素（prostaglandins）：炎症、發熱、疼痛介質
  • 血栓素A₂（thromboxane A₂）：血小板凝聚，參與血栓形成

芳香聚酮類：白藜蘆醇

4-羥基肉桂酸CoA硫酯 + 3×丙二醯CoA →[縮合]→
線形四酮 →[aldol環化]→ 6員環 →[脫水/烯醇化/去羧基]→ 白藜蘆醇（resveratrol）

白藜蘆醇存在於紅葡萄皮中，可能與預防心臟病有關。

萜類（Terpenes）

萜類通過異戊二烯（C₅）單元首尾相接構建，但真正的生物合成前體是甲瓦龍酸（mevalonic acid），而非異戊二烯：

甲瓦龍酸途徑

3×乙醯CoA →[Claisen+aldol]→ HMG-CoA（3-羥基-3-甲基戊二醯CoA）
HMG-CoA →[2×NADPH, HMG-CoA還原酶]→ 甲瓦龍酸
甲瓦龍酸 →[ATP磷酸化]→ 甲瓦龍酸焦磷酸 →[消除]→ 異戊烯焦磷酸（IPP, C₅）
IPP ⇌ 二甲基烯丙基焦磷酸（DMAPP, C₅）
HMG-CoA還原酶是膽固醇生物合成的限速步驟，也是降膽固醇藥物史他汀類（statins, 如lovastatin, atorvastatin）的靶點。

萜類的鏈延長

IPP + DMAPP → 焦磷酸牻牛兒酯（GPP, C₁₀, 單萜）
GPP + IPP → 焦磷酸法尼酯（FPP, C₁₅, 倍半萜）
2×FPP → 角鯊烯（squalene, C₃₀, 三萜）→ 固醇
GPP → IPP → 焦磷酸牻牛兒牻牛兒酯（GGPP, C₂₀, 二萜）

環化：從C₁₀到複雜萜

GPP（trans雙鍵）不能直接環化，需先通過烯丙基重排生成牻牛兒基焦磷酸（neryl-PP，cis雙鍵），才能發生環化：

GPP（trans）→[烯丙基Mg²⁺重排]→ 烯丙基陽離子（可自由旋轉）→
cis-neryl-PP → 環化 → 薄荷烷碳正離子 → 檸檬烯（limonene）
檸檬烯碳正離子 → 二次環化 → α-蒎烯（alpha-pinene）

數千種單萜和更複雜的萜類均由此類碳正離子級聯環化衍生。

固醇

角鯊烯（C₃₀）通過酶催化的協同四環化反應生成固醇前體，再通過多步酶催化轉化為睾酮、雌激素、孕酮和膽固醇（用於細胞膜，也是動脈硬化的元兇）。

本章摘要

  • 核酸：五種鹼基（嘌呤A/G，嘧啶T/U/C）；Watson-Crick配對；RNA的2'-OH→自我水解；SAM甲基化；AZT/3TC/阿昔洛韋作為核苷類似物藥物
  • 蛋白質：穀胱甘肽抗氧化；青黴素模擬D-Ala-D-Ala阻礙細胞壁交聯；膠原蛋白Gly-Pro-Hyp三螺旋
  • 糖類：異頭效應（n→σ*穩定軸向取代基）；半縮醛→縮醛固定環形；α/β-糖苷；纖維素（β-1,4），澱粉（α-1,4），几丁質
  • NAD⁺/NADH：生物的氫化物傳遞體，每次轉移均有立體選擇性
  • CoA硫酯：活化醯基，促進Claisen和aldol縮合（檸檬酸合酶、醛縮酶、脂肪酸合酶）
  • PEP：丙酮酸的高能烯醇形式，由烯醇酶催化E1cB脫水製備；用於糖解和莽草酸途徑
  • 莽草酸途徑：植物合成芳香族胺基酸（Phe, Tyr, Trp）的唯一途徑；草甘膦靶點；奧司他韋（Tamiflu）原料
  • 吡咯烷生物鹼：鳥胺酸→腐胺→莨菪鹼→托品酮；Robinson合成（1917）
  • 苯基異喹啉生物鹼：來自酪胺酸；罌粟鹼（Pictet-Spengler反應）
  • 脂肪酸：偶數C，直鏈；丙二醯CoA兩碳延長循環；花生四烯酸→前列腺素/白三烯/血栓素
  • 萜類：甲瓦龍酸→IPP/DMAPP（C₅）→GPP/FPP→環化；史他汀類抑制HMG-CoA還原酶
