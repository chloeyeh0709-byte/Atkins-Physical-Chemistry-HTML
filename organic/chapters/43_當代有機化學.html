第43章 當代有機化學

Clayden Organic Chemistry · 第43章（pp. 1169–1181）

這是本書的最後一章，以兩個引人入勝的全合成案例——印第那韋（抗HIV藥）和奧司他韋（克流感，抗流感藥）——示範前幾章所有技術的集大成應用。有機化學不只是學術，它是改善和拯救數百萬生命的工具。

癌症治療藥物

癌症的本質是細胞失控增殖，治療策略瞄準快速分裂的細胞：

  • 格列衛（Imatinib/Gleevec）：針對慢性髓性白血病（CML）的Bcr-Abl酪胺酸激酶抑制劑，開創了靶向治療時代（2001年FDA核准）
  • 5-氟尿嘧啶（5-FU）：尿嘧啶的氟代類似物，干擾DNA合成（胸苷酸合酶抑制劑）；最古老的化療藥物之一
  • 紫杉醇（Taxol）：太平洋紫衫樹中提取，穩定微管（阻止細胞分裂），1994年FDA批准；每年需求量極大，現已可半合成
  • 貝伐珠單抗（Avastin）：單克隆抗體，靶向VEGF（血管內皮生長因子），抑制腫瘤血管新生（抗VEGF療法）

HIV/AIDS的化學故事

HIV/AIDS於1980年代出現，有機化學對此的應答是逐步深入的：

第一階段：AZT（齊多夫定）

1987年FDA批准，HIV逆轉錄酶抑制劑。3'-疊氮基（N₃）取代OH，在體內磷酸化後作為假性核苷底物，嵌入病毒DNA鏈後無法延伸（鏈終止子）。AZT能延長患者生命，但不能根治，且副作用明顯。

第二階段：HIV蛋白酶抑制劑

HIV蛋白酶負責切割病毒多聚蛋白前體（Asp蛋白酶），是病毒成熟的關鍵。靶向HIV蛋白酶的藥物誕生：

  • 印第那韋（Indinavir/Crixivan，Merck，1996）：含5個立體中心的複雜分子（詳見下節全合成）
  • 立他韋（Ritonavir/Norvir，Abbott，1996）：結構類似，但更快完成臨床試驗

第三階段：雞尾酒療法（HAART）

高效抗逆轉錄病毒聯合療法（HAART）將多種機制的藥物聯合使用，大幅降低病毒進化抗藥性的機率：

  • 核苷逆轉錄酶抑制劑（NRTIs，如AZT, 3TC）
  • 非核苷逆轉錄酶抑制劑（NNRTIs）
  • HIV蛋白酶抑制劑（如印第那韋）

HAART使HIV感染從「必死之症」轉為可長期控制的慢性病，是有機化學改變人類命運的最佳範例之一。

印第那韋（Indinavir/Crixivan）的合成

印第那韋（Merck，1996）含有5個立體中心，需要多種不對稱合成技術集成，是真實工業規模不對稱合成的里程碑。全合成策略分為三個片段，再組合。

整體策略：三片段組合

片段1（環氧甲苯磺酸酯）
    +
片段2（手性哌嗪）
    +
片段3（順式-氨基茚醇）
    ↓ 按序組合 ↓
印第那韋（5個手性中心，單一對映體）

片段1：Sharpless不對稱環氧化

烯丙醇 + t-BuOOH/Ti(OiPr)₄/L-(+)-DET →
  手性環氧醇（高ee）
環氧醇 + TsCl/Base → 環氧甲苯磺酸酯（片段1）
  （此片段含有2個後續組合所需的立體中心）

片段2：手性哌嗪的製備

吡嗪（pyrazine） →[H₂/Pd-C]→ 哌嗪（piperazine）
哌嗪 →[不對稱氫化, (R)-BINAP/cod·RhOTf催化]→
  2-甲基哌嗪（99% ee）
→ 保護（Cbz/Boc保護NH）→ 片段2

手性哌嗪的關鍵是Rh/(R)-BINAP催化氫化，99% ee，體現第41章BINAP配體的實際工業應用。

片段3：順式-氨基茚醇

印第那韋特有的順式-氨基茚醇骨架來自茚（indene）：

方法A（Merck早期路線）：
  茚 → H₂O₂/MeCN（Ritter反應）→ 乙醯氨基-茚醇外消旋體
  → 酒石酸鹽拆分 → 99.9% ee順式-氨基茚醇

方法B（工業後期改進）：
  茚 → 0.6 mol% Mn-salen複合物（Jacobsen環氧化）→
  環氧茚（84% ee, 79% 收率）
  → 開環（NaN₃）→ 疊氮醇 → 氫化 → 順式-氨基茚醇

這正是第41章介紹Jacobsen環氧化時所預告的，茚的環氧化物是抗HIV藥物的關鍵中間體。

Evans輔助基的應用

苯丙胺酸衍生的Evans噁唑啉酮 →[烯醇鹽+烯丙基溴]→ 烷基化（96:4 d.r.）
→ 環氧化（mCPBA，再次不對稱控制）→ 環氧中間體

三片段組合

哌嗪（片段2）+ 環氧甲苯磺酸酯（片段1）→
  SN2開環（環氧）→ 胺基醇中間體
→ 3-氯甲基吡啶烷基化 →
→ + 順式-氨基茚醇（片段3，保護基移除後） →
→ 縮合 → 去保護 → 印第那韋
印第那韋合成完美整合了：Sharpless不對稱環氧化（片段1）、Rh/BINAP不對稱氫化（片段2）、Jacobsen環氧化（片段3）、Evans輔助基烷基化——本書最後幾章所有不對稱合成技術的完整示範。

奧司他韋（Oseltamivir/Tamiflu）的合成

奧司他韋（克流感）是流感病毒神經氨酸酶（neuraminidase）的過渡態類似物抑制劑，阻止新病毒從感染細胞釋放（阻斷傳播）：

藥物原理

流感病毒表面的神經氨酸酶切割唾液酸（sialic acid）與細胞受體的鍵，使新生病毒從細胞表面釋放。奧司他韋模擬過渡態唾液酸，不可逆地與神經氨酸酶活性位點的Arg結合。

Roche原始路線（莽草酸為起始原料）

原始工業路線以(−)-莽草酸（(-)-shikimic acid，莽草酸，主要提取自中國八角茴香）為起始原料，約10步合成，但莽草酸供應高度依賴季節和地區，在禽流感爆發時期出現嚴重短缺。

Corey 2006路線（全化學合成）

Corey及其同事（哈佛大學）於2006年H5N1禽流感恐慌期間，開發了不依賴天然原料的全化學合成路線：

1,3-丁二烯 + CF₃CO₂CH₂CF₃  →[CBS型Lewis酸催化不對稱Diels-Alder]→
  手性六員環（設定兩個鄰近的立體中心）
→ 12步化學轉化（疊氮化、環化、選擇性胺化、醯化等）→
奧司他韋  30%總收率
Corey路線的關鍵創新

以CBS型Lewis酸催化的不對稱Diels-Alder反應為立體化學建立步驟，一步設定兩個相鄰手性中心，避免了對莽草酸的依賴，為應急藥物供應提供了獨立合成路徑。30%總收率在多步合成中相當可觀。

有機化學的未來

最後，本書展望有機化學的幾個重要發展方向：

多樣性導向合成（Diversity-Oriented Synthesis, DOS）

傳統全合成針對單一靶分子，但藥物探索需要快速製備多樣性化合物庫（scaffold diversity）以篩選活性：

  • 一個反應序列通過改變分叉點，合成多種骨架不同的化合物
  • 高通量篩選（HTS）從化合物庫中尋找先導化合物
  • DOS已成為化學生物學和早期藥物發現的重要策略

酶工程（Directed Evolution，定向演化）

Frances Arnold（2018年諾貝爾化學獎）發展了通過反覆誘變和篩選來改造酶的技術：

  • 可以使天然酶催化全新的反應（如碳矽鍵形成、卡賓插入）
  • 製藥工業已將定向演化酶用於手性中間體的規模化製備（如節省多步合成保護基策略）
  • 定向演化使酶變成了「可程式化的催化劑」

手性Brønsted酸催化

BINOL-磷酸（BINOL phosphoric acid）是新一代手性Brønsted酸催化劑，可催化多種親電-親核縮合反應：

  • Mannich反應、Pictet-Spengler反應、transfer hydrogenation等
  • 催化活性來自磷酸的雙功能性（酸和鹼同時活化底物和親核試劑）
  • BINOL的軸手性傳遞到產物，ee通常>90%
有機化學的未來不僅僅是更複雜的全合成，更在於更高效、更選擇性、更環境友好的合成方法，以及有機化學與生物學的深度融合。每一個新藥物的背後，都是有機化學無數年積累的智慧結晶。

本章摘要

  • 印第那韋合成：三片段組合；片段1用Sharpless環氧化；片段2用Rh/BINAP不對稱氫化；片段3用Jacobsen環氧化；Evans噁唑啉酮輔助烷基化——集本書全部不對稱技術於一體
